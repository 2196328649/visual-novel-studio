# 组合轨道编辑

组合的主要编辑方式改为轨道剪辑。双击“标题演出组合”进入内部，每个直接子对象占一条轨道；双击子组合或点击“进入”继续编辑。顶部路径和“返回上层”逐级返回。单击文字或图片片段后，右侧直接显示相应内容与变换属性。

支持片段移动、左右两端调时长、吸附、缩放、播放头定位、图层排序、素材拖入、复制和删除。暂停预览时可以直接拖动当前层对象的位置。属性旁的菱形用于添加关键帧，时间轴“关键帧”开关显示可拖动的属性帧。每次片段拖动、关键帧拖动、预览位置拖动和复制分别进入撤销历史，Esc 取消片段拖动。

图层按实际绘制顺序显示，上方覆盖下方。音频继续在外层时间轴编辑。粒子、遮罩等完整设置保留在“高级效果”中。

## 数据与时间

编辑继续使用原来的组合树与稳定实例 ID。进入和返回不修改工程，拖动过程中只更新临时预览，松开鼠标才提交。

子对象时间按当前组合中的实际秒数显示。写回开始时间和时长时换算父组合的时间比例，保持原始曲线、其他对象及字面参数覆盖。关键帧写回各自的原始动画时钟。已公开的文字、图片和时长通过对应输入默认值修改，共享输入继续同步；由计算节点控制的具体属性受保护，不阻止其他属性或位置编辑。

超出父组合结束时间以及零时长对象仍保留在编辑轨道，可移动和重新延长。复制递归生成新实例 ID，同时复制相关字面覆盖和参数绑定。删除只移除对应对象与失效连线。所有正式修改经统一的时间轴验证，拒绝在外层调用链中引入或扩大同轨重叠。

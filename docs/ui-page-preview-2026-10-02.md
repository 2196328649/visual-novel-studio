# 高级 UI 自定义页面等待预演（2026-10-02）

本页记录自定义页面的打开、等待、关闭结果与叠加预演。确认框和蓝图标准菜单调用后续已补齐，见 [确认框与菜单验收](ui-confirm-preview-2026-10-02.md)。整体目标未完成，其他集合及演出协同仍需继续处理。

## 行为与实现

`preview-actions.ts` 的共享解释器新增可暂停的 `previewActionRunner`。打开等待页面时保留函数调用、执行路线、循环计数和输出；关闭后将结果交给原节点，再执行后续路线。静态演出预览遇到等待输入会标记不完整并停止，避免提前改变后续参数。它继续复用同一套算术、参数、属性和演出解析，没有另建一套节点执行规则。

`ui-logic-preview.ts` 管理根页面、等待页面和非等待叠加页面；叠加页按原生生成器的页面声明顺序排列。模态层拦截底层控件和键盘，非模态层允许未消费的输入继续向下分发。各页面单独初始化并计时；关闭停止其计时，重新打开重新初始化。底层页面的计时器在模态页面显示期间继续。关闭事件的动作先完成，再恢复等待者；同一事件未返回时不重复启动。重复打开已显示页面不再次初始化。

Escape及右键取消顶层自定义页面并返回“取消”；明确按键蓝图优先。直接从自定义页开始预演并关闭后显示已关闭提示，恢复测试值即可重开。恢复测试值也会丢弃所有临时等待。自定义页的背景沿用工程设置；“非模态”只控制输入，不等于透明背景。

`UiLogicPreviewFrame` 按页面分层显示、拦截被模态层覆盖的输入，并在新增页面时移入焦点、真正关闭时恢复原按钮焦点。预演按键不向外触发蓝图编辑快捷键，同时保留预演按钮的Enter操作。已有图鉴详情继续覆盖各页面并保持其输入隔离。

## 文件名同步

“保存时同步素材文件夹”现在也同步普通素材的显示名。扩展名沿用原格式，显示名已经带有相同扩展名时不会重复添加；Windows 禁用字符替换为下划线，保留中文全角标点，保留字和过长名称作兼容处理。不同内容的同名目标不覆盖，添加素材编号区分。

骨骼动画以“显示名_素材编号”作为整组目录，保留骨架、图集及图片的内部文件名。外部引用不改动。保存前复制、哈希核验，工程持久保存后清理旧文件；自动保存不移动文件。

撤销和重做历史接受新路径，不新增历史步骤。恢复记录增加按素材 ID 区分的旧名称映射：即使旧名称被另一个素材占用，历史工程和另存副本仍读取原素材。读取恢复记录按磁盘时间与大小缓存，不在每个文件读取时重复解析。

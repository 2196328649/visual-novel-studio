# AI 打开与关闭 UI 预览窗口（2026-10-03）

独立助手已支持“打开 UI 预览窗口”和“关闭 UI 预览窗口”。动作经原有建议按钮、IPC 和主编辑器执行，使用当前实际页面、界面方案及未保存草稿；生成回复不会操作窗口。游戏试玩继续使用原有命令。

主编辑器只有在界面设计或事件图正在打开时提供预览控制。重复打开显示已有窗口，不重置计时或试听；关闭结束该窗口的媒体与计时。不在界面、没有可预览页面或窗口已关闭时返回取消，加载异常返回失败；打开尚未完成时离开界面会清理窗口并返回取消。已有保存提示不被绕过。这两项本机视图动作可用于只读询问，不写入工程或玩家资料。

命令 Schema、中文名称、通用工程提示及创作规划提示均已补齐。`UiEditor` 只向主 App 注册当前挂载的窗口控制；`useUiPreviewWindow` 返回实际结果，并检查异步打开期间的挂载状态。

# 解压即用版

适用于 Windows 10/11 64 位，无需安装 Node、Python 或 Ren’Py。

1. 将 `Visual-Novel-Studio-0.8.0-portable-win-x64.zip` **全部解压**到普通文件夹，例如 `E:\叙事工坊` 或桌面。
2. 打开解压后的文件夹，双击 **Visual Novel Studio.exe**。
3. 首次启动会准备随附的游戏运行时；然后可新建空白作品或哀鸿模板。
4. 在右上角“作品设置 → 游戏导出”中选择 Windows 和 ZIP／单 EXE，设置输出位置，就绪后点击“导出”；如提示环境缺失，再点击“一键配置”。ZIP 需解压；单 EXE 直接运行，均不需要编辑器。

不要在压缩包预览窗口里直接双击程序。`resources`、`locales`、DLL 等都是运行所需文件，请保留整个文件夹。

编辑器外观、最近工程、草稿、运行时与下载缓存保存在程序旁的 `data` 文件夹。移动便携版时带上整个文件夹；工程保存在你选择的目录，建议单独备份。若移动后最近工程的旧路径失效，用“打开工程”重新选择。更换 Windows 账户或电脑后，受系统保护的 AI 密钥需要重新填写。

更新时将新版解压到新文件夹，关闭旧版后复制旧版 `data` 文件夹，再运行新版。工程格式兼容旧版；首次更新会准备对应版本的运行时。

Android 的“一键配置”需要网络，并需要你先阅读和同意界面中的 Android SDK 许可。工具安装在便携版 `data/export-tools`，不修改系统环境变量。首次打包还会下载 Gradle 和构建依赖。若工程使用 Spine，检查列表会单独检查 Android 原生库；缺少时会明确阻止导出。

# 界面画布的完整框选

在「界面 → 设计」画布的空白处或未选中的控件上按住鼠标左键拖动，可以同时选择多个控件。画布四周的留白也可以作为起点。只有完整外框被包含的控件才选中；擦到、穿过或只包住一部分都不会选中，四个拖动方向使用相同规则。

## 操作

- 普通拖框替换当前选择；Shift 拖框追加；Ctrl（或 Meta）拖框切换框内对象的选择状态。修饰键以按下鼠标时为准。
- 控件须先单击选中，下一次拖动才能移动。首次按住未选控件直接拖动进入框选，不把该控件一起挪走；4屏幕像素以内松手才视为单击选中。
- 拖动时实时高亮，松开后更新主选对象和右侧属性面板。已有对齐、微调、整组移动、复制及删除仍使用原来的多选规则。
- 空白单击清空选择；按住 Shift／Ctrl 单击空白保留选择；4 屏幕像素内的抖动不算拖框。
- Esc、失焦、指针取消或捕获丢失取消本次拖框，保留起始选择和主选对象。
- 拖至画布视口边缘会自动滚动，也可按住拖框使用滚轮；起点固定在游戏画面的内容坐标。缩放、换页、换方案、换工程或修改控件数据会终止旧手势。
- 列表内部部件编辑保留原操作范围：空白点击退出并清选，这一次拖动不会立刻框选整个控件；退出后从空白重新起拖即可。

隐藏、锁定、继承父级隐藏或锁定、被完全裁掉的控件不进入候选。父子均完整包含时可以同时选中，批量移动只改变选中树的根对象，避免重复偏移。被父容器或根画布部分裁切的控件仍需包含原来的完整外框。旋转、镜像、父级变换和参数控制的初值均按实际绘制位置处理。

## 实现与维护

`src/core/ui-marquee.ts` 处理候选、完整包含、方向归一化与起始选区合并。画布裁切只用于可见性门槛，不用于缩小候选外框。`useUiMarquee.tsx` 在起手时一次缓存实际 DOM 完整边框以消除 CSS 量化误差；拖动中只读取整体画布和视口的位置，用动画帧更新固定遮层，只在命中集合变化时刷新控件高亮。

选框固定在视口，裁切于画布滚动区，不占内容尺寸或截获点击。整组选择仅在松手后交给 `useUiSelection`，中途不改主选、属性草稿或工程数据。未选控件的按下由画布捕获阶段接管，指针捕获仍留在原控件，保证连续双击可以进入内部部件；右键菜单通过 document 捕获阶段关闭。移除了父容器覆盖整个内部区域的拖动遮层，边框和缩放手柄保留，内部未选子对象能够成为框选起点。Alt 轮选、已选控件拖动、缩放手柄、原生占位以及选中后剧情图内部操作保留自己的事件处理。

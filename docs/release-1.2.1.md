# 叙事工坊 1.2.1

2026-09-27 的 Windows x64 编辑器。安装器为 `release/Visual Novel Studio Setup 1.2.1.exe`，可选择安装目录，随附 Ren’Py 8.5.3、Spine 4.2、素材模板与中文文档。

## 角色站位预设

在「角色 → 角色站位预设」提前设置左、中、右的位置与缩放，也可复制出自定义预设，并指定每个角色的默认项。显示角色、自动发言角色、文本指令和蓝图都可引用预设；修改预设后，所有引用同时更新。选择「角色默认」的指令还会跟随默认项的切换。舞台拖动或单次修改几何参数会将该处改为手动，便于局部微调。

默认构图按图片实际可见范围计算，切换不同尺寸的表情保持半身位置。旧工程的手动坐标继续生效。操作示例见[角色站位预设](character-presets.md)。

## AI 一句话搭建框架

打开 AI 助手，可以直接输入：

> 用现有角色做一个雨后重逢的古风短篇，安排两个场景、一个两项选择、两个结局，配置背景、配乐、表情和左右站位，生成可玩的整体框架。

助手生成普通可编辑的场景、对白、选择与结局，检查分支连接和素材引用，显示数量及方案后一次应用。接着可在文本或模块中改细节，再试玩并导出 Windows 游戏。生成新框架会替换当前剧情，可一次撤销；角色、素材和界面继续保留。

后续还可要求配置已有场景的背景与配乐，或根据录音目录及文本索引匹配配音。当前接口不生成语音、不识别音频内容。缺少立绘或可靠录音时会列出待补项，详见[AI 助手](ai-assistant.md)。

## 界面与演出修订

- 对话按钮中文悬停提示、流程图 A 快捷键；白色粗宋体选项，修正位置、间距和多余滚动条。
- 自动档与四个手动槽、11 页分页、多段对白摘要，以及中文读／写和返回标题图片按钮。
- 设置页文案、紫色选中态、明亮箭头与滑条方向；加载存档保留玩家偏好。
- 整体全屏渐变、左侧进入的题字、向左下吹散的白粒子；黑屏结局报幕后自动返回标题。
- Windows 客户区保持作品比例，支持窗口拖动、尺寸和全屏切换；自定义图标写入实际游戏 EXE。
- Android 图标安全区域、圆形裁切和缩放预览。内嵌试玩处理 Windows 控制文件的短暂占用，并保留最小化前的画面尺寸，恢复窗口后继续显示。

新版哀鸿模板有 183 个界面组件、277 项资源和九角色的 100 张表情。从「新建工程 → 哀鸿模板」取得新版模板；已有工程使用原先保存的组件。

## 安装与验收

1.2.0 安装器保留。工程、素材和自动保存由工程目录管理；API 配置和密钥不写入安装包或导出游戏。最终安装升级、独立运行时、旧工程、DOCX 导入、保存重开与导出游戏的记录在 `release/verification-1.2.1.json`，文件校验值在 `release/SHA256SUMS-1.2.1.txt`。

[本轮详细验收](ui-fidelity-1.2.1.md)包含原生游戏截图、100 表情与 400 组站位、三个模板结局、真实 AI 生成及双分支 EXE 试玩。测试使用独立配置和工程。当前发行对象为 Windows x64，程序未签名；本轮 Android 仅验证图标编辑与生成，没有新 APK。

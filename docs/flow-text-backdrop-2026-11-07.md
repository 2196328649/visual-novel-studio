# 剧情图文字黑底恢复

2026-11-07，用户反馈“剧情流程图的文字黑色底又没有了”，并提供原游戏截图 `7CC3A4C96C7EC4C755542563B0872577(1).png`。

## 原因与修复

原图的黑底是贴着字形的柔边衬底，和灰色、淡紫色的节点笔刷底图分别绘制。真实工程主文件的基础样式和三个内置共享样式仍是柔化7、不透明度40%；其中主线框单独设置了扩展5。此前模板已加深到柔化14、扩展4、不透明度90%，但加载兼容只覆盖了更早的硬阴影版本，没有覆盖这一版。共享样式优先于基础样式，因此只调基础值也不能修复所有节点。

本轮补齐旧样式的精确兼容签名，同时处理基础、界面实例、自定义页中的原模板控件，以及三个内置共享样式。修复保留显式的扩展值（包括0）、分段设置和布局。自定义字体、颜色、字号、底图或阴影参数不匹配时不自动套用。

真实工程还存在较新的自动恢复界面草稿：基础阴影纵向偏移已调为-0.5，分段设置是两个空槽。原恢复流程会用这份未更新的草稿盖回刚修好的旧样式。现在先修复恢复包中的基准，再只重放用户实际改动；-0.5偏移、分段及主动关闭阴影都保留，未改的旧阴影不会复现。打开时不写主工程文件。

预览原来用多份低透明度的模糊影子近似阴影扩展，和游戏加粗字形再模糊的效果不同；长文字适配还会把阴影一起缩薄。现在玩家剧情图的画布、目录和属性样例统一使用独立的加粗黑色文字层，整体柔化并应用一次透明度。自动缩小标题只改变字形，阴影长度仍按设定值；整图缩放再统一缩放这些长度。彩色分段只改变前景字色。

游戏补齐了漏乘缩放比例的`shadowSpread`，模糊底层增加外围留白，并统一默认阴影透明度及RGBA透明度乘法。基础和共享属性新增“使用柔边黑底”“关闭阴影”，共享样式还可“恢复基础阴影”；按钮分别形成一个撤销步骤。

## 使用

重新启动本轮源码构建的编辑器，再打开旧工程即可在内存中修复匹配的旧样式，包括自动恢复草稿。需要手动套用时，在“界面 → 剧情流程图 → 节点样式 → 文字描边与阴影”使用“柔边黑底”；节点使用共享样式时在相应共享样式中调整。后续保存界面会保存这些设置。

本轮没有直接写入真实工程，也没有打包或更新已安装的发行版。

对照图为 `artifacts/flow-text-backdrop-2026-11-07/reference-legacy-corrected.png`，从上到下是原图、旧40%阴影、修复后的90%衬底，按节点宽度缩放。这里只恢复黑底及其渲染一致性；文字位置、各段比例仍由当前节点样式决定，未强行改成截图布局。浏览器与Ren’Py的字形边缘也不保证逐像素相同。

## 问题与修改

哀鸿模板的界面语言、配音语言各有两个禁用箭头。旧模板保留了占位 `return` 操作；页面流程分析把它们当成有效导航出口，并把 `disabled` 与显示条件、目标停用统一写成「按条件」。真正的 `enabledWhen` 反而没有显示。

- 自动出口忽略设计中禁用的按钮；作者主动公开的禁用按钮仍显示，并明确标记「已禁用」。用于事件动态启用的按钮可以继续手动公开。
- 「有显示条件」「有启用条件」「目标已停用」分别显示。属性直接列出参数条件，可定位原按钮调整，不再把静态禁用伪装成条件分支。
- 原工程的四个禁用箭头即使仍带 `return`，也会被编辑器正确过滤，无须改写或迁移工程。
- 内置模板和生成器为箭头补充具体名称，并删除占位返回行为。原有中文说明、禁用状态和外观保留，未添加不存在的语言切换功能。
- 返回、角色音量、返回标题和退出等正常导航保持展示；流程图仍编辑原按钮的行为数据。

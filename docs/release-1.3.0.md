# 叙事工坊 1.3.0

2026-09-27，Windows x64。

## 长章节与外观

文本编辑默认按章展示，支持章节选择、上／下章与显式全文。全局前置指令单独显示；查找替换、批量演出和结构视图跟随当前章节。高亮和结构列表按可见区域渲染，已验证 5000 句章节编辑、切换、保存与重启，以及四章各 5000 句的数据往返。其他章节的原文、换行和稳定编号保留。

默认配色改为黑白灰，另有亮白、石墨和蓝灰。面板、工具栏、文本、蓝图、资源、设置和导出控件统一采用编辑器色板；自定义配色会根据所在表面自动选择可读文字。游戏画面的原作配色仍属于作品设计。

## 导出与便携版

「作品设置 → 游戏导出 → 一键配置」准备并修复私有运行时，显示进度、取消、重试、详细记录与最终检查。Windows 随包提供运行时，可离线配置。正式导出路径过长时自动改用较短的临时构建目录。

Android 配置入口支持 JDK 21、匹配的 RAPT、Android SDK 的官方来源下载与 SHA-256 校验。SDK 许可默认未勾选；未同意不会安装 SDK。Android 首次实际构建仍需要网络。此版本验收以 Windows 为主；Android APK 与设备运行未完成实测，含 Spine 的作品还需要三种 ABI 的 Android 原生库，检查列表会如实阻止缺库导出。

- 安装版：`release/Visual Novel Studio Setup 1.3.0.exe`
- 便携版：`release/Visual-Novel-Studio-1.3.0-portable-win-x64.zip`

便携版全部解压后运行 `Visual Novel Studio.exe`，无需开发工具。编辑器配置、草稿与私有运行时保存在相邻 `data` 文件夹。详见[便携版说明](portable.md)。旧版本安装器保留。

## 原作章节与菜单

在 1.2.2 的七秒时序、题字消散、粒子力场曲线基础上，加入原游戏 Ripple 着色器的三层 value noise、时间偏移和对角 UV 位移。源参数保存在 `src/core/chapter-source.json`，编辑器 WebGL 与 Ren’Py 使用共用 GLSL 定义。没有 WebGL 时回退到静态背景；背景波动可在游戏设置的章节进场属性中关闭或调整幅度与速度。

只读核对原游戏 `UtageUguiMainGame.Update` 后，模板的 Esc 菜单改为设置页，再按 Esc 返回原来的台词。通用工程可在「游戏设置 → 菜单快捷键打开」选择设置、存档、读档或暂停菜单。已有工程保留原先默认的存档菜单，作者可以自行调整。

原作 Unity 粒子的随机种子和噪声细节并未逐帧移植，不宣称画面逐像素或逐帧完全一致。原游戏和上层 SDK 只读；模板与运行验收使用复制的资源。

## 验收

章节长文本、四种内置外观及极端自定义配色经过真实编辑器操作；原生游戏验证水波方向和时间变化、七秒章节动画、100 张表情的构图、400 组预设、设置、存读档、选项与返回标题。Windows 一键配置后实际生成 ZIP，并用包内 EXE 验证游玩和存读档。

最终安装版、便携版、核心测试和受保护文件校验记录在 `release/verification-1.3.0.json`，发行哈希见 `release/SHA256SUMS-1.3.0.txt`。AI 一句话框架、场景与配音匹配沿用既有功能和真实服务验收，本轮没有再次付费生成。

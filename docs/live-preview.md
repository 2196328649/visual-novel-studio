# 开发版实时试玩

实时试玩已随 [1.2.1 正式版](release-1.2.1.md)提供。需要开发调试时，双击项目根目录的 `启动开发版.cmd`，或在该目录运行 `node scripts/dev.mjs`，即可打开源码对应的桌面开发版。

双击入口会自动寻找系统 Node.js，未安装时使用本机已有的 Codex 开发运行环境，无需修改系统 PATH。启动控制台显示准备进度；启动失败会保留错误，详细记录在 `artifacts/dev-launcher.log`。开发版运行期间请保留启动控制台，关闭编辑器后控制台会自动退出。

## 操作

- 点击顶部“试玩”、文本页“实时试玩”，或按 F5，打开中央试玩工作区。准备素材、启动中、运行中和失败都有明确显示。
- 默认在编辑器内运行真实 Ren’Py 游戏。点击游戏画面即可推进对白、选择分支和操作游戏界面；右侧显示当前段落、行号和剧情状态。
- F6 或“暂停 / 继续”控制运行；Shift+F1 将操作焦点交回编辑器，Shift+F5 或“停止”结束试玩。返回编辑会暂停游戏，重新打开试玩画面后按 F6 继续，文本与蓝图的编辑内容保留。
- “重新运行”采用最新内容，包括未保存的有效文本修改。“试玩”旁的下拉按钮可设置起点、测试状态，并选择独立游戏窗口；独立窗口可用“显示游戏窗口”找回。
- 试玩使用独立存档与构建目录。源工程和导出游戏不包含编辑器的窗口控制代码。

日常测试的开发版使用本地编译界面，避免大型属性面板中逐控件调试追踪造成输入卡顿。启动时检查源码时间，有更新才重新编译；这一步不生成安装包或游戏发行包。修改源码后保存当前作品，再关闭并重新打开开发版即可加载更新。

需要热更新调试时运行 `node scripts/dev.mjs --hot`；该模式会保留界面调试检查，不能用它的输入耗时代表日常版本的性能。1.2 正式版采用本地编译界面并包含本页功能，安装说明见 [1.2 发行说明](release-1.2.md)。

## 修复原因

原先用隐藏控制台的方式启动游戏，Windows 也可能隐藏 SDL 的首次窗口显示。现在交互试玩使用 `pythonw.exe`，避免控制台，同时保留正常的游戏窗口显示；编译与检查继续在后台运行。

OpenGL 子窗口还可能被 Electron 的 DirectComposition 合成层遮住，此时内部截图正常、`IsWindowVisible` 为真，也不能保证桌面上有画面。

开发版现在采用由编辑器拥有的无边框游戏窗口，贴合中央试玩区域并跟随移动、尺寸与 DPI 变化。它保留独立的图形呈现表面，编辑器最小化或返回编辑时隐藏，恢复时重新对齐。启动成功仍需等到实际游戏首帧，验收另行检查桌面合成后的像素与真实标题是否匹配。

试玩快捷键保持在菜单和章节模态画面之上；交还焦点的操作在松开按键后执行，避免游戏窗口停用后丢失按键释放。原生暂停状态同步到后台，后续画面位置更新不会意外解除暂停。

1.2.1 处理 Windows 的控制文件短暂占用：原子替换遇到读取锁时有限重试，保留原来的完整文件；读取暂不可用的快照时继续保持上次状态，避免无关的启动或暂停失败。持续写入错误仍会明确报告。窗口最小化期间的临时零客户区不会覆盖原有试玩区域，恢复时重新应用实际位置与尺寸。

启动前错误、运行时启动异常和超时会显示原因；停止会取消当前编译或结束所属游戏进程，旧试玩的迟到事件不会覆盖当前状态。调试回调也会避开尚未初始化的剧情状态，保留原始启动错误。

## 验证

`pnpm test:live-preview` 使用开发服务器、隔离工程和配置，检查文本草稿、桌面实际像素、窗口所属关系、DPI 尺寸、移动/最小化/恢复、实体鼠标与快捷键、标题与章节内暂停、运行位置回传、返回编辑、停止和编译取消、独立窗口以及真实启动异常。原始记录在 `artifacts/live-preview-verification/`。

设置 `VNS_INSTALLED_EXE` 为安装程序的实际 EXE 路径，直接运行 `node --import tsx scripts/verify-live-preview.ts`，可用隔离配置检查随包代码、模板与内置运行时；同时记录实际 EXE、app.asar 哈希和版本。

这些测试不生成安装包，也不修改已有安装版或用户工程。

桌面像素测试需要解锁且活跃的显示设备。测试会向自身窗口发送一个无功能的修饰键，并在运行期间临时阻止显示休眠，随进程退出释放。2026-09-13 的排查确认：长时间无输入后，未嵌入编辑器的最小 Ren’Py 示例也会只能捕获空白；唤醒后恢复正常，因此不能把熄屏期间的截图误判为渲染代码回归。

通过记录：`artifacts/live-preview-verification/2026-09-12T23-37-45.086Z/report.json`，9 组真实试玩检查全部通过，包含标题/章节/对白中的连续暂停与继续。桌面画面与引擎帧的平均 RGB 差为 7.69 / 255。

配乐、章节蒙板、控件层级与图片预览的使用方法见 [界面与演出编辑](ui-presentation.md)。

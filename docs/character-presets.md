# 角色站位预设

在「角色」中选中角色，进入「构图与站位」，展开「角色站位预设」。每个角色都有左、中、右三个站位，可改位置和缩放，也可「复制为新预设」后命名。默认项在「默认站位预设」选择；每个角色可以使用不同的默认项。入场、离场和表情切换设置集中在单独的「角色过渡」页签，默认离场为 0.5 秒渐变。

「按角色默认构图计算」开启时，预设基于上方的半身／全身构图，忽略图片透明留白，切换不同尺寸的表情仍保持构图。横向 50% 对应默认构图中心，纵向偏移 0% 保持头顶位置，缩放 100% 保持默认构图大小。关闭后使用原图的中心／底部锚点和原图缩放。

在显示角色指令、舞台工具或蓝图的「站位预设」中选择：

- **角色默认**：跟随此角色的默认项，之后更换默认项也会同步。
- **左、中、右或自定义项**：固定引用这一项，修改预设后所有引用同时更新。
- **手动位置**：仅调整这一次演出。在舞台或参数面板拖动角色、修改坐标／缩放，会自动解除这一处引用，保留其他引用。只换表情或图层不会解除引用。

文本命令示例：

```text
@显示角色：林翩翩，微笑，站位预设=角色默认
@显示角色：苏怜烟，平静，站位预设=右
```

选择实际角色已有的表情名称；输入命令后可用补全选择站位。文本中指定预设时，预设优先于同一指令的坐标；单次改动可改为「站位预设=手动」并填写坐标。自定义预设导出文本时携带稳定标识，重命名预设不会丢失关联。保存、重开、模块／文本转换、演出蓝图、预览与导出都保留引用。

`@显示角色` 省略角色名时跟随当前发言人，省略表情时使用默认表情。只在需要覆盖本次演出时填写参数。

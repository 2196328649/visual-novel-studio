# 试玩演出与独立演出参数

2026-10-08，v0.8.0。

角色过渡期间保留上一句对白框时，原来的常驻 `say` 画面会把过渡时间带入下一句文字的显示计时。现在保留画面只作用于当前交互；下一句重新计时。默认和自定义对白界面均验证了进场、同角色再次说话、换人、离场、舞台等待，以及点击先补全文字再推进。

章节演出现在复用静态文字和图片，缓存固定粒子种子与噪声方向，同一发射器的粒子按原顺序批量绘制。改变文字、字体、样式、裁切、图片适配或尺寸会使对应缓存失效。粒子运动公式、数量和演出时长保持原有设置。

文字版章节右侧的年代沿用原题图的轻微斜体，数字与汉字的字形向右倾斜。预览、原生试玩和散字粒子使用相同斜体设置，文字对象中可勾选「文字斜体」。旧生成预设会补上缺失的年代斜体；已明确设置的字形、文本、字号、字体和动画保留。

## 独立演出写法

```text
@等待：2
@独立演出：章节进入，允许点击跳过=否，结束转场=纯色，淡出=0.5，停留=0，淡入=0.5，颜色=#000000
```

名称和设置可以省略；含逗号的名称需要加引号。省略的设置继承演出默认值。结束转场可选“无”“溶解”“纯色”。文本参数补全和模块播放设置都编辑这一行。

播放结束后继续执行后续指令。需要返回标题时，在后面另写 `@返回标题界面`；播放设置与参数补全不再提供“结束后”选项。旧工程已经保存的结束行为仍可读取。

打开旧工程时，独立演出的播放设置行会合并到声明中，保留节点、连线、台词和注释。尚未写完、存在语法错误的草稿保留原文；仍附着在对白上的旧设置维持原来的含义。

## 本机原生测量

使用作者工程“我的视觉小说1”的章节进入演出，在 Windows、Ren’Py 8.5.3、GL2、RTX 3060 Laptop GPU 上比较。两次测量均关闭截图与 cProfile；统计同一段动画的实际更新间隔。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 动画更新间隔中位数 | 30.7 ms | 10.1 ms |
| 动画更新间隔 P95 | 284.7 ms | 33.2 ms |
| 构建画面耗时 P95 | 56.7 ms | 6.9 ms |
| 文字对象创建次数 | 552 | 8 |

测试向引擎请求 60 Hz，但实际调度不是固定 60 Hz，因此不能把这些结果等同于稳定 60 FPS。首次准备字形仍有一次较长开销；P95 不代表每一帧的上限。

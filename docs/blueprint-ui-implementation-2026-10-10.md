## 页面接入与运行修复

- 新页面只创建所属页面内部事件图，外部调用图另行生成，公开关闭结果与原因；不自动改写旧混合图。
- 接入已有按钮支持追加/替换；追加入口先执行一次，再执行原点击事件与主操作。替换停用原回调但保留可复用图资源；派生方案按实际归属编辑。

- 原常驻页面宿主在启动页关闭后仍保留 modal 状态，会挡住标题按钮。真实游戏复现后，改为每次交互按当前页面会话刷新宿主模态值；控件输入可用性也使用会话顺序及本次 modal 覆盖。

## 蓝图任务取消与会话恢复（本批）

- 任务记录所属页面实例和流程步骤，嵌套调用继承任务；页面事件建立自己的来源任务，不误继承外部等待调用者。关闭后重开使用新实例标识，不会唤醒旧任务。
- 跳过会将当前步骤标为取消。在节点边界、循环、嵌套返回、确认分支、动画及时间轴等待处停止后续执行；时间轴取消仍返回数值时钟，避免父流程转换返回值时报错。
- 只关闭该步骤打开的页面、清理其拥有的动画、视觉对象和有限音频；不关闭此前已有的无关叠加页，不回滚已完成的变量修改，也不一概停止作者设置的普通背景音乐。跳过按钮位于确认层之上；禁止跳过的步骤拒绝跳过请求。
- 页面关闭会停止当前事件链和剩余按钮主操作；外部等待页面的调用者仍只恢复一次。关闭父页取消子页调用链；页面定时继续在上层模态页下运行，键盘/指针输入仍受模态顺序约束。
- 自定义页面的显示事件按实例显式派发一次，修复常驻宿主动态 `use` 页面时原生 `on "show"` 不稳定的问题。显示标记在派发前保存，支持显示时自关；读档不重播初始化，旧会话缺失标记时按已显示兼容。
- 等待保存已用时，并用临时采样标识排除离线时间。原生定时等待会被模态页阻塞、也可能在读档后提前返回，因此改为非模态等待与剩余时长循环；取消使用有效的交互结束值，而不是无效的 `end_interaction(None)`。
- 预览同步实例取消、剩余主操作抑制、外部调用者恢复、重复非等待打开的 `alreadyOpen` 结果及媒体结束时间；返回标题后不再执行旧页面的续接任务。旧小游戏也保留独立运行标识，完整兼容矩阵仍未完成。

## 续接批次：启动路径与页面诊断

### 本批实现和边界校准

- 新增 [可达路径分析器](../src/core/game-flow-analysis.ts) 与 [静态输入求值](../src/core/blueprint-static-values.ts)。从实际连线执行的标题前/新游戏前步骤出发，追踪模块调用、页面显示/点击/按键/定时事件、角色事件及实际消耗的数据输入，不把未接线节点或确定不执行的分支算作启动依赖。结构与资源校验仍保留。
- 遵循分支、顺序执行、有限循环、模块返回及调用输入/输出；明确角色参数不误认成当前说话人。布尔短路不读取未求值输入；动态页面不偷换成模块默认页面；Python 数值格式化无法精确判定时保留未知值，避免用 JavaScript 的字符串结果裁掉真实分支。
- 页面显示入口和播放器共用有序的 uiPageShowGraphIds：保留所属页面、活动/继承方案、独立回调及去重顺序；旧混合图的主调用入口不自动变成 OnShow。
- 已校准真实调度：同步打开再关闭不会派发 OnShow；非零等待及封装/文本等待期间会分析页面事件；模态子页会阻挡底页的 OnShow 定时器，但不会阻止页面级定时事件；子页关闭到等待调用者恢复之间，底页可能先获得 OnShow，不能假设下一节点立即同步执行。
- 重复打开已有自定义页面只警告 **alreadyOpen** 复用，不误报无限递归或第二实例。顺序等待关闭后重开允许新实例；关闭父页会取消子页任务，外部子页调用可收到 **parentClosed**。完成出口只从实际事件路径确认，不凭任意位置的关闭节点判断；取消与完成分开，缺少完成出口是警告，并说明页面可交互时的 Esc 取消。
- [问题定位](../src/core/diagnostic-location.ts) 保留来源流程步骤，同时优先定位真正出错的蓝图节点或控件；没有具体节点的页面完成出口警告定位到统一流程画布。动态目标、递归模块和分析规模上限明确提示尚未验证，不把静态分析当作全部运行行为的证明。

### 能力规则与入口

- 独立 UI 图、主调用入口与页面事件共用可达执行分析，不再用“全图存在危险节点”代替实际能力要求。确定不执行的分支、未接线节点和未消费的数据输入不误报；动态、递归或超过分析上限的情况保留可定位诊断。
- 节点库、拖线候选、插入及编译按相同规则检查实际参数：明确 false 可使用默认分支需要台词的公共模块，true 则被阻止；“显示所有节点”不绕过检查。明确角色不再误当成当前台词角色。
- 主调用入口的摘要与页面事件入口分别计算；旧混合图仍保留原主入口。旧小游戏页面的显示事件由真实小游戏宿主按本局派发，完成后抑制事件链剩余动作，读档不重播初始化。

### 会话、清理与鼠标焦点

- 原生菜单的任务绑定到屏幕实例和所属 Ren’Py 上下文，而不是只看菜单名。设置/图鉴等菜单替换、Return/Esc、保存读取和回滚取消旧任务；重新打开不复活旧等待、覆盖值或动画。嵌套回调的菜单导航先退出临时回调，再在真正菜单上下文执行，外部调用者只继续一次。

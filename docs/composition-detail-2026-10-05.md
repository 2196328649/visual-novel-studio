# 组合详细编辑与隐藏演出耗时

后续更新：组合双击已改为进入完整的轨道剪辑工作区，见[组合轨道编辑](composition-workspace-2026-10-05.md)。本文记录此前的高级属性入口修复；完整表单仍可从“详细编辑”或“高级效果”打开。

## 交互修复

灰色“标题演出组合”属于保存的画面组合。原来的双击处理只识别时间轴调用和旧章节指令，因此双击该组合会直接返回。绿色显示区间仅支持选择，且选中片段时未关闭“播放设置”，也会让属性面板看起来没有响应。

现在双击普通片段会打开属性；组合和画面对象会展开“动画与效果”，滚动到详细编辑区并将键盘焦点移入。双击真正的时间轴调用仍进入内部时间轴。提供以下入口：

- 双击灰色片段，或选中片段后按 Enter。
- 双击绿色显示区间，或点击左侧对象名称。
- 在片段属性中点击“详细编辑”；右键菜单“编辑片段属性”也会展开详细编辑区。
- 在组合内容中双击子片段，或点击子对象名称；“返回外层组合”回到根组合的详细编辑区。

选中片段会退出时间轴属性／播放设置。打开详情不修改工程，修改对象仍沿用现有撤销、参数绑定及实例身份处理。已公开的内容仍可在“时间轴属性”或根片段的“调用参数”中修改默认值。

## 隐藏演出的开销

文本变化后仍要重新计算指令与台词的折叠关系；新增换行、删除台词或修正错误指令都可能改变归属。此前优化已复用文本解析结果，因此不会为每次折叠再单独解析一遍全文。

`scripts/benchmark-text-folding.ts` 使用 1,500 句对白、每句一条等待指令，共 55,909 字符，5 次预热后采集 25 次文本变化。投影显示／隐藏的执行顺序交替；每次使用同一份解析结果比较，不包含预览、DOM 更新和输入事件。

| 阶段 | 中位数 | P95 |
| --- | ---: | ---: |
| 文本解析 | 43.60 ms | 49.00 ms |
| 折叠关系计算 | 0.56 ms | 0.69 ms |
| 隐藏模式文本投影 | 2.57 ms | 3.49 ms |
| 显示模式文本投影 | 9.41 ms | 11.95 ms |

此样例中折叠判断开销较小，隐藏模式省去了部分可见行的引用处理，因此投影更快。结果不能直接代表所有工程；不据此跳过折叠更新，以免输入后误隐藏或错绑演出。测量原始数据：[text-folding-cost.json](../artifacts/text-folding-cost.json)。暂停实时预览的功能与此前输入响应测试见[前一轮报告](text-preview-pause-2026-10-05.md)。

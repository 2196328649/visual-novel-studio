# 游戏流程演出禁止跳过修复

日期：2026-11-14（Asia/Shanghai）。用户报告：流程图加入演出，没有勾选“允许玩家跳过这一项”，仍能鼠标点击提前结束。

状态：修复、统一构建及验收完成。随后追加的 PNG 导入修复也已完成，最终全量 2492／2492 通过。测试工程、profile、游戏与存档已自清理；两轮 unit-temp 的精确删除被工具政策拒绝，命令未执行，不称全部临时清理完成。

## 原因与行为

原来的 `allowSkip` 只控制“跳过这一项”按钮。普通等待和时间轴间隔／尾部等待仍使用可由鼠标结束的暂停；点击返回后，编译生成的时间轴会提前截止。

现在关闭开关时，所属蓝图任务及其嵌套函数、宏、时间轴调用都使用同一规则：鼠标点击、Enter、Tab 和按住 Ctrl 不会缩短演出等待，进入该步骤时停止已有快进。演出内的按钮、确认框和页面仍可操作。返回后恢复普通台词和独立演出原有规则；勾选允许跳过的步骤继续支持点击提前结束及显式跳过取消后续工作。

步骤设置独立保存，不覆盖共享演出的 `playback.clickSkip`。页面步骤未增加全局输入拦截。

## 实现

- `src/runtime/blueprint-task-runtime.ts`：按任务的流程归属保护跳过，使用 Ren’Py 动态调用作用域保存／恢复 `_skipping`、`_dismiss_pause`，并停止已启用的快进；暂停入口只将受保护等待提升为 hard。
- `src/runtime/compiler.ts`：生成蓝图入口先继承／创建任务，再执行跳过保护，覆盖嵌套调用。
- `src/renderer/GameFlowInspector.tsx`：在开关下说明点击、快进和按钮的实际行为。

暂停入口还覆盖直接恢复到该等待的旧续点；本轮不宣称所有旧版本存档、所有转场续点都已兼容。存读档实际验收使用本轮生成的新保存点。

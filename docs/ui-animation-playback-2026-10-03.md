# 控件动画的方向、循环与连续换向

开发版继续按 Widget Blueprint 的控件事件图工作流实现。本轮让同一段命名动画支持正放、倒放、往返及循环，并用实际鼠标事件验证“悬停展开、移出收回”，没有增加另一套参数预览主界面。

## 作者操作

在当前页面的事件图里，从左侧动画列表添加播放节点，选择方向；循环次数、速度、沿用当前进度和等待结束均有数据引脚，可接变量。节点本体和详情栏都能设置。停止节点的“到达方向终点”明确区分正放末帧与倒放/往返首帧；旧节点的字段名称会同步更新。

推荐的悬停行为为：OnHovered → 播放动画（正放、沿用当前进度=是、等待=否）；OnUnhovered → 播放同一动画（倒放、沿用当前进度=是、等待=否）。动画还在运行时切换方向，沿原关键帧曲线反向采样，保留首次捕获的起始值，首帧晚于零时也不会产生跳变。

| 参数 | 语义 |
|---|---|
| `playMode` | `forward` 正放、`reverse` 倒放、`pingpong` 往返；默认正放 |
| `loops` | 0～1000000 的整数；默认1，0为无限。往返一次包含完整正向与反向 |
| `speed` | 0.01～100倍；默认1，改变实际用时，不改变关键帧时间 |
| `fromCurrent` | 默认false。为true时，只有同一动画的全部轨道仍属于同一次播放才沿用当前时间位置与捕获值；部分轨道被其他动画替换、停止或播放已结束后，重新从该方向起点播放 |
| `wait` | 等待全部剩余轨道结束或被停止/替换；无限播放不会按单次时长自动继续。游戏跳过仍沿用动画完成行为 |

沿用进度会缩短第一轮：正放从当前点到末尾，倒放从当前点到开头，往返从当前点向末尾再返回开头；后续循环完整播放。往返模式选择后从当前位置向前开始，不继承旧播放的回程方向。普通正放/倒放每次循环在边界重新从方向起点播放，往返则连续转向。停止但不完成时冻结当前值；完成时正放落在末帧、倒放或往返落在首帧。无轨道或零时长动画即使选择无限也立即结束。

## 实现与兼容

- 预演与导出使用同一组播放语义；数值及布尔参数在开始修改前验证，非法数据接线不会替换正在播放的动画。
- 原节点缺失新字段时沿用正放、一次、1倍速、不沿用进度；签名同步补充数据引脚而保留原有连线。
- Ren’Py 保存经过时间、方向、轮数、倍率与起始偏移。读档重新采样时钟，忽略离线时间，保留往返回程和无限播放状态；旧动画存档没有新字段时继续按原正放时间采样。
- 停止和替换仅影响仍属于该动画的轨道。既有嵌套回调顺序与等待入口的重入保护保持原语义。
- AI 字段说明已更新；没有新增真实模型调用验收。

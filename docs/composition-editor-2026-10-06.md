本次目标：统一外层时间轴和组合内部的素材、添加菜单、片段属性、动画与参数编辑。

验收：
- [x] 用共用属性面板替换“动画与效果 · 标题演出组合”，按当前对象显示基础、动画与效果、可替换参数。
- [x] 预览中直接移动、等比缩放和旋转，支持嵌套坐标、Escape 取消和一次操作一次撤销。操作框独立于图层、透明度和遮罩。
- [x] 外层轨道及组合内图层的独显、隐藏；可切换隐藏组合以外内容。旧背景、角色及音乐轨道也已验收。
- [x] 多选、右键制作组合、保存资源、跨时间轴点击或拖放复用、来源修改同步。画面与声音混合组合保留内部轨道及相对时间。
- [x] 组合参数逐层传递；题字和字形粒子可共享图片参数，调用实例值相互独立。图片、文字、时长、数值及视频／字体类型有回归覆盖。
- [x] 添加菜单和素材库提供粒子入口；动画页提供淡入淡出、滑入、笔触消散及从文字／图片生成粒子，保留高级效果和生命曲线。
- [x] 从空白用实际界面手动重建哀鸿第一章标题演出，验证结构、关键帧、素材与粒子；桌面 5 个时刻与原生 16 个时刻比对通过。
- [x] 整体桌面回归、窄窗口检查、生产构建和原生运行验证。

设计：本地组合整理当前画面；可复用的画面组合使用资源管理器中的时间轴资源作为来源。调用实例保留自己的变换、时间和参数值，来源修改同步到所有实例。参数有明确的组合边界，可先公开到上一层组合，再继续公开到时间轴组件。独显、隐藏和隔离只控制编辑预览，不改写演出内容。

## 操作入口

1. 双击时间轴上的组合片段进入；点击轨道片段选择对象，在右侧“基础”中调变换，也可以直接拖动预览操作框、四角或顶部旋转手柄。面包屑逐层返回。
2. 轨道名称旁的眼睛控制隐藏，取景框图标控制独显；组合工具栏有“隐藏不相关内容”和“恢复全部预览”。播放期间，隐藏的音乐及非独显轨道声音会静音。
3. Ctrl／Shift 点击多选片段，右键“制作组合”。纯画面组合可在属性面板“保存为组合资源”；包含声音或指令的组合保存为带内部轨道的时间轴资源。在左侧“组合”页添加到其他时间轴。
4. 在“可替换参数”中点击“公开到上层组合”。到父组合再继续公开；最外层显示“公开到时间轴”。可把题字与粒子来源关联到同一个已有参数。资源实例中修改参数值，通过“编辑组合资源”修改来源，再返回调用的时间轴。
5. “添加片段”以及素材库“添加”页提供文字、图片、视频、色块、组合、粒子。文字动画在右侧“动画与效果”；由文字或图片生成的粒子会保留文本／素材绑定。

## 空白重建与原生比对

`scripts/verify-composition-editor.ts` 从模板读取素材及标题页面配置，新建的“手动重建”时间轴起始为空。脚本通过实际按钮、素材浏览器和属性输入逐层搭建黑底、整体组合、波动背景、遮罩、标题装饰、题字和字形粒子，并手动填写整体不透明度曲线。参照演出只用于比对，没有把参照对象写入重建时间轴。

桌面工程及截图：`artifacts/composition-editor/2026-10-05T20-59-31.872Z`。可直接打开该目录的 `manual-title.vns.json` 检查重建结果；`resource-instances.vns.json` 包含逐层参数、来源资源及两个不同调用实例。桌面 0.5、2、3、4.5、6 秒的四幅比较完全相同，一幅最大差异为 1/255。

`scripts/verify-composition-editor-runtime.ts` 使用界面保存的资源实例工程，经真实编译调用捕获画面数据，验证题字和粒子同时换图、默认实例保持第一章图片、背景波动来源修改同步及实例身份独立。随后与现有 Ren’Py 标题实现比较 16 个时刻；最大色差为 1/255，最大平均绝对色差约 0.00001063（0–255 范围）。这项参照是项目现有 Ren’Py 演出。

原生报告：`artifacts/composition-editor-runtime/2026-10-05T20-40-43.622Z/report.json`，输入为同一界面重建流程较早生成的 `artifacts/composition-editor/2026-10-05T20-34-52.321Z/resource-instances.vns.json`。

# 演出轨道、指令参数与参数集

## 在台词旁调整演出

剧本的文本模式开启「隐藏演出」后，正文只保留台词和目录，当前台词的演出移到右侧实时预览下方。默认只显示选中的台词；勾选「显示未选中台词演出」可查看同段落的其他台词。选中一条台词时会自动打开演出参数，选择多条时按台词排列。

「跟随光标」在预览标题栏。关闭后保持当前预览台词，便于对照其他位置。演出区直接显示台词，不再增加「段落演出 · 正文」标题。问题提示统一在左下角：点击可打开清单，并定位到相应指令、蓝图节点或界面控件。

## 用轨道制作并复用进入动画

1. 打开顶部「演出」→「新建演出」，直接进入「时间轴」。
2. 点「添加片段」，加入章节演出、镜头、震动、背景、角色、音乐或音效。点「轨道」增加轨道。图片和音频也可从资源管理器拖入轨道。
3. 左右拖动片段修改开始时间，上下拖动更换轨道；拖右边缘修改时长。选中后可直接输入开始秒数和参数。方向键微调 0.1 秒，Shift 加方向键微调 1 秒，Delete 删除片段。
4. 持续拖动标尺或播放头定位画面。中键或空格加拖动平移，滚轮横向滚动，Ctrl 加滚轮缩放，「适合窗口」显示整段。拖片段靠近边缘会自动滚动；按 Shift 临时取消吸附。播放、暂停与预览进度条共用同一时间。
5. 选中章节片段，在「标题」「章节背景」「章节音效」旁点击「公开」。这些参数成为调用时可覆盖的输入。
6. 打开「调用参数」，将演出名称设为「哀鸿进场演出」，调整参数名称和默认值。公开参数的顺序就是按位置填写时的顺序。

只公开标题、章节背景和章节音效时，可以这样调用：

```text
@哀鸿进场演出：第一章，夜宴庭院，花街柳巷
@哀鸿进场演出：标题=第二章，章节背景=城中小巷
```

第二次调用省略的音效会使用默认值。示例资源名需替换成作品内已有的素材名称。若公开更多参数，按指令提示中的顺序填写，或直接使用参数名。

图片、音频、角色等参数会沿蓝图连线识别用途。输入名称、拼音或首字母搜索，也可以点文件夹按钮打开资源选择窗口。图片名称前显示小缩略图；浏览窗口可以按分类与文件夹查看资源。

已有章节指令可用 Ctrl+点击进入蓝图工作区；选中连续演出指令后，也可右键「封装选中演出为蓝图」。章节标题、背景、题图和音效会组成同一个可复用片段，包括采用命名参数的指令。

多个片段放在相同起始秒数就会同时执行，例如把镜头和震动都放在 0 秒。播放会等待最晚结束的片段完成；调用时增加公开的时长，也会延长等待。

轨道和蓝图编辑同一份演出：轨道适合有确定时间顺序的片段；条件、循环或计算驱动的复杂执行路径在「蓝图」中编辑。音效可按时间触发，音频片段支持波形与裁剪。角色动画使用已有关键帧；可在舞台编辑中调整它们。

## 指令参数可以按顺序或名称填写

```text
@显示角色：王生，通常，0.5，1，1.2
@显示角色：王生，缩放=1，纵向位置=1.2
@显示角色：角色=王生，表情=通常
@跳转：段落 2
@跳转：段落 2，溶解，0.5
@跳转：目标=段落 2，时长=0.5，切换方式=溶解
```

点击参数提示中的「表情」，会在当前指令中补入 `表情=` 并打开候选项；已填写的参数会定位到对应值，避免重复添加。资源参数可通过旁边的浏览按钮选择，选择后焦点返回文本。

位置参数按顺序绑定到尚未填写的参数；名称参数可以跳过中间项。文本包含逗号或等号时使用引号，例如 `标题="第一章，夜宴"`。错误名称、重复参数和缺少值会在问题列表里指出。没有转场的跳转只写 `@跳转：段落 2`。

补全列表用滚轮上下滚动，用 ↑／↓ 改变选中项，用 Enter 或空格采用；分组可以展开或收起。

## 参数集和玩家自定义设置

顶部「参数集」用于整理同一批数据，初始提供「剧情参数」和「游戏设置」。可创建更多参数集，并添加开关、数值或文字参数。

制作「减少闪烁」选项的步骤：

1. 打开「参数集」→「游戏设置」→「开关」，命名为「减少闪烁」，设置初始值。
2. 点击「放入设置界面并调整布局」。编辑器会创建或定位绑定该参数的控件，进入界面编辑的「组件设置」。
3. 在蓝图中读取同一个「减少闪烁」参数，用条件分支控制是否执行震动或闪烁。

数值参数可设置滑条最小值、最大值与步长；文字参数可提供选项列表或自由输入。范围定义用于游戏中的滑条，编辑器数值框仍支持先清空再输入。

设置参数默认跨存档保存：玩家修改后，读取旧剧情存档不会覆盖它。蓝图与界面读写同一参数，不需要维护第二份同名变量。「恢复初始设置」恢复自定义设置的初始值。尚未放置控件的可见设置仍会出现在默认设置组或「更多设置」中。

移动或删除参数集保留其中参数的身份；删除参数本身可以撤销。普通剧情参数也可按需要单独设置跨周目保存。

## 界面属性与编辑器风格

界面右侧分成「游戏设置」和「组件设置」：前者调整全局初始选项、颜色与字体；后者调整当前控件。点击画布或层级中的控件会自动切到它的组件属性。

「作品设置 → 编辑器外观」提供石墨、蓝灰、墨绿、暖白和自定义，默认石墨。可以分别修改背景、面板、边框、文字、重点色和节点相关颜色，并恢复默认。配色保存在本机，也同步到独立 AI 辅助窗口。

双击 `启动开发版.cmd` 会加载本地编译界面；有源码更新才重新编译，不生成安装包或游戏发行包。需要边修改界面源码边热更新时，运行 `node scripts/dev.mjs --hot`。界面输入验证见 `scripts/verify-ui-responsiveness.ts`，测试使用完整哀鸿模板副本和独立配置。

时间轴打开时自动适配完整演出，调整窗口大小时随之适配。手动选择缩放或 Ctrl+滚轮后保留手动比例；点击「适合窗口」恢复自动适配。长演出会调整刻度间隔，十分钟以上的演出也能完整缩放到窗口内。预览按可用高度等比显示，片段参数在右侧独立滚动。

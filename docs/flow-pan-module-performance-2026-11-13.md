# 剧情图平移与模块编辑性能

日期：2026-11-13。范围对应用户确认的第 1、2 项：补齐剧情图中键／滚动条变换，降低模块编辑选行、展开、滚动与连续改文字参数的停顿。

## 实现

### 剧情图浏览

- 中键平移使用控件及父级的完整仿射矩阵。屏幕位移逆变换后直接写入 DOM 滚动位置，避免额外乘编辑器比例；节点移动仍使用编辑器比例与图内缩放转换为剧情图坐标。
- 横向、纵向滚动条使用实际轨道边界与局部轨道矩形恢复指针位置，支持旋转、非均匀缩放、镜像、轴心偏移及组合变换产生的剪切。
- 历史对话列表复用同一滚动条，其设计预览及事件预演均传入实际控件几何信息。
- 有效松手使用最后指针位置。Escape、失焦、丢失捕获、第二指针、坐标系／范围／分组切换会结束手势；保留已经滚动到的位置。第二指针不会接管未结束的拖动。
- Home、End、方向键和翻页键继续按内容坐标工作。鼠标操作滚动条聚焦时不额外移动外层设计画布。
- 滚动条可访问值夹紧到合法范围，避免浏览器像素取整后大于最大值；键盘改值立即同步实际滚动位置，连续 Home／方向键不再读取上一帧的旧值。历史列表共用此行为。

### 模块编辑

- 台词行的选中外壳与表单主体分开记忆。仅切换选中高亮时，不再重建角色选择、台词输入框、演出字段和文字样例。
- 点击／聚焦已经到达的行不再额外调用整行 `scrollIntoView`。目录、新增和复制仍有显式定位；重复点击同一目录项也会定位，目标模块收起时先展开。
- 目录目标是仅演出模块时，没有对应台词行则回退到模块标题；避免章节开头的演出找不到定位目标。
- 离屏且未选中、未聚焦的已展开行也可跳过布局。保留 DOM、字段状态及浏览器记住的高度；选中行和聚焦行仍允许菜单正常显示。
- 项目切换清空展开行与选字范围，避免不同工程复用台词 ID 时继承旧选区。
- 舞台预览缓存区分文字显示和舞台输入：正文、文字样式、局部样式、文字停顿不再触发前序舞台推演；台词动作、说话人、仅演出标记、身份、顺序、剧情路线、资源和未知字段仍会使缓存失效。
- 复用缓存时刷新当前台词、前后舞台以及过渡前画面中的对白。结构相同的对象保留引用，真实文字变化立即更新；台词索引按变更段落维护。
- 对话框布局按界面、变量、悬停状态、画布尺寸和透明度缓存。文字显示帧和样式修改不再重复解析相同对话框布局。

## 验证口径

全部实现完成后统一编译、单测与桌面验收；验收发现的产品问题修复后再构建并补验。

性能对照使用本轮改动前保留的构建和当前源码构建，使用同一脚本协议及真实作品的隔离副本；作者工程只读。原作保留 469 素材与 20 角色；`--lines 240` 将最长段落重建为 240 句，报告同时记录实际场景总行数。

交互计时取输入／focus 到下一帧，列表测试定位安排在选择采样窗口外。滚动记录帧间隔、超过 50ms 的任务、布局耗时与实际滚动事件。CPU profile 中自动化查询和等待不视为产品代码耗时。

验收覆盖矩阵下的实际鼠标／键盘滚动、节点拖动回归、台词分界像素、文字样式预览、中文文本插入、Tab、选字、离屏往返、目录重复定位、新增／复制／撤销和保存重开。中文文本插入不等同于真实中文输入法候选窗口验收。

本轮不修改游戏运行时或安装版。不是整个应用所有性能问题的完成声明。

### 性能结果

两版都使用同一份只读作品生成隔离工程，最长台词段 240 句，场景合计 242 行，469 素材、20 角色。编辑、滚动分别按旧／新／新／旧串行采样。

| 操作与口径 | 改前 | 改后 |
| --- | --- | --- |
| 连续改字号，输入到下一帧中位数，两轮各12次 | 53.55ms | 39.75ms，减少约25.8% |
| 同组字号输入 p95 | 60.60ms | 49.10ms |
| 同组字号输入超过50ms的主线程任务 | 12次 | 0次 |
| 五次本地选行引起的额外 `scrollIntoView`，每轮 | 4次 | 0次 |
| 六种滚动场景，两轮合计超过50ms的主线程任务 | 0次／2618帧 | 0次／2604帧 |

编辑对照在 build04 完成；build05 随后仅加“仅演出模块目录定位”回退，最终完整编辑复验再次通过，字号中位 **44.5ms**、p95 **53.6ms**，其中1次53ms长任务；打字 p95 **50.1ms**，首次选行 **67.8ms**。这些独立样本也保留，不能只报告对照中较快的数据。

首次选行、远距离换行和新增对白仍可能停顿；最终滚动两轮新增对白分别记录 **117ms／99ms** 长任务。普通展开与打字未观察到稳定的大幅改善。两版滚动采样均较平稳，**未复现用户此前的偶发长卡顿，不能宣称整个模块编辑已完全不卡，也不能把这轮滚动数字当作改善百分比**。此次减少了重复定位与离屏展开行布局的条件；后续若仍有卡顿，应针对实际工程、具体操作采集长任务。

详细原始帧、CPU profiles、样本范围及版本在 [性能汇总](../artifacts/flow-pan-module-performance-2026-11-13/validation-main/performance-summary.json)。

### 验收中发现和处理的问题

- 产品：滚动到底的ARIA数值可能因取整越界；连续 Home／方向键读取旧位置；仅演出模块没有台词 DOM 导致目录定位失败。均已修复并用真实操作复验。
- 验收：先选中控件后才能操作设计预览；大型作者工程前面有开场演出，需先定位到台词再开始测量；滚动边界按真实 DOM 像素验证，保留1.5 CSS像素的取整容差；固定预览先回到正常流位置再测试吸顶，避免把容器底部离开视野误判成吸顶失效。失败报告与trace保留。
- `build01` 仅因新验收脚本的布局类型推导失败，修正脚本声明后通过；不把它记作产品编译故障。

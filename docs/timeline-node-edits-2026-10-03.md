# 时间轴组件连线编辑与旧轨道播放一致性

用户要求同一轨道的片段不重叠，上方轨道显示在前；时间轴默认保持素材剪辑操作，外层可作为蓝图组件调用。

本批修复两个实际缺口：组件连线视图直接修改时长、公开默认值或数据线时没有检查同轨冲突；旧重叠工程在编辑器临时分轨后，导出仍用原始轨道层级。

## 修改

- `BlueprintGraphEditor` 在实际历史事务里保存修改前状态，修改并同步全部端口/调用签名后，再比较固定时间轴的同轨冲突。新增或扩大的冲突整次拒绝；保留旧冲突的无关编辑和修复仍可继续。
- 普通舞台提交会自行捕获异常，UI 草稿会向上抛出异常，编辑器同时处理这两种情况。拒绝时不清除选择、不显示添加/删除/接线成功消息，也不占用修改历史。
- 首次桌面测试发现：仅在端口同步前检查，会在属性面板把对象时长改为5秒时读到旧的2秒默认值。因此检查放在完整签名同步之后，两种入口均验证生效。
- 普通时间轴补“查看组件连线 / 返回时间轴编辑”；“由蓝图连线控制”打开当前组件的连线，不再错误返回父图或无响应。默认仍进入时间轴剪辑。
- `timelinePlaybackLayout` 复用编辑器对旧同轨重叠的分轨结果；预览与编译都先应用这份私有布局，再计算嵌套层级、交错播放。保持原起止时间和源工程不变。
- 时间轴测量单个节点时跳过布局重建，避免布局→节点取样→布局的递归；没有按工程对象身份缓存，因此原地修改项目后不会沿用旧布局。

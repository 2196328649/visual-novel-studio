## 导航与文本

工作区按“剧本、演出、蓝图、界面、资源、角色、参数集”排列在同一排标签中。“剧本”提供“模块编辑”和“文本编辑”两种模式，共用剧情目录、选中对白与撤销历史。舞台编辑并入右侧实时预览，通过“编辑舞台”切换。目录可收起或折叠章节；文本模式中点击目录会定位正文。

文本指令插入保留光标和滚动位置。工具栏与斜杠插入都接入项目历史，Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z 和顶部撤销/重做使用同一记录；一条插入指令单独撤销。

文本模式自动隐藏对白及场景、段落、素材等引用的内部编号，保留中文名称、台词和演出指令。行号、语法颜色、Ctrl+F 查找、Ctrl+H 替换和 Tab 缩进便于编辑长篇内容。复制、插入和撤销按可见文本操作；编号保存在工程内部，预览、目录定位和错误行号均对应可见正文。

## 素材

完整资源页与底部资源抽屉共用项目目录，图片、音频、蓝图、角色、状态等都在同一棵树中。“类型筛选”可同时选择多个类型；“在文件夹内”保留匹配内容所在的目录层级，“全部匹配”平铺所选类型的全部结果。导航时保留筛选，切换到全部类型即可恢复完整目录。卡片使用同样大小的方形预览框、两行名称和类型栏，右下角滑块统一调整大小；列表视图使用固定行高与名称、类型、位置列。

从 Windows 文件管理器拖入文件或目录即可导入，也可以使用“导入素材”和“导入文件夹”按钮。导入按工程设置复制或引用原文件，保留子目录、跳过重复内容和不支持的格式，报告无法读取的文件。任意资源类型可以放入同一个项目文件夹；图片、音频等只在用途兼容时继承目标文件夹的分类。移动和分类调整保留稳定 ID 与已有对白引用，工程内素材的磁盘路径在保存时同步。

“作品设置 → 资源管理 → 保存时同步素材文件夹”默认开启。手动保存时，工程内素材按资源目录、分类和编辑器文件夹层级整理；没有文件夹归属的旧素材也会按类别归档。普通文件采用素材显示名和原扩展名，重命名素材后再次保存即可同步；同名冲突添加稳定编号，Windows 不允许的字符替换为下划线。骨骼动画按“显示名_编号”整组归档，保留骨架、图集和图片的内部名称。外部引用素材仍保留在原位置。关闭此选项后，移动或改名只调整编辑器中的信息。自动保存不整理磁盘文件，文本输入不会因此逐字扫描或移动文件。

整理会检查并核验复制结果，先保存新路径，再清理旧文件；缺失文件和无法处理的冲突会保留并报告。工程的 `.studio/resource-paths.json` 保留旧路径映射和素材身份映射，支持旧工程快照恢复和保存后的撤销、重做；旧名称被其他素材复用时，恢复仍匹配原素材。`.studio/resource-layout` 记录各次整理，不要单独删除这些记录。目录整理及彩色标注见[前一轮记录](resource-sync-colors-2026-10-05.md)，最新文件名同步见[悬停音效与素材命名](ui-hover-resource-names-2026-10-05.md)。

## 批量选择与操作

完整资源页、底部资源管理器和资源选择窗口采用同一套选择操作。在空白处拖出选框，碰到的卡片即可选中；Ctrl 点击增减，Shift 点击选择连续区间，Ctrl+A 选择当前列表全部项目。方向键移动选中项，Enter 打开，F2 重命名，Esc 清除选择。框选到边缘时自动滚动，可跨出一屏选择。

选中的文件夹和资源可以一起拖到目标目录。Ctrl+X 剪切，进入目标目录后 Ctrl+V 移动；右键菜单也提供相同操作。重命名蓝图会同步剧本中的调用名；移动资源保留 ID 及已有引用，启用目录同步时会在保存后更新磁盘路径。删除操作只从工程中移除，仍被引用的资源会说明引用位置，批量删除不会只删掉其中一部分。磁盘原文件不因此删除。操作进入统一撤销历史。

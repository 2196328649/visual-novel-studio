# 文字演出

文字演出控制一句台词怎么显示：字体、大小、颜色、描边阴影、播放速度、显示位置，以及逐字入场和持续动画。适合惊吓、低语、回忆、系统提示、画面大字等场景。

## 在哪里设置

- **单句**：模块编辑里点最左侧行号下方的小箭头，在台词下方设置文字演出；文本编辑里仍可通过右侧本行演出列表的“+ → 文字演出”设置。流程图属性面板的“当前对白”里也有“文字演出”分组。
- **角色默认**：在“角色”工作区打开角色，切到“文字演出”页签。这个角色的每句台词都会使用这里的设置；单句可再调整。派生角色沿用基础角色的设置，只覆盖自己改过的项目。
- **文本模式**：在台词上一行写 `@文字演出：`，参数见下文。

各项按“对话框主题 → 角色 → 预设 → 本句”逐项叠加：没有单独设置的项目沿用上一层。面板里每个字段显示当前生效的值；本句改过的字段名后有圆点，旁边的箭头可恢复为继承值。“全部恢复默认”清除本句的全部设置。

角色存在继承时，先展开每一代角色自己的预设与覆盖，再从基础角色到派生角色依次合并。派生角色换预设只覆盖该预设包含的项目，其余继续继承；显式换入场或退场效果时，旧效果的自定义位移、旋转等不会串入新效果。

面板顶部的小预览会在每次修改后重播，并显示字数和显示完所需的时间。剧本右侧的实时预览也按同样效果播放。

## 字体、粗斜体与对齐

字体可以使用项目里登记的全部 TTF、OTF 素材，没有固定的几种字体限制。整句和选中文字的字体栏都可以输入名称搜索，或点右侧文件夹浏览、预览字体；在资源浏览器里点“选择项目外素材”可导入新字体，导入后立即选用，也能从“资源”页先导入。

未单独指定字体时，台词沿用对话框控件的字体；放到“画面上”的台词沿用对话页面的字体。局部文字默认沿用整句字体，可以在一句里混用多个项目字体。

“粗体”“斜体”在选中的字形上加粗或倾斜。导入字体通常是一份单独的字形文件，编辑器按笔画加粗并允许合成斜体，游戏中也使用所选字体加粗、倾斜。取消“粗体”恢复该文件原本的字形；如果选的是 Bold、SemiBold 字体，取消后仍保留字体本身的粗度，需要细体时应选择 Regular 等文件。预览与游戏使用不同文字引擎，笔画边缘可能略有差别。

“对齐”控制整句在文字区域中的左、中、右位置，多行文字逐行对齐。没有单独设置时，台词沿用对话框控件的对齐；“画面上”默认居中。面板小预览、剧本右侧预览和游戏都遵循这一规则。

时间轴预设打开或停止播放后从 0 秒显示，切换预设不会继承上一张的播放位置。文本工作区点击“暂停实时预览”时，会同时停止自动配音及手动 BGM、配音、音效试听；恢复后显示当前台词，试听音频需重新点击播放。BGM 平时也通过预览下方的播放器手动试听。

## 播放速度

| 显示方式 | 效果 |
| --- | --- |
| 跟随玩家设置 | 使用玩家在设置里选择的文字速度（默认） |
| 按时长 | 整句在指定秒数内显示完，字数多则每个字更快。适合和配音、音乐节拍对齐 |
| 按速度 | 每秒显示固定字数 |
| 瞬间显示 | 整句立即出现 |

按时长时，停顿、局部速度和各字入场都计算在内，以当前顺序中最后完成的字为准；每字入场最多占文字显示预算的一半。台词有配音时，可点“时长与配音一致”，直接读取配音长度。

配音读取期间可以继续改其他样式，返回时只更新速度和时长。再次读取、切换配音、收起面板或删除台词会取消旧读取，避免晚到结果覆盖新编辑。

停顿总长小于整句目标时，文字和停顿仍在目标内完成。停顿总长达到或超过目标时，保留明确设置的停顿，同时给文字保留原目标时长的预算。例如整句目标 1 秒、停顿 2 秒，实际 3 秒完成；面板会显示顺延原因和实际时长。没有文字的空行只保留明确停顿，不额外等待文字预算。“瞬间显示”和玩家把文字速度设为瞬间时忽略所有逐字停顿与入场。

按速度及玩家速度时，实际结束取“原逐字序列加句末停顿”和“各字真实入场结束”中较晚的一个。局部某个字入场较长，不会再把它的整段入场时间加到最后一个字之后；从右到左、从中间展开及随机顺序遵循同一规则。按时长会据此求出基准文字速度，预览和游戏使用相同的起点及完成时间。

## 位置

“对话框内”保持原有位置。“画面上”会隐藏对话框和说话人名，把这句文字放在画面上。可以在右侧预览里直接拖动文字摆放，靠近画面中线时会吸附（按住 Alt 不吸附），两侧手柄调宽度，方向键微调（按住 Shift 走得更多）；正在播放预览时不能拖动。属性面板里的横向、纵向位置是文字中心占画面的百分比，宽度是文字区域占画面宽度的百分比。历史记录和存档摘要仍记录这句文字。

## 文字动画

- **入场效果**：普通（逐字出现）、逐字淡入、逐字放大、逐字砸入、逐字翻转、逐字落下、逐字升起。“每个字入场时间”是一个字从开始到完成的秒数。
- **持续效果**：抖动、波浪、呼吸（明暗变化），在这句显示期间一直播放。抖动和波浪的幅度单位是像素，呼吸是明暗变化的百分比。

玩家快进、回退或已读跳过时，文字直接完整显示。

## 文字动画器

每个入场效果都可以展开“调整入场动画”继续调，不用从零开始：

- **横向位移、纵向位移**：字从哪里来（负的纵向位移是上方）。
- **缩放**：字从多大变到原大小，0 是从无到有，250 是从大砸下来。
- **旋转角度、水平翻转**。
- **不透明度**：开始时的不透明度，默认 0。设成 100 时字一开始就完全可见。
- **运动曲线**：匀速、先快后慢、先慢后快、缓入缓出、回弹、弹跳、弹簧。
- **顺序**：每个字开始的先后，从左到右、从右到左、从中间向两边、从两边向中间、随机。

调整后可以“存为预设”，以后一键套用。换成另一个效果时，之前的调整会清除（可撤销）。新增内置预设：弹跳登场、旋转飞入、散落聚拢、由中散开。

局部文字（选中的几个字）可以选另一种入场效果和入场时间，细项调整和顺序只在整句上设置。

## 文字退场

“文字退场”让玩家点击之后，文字先离开再进入下一句。效果有逐字淡出、缩小、放大消失、翻转、落下、飘起，同样可以调整。

- **退场总时长**：整句退场用的秒数，默认 0.4。
- **每个字退场时间**：一个字从开始到消失的秒数，默认 0.25。两者相减就是字与字之间错开的总时间，设成相等时所有字一起走。
- 退场期间再点一下可以跳过。快进、回退、隐藏界面和正在演出时不播放。
- 退场后文字不会留在画面上，所以下一句前面的等待里看不到这句。

## 时间轴文字片段

时间轴的文字片段用同一套动画。选中片段，在“动画与效果”里展开“文字动画”：

- **文字显示方式**：默认“瞬间显示”，和以前一样。按时长、按速度、跟随玩家设置时逐字出现。
- **入场、持续效果、退场**：和台词相同。
- 退场在片段结束前播放完。持续显示的片段没有结束时间，不播放退场。

要让文字和音效、震动、立绘配合，就用时间轴片段。片段的动画按片段自己的时间走，拖动播放头可以在预览里查看任意时刻。普通文字对象（包括字体、样式和逐字动画）可用 `@显示文字` 表达；多关键帧、曲线、组合等复杂片段继续保存成 `@演出实例`，完整保留时间轴设置。

## 显示独立文字

台词之外的浮空文字统一用 **显示文字**。在台词上方的“+”选择“显示文字”，或在文本模式的 `/` 指令面板选择同名入口。每次新增默认分配不同的对象 ID，所以一句台词可以同时放多段文字，各自有位置、字体、字号、颜色和可选的文字动画；台词自身的文字演出保持独立。

- 不设置“文字动画”时，文字立即完整显示。需要时展开它，设置显示方式、逐字入场、持续效果和退场；“清除文字动画”保留文字、位置、字体等设置。
- “显示时长”是对象在画面上保留多久；“逐字显示时长”是文字全部出现需要多久，两者分开设置。
- 显示时长为 0 时持续显示，直到 `@隐藏对象` 或切换背景。定时文字的逐字退场在显示时长结束前完成；持续文字没有预定结束时间，不播放逐字退场，可在隐藏对象时设置离场过渡。
- 不同 ID 同时显示；相同 ID 替换同一段。手写旧指令未填 ID 时仍使用 `text`，兼容原来的替换行为。
- `@添加文字演出` 作为同一指令的别名读取，界面入口和输出统一为 `@显示文字`。

```text
@显示文字：三年后，对象ID=caption_a，纵向位置=0.3，字号=72，时长=4，逐字时长=1，入场=逐字淡入，退场=逐字飘起
@显示文字：冬夜，对象ID=caption_b，纵向位置=0.5，字号=40，颜色=#aabbcc
@文字演出：颜色=#ff6666，时长=2
旁白：门外传来脚步声。
@隐藏对象：caption_b
旁白：风停了。
```

“显示文字”支持字体、斜体、对齐、描边、阴影和与时间轴相同的动画参数。需要配合声音或其他舞台演出时，继续使用已有时间轴。

## 打字音

逐字显示时播放声音。在“文字演出 → 打字音”选择音频素材，设置“每隔几个字响一次”（默认 2）和音量。设在角色的“文字演出”页签上，这个角色的每句台词都有自己的打字音；某一句不想要时，把这句的音量设为 0。

- 标点和空格不发声；停顿和局部变速期间声音跟着文字走。
- 声音跟随玩家的音效音量。玩家点击补全文字、快进或打开菜单时不发声。
- 面板小预览修改时不发声，点“重播”才试听；剧本右侧“播放预览”时也会播放。
- 音调不能调：Ren'Py 播放声音时没有变调功能。想要高低不同的声音，可以准备多个素材分别用在不同角色上。

## 预设

内置预设：惊吓 / 大喊、低语、回忆、梦境、系统提示、画面大字、缓慢叙述、瞬间显示。

- 选择预设后，仍可在其基础上单独调整某几项。
- “存为预设”把当前效果保存为工程预设，本句改为引用它。
- 选中工程预设时可“更新预设”（把本句调整写入预设，所有引用一起更新），也可在“管理预设”里重命名或删除。删除后，使用它的台词和角色保留相同效果，改为各自的设置。
- 引用的预设或字体被删除时，检查面板给出提醒，游戏中该项改用默认值。

## 文本指令

```text
@文字演出：预设=低语，时长=3，入场=逐字淡入
苏怜烟：别出声……他们还在外面。

@文字演出：位置=画面，纵向位置=0.4，大小=180，粗体=是，入场=逐字落下
旁白：三年后。
```

参数（都可省略，只写需要改的）：预设、字体、大小（百分比）、颜色、粗体、斜体、对齐、描边宽度、描边颜色、描边不透明度、阴影横向、阴影纵向、阴影柔化、阴影颜色、阴影不透明度、速度（跟随玩家设置 / 按时长 / 按速度 / 瞬间显示）、时长、每秒字数、位置（对话框 / 画面）、横向位置、纵向位置、宽度、入场、入场时间、入场横移、入场纵移、入场缩放、入场翻转、入场旋转、入场透明度、入场曲线、入场顺序、持续效果（无 / 抖动 / 波浪 / 呼吸）、幅度、频率、退场、退场总时长、退场时间（以及退场横移、退场纵移等同样的八项）、打字音、打字音间隔、打字音音量。只写“时长”时自动按时长显示，只写“每秒字数”时自动按速度显示。在面板里修改时，文本中的这一行会同步更新。

## 在台词上编辑

模块编辑里，`@` 舞台演出和配音始终放在台词上方，可以直接查看、添加和编辑。行号和小箭头在最左侧同一列上下排列，为台词框腾出空间；小箭头只展开这句台词的文字演出，面板显示在台词下方，默认收起。箭头数字只计算本句文字设置和局部效果，不包含上方的舞台演出或配音；收起时下方摘要也只描述台词文字。

单行台词框与左侧说话人下拉框默认32px等高、顶部对齐，换行时随文字增高，仍可手动调整高度。每句之间的分隔线在高DPI、选中、展开和滚动后保持可见，见[模块台词显示修复](https://github.com/2196328649/visual-novel-studio/blob/v0.8.1/docs/module-separators-and-preset-2026-11-07.md)。

台词面板分页为：文字样式、播放速度、位置、文字动画、文字退场、打字音、局部效果。在台词框里选中几个字时，面板会自动展开，顶部出现这几个字的设置。删除台词文字演出只清除该句的文字设置和局部效果，不会删除上方的独立文字对象。

小预览在设置上方保持可见；滚出视野后暂停文字动画和打字音，滚回后从原来的进度继续。已经播放完成的预览不会因滚动重新播放，已退场文字保持消失，修改设置或点击“重播”才会重新开始。打字音复用单个播放器，完成时停止，离屏或收起面板时释放。

文本编辑模式保留右侧的演出列表。

## 局部效果（一句里的几个字）

整句演出之外，可以只给一句里的几个字单独设置，例如“我……不想死”里只让“不想死”变红、放大并抖动，或让它们停一下再出现。

- **模块编辑**：在台词框里选中几个字，下方出现工具条，可设置颜色、大小百分比、粗体、斜体、字体、速度倍数、入场效果和每字入场时间、持续动画及其幅度和频率，以及显示前停顿的秒数。大小和速度都直接填数字。
- **查看和修改**：台词展开面板的“局部效果”分页，以及属性面板“文字演出”分组顶部的“局部效果”列表，列出每段带效果的文字和每个停顿，可展开修改或删除。
- **删除**：台词展开面板里的“删除文字演出”会同时清除这句的文字演出和全部局部效果，可以撤销。
- **改台词不丢效果**：在带效果的文字前后增删内容，效果仍跟着原来的字；在效果中间打字会延长这段效果；整段删除时效果和它前面的停顿一起删除。AI 改写、导入修订稿也遵循同样规则。
- **速度与时长**：局部速度是相对整句速度的倍数。整句设为“按时长”时，停顿、局部变速和各字入场都参与计算；停顿达到或超出目标时保留停顿并顺延，规则见上方“播放速度”。“瞬间显示”的句子忽略停顿和变速，只保留颜色、大小等样式。
- **入场和动画**：工具条里的“入场”“动画”默认跟随整句；选了具体效果就只替换这几个字的，选“普通（逐字出现）”或“无动画”可以让这几个字不用整句的效果。历史记录、存档摘要和语音收藏只显示文字本身。

文本编辑中写在台词里：

```text
苏怜烟：我……〖不想死｜颜色=#ff3030，大小=150，粗体，抖动〗。
旁白：门开了。〖停顿=1.5〗外面什么也没有。
```

- `〖文字｜效果〗`：效果写法有 颜色=#rrggbb、大小=百分比、粗体、斜体、字体=字体名、速度=倍数、入场=逐字砸入 等、入场时间=秒、持续效果=无/抖动/波浪/呼吸、幅度、频率；常用效果也可只写一个词，如 逐字砸入、抖动、波浪、呼吸、较大、很大、慢、快、#ff0000。
- `〖停顿=秒〗`：显示到这里先等待指定秒数。
- 右键选中的文字可选“设为局部文字效果”或“在此处停顿”，会自动插入标记。
- 要在旧格式台词里写 `〖` 本身，写成 `〖〖`。旧格式写错的标记会给出提醒，并按原样显示文字。

选中文字包含 `〖`、`〗` 或换行，字体名称含分隔符，或者正文需要保留行首尾空白时，编辑器会为这一句自动加入带引号声明。该声明只作用于下一句和紧接的 `@续行`，后一句继续按原来的格式读取：

```text
@局部文字语法：带引号
旁白：〖"甲〖乙〗丙"｜颜色=#ff0000〗
@续行：〖"  原文两端保留空格  "〗〖"换行\n也可保留"｜粗体，字体="字体，名【font_id】"〗
```

带引号格式的每个效果正文都使用 JSON 双引号；`\"` 表示双引号、`\\` 表示反斜杠、`\n` 表示换行、`\r` 表示回车。`〖"原文"〗` 只保留文字，不添加效果；`〖""〗` 可保留空首行或空续行。普通未设样式的词仍可直接编辑。字体参数的引号包住名称和稳定引用，名称中的逗号、等号和括号不会拆成其他参数。

声明必须紧接台词；空行、注释、其他指令或段落标题会取消尚未应用的声明并报错。已经开始的台词中，紧接的空 `@续行：` 仍属于同一句；声明后手写的空 `旁白：` 会结束这次格式作用。带引号标记未闭合、转义无效或效果参数错误时，保留整行草稿并报错，修正后才能试玩和导出。右键只在标记外的普通文字和边界插入效果或停顿，已有标记内部可直接改写正文或在属性面板修改效果。

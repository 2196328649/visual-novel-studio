# 叙事工坊 1.3.4

2026-09-30，Windows x64。

在「界面 → 剧情流程图」选择流程图组件，展开「流程图显示区域与导航」，可单独调整图的显示区域、横向滚动条位置与大小，选择轨道和滑块图片，并设置普通、悬停、按住、禁用状态的明暗。轨道厚度和滑块高度互相独立，滑块会在指定区域内垂直居中。可以分别显示或隐藏缩放/定位按钮和竖向滚动条。

哀鸿新建模板按已提取的原始布局数据，使用 733 像素宽、5 像素厚的底部居中轨道，滑块高 31 像素。图的显示区域从画面纵向 200 像素开始，高 736 像素；默认隐藏缩放按钮和竖向滚动条。现有作品保持作者已有布局，可在上述属性中自行配置。

编辑器预览支持拖动滑块、横向滚轮和中键拖动查看。聚焦滚动条后可用方向键、PageUp/PageDown、Home/End；启用导航按钮后可缩放和定位到入口。预览操作不写入剧情进度或修改组件位置。运行中的游戏继续使用当前剧情位置与真实解锁记录。

修复自定义滑块首次打开时过短、缩放后长度滞后，以及按住和禁用图片未生效的问题。滑块尺寸在绘制时依据实际可视范围计算，内容不足一屏时填满轨道并显示禁用状态。旧工程未设置自定义导航时，继续使用原有横竖滚动条。

验证入口：`pnpm test`、`pnpm exec tsx scripts/verify-game-flow.ts` 和 `pnpm exec tsx scripts/verify-flow-navigation-editor.ts`。设置 `VNS_FLOW_GENERIC=1` 可检验旧布局；设置 `VNS_INSTALLED_EXE` 可对安装后的编辑器执行同一套交互、保存与重开验收。结果与文件校验值见发行目录 `verification-1.3.4.json`。

原游戏窗口捕获在本次刷新和重试后仍失败，尚未完成原作界面与章节动画的直接视觉对照。上述几何数据来自原作布局文件，编辑器和导出游戏的截图不作为原作视觉一致性的证明。Android 本版未重新构建或进行设备验收。

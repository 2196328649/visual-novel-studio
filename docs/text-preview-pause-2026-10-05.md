# 文本输入优化与暂停实时预览

2026-10-05。优化长剧本文本模式下的输入响应，并增加可以完全暂停实时预览的开关。开发版已构建。

## 使用

实时预览标题栏新增“暂停实时预览”。暂停期间停止舞台推演、画面组件、动画和预览音频；输入、切换台词、隐藏演出、撤销、重做及保存仍可使用。点击“恢复实时预览”重新显示当前台词的最新内容，不继续之前的播放进度。偏好保存在本机，重开编辑器后仍有效。此开关只作用于文本模式。

## 原因与优化

- 文本折叠在输入事件中解析全文，剧情目录随后又解析相同内容，诊断也需要解析。现在这些读取共用解析缓存。缓存按完整源码、来源名称以及不可变工程分支校验，素材、节点、蓝图、设置等变化时失效；最多保留最近两份结果。需要修改解析结果的操作仍使用独立解析或克隆。
- 每条文本指令查询可用蓝图时，原本反复创建自动角色与结局蓝图，包括节点 ID 和连线。CPU 采样确认这些构建占用大量时间；现在与章节预设一起复用，安装到工程时仍克隆，用户编辑不会污染预设。
- 暂停开关卸载实时预览子组件，执行现有播放清理。暂停时不调用舞台推演与绘制，恢复使用当前工程和选中台词。

## 测量

同机、同一份 1,500 句合成剧本，每句含等待指令，开启“隐藏演出”，在最后一句逐键输入 12 个字符。指标为原生 `input` 事件到下一次动画帧的耗时，包含编辑器响应。旧版与新版测量期间均未并行运行构建或测试。

| 状态 | 中位数 | 最大值 |
| --- | ---: | ---: |
| 优化前，实时预览开启 | 355.3 ms | 914.7 ms |
| 优化后，实时预览开启 | 55.1 ms | 67.0 ms |
| 优化后，实时预览暂停 | 50.0 ms | 53.8 ms |

这是该测试场景的结果，复杂角色、粒子、蓝图及工程规模会影响实际耗时。没有改成延迟提交文本，也没有延迟保存或降低指令解析校验。

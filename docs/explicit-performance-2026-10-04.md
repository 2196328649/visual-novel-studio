# 独立演出声明、章节蓝图与预览边界

2026-10-04。本轮按用户要求修正剧情模块归属、章节蓝图入口、旧章节指令和播放结束后的预览越界。交付为已构建的开发版。

## 当前行为

- 是否单独占一个剧情模块只由 `@独立演出` 决定，有名称和无名称均有效。蓝图的 `performanceKind` 不再自动拆模块；多个调用可以由一次声明组成一个独立模块。
- 不写声明时，演出动作附着到下一句对白；遇到段落结束或流程操作时，保留为普通演出行，不擅自改为独立模块。
- 章节进入演出采用普通外层蓝图，公开输入通过数据线传到内部时间轴组件。Ctrl＋左键先进入外层蓝图；双击组件进入时间轴，返回后继续编辑蓝图。即使只有一个时间轴组件，也保留这层结构。
- 旧章节时间轴迁移时保留公开调用 ID、自定义名称、输入／输出、全部轨道与节点。公开输出也通过普通写入输出节点返回调用方。
- 工作区的试播方式只改变预览环境，不决定剧本模块结构。

```text
@章节进入演出文字版：标题=第一章，副标题=归途，时长=2.5
@独立演出：章节进入
旁白：故事从这里开始。
```

## 旧指令处理

从正常文本解析、补全、封装入口和创建菜单中移除 `@章节标题`、`@章节背景`、`@章节题图`、`@章节配乐`、`@章节动效`、`@章节演出`。

旧工程加载时转换旧章节内容和隐式模块边界，写入新的显式语法标记。迁移保留原有内容、素材、播放设置、剧情身份与连接以及周边未应用草稿；再次加载不会重复迁移。无效旧数据报错，不覆盖原文件。兼容的数据类型用于读取既有工程，不再作为新创作指令提供。内置示例、哀鸿模板及当前使用说明同步更新。

## 预览修复

已在桌面版复现：预览画面只有约 586 × 330 像素，播放结束的转场层却覆盖整个 1440 × 900 窗口。转场层本来不接收鼠标，所以出现遮住编辑器但点击穿透的现象。

原因是原外层使用 `display: contents`，没有形成实际定位区域，绝对定位的转场层扩展到窗口。现在画面和转场层共同放入有实际尺寸的定位容器，并限制溢出。宽窄窗口实际播放结束后，两者的边界一致。

另修复参数跨蓝图传入时间轴后的用途追踪，素材选择与校验会继续沿组件连线判断图片、配乐和字体等实际类型。

# 编辑器界面简化（2026-10-03）

开发版已按“常用操作直接可见，说明和详细设置按需展开”整理多个工作区。UI 交互预览仍通过设计/事件图顶部的“预览窗口”独立打开，草稿、当前页面和界面方案继续同步。

## 本轮改动

| 界面 | 现在的入口与布局 |
|---|---|
| 界面设计 | “当前页面”下拉替代整排页面按钮；位置和尺寸集中排列；文字、点击行为和主要样式直接编辑；事件绑定、按钮皮肤和状态颜色分组展开 |
| 界面事件图 | 点击、值改变和文字提交保持直接入口；悬停、移出、按下和松开放入“更多按钮事件”；事件列表仍可直接定位已有事件 |
| 蓝图工作区 | 顶部统一选择和新建蓝图，移除内部重复的选择/新建入口；用户节点、示例、节点添加、时间轴和连线工具仍可使用 |
| 蓝图与剧情连线 | 连线点击范围保持固定屏幕宽度，绘图边界随实际曲线更新；缩小后仍可点选、断开和拖动改接 |
| 剧本 | 导入与导出集中到“文本文件”；支持 Enter 打开、Tab 访问、Escape 关闭并回到菜单入口，点击外部也会收起 |
| 素材 | 搜索、导入和视图切换直接可用；分类、类型和排序集中到“筛选与排序”；收起后仍显示当前筛选，可一键清除 |
| 角色 | 名称、姓名颜色、默认表情与表情列表优先；构图和站位预设默认收起，继承与蓝图集中分组；已有继承或绑定时显示相应设置 |
| 参数集 | 名称、类型和初始值直接编辑；参数集名称/用途、分组/存储与用法分别展开 |
| 作品与试玩设置 | 作品入口说明按需展开；测试初始状态默认收起，已有覆盖值时展开并显示调整项数；试玩方式、起点和开始试玩直接可用 |
| 共用属性表单 | 字段说明通过标签旁的说明按钮展开；控件仍有对应标签，说明按钮与控件分开操作 |

## 实际验收

类型检查、前端构建、桌面构建及 **681 项核心测试全部通过**，日志为 `artifacts/ui-simplicity-{types,build,all-tests}.log`。构建与核心测试已在最后的连线点击修复后重新执行。

- 文本文件菜单的键盘、关闭与导出入口。

- 修改草稿、撤销重做、独立预览同步、页面往返、显式保存。

- 素材实际筛选、排序提示与清除；角色构图和站位编辑。
- 参数名称/初始值/跨存档存储编辑，测试覆盖值与初始值区分，工程保存重开。

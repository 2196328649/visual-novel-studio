# 页面设置

界面右侧现在按编辑对象分成「组件设置」和「页面设置」。选择控件时编辑控件；取消选择或切换页面时显示当前页面设置。也可以直接点击标签切换，不必清除已有选择。

## 入口与作用范围

- **页面设置**：当前页面的默认外观、页面行为、输入与结果、页面状态、参数联动和页面事件。
- **组件设置**：单个控件的文字、素材、位置、独立样式与点击行为。多选时，右侧只编辑最后选中项；布局工具作用于全部所选控件。
- **作品设置 → 全局界面**：所有页面共用的主题、玩家初始设置、标题音乐、章节进场与对白框。页面设置底部也有直达入口。
- **顶部「…」→ 恢复面板布局**：只恢复编辑器面板的位置和尺寸，不改变页面、控件、微调步长、选择、草稿、撤销记录或其他工作区布局。

在界面工作区打开全局界面设置，修改仍加入界面草稿；「完成」仅关闭设置窗口，「保存界面」才写入工程。切换页面不会丢弃草稿或反复询问保存，离开界面工作区仍会提示保存或放弃。

## 常用页面与更多内置页面

顶部页面下拉框保留标题、对话、选项、存读档、设置、对话历史、确认对话框、画廊、音乐室、语音收藏、剧情流程图和自定义页面。可选页面配置了当前方案的固定入口后，也会出现在这里。

下拉框末项或右侧「更多内置页面」按钮可打开页面库：

- 暂停菜单、章节选择、角色音量、制作人员、虚拟键盘、游戏结束等备用页在这里编辑。浏览只切换编辑对象；当前选中的备用页会留在下拉框中，切换设计／事件图不跳页。
- 已停用页面显示「启用并编辑」。启用保留原控件、外观、事件和引用，加入界面草稿，可以撤销；保存后才写入工程。
- 「章节演出」按项目实际资源打开对应时间轴；已在剧情中使用的演出排在前面，改名不影响入口。若蓝图仅包装一条时间轴，会直接进入子时间轴并保留返回蓝图入口。
- 「旧版章节布局」保留兼容编辑入口，用于旧调用和新演出的初始生成。修改它不会同步到已经生成的章节时间轴。全局界面中的同类设置也已明确标为「旧版章节默认配置」。

原「消息框」改称「确认对话框」，指退出、覆盖存档等操作使用的确定／取消界面。工程中的页面标识保持原值。

页面设置顶部显示用途摘要，点击可看「打开位置」和「引用与其他方案」。清单包含系统菜单、Esc／右键、各方案按钮、剧情、场景、流程和页面事件；按蓝图执行连线追踪普通调用、宏和后台任务，未连接节点及跨页状态读写只列为引用。未知数据驱动的目标标为动态调用，不推断为未使用。这是已配置入口的清单，不保证每个条件分支在实际游戏中都会执行。

停用页面的系统菜单入口会隐藏，保留的自制按钮绑定显示停用状态，预演与游戏中不再响应。Esc 的目标不可用时依次尝试存档、设置、暂停菜单；全部不可用时不打开菜单。对白、选项、确认和输入等引擎必需界面保留默认内容，避免停用自制布局后无法继续游戏。

## 默认外观

每页可以独立设置默认字号、文字色、强调色、字体与按钮悬停音效。控件没有独立覆盖时才沿用页面默认值，不会把页面值复制到每个控件里。

解析优先级：运行时临时覆盖 → 控件独立样式 → 当前方案的本页覆盖 → 继承方案的本页覆盖 → 基础页面覆盖 → 当前方案主题 → 全局主题。标准页面的外观按字段继承，不会因为修改文字色而丢失继承字号。自定义页面的外观存放在该页面自身，不与另一个自定义页面共用。

字段旁的「恢复继承」只移除该字段在当前页／方案的覆盖，其他字段保持不变。字体可明确选择「内置字体」，音效可明确选择「不播放」；这两种选择与「沿用上级」不同。单个按钮原有的静音设置仍然优先。

背景优先使用画布上的图片或色块控件。旧工程已有的页面背景保留，并在「已有页面背景」中调整。系统默认内容可以在「页面行为」中关闭；这不会移动或删除自制控件。自定义页面还可以选择是否阻止下层交互。

## 数据与蓝图

- **输入与结果**：打开页面时传入数据，正常完成时返回结果；取消不冒充正常完成。复用原有页面接口和类型检查。
- **页面状态**：当前选择、临时计数等本次打开的私有状态；页面关闭后释放，不增加全局参数。接口和状态的定义在该页面的各方案间共用，运行时的值属于各自页面实例。
- **参数联动**：直接引用参数集中的原参数驱动控件属性，也可新建参数并放入指定参数集。不会复制一套同名全局数据；仍可进入生成的蓝图添加条件或计算。
- **页面事件**：直达显示、请求关闭、关闭完成，以及创建／获得焦点／失去焦点事件。重复点击复用本页入口；新增节点只写入当前页面的当前方案，不悄悄修改继承或共用蓝图。

页面设置中的读／写按钮可以自动建立本页事件图并定位节点。关联图会标明「本页」或「继承 / 共用」。界面方案的跨页蓝图仍保留在顶部页面选项中，名称明确为「方案共用蓝图」。

默认外观统一用于设计画布、独立页面预览、蓝图的设计默认值／属性重置，以及生成的游戏。系统菜单也使用各自的页面字体和颜色，不会将上层页面的样式带回下层页面。系统控件仍保留原有的文字尺寸上限与自动适配规则。

# 时间轴编辑整理与操作修复

日期：2026-11-14。对应用户反馈：时间轴演出编辑界面复杂、混乱，操作不如剪映方便。

## 本轮实现

默认布局改为上方素材、预览、片段属性，下方通栏时间轴；时间轴放在上方时也占满一行，主动拖到左右侧时保留原四槽自定义布局。保留面板拖换、分隔条和恢复默认布局，不更换用户布局存储格式。

片段属性跟随选择显示。移除外层重复的“时间轴组件／片段”页签，在属性栏标题提供“时间轴设置”。视觉片段保留“基础／动画／可替换参数”；字体、字号、颜色、斜体、对齐、描边、阴影和裁切集中在基础页，动画页保留动画。共享静态文字字段用于普通对象与时间轴对象，逐项修改描边、阴影不会把其他受控字段的计算结果写回。

名称、开始／时长、轨道信息顺序统一；开始和时长同行，所在轨道默认折叠。组合内部也使用同样的名称、时间布局。字体与字号同行，文字样式按需展开。字号接受正整数，不再限制为12～300。音频只保留一套素材、时长、入点、音量、淡入淡出表单；游戏音量分类和可替换参数默认折叠。包含音频的子时间轴显示调用属性，避免误把其内部第一条音频当作外层可直接编辑的音频。

根时间轴支持一次复制、删除整个选区，复制后所有副本保持选中；多选拖动使用共同的时间／轨道位移，避让也按整组选区处理。方向键每次0.1秒、Shift加速到1秒，键盘精调不会被鼠标吸附距离抵消。拖动、左右裁切、轨道重排支持取消；Escape、失焦、pointercancel等不提交草稿。新增素材发生同轨避让后，播放头定位到实际新位置。

组合内部支持多选复制、删除及一次撤销，多选时显示集合操作，单选时编辑对应片段；拖动期间不执行复制、删除、方向键和Enter等结构修改。根时间轴和组合内统一用空格播放／暂停，文本输入和中文输入合成不拦截；中键平移保留。

根时间轴视频封面使用素材入点处的一帧，保持暂停，接近可见区才挂载媒体元素，离屏卸载；入点调整后更新封面。不再为每个轨道封面持续播放视频。尚未做位图缓存，组合内部视频封面未扩展此懒加载，未量化性能收益。

逐片段的时长采样只准备当前图及固定调用依赖，完整资源库仍供组合、角色、输入和来源解析使用；遇到间接调用保守退回原全库准备。依赖范围每次按当前工程计算，没有加入可能误用原位修改结果的全局缓存。完整预演仍全库准备一次，图层范围仍全库计算，本轮没有把这两项称为按依赖裁剪。

## 验收中发现的真实问题

- 根复制把新节点加入图后未接入执行链，导致“未连接的执行节点”而无法复制。现在先连入原执行尾部，再统一排轨；不放宽原图校验。
- 复制嵌套组合后，子属性引脚、固定覆盖值及输入连线未随新对象标识更新。现在按对象结构路径同步映射，保留公共参数和相对图层间距。
- 字体选择“默认字体”时旧固定覆盖仍残留。现在清除覆盖，公开参数恢复该字段声明的默认值，保留计算关联的只读保护。
- 简单子时间轴的两次同时调用会共用内部画面和音轨标识。播放准备为每个调用建立私有实例图，保留真实调用帧、参数、输出默认值和局部变量；作者资源与保存格式保持原样。采样、预览和编译使用相同调用路径，嵌套组合参数目标也同步更新。
- 播放实例标识与作者对象标识分离后，舞台拖动通过播放树的结构路径定位作者对象；不穿过组合资源边界修改其缓存子对象。源码映射仍指回作者节点。
- 普通蓝图里的命名显示对象保留原有替换／隐藏协议，包括通过参数把时长改成零的持续显示；真正登记在时间轴上的调用片段仍分别隔离，不能因为外层来自普通蓝图就共用对象。
- 调试轨迹、暂停位置、断点和子属性引脚指回作者图与节点；执行帧和参数存储仍使用各自的播放标识。交错播放的数据来源可定位到另一个作者图，合成等待和参数快照不会重复触发作者断点。
- 长字体名和音频名在属性栏内收缩并显示省略号，避免把同一行的字号或资源操作按钮挤出面板。
- 默认属性栏去掉文字内容的重复标签行，使字体／字号完整可见；音频参数提示只检查实际属性连线，普通执行连线不再误显示“已关联参数”。
- 内容不变而无关演出库增大时，逐片段采样反复为全库建立私有实例，使预演变慢。限定采样准备范围以消除这部分重复，保留原有执行、资源和诊断规则。
- 时间轴正在等待时读档，等待和音频已保存中途进度，视觉时钟却回到当前语句起点，造成约0.75秒回跳。现在为同一活动等待保存上下文中的视觉进度，等待与视觉使用本次轮询的同一事件时刻，普通绘制继续使用帧时刻。读档先恢复补偿再恢复过渡／媒体；普通回滚沿用可回滚的上下文，不执行读档补偿。记录绑定等待对象、所属上下文及深度，已结束或被替换的等待不应用旧记录，同档反复读取不累加。不修改引擎Context.runtime、不新增计时器。

私有实例展开按原父图最多65536个生成节点预检，超限明确报错，拒绝该图的准备；现有延迟交错播放4096节点和其他校验继续有效。静态预演本身的执行步数限制也继续有效。本轮不承诺旧版本任意存档续点迁移。

### 性能测量范围

`validation-main/sampling-performance.json` 是补修前的六组合成诊断：当前图固定24段文字或8个子调用，无关库图分别为1／8／24，每个库图有4个立即调用。每组独立Node进程，上限10秒，预热1次、采样3次，交替测当前时间轴模型和完整预演。24个无关库图时两种完整预演中位为1470.07／1170.62ms。此处是本轮补修前后的对照，不是与历史发布版本对比，也未使用真实作品或GUI。

复测脚本 `scripts/measure-timeline-sampling.ts` 按原诊断算法整理，校验源图／生成图及节点数、片段数、时长和动作数一致；原stdin脚本未保留，不声称两份脚本字节相同。全部6组通过，源码哈希不变，完整数据在`sampling-performance-after.json`。24个无关库图时，当前模型中位从302.35／89.39ms降至12.08／4.71ms，完整预演从1470.07／1170.62ms降至81.18／78.84ms。后者仍随全库布局计算增加，不能称常数时间。测量发生在编译／全量结束后、桌面前，未主动并行本轮其他负载；宿主其他程序负载未控制。

## 下一轮仍可改善

这轮重点整理现有入口和基础操作，以下剪辑能力尚未实现：

1. 在播放头处分割片段，以及局部区间循环预览。
2. 直接选时间轴上的菱形关键帧编辑缓动，属性轨道紧跟所属片段。
3. 组合内部像根时间轴一样整体拖动多选片段。
4. 大工程真实交互性能采样，评估素材缩略图缓存、属性面板更新和时间轴滚动。

前轮另有玩家图调用／返回连线易误读、字面`〖〗`局部样式往返丢失两项待办，本轮没有扩大范围处理。

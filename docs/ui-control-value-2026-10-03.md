# 从控件直接读写值（2026-10-03）

高级 UI 中，选中滑块、开关、选项或文字输入框后，现在显示“值来自”和“读取值 / 设置值”。拖入事件图也可选择“读取控件值 / 设置控件值”。这些入口创建现有的变量或玩家设置节点，保留绑定 ID、角色身份和正确的数据引脚类型，可继续接执行线和数据线。

例如：选择“应用”按钮添加点击事件，再选择音乐滑块添加“设置值”，填入 0.25。所有绑定音乐音量的控件都会同步更新。读取该滑块的值，可接到进度条的“进度”输入。位置、显示状态等仍由“设置属性”控制。

变量节点默认填入变量初始值，玩家设置默认填入工程的玩家默认设置。程序写入沿用原有语义，不额外触发用户输入事件。绑定失效时明确提示在设计中重新选择，不会自动改成另一个变量或角色。角色音量节点摘要显示指定角色；未指定角色时保留原有默认角色音量语义。

同时修正控件列表的类型标签，分别显示滑块、开关、选项、文字输入；事件入口允许换行，避免窄侧栏横向溢出。

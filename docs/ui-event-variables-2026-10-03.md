# 控件事件图：已有绑定与变量 · 2026-10-03

接续用户对 UE5 风格控件蓝图的要求。本轮重点是让已有工程中的点击逻辑可定位，并让作者在事件图内创建、读取和设置变量。

- 左侧选中按钮后按运行顺序显示点击根节点、旧 onClick 回调、主蓝图调用或预设动作。点击“OnClicked”优先定位已有图及入口，不再因为旧绑定形式不同而新建空图。缺失引用保留在列表中提示修复；预设动作使用中文名称，并可回到设计属性编辑。
- “添加独立点击事件”只在当前页面、当前方案拥有的图中添加节点，否则新建当前页面图，不修改被调用的共享流程。旧 action 与 events 字段保留，实际运行顺序不变。跨页面显式调用的图仍可见，过期 blueprintId（按钮已改为其他预设动作）不再被算作绑定。
- 在事件图中直接创建开关、数值或文字变量，设置初始值和所属参数集。变量使用现有工程参数体系：故事参数不持久化、游戏设置参数持久化。名称检查、类型检查和失败时不产生半成品均有覆盖。变量与图节点一起进入 UI 草稿，仍需显式保存。
- 将变量拖到画布后选择“读取变量”或“设置变量”。可将读取值连接到条件/计算和控件属性，写入节点通过执行引脚决定时机。
- 修复新建和编辑节点的值引脚未及时跟随类型的问题。读写变量、控件属性、输入输出及玩家设置在同一编辑提交中更新值引脚；新节点自动接线前也先确定类型。错误类型会拒绝接线，变更类型后原有不兼容连线保留供诊断，不自动改值。移除的引脚不遗留悬空连线。

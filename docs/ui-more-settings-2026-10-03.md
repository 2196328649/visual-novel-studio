# 自定义布局的“更多设置”预演（2026-10-03）

本轮关闭上一批标准设置预演留下的补充入口缺口。作者将设置页设为“全部自定义”，或用作者控件替换全部基础设置时，原生游戏仍会提供“更多设置”来收纳尚未放置的可见设置参数；此前设计画布只处理前一种情况，事件图预演两种情况都没有完整支持。

## 修正

- 设计画布、预演和原生生成共用基础设置替换判定。完全替换基础设置时，设计画布隐藏标准设置正文，显示实际存在的补充入口；标准布局的标题与导航仍保留。
- 完全自定义页面只增加右下角的临时入口，不添加标准设置正文或背景容器。入口置于作者组件之上，避免被整页面板遮挡；没有可见且未放置的参数时不显示入口。
- 点击后进入独立“更多设置”预演页，按设置参数集分组，排除已放置、隐藏和剧情参数；数值、开关、文字选项、自由文字使用同一份测试值。文字控件增加可见名称。
- 返回按钮、Escape、右键均先回到设置页。蓝图等待菜单时，返回设置不恢复后续节点，关闭整个菜单后才继续；参数值跨页保留。补充页面不触发作者设置页或方案的显示事件。
- 补充入口及控件只在预演中生成，不改变项目格式，也不写工程、UI 草稿或玩家资料。活动方案的继承控件和当前页草稿参与参数排除。

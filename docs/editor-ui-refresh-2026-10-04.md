# 编辑器整理与演出模块（2026-10-04）

本轮完整目标与验收要求：

- 删除旧 `@结局` 专用字幕功能及重复入口；新剧情只使用可编辑结局演出和返回标题。旧工程载入时迁移内容，运行与编辑层不再继续提供旧功能。
- 整理编辑器布局，重点改善时间轴工具、属性区及角色页；在调整组件、切换选中项和编辑属性时保持时间轴视口与播放位置。
- 说明章节标题／副标题与题图的用途，提供明确的文字／图片选择。
- 章节进入演出由普通、可分别编辑的基础对象和时间轴组成，用户可以修改背景、标题、粒子、消散和音乐等部分。
- 模块参数的覆盖复选框与参数放在同一行，删除重复的“本次单独设置／沿用默认”占位文字。

以上每项均需要当前源码和实际界面证据。完成前保持目标进行中；本文件记录全部范围，不以已完成的局部替代整项目标。

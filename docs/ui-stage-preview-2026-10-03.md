# 控件事件与时间轴演出协同预演

2026-10-03。开发版本已支持在“界面 → 事件图 → 交互预演”开启“按时间预演”，直接点击控件，检查时间轴画面、声音、后续控件操作的执行顺序。时间轴内部仍使用普通素材片段，事件图负责调用及接续行为。

## 行为

- 共用预演时钟：阻塞演出暂停当前执行流程，到期后从原位置继续；独立页面计时器继续运行。不等待的时间轴可以让后续控件动画与有限素材片段并行。
- 图片按片段起止显示，舞台置于 UI 页面下方。不透明页面背景会遮住舞台，与原生层级一致。
- 演出声音使用真实媒体，遵守素材截取偏移、片段长度、音量、淡入淡出及分类音量。计时暂停时声音暂停，继续时同步位置；逐步推进不播放声音。恢复测试值和关闭预演均停止媒体。
- 默认不计时时，遇到舞台动作会停止该执行流程并提示开启计时，避免提前修改等待后的控件。
- 演出完成可进入确认框，只有实际回答后才继续控件变化。预演状态不写入工程或 UI 草稿。
- 预演说明缩为主要操作提示，菜单返回、按键与舞台层级的详细说明折叠显示。

## 实现和修正

共享动作解释器可按需逐个让出舞台动作，默认的剧情/静态调用保持原模式；UI 预演保留解释器续体。绝对事件时间转换为既有画面与声音计划，去掉已计入时钟的等待，包含省略 `wait` 字段时的默认转场等待，避免重复累计。

真实对照发现并修正两个问题：音频片段的时钟原先只登记为 overlay，主菜单中没有推进/清理，现登记为 always-shown screen；SVG 素材原先以 `application/octet-stream` 返回，导致浏览器解码失败，现返回正确的图片类型。没有修改原作资源或已安装编辑器。

## 边界

这仍是编辑器内的局部交互预演。沿用 60 秒、256 次输入事件及执行预算上限，实时界面约每 100 毫秒更新。画面复用既有舞台采样器，本轮完整桌面与原生对照集中在有限图片/音频片段和控件动画，没有逐一重新验收全部角色、镜头、章节特效。标准菜单内置控件、小游戏和其他尚未支持行为仍需实际试玩。整体 goal、AI 全覆盖、原作资源歧义及其他核对表待办保持未完成；没有新增外部模型或原作窗口操作。

# 流程图、界面和参数集补齐记录

本轮已完成三块编辑功能的日常操作、引用导航、保存恢复及实际游戏验收。最终构建、类型检查、1733/1733 单测通过；8 项桌面专项覆盖 46 组操作，12 项游戏专项覆盖 83 个用例、568 条断言，均通过。结论限于下列覆盖，不代表任何工程和任意组合都没有问题。

## 参数与引用

- 参数名称在属性栏、右键菜单和界面联动新建入口共用校验；空白、重名和超长名称不写入工程，中文输入法候选回车不提前提交。Ctrl+S 先提交正在编辑的字段。
- 参数详情列出剧情、蓝图、界面条件与控件的直接引用。点击可定位；派生方案定位到拥有该定义的方案，不创建多余覆盖。尚未应用的剧本文本保持草稿状态。
- 删除前显示引用，可选同类型参数替换，或保留失效引用供诊断和修复。替换、删除、改类型均可单次撤销；参数类型变更保留引用并重置不兼容的初始值设置。替换不合并玩家数据。
- 文本参数使用稳定编号，改名只改引用操作数，保留普通台词、注释、赋值内容和未完成文本；删除后不会因重新解析旧名称而复活参数。复合条件与带引号、逗号、等号的赋值共用解析规则。
- 存储方式变更同步蓝图显式全局作用域，不修改页面或调用局部变量。游戏加载旧数据时，只重置与当前类型不兼容的值或已失效的素材，保留兼容值。

## 界面草稿与导航

- 主工程和未接受的界面草稿分开自动恢复；只修改界面也能恢复。未完成的控件绑定允许恢复和放弃，正式保存仍使用完整校验。
- 放弃草稿先串行更新恢复副本，再离开界面，避免旧自动保存稍晚完成而复活草稿。主工程已有的修改不随界面草稿一起丢失。
- 保存、另存、重新定位与原生关闭提示保留草稿语义。恢复后保留可保存／可放弃状态，不承诺恢复跨进程撤销历史。
- 可从参数或问题列表定位停用页面，查看和修复；保存不会隐式启用页面。启用仍是独立按钮。
- 流程图读档节点的双击和属性入口统一打开存读档设计页，并选中读档预览。
- 任务等待原先在剧本语句层不断轮询，能挤掉前一句台词的回滚记录；改为单条语句内等待，任务状态仍独立序列化，读档按剩余时间继续。原回滚与任务生命周期用例保留复验。
- 原生按钮失焦只对仍按下的按钮检查取消；鼠标按下先检查命中，未绑定的非悬停事件直接返回，属性读取避免创建大量临时回滚对象。没有保留跨事件的布局缓存，隐藏、禁用、遮挡与抓取仍读取当前状态。

## 参数控件的小尺寸排版

- 截图复核发现：参数开关和选项控件缩到约 76 像素高后，标题、原生按钮留白和内容合计超出控件高度，压到下一行。原先只验证布局数据与滚动的用例没有发现实际绘制重叠。
- `vn_parameter_control` 将标题与输入区按控件实际高度分配，约束内部字号和留白，并裁切外边界。文字输入保留原有焦点、提交、只读和最大长度行为。
- 较长的选项行可以横向滚动或拖动；滚动到边缘后将滚轮交给外层容器。无需横向滚动的短选项也不会拦住页面的上下滚动。
- 新验收测量实际渲染的标题／输入区边界，验证 200 个控件页面和 48 像素高的开关、选项、文字输入，实际点击滚动到最后一项，保存截图供人工复核。未通过增高测试控件规避问题。

## 范围与边界

文字计时优先规则、局部粗斜体三态仍待用户讨论，本轮不改变。真实工程“我的视觉小说1”只读；未提交、未打包、未发布。

界面草稿恢复不保留跨进程撤销历史；参数替换不合并玩家数据。改类型后的游戏保留兼容的旧值，不兼容值恢复新初始值。这些是已实现的行为边界，不是“所有旧数据自动转换”的承诺。

页面库验收中，约 300 项素材的隔离工程首次保存、整理路径耗时 29.8 秒；本轮没有优化这段首次保存耗时。按钮性能 profile 中，短点击的全页布局调用由 232 次降到 26 次，累计求解约 4.4 秒降到 0.39 秒；该数字含 profiler 开销，不能当作普通点击延迟。200 控件页最终记录为 2 次屏幕评估、2 次布局求解，累计求解 0.052 秒。此前记录的首次选行开销也不能据此视为消除。

## 中途失败与复核

- 首轮参数引用单测暴露未应用文本中的名称没有同步，已修复并保留 CRLF、台词／注释／赋值文字不误改的用例，最终全量通过。
- 通用任务初轮在防抖、取消、等待和回滚处失败。修复脚本语句级等待挤掉回滚记录的问题，并通过 profile 减少按钮事件的重复全页布局；原有任务时序断言未删除，最终 16 项全部通过。诊断用 `--case` 名称和部分运行计数的脚本错误另行保留，不能当作全量验收。
- 流程图前两轮旧定位器分别匹配了两个折叠标题、以及仍使用“默认界面”的旧名称；定位器按当前控件和“基础界面”修正，产品逻辑未因此更改。
- 页面库首轮保存中断与系统睡眠重合：Windows 电源事件记录睡眠 UTC `2026-11-05T20:48:26.570Z`、唤醒 `2026-11-06T00:48:35.223Z`。事件证据保存于总目录 `system-sleep-events.json`；唤醒后全量复验通过。
- 素材参数首轮功能断言通过，但截图早于图片加载。增加图片完成加载和实际可见检查后重跑，最终截图显示素材。
- 任务总步数保护首轮超时；诊断确认持续推进并触发上限，诊断代码先后出现用例名称和结束记录字段错误。最终在正式的原 90 秒门槛下完整复验通过，总步数保护用例 35.738 秒，没有以诊断模式的宽限替代正式验收。
- 布局首轮鼠标坐标用了 list 而 Ren'Py 要求 tuple，修正后功能断言通过；截图随后发现上述真实排版问题。新增小控件点击时，Ren'Py textbutton 的 ID 指向文字子对象，测试定位漏算父容器变换；改从真实按钮焦点区域取坐标、断言命中，再发送鼠标点击。临时 probe 的类型错误也保留在失败报告，最终脚本已移除 probe。
- 控件交互旧用例按 0～200 的旧刻度调用了目前使用 0～1 比例的文字速度滑条。改为半步 `0.0025`，保留舍入预期 2；增加中点 `0.5 → 101`，端点 `1 → 0（瞬显）`，最终完整通过。产品文字计时规则未改。

最终 200 控件、小控件、长选项截图均人工复核。此前仅数据和操作断言通过的截图不作为最终显示验收。

# AI 主动选择蓝图节点与连线（2026-10-03）

用户可让 AI 建立一组蓝图选择，再继续要求修改。新增 editorTargets 的 blueprintSelection 目标，明确包含 graphId、nodeIds、linkIds；两个数组都必填，都为空表示清空选择。可混选节点与线，也可只选线而不选端点。frame 默认定位所选内容，false 保留视角。既有选中上下文会把完成后的实际选择传给下一次请求。

目标按 ID 区分同名对象，去除重复 ID；任一节点或连线缺失、标识不唯一时整次拒绝，不留下部分选择。只改变编辑器选择与视角，不写工程或占用撤销记录。

## 工作区和草稿

- 普通蓝图可从其他工作区打开并选择。
- 拥有所属页面的 UI 事件图打开对应标准/自定义页面及界面方案。当前 UI 中操作、跨页及跨方案选择保留未保存草稿；方案选择用于编辑预览，不改变保存的默认方案。
- 在当前 UI 事件图内，可以沿真实时间轴调用路径进入尚未打开的子组件，直接查看并选择组件连线，再返回时间轴剪辑和事件图。普通时间轴同样可进入节点视图后返回剪辑视图，默认操作仍是普通片段编辑。
- 离开有草稿的 UI 前继续沿用保存/放弃/取消提示。取消保留草稿与现场选择。
- 成功结果来自实际挂载画布的完成回报，核对真实节点和连线选择。定位期间切换工作区会取消；超时或取消后的迟到回调不会重新应用选择。

无页面归属的旧共享图，从其他页面请求时使用普通蓝图工作区；如果已经在 UI 中打开该图，则保留当前 UI 编辑上下文。未在当前 UI 调用链上、也没有明确 UI 页面归属的时间轴使用普通工作区，避免猜测所属界面。

# AI 创作助手

在「作品设置 → AI 服务」或助手窗口右上角的「AI 服务设置」填写服务地址与 API 密钥，点击「获取模型列表」，选择模型后「保存并测试连接」。支持兼容 OpenAI Chat Completions 的服务；地址可以是服务提供的 API 根地址（例如 `https://api.openai.com/v1`），也可以是完整的 `/chat/completions` 地址。

模型列表使用当前填写的地址和密钥请求对应的 `/models` 接口，获取列表本身不会保存配置或发送工程。选择支持对话接口的模型；也可以直接输入模型 ID，服务没有模型列表接口时仍可手填。不支持 JSON 模式的服务可以选择「仅用提示约束 JSON」。两个窗口共用本机 AI 配置，保存后助手会更新模型名称。

桌面请求使用系统网络和代理设置，包括连接测试、模型列表和创作任务。

桌面版顶部的「AI 助手」打开独立窗口，可以拖到编辑器旁边或另一块屏幕、缩放及最小化。主编辑器仍可选择台词、修改文本、调整资源和查看预览。助手顶部显示当前工程、小章节和台词，处理范围可选择当前台词、当前小章节或全部台词，包含尚未保存的模块修改和文本草稿。再次点击入口会聚焦已有窗口；关闭助手不关闭工程。

助手提供「聊天」和「协助编辑」两种模式，共用输入框与会话记录。「聊天」用于讨论、解释与构思，支持流式显示回复；「协助编辑」沿用原来的创作与工程修改功能，先生成方案，再由用户审阅应用。可使用 Ctrl+Enter 发送；生成时可以继续写下一条草稿。

## 连续使用工具与核对结果

“协助编辑”统一使用工具循环。助手可根据每一步的实际结果，继续查工程、分页读附件、导入素材、绑定角色、导入或修改剧本、修改设置以及检查草稿；不再按“导入”“立绘”等关键词选一条固定流程后结束。例如可以一次要求两个角色分别换用图片与目录，再调整作品宽度。故事生成、场景配置、发言演出、表情初选和配音匹配仍可作为工具组合使用。

结束前会核对最终草稿，并逐项显示已核对、无需修改或未完成。完成状态需要实际工具或检查结果支持；仅导入图片不能证明角色绑定成功。模型对需求的理解仍可能有偏差，逐项核对和立绘前后对比用于应用前检查。可按角色切换表情，查看最终实际素材；缺少同名表情的替代提示随最终绑定更新。

组合修改生成一份方案，点击应用后可以整批撤销。没有实际修改时无需应用，查看页面或检查工程等按钮仍可使用。部分任务未完成时明确列出，已有修改可单独审阅。等待期间若修改工程或文本，需重新生成整批方案；避免旧方案覆盖新编辑。取消或任务失败不会应用草稿，已复制的素材文件可能留在资源目录，尚未登记到工程。

当前每次最多48轮、160次工具调用，每轮可顺序调用最多8个工具，每批工程操作最多200项。暂时的网关故障或超时会对当前模型回复重试一次，不重放已完成的工具。仍失败则报告错误并保留用户工程。支持兼容服务在单个工具JSON代码块前后附带说明的格式；多个含糊的代码块会要求模型修正。

## 历史会话与上下文

会话按工程 ID 隔离，保存在本机应用数据目录的 `ai-conversations/<工程 ID>/` 下，不写入游戏或工程资源。再次打开助手或重新启动编辑器，会恢复该工程上次使用的会话和文字草稿。复制工程文件且保留相同工程 ID 时仍视为同一个工程；聊天记录不会随工程文件自动同步到另一台电脑。

助手左侧常驻会话列表，直接显示「新建会话」、搜索框和之前的会话。点击任意会话即可查看全部记录并继续聊天，当前会话会高亮显示；列表按置顶、最近使用排序，并显示消息数量和内容预览。窄窗口中列表排在聊天区域上方，仍可直接选择。当前会话支持重命名、置顶、导出 Markdown 与删除；删除记录不撤销已应用的工程修改。消息支持复制、固定为早期上下文、编辑后重发，以及重新生成或失败重试。编辑、重试和重新生成会从对应用户消息创建分支，原会话保留。回复支持基本 Markdown、代码块和中文内容显示。

同一会话会携带经过限制的近期消息和固定消息；实际请求最多带上近期 40 条消息，近期正文共约 6 万字符、单条最多 1.2 万字符。更早内容会选取最多 40 条摘录（正文共约 1 万字符），优先保留已固定的消息，再保留开头和较近的早期消息。固定数量超过上限时优先较新的固定消息。摘录明确标记为不完整历史；未完成和已停止的 AI 回复不用于后续上下文。需要完全独立的上下文时点击「新建会话」。

历史记录保留修改建议的应用状态与操作结果。重新打开的历史建议只供查阅，需重新生成后再应用，以核对当前工程。记录不保存可直接再次执行的旧操作按钮。普通消息单独存储，不保存服务配置或 API 密钥。单个会话最多 2000 条消息、文件最大 24 MiB，超过上限会提示保存失败，此时应导出并新建会话。

附件正文不会随聊天记录保存。历史消息保留引用路径；重新打开或切换会话后，如需在新问题中再次引用，应重新添加附件。重试或编辑旧问题会重新读取该条消息原有的附件路径，文件已移动或删除时会提示错误。

## 缓存和用量

聊天记录与服务商提示缓存是两件事：助手通过每次请求携带历史消息提供上下文，并不依赖服务商“记住”上一轮。服务商缓存用于复用已处理的提示前缀，可能降低延迟和输入费用；缓存未命中不代表没有聊天上下文。助手会保持系统提示和聊天前缀的顺序稳定，把变化的工程参考数据放在后面，但不保证命中缓存。

每条成功回复显示服务商实际返回的输入、输出及缓存 token；创作任务的多次内部调用会合并统计。明确返回 0 时显示 0；没有缓存字段时显示「缓存用量未返回」，不推断为未命中。第三方兼容服务的支持范围和计费方式以其返回数据及说明为准。OpenAI 的规则参见[提示缓存文档](https://developers.openai.com/api/docs/guides/prompt-caching)。

聊天默认使用 SSE 流式响应并请求用量统计。若兼容服务不支持流式响应或 `stream_options`，在 AI 服务设置中关闭「聊天流式回复」即可使用普通请求；工程修改方案仍以完成后审阅为准。停止或中断时保留已收到的文字并标记未完成，服务商可能仍按实际处理量计费。

生成建议时工程不会改变。普通修改可逐项选择，点击「应用选中的修改」后，由主编辑器写入同一份撤销历史；可通过助手标题栏或主工具栏撤销。定位台词会在主编辑器中选中对应内容，助手保持打开。若等待回复期间修改了相关内容，旧建议会要求重新生成。长剧本通过工具分页读取，每页最多100项；模型可分批提出修改，表情初选工具每批16句。助手显示当前进度，可随时停止。表情批次遇到超时或回复过长时自动拆小，最多拆两次；短暂服务故障会重试当前批次一次。已完成批次在本次任务内保留，全部完成后再统一审阅。

表情建议只使用当前发言角色已有的表情，并附带前后文、发言人和顺序。专用表情请求仅发送这些内容，不携带无关素材、蓝图清单和编辑器手册。旁白和纯演出行不参与表情选择。自动导入工作流会为没有立绘的角色预留发言演出，并列出缺失角色；在「角色」页配置后即可显示，不会借用其他角色的图片。模型遗漏的表情使用该角色默认表情，并在方案中提示复核。应用建议保留已经添加的其他演出。

## 拖入参考文件

可以将多个文件或目录直接拖入助手窗口，也可点击「添加文件」或「引用目录」，最多保留 10 项。添加时只检查文件信息；点击「发送」才读取最新内容并发给已配置的 AI 服务。附件列表可以逐项移除，后续追问会继续引用保留的附件；切换工程会清空附件。提示词中直接写本机绝对路径时，先勾选「允许访问项目外文件」；助手会复核路径后读取文本，或列出目录中的受限文件清单。路径可含空格；包含逗号等标点时用引号或反引号包住完整路径。开关默认关闭，切换会话或工程时会重置；通过文件选择和拖放添加的附件可直接引用。

DOCX、TXT、Markdown 以及常见文本、代码、字幕和数据文件可引用正文，初始摘要每份最多3万字符、合计最多6万字符，截取时会明确标注；协助编辑时可继续按页读取余下内容。图片和音频不上传媒体内容；目录会提供相对文件名清单，不代表 AI 看过图片或听过音频。单份文本文件超过 32 MB 时会提示缩小文件。

例如拖入人物设定后输入「参考附件中的人物设定，修改当前场景对白」。拖入剧本后输入「导入这个附件并配置演出」，即可使用所选文件而无需手填绝对路径；完整导入读取整个 DOCX、TXT 或 Markdown 文件，不受参考摘录字数限制。导入仍需审阅并应用创作方案，且可一次撤销。拖入配音目录后可以要求按现有文本索引匹配配音。

## 一句话生成可玩框架

可以直接从创意开始，无需先准备剧本文件，例如：

```text
用现有的林翩翩和苏怜烟做一个雨后重逢的古风短篇，安排两个场景、一个两项选择、两个结局，配置背景、配乐、表情和左右站位；先生成可玩的整体框架。
```

助手会生成普通可编辑的场景、对白、选择和结局，使用工程里已有的背景、配乐与表情。立绘使用[角色站位预设](character-presets.md)，后续可统一调整位置和大小。方案显示场景、对白、选择、结局数量及安排；应用后可以在模块或文本编辑器改细节，再从作品设置导出 Windows 游戏。生成方案会替换当前剧情，保留角色、素材、界面与作品设置，可一次撤销。

生成时会检查入口、每个分支目标、结局可达性、角色表情归属和素材分类。发现连接或引用问题时自动尝试修复一次；仍不通过会报告问题，保持工程原状。没有现成立绘的新角色会保留角色与显示演出，并列出待补素材；不会借用其他人的立绘。

也可以继续要求：「为所有场景按内容配置合适的背景与配乐」，或「把某场景的背景改为某张图片，保留台词和角色演出」。背景和配乐写入场景入场演出；有明确单句切换要求时才添加到台词。

配音支持已有音频绑定及下述录音目录匹配。当前对话接口不生成录音、不识别音频内容；没有可靠录音时保留无配音，不会用音乐替代。

## 一句话导入并配置演出

例如：

```text
导入游戏剧本 "C:\Users\LiuXiangdong\Downloads\琼.第一回：归（崇祯五年）.docx"，并为每个角色台词添加显示立绘的演出，结合台词前后文初步选择已有表情。
```

助手只读取本次请求明确给出的绝对路径或所选附件，完整导入支持 DOCX、TXT 和 Markdown。导入器建立章节、角色、对白和流程；未提供结局指令的剧本以“未完待续”收尾。已有素材、角色立绘和界面继续使用，对白原文不由模型改写。

结果以创作方案展示实际台词、演出、表情和配音变动，列出变更明细与缺失素材。点击「应用创作方案」整体写入工程，可一次撤销；完整导入会替换当前剧情，须先选择“全部台词”范围。新建整体故事框架也遵循这一范围检查。生成期间若修改了工程或文本，需要重新生成方案。

可以要求“导入正文，按情节转折分成章节和小章节，保留原对白”。助手先导入，再读取并修改章节标题，不依赖正文原先已有标准标题。章节划分由当前模型判断，应用前检查章节名称与结构；也可明确要求追加到新章节，或仅更新台词。

只想改稿时，可要求“导入修订稿，仅更新台词并保留演出”。修订稿应携带稳定行标识或对应表，详见[文本导入导出](text-authoring.md)。

## 根据台词匹配目录配音

```text
根据台词寻找 "D:\游戏配音\第一章" 目录下的录音，为能可靠匹配的台词添加配音演出。
```

先保存工程。支持 OGG、OPUS、WAV、MP3、FLAC，读取文件名、同名 TXT/SRT/VTT 旁注和目录中的 `voices.json`、`voice-manifest.json` 或 `manifest.json`。编号文件可提供对照表：

```json
[
  {"file":"琼华/001.ogg","speaker":"琼华","text":"你终于回来了。"},
  {"file":"琼华/002.ogg","lineId":"line_example","text":"我们走吧。"}
]
```

唯一且明确的匹配直接采用；相近候选由当前模型核对，低置信度、不一致或多个同样匹配的版本不会自动绑定。原有配音默认保留，明确要求覆盖才会替换。只复制匹配到的文件，未匹配台词保持原状并给出数量。此功能不进行音频转写；只有编号且没有文本对照的文件，需要先补充索引。

切换工程会取消旧请求并加载对应工程的聊天记录；主编辑器关闭时助手一同关闭。已有开发版进程需要先保存工程、重新启动，才能加载新增的桌面接口。

对话请求只在用户发送时发出，可以随时停止。所选台词、邻近上下文、角色、表情、资源名称和近期对话会发送到配置的服务；配音匹配会发送候选文件名及文本索引，不上传音频。密钥保存在本机设置中，支持系统加密；不会写进工程、自动保存或生成的游戏。若系统无法安全保存密钥，可仅在当前会话使用。更换服务域名时需重新填写密钥。

普通建议可修改台词、表情、配音、蓝图、UI、参数集和工程结构，先审阅再应用。助手也能提供撤销、重做、检查、保存、试玩、导入素材、导出游戏及页面定位按钮；点击后由主编辑器完成原有流程，需要选择文件时仍会显示文件选择窗口。桌面工作流另支持上述本机文件导入及配音整理。实际试玩仍是检查分支和演出效果的入口。

可以要求“导入素材文件夹”或“导入骨骼动画”。文件夹导入保留子目录、自动归类并跳过重复内容。补齐立绘时，可引用目录，或勾选「允许访问项目外文件」后直接给出路径，再要求“为当前剧本中立绘缺失的角色补上立绘”。助手按角色名子目录或“角色_表情”文件名匹配当前处理范围内缺少立绘的角色，复用已导入的相同图片，优先选用“通常”等默认表情；已有立绘和台词演出会保留，无法可靠匹配的角色会列在方案中。明确要求显示角色时才添加台词演出。素材遵循工程当前的复制或引用设置；复制素材在准备方案时写入资源目录，点击应用后登记角色和资源，撤销恢复登记与绑定，源文件不会修改。骨骼动画需选择Spine 4.2 JSON（或内含JSON的.bytes）、atlas和对应图片。重复导入同一骨骼不会覆盖已有名称。界面有未保存草稿时先保存或放弃再导入。

要更换已有角色的立绘，可以在一次请求中分别指定附件来源，例如：“把方知宥的立绘换成附件图片 2.png，琼华使用附件琼华文件夹中的立绘。”单张图片可替换该角色的图片，也可明确只更换某个表情。角色文件夹按表情名称匹配并增加新表情；原表情找不到同名图时暂用新目录的“通常”图片，并在方案中逐项提示。原表情编号、台词和演出引用保留；更换继承角色不会改动其父角色或其他角色。此功能仍先生成可审阅方案，应用后可整批撤销。

创作方案的“检查范围”表示读取了多少句台词，“台词修改”只统计实际新增、删除、改写或更换发言人的台词。仅更换角色图片时，检查范围可以是 227 句，台词修改应为 0 句；立绘更新、角色演出、表情初选和配音分别统计。

可以要求“导出完整脚本”“导出纯对白”或“导出对白修订稿”，点击相应按钮后选择TXT保存位置。纯对白和修订稿会同时生成对应表，便于以后回填。导出使用当前编辑内容，工程仍保留未保存状态。选择“导入文本…”后先选择文件，再核对完整替换或仅更新台词的预览，点击应用后才修改工程；可以取消或整批撤销。界面有未保存草稿时，先保存或放弃再导入文本。

可以要求“打开当前组件的高级UI蓝图”或定位指定素材。素材会在所属文件夹选中，遮挡它的搜索和筛选会清除；普通与高级UI切换保留草稿。离开未保存的UI去定位素材时，会先询问保存、不保存或取消。

在普通蓝图或高级UI的节点蓝图中，可以要求“自动排列当前蓝图”“显示全部蓝图节点”“收起/展开节点参数”，或打开连线列表、输入与输出、节点属性。按钮作用于点击时打开的当前图，时间轴视图不能执行这些动作。自动排列修改节点位置，可撤销；计算期间改图或切换后会取消过期结果。高级UI内的排列属于界面草稿，需要保存界面。取景、折叠与属性页切换不改工程内容。

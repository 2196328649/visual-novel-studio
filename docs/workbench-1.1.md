# 1.1 工作台与剧情示例

更新日期：2026-09-12（北京时间）。本轮改善蓝图连线操作、编辑器工作区与资源组织，并将哀鸿模板扩展为两章、六场景、三个结局的可编辑短篇示例。

## 蓝图与工作区

- 剧情流程和节点编程共用连线选择：点击区域保持 28 屏幕像素，缩小画布后仍容易命中；选中时金色高亮，浮动按钮断开，右侧列表显示两端节点与引脚。
- 拖动端点可以改接。类型不匹配或形成循环时保留原线；Delete 删除与 Ctrl+Z 撤销不会误删未选中的节点。
- 节点库默认收起，右键或空格调出搜索；方向键和 Enter 添加节点，采用鼠标所在位置。支持自动排列、双击聚焦、收起属性与项目导航。
- 底部资源管理器使用 Ctrl+空格展开或收起，上边缘可拖动调整高度。搜索、类型筛选、缩略图/列表、预览、收藏和项目文件夹便于管理内容。
- Ctrl/Shift 多选后可批量移动；双击打开资源或蓝图，将图片、音频、角色、状态、场景与蓝图拖入画布可创建相应节点。

资源文件夹、收藏和归类保存在工程中。移动文件夹和改显示名称不改变素材的物理路径与稳定引用；删除文件夹会把其内容移到上级。详细用法见 [中文节点编程](blueprint-authoring.md)。

## 哀鸿模板

通过“新建工程 → 哀鸿模板 · 两章与三个结局”创建独立作品。模板包含 30 个剧情节点，8 张原作背景、4 首原作音乐、5 张新增剧情蓝图，并沿用标题骨骼动画、玩家设置、存读档和可编辑界面。

第一章“酒醒城破”与第二章“方院抉择”节选改编原文；“灯火暂安”“惊梦未醒”是新写的短篇演示结局，“远舟”节选原作结局并通过时间跳跃衔接。状态影响路线，所有结局均可达。具体选择顺序及原文范围见 [哀鸿剧情示例](aihong-story-sample.md)。

# 玩家设置与确认框

这些功能通过界面组件和中文蓝图配置，试玩与导出使用相同的数据。玩家调整过的选项独立于剧情存档保存，读档不会把音量、显示模式或文字速度改回旧值。

## 制作设置页

进入“界面 → 设置”。“标准组件”可以添加文字速度、自动播放间隔、总音量、音乐、音效、环境音、语音、角色单独音量和对话框不透明度滑条。右侧“玩家设置”决定滑条控制哪一项。

在“滑条外观”选择底图、填充图、滑轨高度和滑块大小。“滑块状态图片”可分别设置普通、悬停、按住、选中和禁用图片；不配置图片时使用默认外观。已有独立文字标签时可关闭“显示滑条标题”。

“标准组件 → 设置下拉菜单”适合窗口分辨率，也能提供开关或数值选项。每一项分别填写玩家看到的文字和实际设置值，可配置箭头、面板底图和选项状态图片。开启全屏时，窗口分辨率选择会暂时禁用。

添加普通按钮，将“点击行为”设为“设置玩家选项”，即可制作全屏／窗口、已读／全部跳过、语音停止方式等选择按钮。选择具体设置和值后，按钮会自动显示是否选中；可以为其配置选中图片。

若要完全使用自己布置的组件，将“页面布局”改为“全部自定义”，并添加返回按钮。默认布局也提供标准设置，可逐项替换。

## 角色音量与对话框透明度

在“角色音量”页添加“角色单独音量”滑条，然后选择“配音角色”。留空控制旁白和未指定角色的配音。对白应同时设置说话人和音频素材，滑条才会影响该角色实际播放的配音。普通设置页可放置“角色音量”按钮，进入这张页面；角色音量页的“返回”按钮回到设置页。

在“对话”页选中底图，开启“跟随玩家对话框透明度”。玩家调节透明度时，这些底图和装饰会随之变化；对白文字通常保持该开关关闭。

“播放音效”蓝图节点可将播放通道设为“环境音”，并选择是否循环。使用“停止音乐”节点，将“停止通道”设为“环境音”，即可结束播放。环境音量滑条只调节这个通道。

## 初始设置和恢复默认

右侧展开“玩家初始设置”，配置作品第一次启动时的值。音量和不透明度使用 0～1；文字速度是每秒字数，0 表示立即显示全部文字。文字速度滑条的最右端同样表示立即显示。

初始值不会覆盖老玩家已经保存的设置。“恢复初始设置”按钮会先询问玩家，再恢复作者配置的值；取消则保留当前设置。音量为 0、关闭的开关和角色独立音量都会正确保留。

## 用蓝图询问玩家

1. 在“界面 → 消息框”点击“创建确认框布局”。它会创建普通背景、确认提示文字和两个按钮，可以继续移动、换图片或修改字体。
2. 确认提示文字的“文字内容”应为“确认提示”。两个按钮分别选择“确定”和“取消”行为。
3. 在“蓝图”中新建逻辑蓝图，添加“显示确认框”节点，填写提示文字。
4. 将“确定”和“取消”两个出口接到各自流程。界面按钮选择“执行蓝图”，再选择这张蓝图。

这张消息框页也用于退出、返回标题、覆盖／删除存档和恢复初始设置。提示会随操作变化，无需分别绘制多张确认页。页面若缺少动态提示或任意一个响应按钮，导出前会提示补齐。

“读取玩家选项”可以将当前值传入计算、条件或用户节点；“设置玩家选项”修改同一份设置。参数类型随选项同步：开关使用是／否，音量使用数值，窗口分辨率从可用值中选择。数据线输入错误类型或越界值时会给出运行错误。

## 哀鸿示例

模板使用原始滑条、按钮、字体和 `UI_MessageBox` 预制体的素材及布局，全部保存为普通可编辑组件。设置页和角色音量页可以作为制作自己作品的参考。

模板的演示内容只有中文，语言切换箭头因此保持禁用；它们没有被当作已经实现的多语言功能。原作完整剧情、解锁规则及逐页运行画面对照仍是后续工作。原素材位置、恢复依据和差异见 `aihong-ui-mapping.md`。

# 玩家设置与确认框

这些功能通过界面组件和中文蓝图配置，试玩与导出使用相同的数据。内置玩家选项独立于剧情存档保存，读档不会把音量、显示模式或文字速度改回旧值。自定义参数是通用变量，每项可单独选择保存和恢复行为，供剧情、蓝图和界面共同使用。

## 制作设置页

进入“界面 → 设置”。“标准组件”可以添加文字速度、自动播放间隔、总音量、音乐、音效、环境音、语音、角色单独音量和对话框不透明度滑条。右侧“玩家设置”决定滑条控制哪一项。

在“滑条外观”选择底图、填充图、滑轨高度和滑块大小。“滑块状态图片”可分别设置普通、悬停、按住、选中和禁用图片；不配置图片时使用默认外观。已有独立文字标签时可关闭“显示滑条标题”。

“标准组件 → 设置下拉菜单”适合窗口分辨率，也能提供开关或数值选项。每一项分别填写玩家看到的文字和实际设置值，可配置箭头、面板底图和选项状态图片。开启全屏时，窗口分辨率选择会暂时禁用。

添加普通按钮，将“点击行为”设为“设置玩家选项”，即可制作全屏／窗口、已读／全部跳过、语音停止方式等选择按钮。选择具体设置和值后，按钮会自动显示是否选中；可以为其配置选中图片。

若要完全使用自己布置的组件，将“页面布局”改为“全部自定义”，并添加返回按钮。默认布局也提供标准设置，可逐项替换。

## 调整内置设置（范围、名称、是否显示）

进入“参数集 → 游戏设置”。13 项内置设置和你自己加的参数列在同一张表里，点一行就能在右侧调整。内置设置不能删除，类型也不能改，其余都能调：

- **显示名称**：设置菜单、“添加组件”和蓝图里显示的名称，留空用默认名称。
- **初始值**：玩家第一次打开游戏和“恢复初始设置”时的值。
- **显示在默认设置菜单**：关闭后这项不再出现在默认设置页。关闭“全屏显示”会隐藏“显示”一行，“跳过未读内容”对应“跳过范围”，“角色单独音量”对应“角色音量”按钮，“窗口分辨率”“语音持续到下一段配音”对应各自的选择组。初始值、蓝图和你放在界面上的控件仍然有效。
- **滑条范围**：最小值、最大值和步长，例如把文字速度改成 10～500。音量和不透明度按百分比填写。
- **单位或显示方式**：文字速度、自动播放间隔可改单位；音量和不透明度可选百分比或小数。

只拦截会出错的值：文字速度和自动播放间隔不能小于 0（上限不限），音量和不透明度必须在 0～100% 之间，最大值要大于最小值，步长要大于 0。填错时面板会说明原因，并保留原值。把最小值填到最大值以上时，最大值会跟着移动，所以可以按任意顺序填写新范围。范围变化后，初始值会自动留在范围内。“恢复这一项的默认设置”可撤销对这一项的所有调整。

玩家本机已经存的值如果超出了新的范围，下次启动游戏时会调整到范围内。文字速度的“立即显示”（0）只在范围从 0 开始时保留，此时滑条最右端表示立即显示。蓝图“设置玩家选项”和按钮不受滑条范围限制，只受上面的引擎限制。放在界面上的滑条默认使用这里的范围，也可以在组件上单独收窄。

## 数值参数的显示方式

自定义数值参数在“界面控件（可选）”里可选显示方式：**数值**可加单位（如“点”“枚”）；**百分比**表示数值按 0～1 保存，编辑器里按 0～100% 输入和显示。参数表的“初始值”一列按这个格式显示。目前游戏内的滑条不显示具体数值，所以这项设置只影响编辑器。

## 通用参数集

参数集列表只有“新建参数集”入口。先填写名称和新参数默认保存方式，提交后创建；取消不写入工程。每个组都能同时整理剧情数据、界面选项和专供蓝图使用的变量。组内的“新参数默认配置”只影响之后在此组创建的参数，移动、改名、复制或移除分组均保留已有参数的保存和恢复配置。

每个自定义参数上方的“保存方式”可选“随存档保存”或“保存在本机”。“恢复初始设置”默认折叠，单独决定玩家执行这项操作时是否将参数改回初始值。例如跨周目解锁可保存在本机且不参与恢复；本局临时选项可随存档保存并参与恢复。

自定义参数不会自动生成玩家设置界面。“更多设置”入口已移除。需要让玩家修改某项时，展开参数详情的“界面控件（可选）”，选择目标界面并点击“添加控件到…”；该页已有控件时可直接定位。目标可以是设置页、标题或自定义页面。素材参数通过控件属性关联或蓝图使用。内置13项玩家设置及作者已经放置的控件继续生效。

蓝图中的“本机变量”与“作品状态”决定保存范围，任意参数集均可选，创建默认不参与恢复。控件属性右键或参数关联面板中新建时，也能设置保存和恢复方式；改变分组保留表单已有选择，需要采用分组默认时可点明确的应用按钮。

## 角色音量与对话框透明度

在“角色音量”页添加“角色单独音量”滑条，然后选择“配音角色”。留空控制旁白和未指定角色的配音。对白应同时设置说话人和音频素材，滑条才会影响该角色实际播放的配音。普通设置页可放置“角色音量”按钮，进入这张页面；角色音量页的“返回”按钮回到设置页。

在“对话”页选中底图，开启“跟随玩家对话框透明度”。玩家调节透明度时，这些底图和装饰会随之变化；对白文字通常保持该开关关闭。

“播放音效”蓝图节点可将播放通道设为“环境音”，并选择是否循环。使用“停止音乐”节点，将“停止通道”设为“环境音”，即可结束播放。环境音量滑条只调节这个通道。

## 初始设置和恢复默认

在“参数集 → 游戏设置”或右侧“玩家初始设置”配置作品第一次启动时的值。“玩家初始设置”里音量和不透明度使用 0～1；文字速度是每秒字数，0 表示立即显示全部文字。文字速度滑条的最右端同样表示立即显示。

初始值不会覆盖老玩家已经保存的设置。“恢复初始设置”按钮会先询问玩家，再恢复作者配置的值；取消则保留当前设置。音量为 0、关闭的开关和角色独立音量都会正确保留。

自定义参数只有勾选“参与恢复初始设置”才参与这项操作，与保存方式和是否放置控件无关。旧工程尚未记录此开关的参数，继续采用旧分组的恢复规则；编辑器读取时不改写，移动参数时会保留已生效的规则。若动态界面范围使恢复值无效，会先拒绝整次恢复，保留变量和内置选项当前值。

## 用蓝图询问玩家

1. 在“界面 → 消息框”点击“创建确认框布局”。它会创建普通背景、确认提示文字和两个按钮，可以继续移动、换图片或修改字体。
2. 确认提示文字的“文字内容”应为“确认提示”。两个按钮分别选择“确定”和“取消”行为。
3. 在“蓝图”中新建逻辑蓝图，添加“显示确认框”节点，填写提示文字。
4. 将“确定”和“取消”两个出口接到各自流程。界面按钮选择“执行蓝图”，再选择这张蓝图。

这张消息框页也用于退出、返回标题、覆盖／删除存档和恢复初始设置。提示会随操作变化，无需分别绘制多张确认页。页面若缺少动态提示或任意一个响应按钮，导出前会提示补齐。

“读取玩家选项”可以将当前值传入计算、条件或用户节点；“设置玩家选项”修改同一份设置。参数类型随选项同步：开关使用是／否，音量使用数值，窗口分辨率从可用值中选择。数据线输入错误类型或越界值时会给出运行错误。

## 哀鸿示例

模板使用原始滑条、按钮、字体和 `UI_MessageBox` 预制体的素材及布局，全部保存为普通可编辑组件。设置页和角色音量页可以作为制作自己作品的参考。

模板的演示内容只有中文，语言切换箭头因此保持禁用；它们没有被当作已经实现的多语言功能。原作完整剧情、解锁规则及逐页运行画面对照仍是后续工作。原素材位置、恢复依据和差异见 `aihong-ui-mapping.md`。

# UI 事件图可读性与节点定位

用户希望高级 UI 能像 Widget Blueprint 一样，通过控件事件和连线控制界面，并明确指出此前界面难以理解。本轮针对已建立的事件图继续改善展示与导航。

## 本轮修改

点击左侧事件会选中并放大定位该节点。此前 `focus.request` 每次变化都调用整图 `fitView`，即使目标包含 `nodeId`，节点较多时仍会缩成整张图。现在等 React Flow 完成节点测量后处理一次定位请求；重复点击、跨图、跨页也定位到实际节点。工具栏增加“定位选中节点”，原有整图查看继续保留。编辑参数或增删其他节点不会重复触发旧定位请求。

控件操作摘要显示实际目标、属性和输入来源，例如“说明文字 · 显示 = 否”“说明文字 · 横向位置（画面比例） = 变量 · 展开位置”。命名动画显示名称、方向和循环来源。输入已接线时不会把失效的默认值当成当前输入显示。

已连接的数据引脚下面显示来源名称；详情中的来源可点击跳到上游节点。变量、图输入、常量、控件属性读取有具体描述，其他输出保留节点名和输出引脚名；缺失节点或输出明确标识。这里展示的是数据来源，不是求值后的游戏运行状态。连线列表也使用输出来源名称，便于区分多个同名“读取状态”节点。

格式化文字、随机值及页面操作节点在详情栏中也正确显示已接线参数，不再提供一个实际无效的默认值编辑框。上游节点修改后，目标节点的来源描述及时刷新；缓存仍复用未受影响的节点视图，移动节点不触发无关重建。

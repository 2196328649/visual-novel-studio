# 项目窗口、文本配色与参数编辑

## 使用入口

- 启动 `启动开发版.cmd` 后先进入项目窗口。可以创建空白项目、哀鸿模板或自制模板项目，也可以选择已有 `project.vns.json` 或最近项目。
- 文本编辑工具栏的「彩色标注」旁增加「文本配色设置」按钮。背景、普通文字、章节、指令、旁白、注释、选中背景及逐个发言人的颜色均可修改，带即时预览和恢复默认。配色保存在本机，不进入工程或导出的游戏；恢复默认后随编辑器主题调整。
- 进入参数集后，左侧选择参数，右侧编辑基本信息和存储方式。「界面控件（可选）」集中放置菜单显示、滑条范围、文本选项和设置控件绑定；剧情或蓝图读写参数不需要这些控件。

## 参数何时保留

| 操作 | 随存档保存 | 本地持久化 |
| --- | --- | --- |
| 新游戏 | 恢复初始值 | 保留本地已有值 |
| 读档 | 恢复该存档的值 | 不随旧存档回退 |
| 退出并重启游戏 | 读档继续；新游戏从初始值开始 | 保留本地已有值 |

目前没有独立的“每次启动清空且不进存档”模式。初始值是默认值，不是正在试玩中的实时值；持久化参数已经存在时，改变工程里的初始值不会覆盖玩家的数据。

参数集的用途决定新参数的默认存储方式，以及是否提供默认设置菜单。移动参数或改变分组用途不会再悄悄修改已有参数的存储方式。滑条范围只约束玩家通过控件调整的值，不限制剧情或蓝图赋值。

内置游戏设置提供滑条和数值输入，音量与不透明度同时显示百分比。编辑的是出厂默认值；玩家选择保存在本地。游戏的恢复默认设置会重置属于玩家设置的参数，普通剧情参数保持原值。

## 项目与恢复

新工程在指定父文件夹中建立独立文件夹并立即保存，同名文件夹不会被覆盖。最近项目保留最多 20 条，兼容原先仅保存一个最近路径的配置，显示不可用文件；移除记录不会删除工程。未保存的新工程提供恢复入口，打开其他工程不会清除该恢复副本。打开已有工程继续使用原有自动保存恢复机制。

# 按对白记录收藏语音（2026-10-03）

已修复不同对白共用同一音频时被合并收藏、只显示第一条台词的问题。历史页、独立 UI 预览窗口及导出的 Ren’Py 游戏现在按对白记录收藏，试听、选中和删除也按记录区分。原作只读材料确认其收藏对象为 VisitKey 日志；本次采用编辑器自己的稳定对白身份，不声称复用了原作键的编码格式。

## 身份与保留内容

新剧情对白使用 `line:${nodeId}:${lineId}`，同一行重复访问不增加重复收藏。收藏保存当时的完整台词、角色名、角色 ID 和音频素材 ID；作品后来修改台词或角色名、清空历史，收藏仍保留原文字。静默行、无有效音频的对白不生成可收藏的语音记录。

音频路径按当前素材 ID 解析。保留该素材而移动音频文件或移除原对白的语音绑定后，旧收藏仍可试听；此行为不表示被删除的素材或丢失文件能够凭空恢复。增益使用该条对白的角色，避免同文件不同角色沿用第一条的角色音量。

旧存档里的历史记录没有来源键时，为实际记录生成并保存独立身份，不按音频合并。已有资源收藏保持可用，与新对白收藏共用先后顺序；旧资源收藏原本没有保存的对白来源和文字不做推测恢复。重新收藏排到末尾，锁定收藏仍可确认移除。删除同文件的另一条记录继续当前试听，删除正在试听的记录才停止。

独立窗口增加“添加测试对白收藏”和“收藏全部对白”，原资源测试入口继续保留。预览测试值与真实玩家资料隔离，关闭窗口结束试听，不改写工程草稿或磁盘文件。

## 实现与实际检查

核心目录列表和对白列表分别由 `storyVoiceEntries` / `storyVoiceLogEntries` 提供，收藏快照保存在 `VoicePreviewState.logs`；媒体播放保留 `assetId`，选中与删除增加 `entryId`。编译器在实际有声对白执行时传递稳定来源键，Ren’Py 的历史回调捕获实际运行后的文字和角色名，新的快照存入 `persistent.vn_voice_collection`。标准与自定义历史/收藏控件共用这些记录。

实际剧情验收发现 Ren’Py 历史中的 `{` 已转义；直接复制会再次转义，现先去除文字标签并还原字面花括号，再由收藏控件转义输出。截图复查另发现小按钮“取消收藏”被挤成四行并溢出，已限制小按钮字号及内边距，按真实文字绘制高度验证完整显示。早期失败记录保留；驱动直接从剧情上下文执行 `Start` 的跳转错误也已改用实际剧情 `Jump` 路径验证重复访问。

# 图片变换、数值拖动与预览

背景音乐指令统一使用 `@背景音乐`。补全、插入面板、模块摘要及文本序列化已同步；旧 `@bgm` 不再作为指令识别。作者工程、内置哀鸿模板和示例中的调用已替换。

## 图片与舞台

`@显示图片` 默认「仅本句」。推进台词后按离场设置隐藏，独立演出中的图片随演出结束清理。需要跨句保留时选择「持续显示」；定时显示填写正时长。

图片变换统一使用位置 X/Y、旋转 Z 和缩放 X/Y，去掉重复的「尺寸＋整体缩放」。X 单独控制宽，Y 单独控制高；100% 以适配后的图片为基准，两个值都为 100% 时保留素材比例：

```text
@显示图片：题图，变换={"位置":[0.5,0.5],"缩放":[0.5,0.5],"旋转":0}
```

单帧图片在舞台上可拖动、通过四角分别调整两轴、通过上方把手旋转；按 Shift 拖动四角时等比缩放。静止状态下修改直接写回基础变换。文本中的变换与面板、舞台共用数据，保存后仍是 `@显示图片`。旧尺寸与单值缩放结构已从指令语法中移除，已用到的调用通过替换工具换成两轴缩放。

「替换过渡」控制仍在场上的同一对象 ID 换图时的效果，例如日间照片渐变成夜间照片。不同 ID 同时显示，单次显示使用入场与离场设置即可。

## 参数与预览

演出数字参数可拖动参数名调整，Shift 精调、Ctrl 加速、Esc 取消。拖动过程只更新局部预览，松开后统一同步剧本，并只产生一条撤销记录；数字输入在离开字段时提交。拖动遵守字段范围，输入文字仍允许暂未写完的数值；鼠标释放时补齐最终位移。

「角色」中的「构图与站位」只显示构图和站位，默认过渡移到单独的「角色过渡」页签。

剧本预览在未播放时采样本句动作完成后的画面，台词完整显示。播放中暂停后修改参数保留暂停时刻，停止后恢复完成画面。切换台词重新建立该句预览。

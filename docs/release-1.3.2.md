# 叙事工坊 1.3.2

2026-09-29，Windows x64。

修复导出游戏的覆盖存档、读档、删除存档、返回标题和退出确认仍显示英文的问题。默认菜单和原作模板的自定义确认界面现在使用中文提示，确认与取消行为保持一致。

自定义确认文字会按原有区域和字体调整字号，避免中文提示被截断；超长提示保留可读字号，并提供可拖动的滚动条。

本版继承 1.3.1 的亮白配色、资源浏览器、剧情流程节点锁定、悬停和燕书体标题修复。已有工程可以直接打开；以前导出的游戏需要用本版重新导出才能更新提示文字。

安装版和便携 ZIP 分别为 `release/Visual Novel Studio Setup 1.3.2.exe` 和 `release/Visual-Novel-Studio-1.3.2-portable-win-x64.zip`。1.3.1 发行文件保留。

原游戏窗口的直接目视对照仍受本机桌面捕获工具故障阻塞。原游戏资源数据、引擎截图和 Android 模拟器验收记录分别保留，不将它们等同于原游戏窗口检查。

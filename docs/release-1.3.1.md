# 叙事工坊 1.3.1

2026-09-29，Windows x64。

## 外观与剧情流程

修正亮白主题中发言人下拉框、演出标签、参数面板、段落属性和素材选择按钮残留的深色样式，角色名字会按底色保证可读性。资源浏览器的文件夹、卡片与预览面板也随主题配色。

修复游戏剧情流程图节点悬停时误换成“进入剧情”子按钮图片的问题，保留各类节点图片并应用原有明暗状态。流程图标题使用原游戏内附的喜鹊燕书体，去掉额外的“已读”“当前”标记和已读计数；未解锁节点只显示锁定图片。横纵滚动条加宽并从画面边缘内缩，支持拖动、缩放和定位。旧模板工程打开时修复仍使用旧默认样式的节点并补入字体，自定义图片和字体不覆盖。

## AI 文件引用

AI 助手支持拖入多个文件或目录，也可使用文件选择器。添加时只检查文件信息，发送时读取最新正文；附件可逐项移除，并保留供后续追问使用。切换工程会清空引用。参考文本支持 DOCX、TXT、Markdown 及常见代码、数据和字幕格式；图片与音频仅引用名称和路径。

拖入剧本后可以直接要求导入，无需手填绝对路径。完整导入读取整个文件，仍需审阅创作方案后应用，并可一次撤销。详见 [AI 助手](ai-assistant.md)。

## Android 导出

发行资源加入 ARM 32 位、ARM 64 位和 x86_64 的 Spine 动画库，使用 NDK r28c 编译并验证 16 KB 段对齐。打包编辑器时检查三种库的哈希，避免发行缺少动画库的安装包。

Android 的 Java 工具和 Gradle 使用系统代理，修复了编辑器可以下载工具、但首次打包下载 Gradle 超时的问题。工具与缓存仍保存在编辑器的私有数据目录；SDK 安装需要明确同意许可。

Android 导出将中文等非 ASCII 资源路径映射为稳定的包内文件名，修复 APK 已包含立绘却无法显示的问题。工程名称和资源名称不变，旧路径兼容入口供已有存档和导入脚本继续使用。

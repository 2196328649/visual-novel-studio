# AI 蓝图多选与连线修改（2026-10-03）

普通蓝图和 UI 控件事件图现在将实际选中的节点、连线分别传给 AI。助手显示选择数量；只选择连线不会把两端节点算入选择，同名节点按实际 ID 区分。独立窗口、请求服务和创作服务共用选择校验，修复新增选择字段导致助手窗口无法打开的问题。

首次上下文最多显示 100 个节点摘要和 100 条连线，保留各自总数和部分标记。新增 selectedBlueprint 只读分页，可读取本次请求的 nodes 或 links；默认每页 30 项、最多 100 项。选择 ID 固定于请求开始时，读取工程采用该请求当前暂存版本，已删除对象标为失效，不用其他对象替代。过大的节点返回字段目录，可缩小分页或通过已有 project 读取深入属性。数组上限与工程模型一致：512 个节点、2048 条连线。

修改继续使用现有可审阅的 editProject 建议及冲突校验，没有绕过确认应用或撤销历史。UI 修改保留在 UI 草稿中，支持撤销、重做、保存和放弃。

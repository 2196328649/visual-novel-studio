# 演出时间轴改为素材剪辑操作（2026-10-03）

本轮按用户最新方向修改：UI 蓝图负责控件事件和控制逻辑，演出时间轴作为蓝图可调用的组件，时间轴内部按片段编辑图片、文字和效果。原作 UI 验收以功能、主要布局和整体观感接近为准，不要求逐像素对应。

## 已实现

- 素材库显示“当前位置”和可点击路径，当前文件夹突出显示；文件夹采用完整宽度的金色文件夹图标与换行名称，素材采用缩略图，并以分区标题分开。
- 点击或拖入图片直接创建有起止时间的图片片段，默认完整显示；同一轨道连续添加时放进可用空位。图片到片段末尾即结束，不再默认插入会清空画面的背景切换指令。
- 片段属性优先显示开始、轨道、名称、显示时长、素材和画面变换。动画效果与调用参数折叠；外层蓝图仍可公开/覆盖素材、文字等输入。
- 同轨正时长片段不能重叠；移动与跨轨拖动寻找最近完整空位，右边缘裁剪停在下一片段处，核心写入再次检查。参数默认值或动画编辑造成重叠会拒绝整次修改。零时长演出指令是时间点；不同轨道允许并行。
- 上方视觉轨道覆盖下方，可用轨道名称旁上下箭头排序。预览和导出使用同一套层级分配；嵌套时间轴使用父轨道的连续层级范围，保留内部顺序。即时子调用和含内部延迟的展开调用均已验证。
- 时间轴属性的每个参数一行：名称、默认内容和垃圾桶；删除保留原默认内容，父调用引脚同步更新，可撤销。
- “预览台词与参数”改为“试播设置”，明确只影响临时试播。原“当前台词生命周期”实际表示角色和图片的出现/消失，已更名并说明；时间轴内去除预览下面重复的区间图，辅助“显示区间”默认关闭。
- 默认预览/时间轴比例调整为 60/40，时间轴区域至少 200 CSS px，1024 窗口可完整看到两条轨道。数字输入失焦时回到实际接受的值，避免被限制的时间仍以错误数字显示。

旧时间轴已重叠的片段会显示到独立轨道，保留原开始和结束时间；试播使用相同的显示轨道，下一次时间轴编辑把轨道分配写入工程。旧背景切换、角色和声音指令保留原有语义，位于“演出指令”入口。

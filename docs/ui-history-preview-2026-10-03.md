# 对话历史与收藏交互预演（2026-10-03）

此文保留首次实现的验收范围。最新入口已改为设计/事件图顶部的独立“预览窗口”，收藏与试听已按独立对白身份区分，详见[独立预览](ui-preview-window-2026-10-03.md)及[对白收藏](voice-dialogue-collection-2026-10-03.md)。下面按资源共用状态及内嵌预演的描述仅对应早期版本。

历史列表原先只有静态的重播/收藏图样。现在事件图“交互预演”中可以重播实际语音、收藏或取消收藏，并在语音收藏页看到同一份测试收藏。标准历史和标准语音收藏页也生成临时控件，不必先改成自定义布局。

## 行为

- 历史按记录显示，重复引用同一语音的两条记录仍分别保留；收藏和播放状态按资源 ID 共用。取消收藏不打断历史页当前的重播，无语音行没有播放/收藏按钮，静默行不进入示例历史。
- 按作者的 `historyLayout` 显示上下或姓名/语音/台词分栏，保留按钮皮肤、姓名宽度、字号和间距；长台词换行并滚动。标准布局使用姓名、台词、文字按钮的上下排列。
- 首次进入和切换示例记录时滚到最新一条；预演缩放或字体布局变化仍保持底部。用户滚回旧记录后，收藏或重播不强行改变滚动位置。
- “历史测试记录”可以选择最近 20 条示例对白、某个段落或空历史。段落最多保留末尾 250 条，与游戏历史容量一致。记录来自当前工程，明确不表示玩家实际走过的剧情路线，也不读取真实存档。
- 历史与语音收藏共用解锁/收藏测试数据。锁定语音不能重播或切换历史收藏；声音沿用主音量、语音音量和对应语音元数据的角色音量。自然结束清除播放标记，重复播放从头重播。
- 确认框覆盖历史页时继续试听并阻止底层输入。从历史切到收藏、从收藏回历史、离开页面、折叠预演或切换测试记录都会停止试听，收藏保留。页面 ID 和实例一起检查，覆盖蓝图菜单切换保留实例的情况。
- 标准历史和标准语音收藏的控件仅用于预演，避开已有 ID；作者集合替换正文，全自定义布局不加标准内容。未修改项目模型或游戏运行时。

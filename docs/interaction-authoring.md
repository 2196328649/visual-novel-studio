# 动态演出与互动

## 演出与复用效果

在剧本中选中一行对白，右侧“本行演出”可以添加背景、角色、音乐、音效、等待、角色动画、镜头运动、画面震动和复用效果。动作按列表顺序执行，可用箭头调整顺序。

“保存为效果”把当前行的动作组保存为中文名称的效果实例。“本行动作替换为效果调用”选中时，当前行改为引用新效果；取消选中则保留原动作。其他对白可以添加“演出效果”，文本中也可以调用：

```text
效果 入场镜头
旁白：她终于回到了这里。
```

文本指令菜单会插入带稳定引用的名称，避免同名效果或资源混淆。不要手动改动名称后的引用标记。带复杂动画或配音的对白仍可在文本页编辑，演出实例标记保留其演出数据。

点击属性栏顶部的星光图标进入“管理效果”，可以新建、重命名、修改动作或调整顺序。保存共享效果后，所有调用位置一同更新；修改支持撤销和重做。仍有引用时不能删除该效果，效果目标列表会排除造成循环调用的项。

## 角色动画与镜头

“角色动画”选择已显示的角色，再设置关键帧的横纵位置、缩放、旋转、不透明度和运动曲线。每个关键帧的“到达时长”是从前一状态到该帧所需的秒数，首帧也遵守这一规则。最多 32 帧。

“循环动画”会重复关键帧；循环时不能同时选择“完成动画后继续”。普通动画可以等待完成后再显示对白，也可以与对白同时播放。镜头运动作用于背景和人物层，包含位置、缩放、旋转和时长，不影响玩家菜单。

剧本的两种编辑模式共用右侧实时预览。“编辑舞台”显示并编辑所选对白的最终布局；“播放预览”可以重播演出。最终时序以“实时试玩”中的 Ren'Py 运行结果为准。

## 点击互动

在剧本或蓝图中添加“点击互动”节点，填写提示，并连接每个区域的“点击后前往”。选中该节点后，打开右侧预览的“编辑舞台”，可以拖动区域、拖动右下角调整尺寸，也可在属性面板填写百分比坐标。

- 区域坐标以整个画面的左上角为原点，宽高按画面百分比计算。
- “关联角色”使区域仅在该角色显示时可用；区域位置仍是画面坐标，不自动跟随人物。
- “满足条件时显示”可绑定状态条件；可关闭区域提示，让玩家自行探索。
- 超时秒数为 `0` 时不限时。启用超时时连接“超时后前往”，并为玩家连接“取消后前往”。

每个互动节点支持 1 至 64 个区域。文本指令菜单中的“互动实例”可复用已有配置，插入后在蓝图中检查其出口连接。

## 用蓝图制作小游戏

普通蓝图可以响应自定义页面中的按钮、按键和定时事件，并读写作品状态、修改 UI 组件属性、计算随机数及拼接文字。“打开自定义界面”支持等待返回结果和叠加显示，“关闭自定义界面”结束页面事件。玩法由节点连接决定，具体接法与可添加的“限时点亮”示例见 [蓝图交互](blueprint-authoring.md#用普通蓝图制作游戏和-ui-交互)。

镜头与震动也可同时播放：连接“事件开始 → 移动镜头（不等待）→ 画面震动（等待）”。两个时长相同时，播放结束再继续对白；不同长度可全部不等待，再追加较长时长的“等待”。

## 预设小游戏

“小游戏”节点提供两个模板，共用成功、失败、取消三个出口：

| 模板 | 可设置内容 | 失败条件 |
| --- | --- | --- |
| 密码锁 | 中文或英文密码、尝试次数、是否区分大小写 | 用尽尝试次数 |
| 限时点击 | 目标点击次数、限时秒数 | 倒计时结束时仍未完成 |

三个出口可以前往不同剧情，也可以把失败或取消连接回此前段落。重新进入小游戏会重置本轮尝试次数、点击数与倒计时。

## 菜单与存档

互动和小游戏中可打开存档、读档、设置等玩家菜单。打开菜单会暂停互动倒计时，返回游戏后继续。存档保存剩余尝试次数、输入内容、已完成点击数和剩余时间；读档从保存的进度继续。

## 已验证行为

真实 Ren'Py 运行与导出的 Windows 包内程序均通过 14 个用例、40 个断言，覆盖热点点击/超时/取消、中文密码、限时点击、存档恢复、菜单暂停计时与重新进入重置。

源码中的验证命令为 `pnpm exec tsx scripts/verify-interactions.ts --export`。完整报告保存在源码目录的 `artifacts/interaction-verification/2026-09-08T12-48-05.438Z/report.json`，安装版文档中的验收摘要见 `acceptance-report.md`。导出测试在开发目录外解压，检查包内没有作品测试脚本和存档，并确认测试未改动原 ZIP。示例只包含附带的授权素材与验收剧情。

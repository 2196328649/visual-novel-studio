# 叙事工坊 1.2.2

2026-09-27，Windows x64。安装入口：`release/Visual Novel Studio Setup 1.2.2.exe`。

## 角色显示范围与实例

“显示角色”增加两种范围：**仅本句**在这句台词结束后隐藏；**持续显示**跨台词、换背景保留，直到使用隐藏角色指令或手动改变显示范围。新添加的显示指令默认“仅本句”。旧指令保留原来的场景内行为，界面显示“场景内（原行为）”。纯演出行中的本句角色保留到下一句真正的对白结束。

在显示指令中设置实例 ID，例如 `hero_left`、`hero_right`。同一角色可以同时显示多个实例，舞台选择列表会显示各自的 ID。再次使用同一个 ID 会更新该实例；换表情时省略显示范围会沿用之前的范围。自动发言不会取消已有持续实例的范围。

```text
@显示角色：主角，普通，预设=左，显示范围=持续显示，实例ID=hero_left
@显示角色：主角，普通，预设=右，显示范围=持续显示，实例ID=hero_right
主角：画面中有两个可以独立控制的实例。
@隐藏角色：主角，实例ID=hero_left
主角：现在右边的实例还在。
```

上例使用工程中的实际角色、表情和预设名称。实例 ID 使用小写字母开头的字母、数字或下划线，最多 64 位；一个 ID 对应一个舞台实例。

显示、隐藏、动画、蓝图及文本补全均支持实例 ID。拖动或动画只改变选中的实例；站位预设仍可关联修改。存档、读档和回退会同时恢复角色画面与实例状态。

## 章节动画数据

本轮读取原游戏 `sharedassets0.assets` 的 `UI_ChapterTitle` 预制对象、ParticleSystem 和材质，核对 `GameAssembly.dll` 的 `UI_TitleAnimation.SetInfo` 及回调，并提取 Direct3D 着色器程序。来源、对象编号和 SHA256 记录在 `src/core/chapter-source.json`，分析产物位于 `artifacts/aihong-chapter-source/2026-09-26T18-36-36Z`。

原作时序是：标题移动 2 秒、停留 0.5 秒，再启动粒子和 2 秒消散；背景从黑色淡入 2 秒、停留 3 秒、淡出 2 秒。移动与淡化使用 OutQuad。模板章节已采用完整的 7 秒节奏；已有工程仍使用保存的时长，如需原作速度，将章节时长设为 7 秒。

新效果使用每秒 200 个、发射 1 秒的原始粒子参数，保留 5 秒寿命、1.5 倍模拟速度、尺寸范围和 X/Y 力场曲线。原始曲线按 Hermite 插值积分为位移。标题采用原着色器的梯度噪声与强度消散；粒子采用原着色器的柔边圆形透明度。其着色器不使用顶点透明度，因此预制对象中的透明度渐变仅留作来源记录。

编辑器与游戏使用同一数据和轨迹采样。Unity 内部随机种子与噪声实现没有直接移植，扰动使用相同强度、频率的确定性采样；随机粒子位置和细微扰动不保证逐帧一致。背景 Ripple 参数也已提取，本轮背景仍使用现有静态图片。

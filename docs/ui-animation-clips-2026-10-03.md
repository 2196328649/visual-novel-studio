# 命名控件动画与关键帧 · 2026-10-03

继续按用户提出的 UE5 Widget Blueprint 工作方式推进。现在可以在当前页面创建命名动画，用控件属性轨道编辑关键帧，然后在事件图中播放、停止或等待它。动画属于 UI 草稿，沿用显式保存、放弃和撤销重做。

## 使用流程

1. 打开“界面 → 事件图”，在左侧“动画”中选择“新建动画”。
2. 选择控件和属性，添加轨道。默认创建起点和末尾关键帧，保持控件设计值。
3. 移动播放头，添加关键帧；选中菱形后编辑时间、数值与到达该帧的缓动。也可拖动关键帧，用左右键移动 0.01 秒、Shift 加方向键移动 0.1 秒。
4. 返回事件图，把动画拖入画布，或点击该动画的“播放”“停止”。连接按钮 OnClicked → 播放界面动画 → 后续行为。
5. 双击播放/停止节点可重新编辑动画，返回后选中原调用节点。保存界面后，动画与事件图一起写入工程。

编辑器支持名称、总时长、多个属性轨道、多关键帧、播放/暂停、播放头取景、关键帧和轨道删除。轨道区默认占中部约 40%，预览完整缩放到可用空间；面板尺寸和交换采用独立布局偏好，不修改设计或事件图布局。关键帧表单按帧 ID 建立，防止快速新增帧时输入框沿用上一帧的本地草稿。

## 数据与播放语义

- `ui.animations` 保存动画定义；标准页面以 `pageId` 和 `uiInstanceId` 管理，自定义页面以页面 ID 管理。动画、轨道、关键帧都有稳定 ID。
- 支持位置、宽高、透明度和适用控件的进度。单个控件的同一属性只允许一条轨道；关键帧时间不可重复，不能超过总时长，透明度和进度使用 0–1。错误修改不会写入草稿，并显示原因。
- 每个关键帧的缓动控制“到达此帧”的区间。首帧晚于 0 秒时，从播放时的控件当前值开始过渡；末帧之后保持到动画总时长。
- `playUiAnimation` 的 `animationId` 引用动画，`wait` 决定是否等待全部仍在播放的轨道结束。动画无轨道或时长为 0 时立即完成。
- `stopUiAnimationPlayback` 停止仍属于该动画的轨道，`finish` 可选择保持当前值或到末帧。单属性动画或直接设置属性接管了某条轨道后，停止旧命名动画不会再影响新动画。
- 再次播放同一命名动画会重新开始。另一个按钮回调重启等待中的动画时，原等待按原生嵌套调用顺序，在替换回调返回后恢复。共享蓝图内部等待标识保持调用局部作用域。
- 运行时继续保存每条轨道的已播放时间，墙钟采样按播放标识及控件属性分开。预演与原生都支持多关键帧、多属性并行、停止和替换。

## 发现并修复的读档问题

原生首次验收发现：加载存档后，页面重建触发“页面显示”事件，再次启动命名动画。保存前位置约 0.357，读取后变成首帧 0.1；播放标识也从 6 变为 7。这不是存档时长精度问题。

页面显示事件现在经 `vn_run_ui_show` 执行，只在引擎的 `after_rollback` 页面恢复阶段跳过入口副作用。正常显示页面仍执行 OnShow，按钮、按键和定时事件不经过这个过滤。最终原生验收同时检查位置、播放标识和已播放时间，恢复误差限制为 0.03；读取后继续跨关键帧并到达末值。

最初失败证据为 `artifacts/ui-animation-clips-runtime/2026-10-02T17-00-57.585Z/runtime.log`；诊断记录包含保存前后状态，最后通过报告见下表。既有单属性动画和 UI 演出时间轴也重新做了原生回归。

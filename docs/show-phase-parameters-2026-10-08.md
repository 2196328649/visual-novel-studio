# 显示角色参数统一

文本编辑器的 `@显示角色` 参数定义漏用了旧的“转场／时长”，与演出面板中的入场、离场、表情切换设置不一致。现已从定义、补全和文本解析中删除这两个参数；旧命名参数和旧位置参数不再接受。

三阶段设置可独立写入文本，省略的阶段继续继承角色设置。普通 `@显示角色` 与仅填写表情的简写保持不变，默认离场仍为 0.5 秒渐变。舞台拖动新增显示动作时使用阶段设置，不再写回旧文本参数。文本说明和相关验收脚本已同步。

已扫描当前作者工程、哀鸿模板和示例工程，分别检查 118、26、4 条显示角色文本指令，均无旧参数，无需改写作者数据。

验证：944 项单元测试通过；桌面验收检查参数提示、点击填入阶段参数、应用并保存、重开后的阶段设置。开发版构建，不打包或安装。

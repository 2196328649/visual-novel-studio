# 事件图单左栏：实现与验收

日期：2026-11-12。对应用户批准的“目录＋详情”方案。

## 使用方式

事件图左侧上方为“我的界面”目录，下方为当前对象的唯一详情；右侧留给画布。目录只保留控件、事件、动画、页面输入与结果、变量和可复用模块的短成员行及新建入口。搜索同时筛选目录中的各类对象，筛选不会切换正在编辑的详情。

- 单击控件查看可用事件。已有事件显示“定位 →”，没有的显示“＋ 添加”；继承事件和另加当前页独立事件仍区分。
- 单击变量、页面输入或结果，在详情编辑定义、读取或设置。新建表单确认后才加入界面草稿，取消不留下空定义。作品／本机共享参数保留参数集里的受保护定义编辑入口。
- “本图设置”编辑图名称、调用输入／调用输出和引用位置；页面输入是打开页面时接收的数据，两者没有合并。
- 动画单击查看摘要，双击或点击“编辑关键帧”进入；可复用模块单击查看详情、双击进入，也可拖入画布创建调用。
- “属性关联”集中设置控件属性的默认、单向跟随或双向同步；旧自动联动的定位与转换保留。“页面设置”显示真实页面设置，其重复的成员定义与关联表单已去除。
- 目录与详情分别滚动。可拖动两条分隔线调宽、调高，或收起目录／整个左栏；分隔线支持方向键、Home／End和双击恢复尺寸。窄工作区暂用抽屉，保留平时的宽度偏好。

普通蓝图、界面设计、时间轴继续使用各自的布局。事件图内不新增实时预览或时间轴预设面板。

## 状态和实现

`UiEventSidebar` 将目录选择与画布选择分开，以稳定的对象 ID 路由至唯一 portal 容器。已访问表单通过 React Activity 保留局部草稿；页面／方案 session 内保存目录查询、详情选择、每图视口、各详情滚动与新建表单草稿，跨图切换不会把变量草稿迁到另一 owner。未保存的新建表单只存在于当前编辑会话，关闭应用不会持久保存未确认的输入。

`UiEventDirectory` 集中目录和控件详情，避免继续膨胀 `UiLogicEditor`；`UiEventWorkspace` 独立承担布局、折叠与滚动。旧底部绑定属性和旧 session 字段已移除。`BlueprintVariables` 和 `UiPageInterfaceEditor` 在事件图启用目录／详情分离，在普通工作区保留原有组件行为。

`uiLogic` 布局改为独立版本：`sidebarWidth`、`directoryRatio`、`sidebarCollapsed`、`directoryCollapsed`。保留原存储键，一次迁移旧四槽偏好，只转换一个有意义的侧栏宽度，不相加。AI 离线布局动作与恢复默认同步采用新契约，拒绝旧的左右交换或 right 尺寸动作。

实施及操作检查修正了：

1. Activity 恢复时无条件重置成员名称或属性关联内选中控件，造成未应用内容丢失。
2. 返回动画时重放旧节点定位请求，抢走目录正在查看的详情。
3. 极窄窗口的旧全局主工作区列位置，使左栏展开按钮落到可操作区之外。
4. 动画返回时底层画布重新启用，恢复保存的选区与视口。

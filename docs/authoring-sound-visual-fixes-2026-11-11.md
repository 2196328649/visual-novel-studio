## 打字音

共享文字演出面板明确区分三个操作：

- **沿用上级／预设**：一次删除本处 `typeSoundId`、`typeSoundEvery`、`typeSoundVolume`，恢复当前有效来源，其余文字设置和 `presetId` 保留。
- **无打字音（静音）**：保存既有 `typeSoundVolume: 0`；保留已选声音和节拍，便于后续恢复播放。素材选择器的“无打字音”同样执行静音，不再错误恢复角色声音。
- **播放打字音**：继续使用原声音，也可选择新声音；有效音量为正时保留，否则恢复上级／预设的正音量，没有正音量则设为 100%。避免旧声音 ID 配合 0 音量仍显示播放已开启。

面板显示当前有效声音、音量、静音、素材缺失或未设置的状态，声音来源按本处／实际预设名称／上级说明解析。旧工程声音 ID + 0 音量被识别为静音，没有本地覆盖但继承了静音时仍显示“沿用”，并明确当前静音。静音状态隐藏声音和节拍输入，可通过“播放打字音”恢复；瞬间显示时说明不播放打字音。读取和打开面板不迁移或补写旧数据。

规则位于 `src/core/text-presentation.ts` 的 `textTypeSoundMode` 与 `editTextTypeSound`；`src/renderer/TextPresentationEditor.tsx` 调用共同规则。未改 schema、文字合并、预览发声和运行时契约；后两者已有音量 0 静音能力。

## 图片／视频过渡

`src/renderer/VisualTransitionsEditor.tsx` 切换方式仅用 `value?.duration ?? .5` 初始化未设置的时长，已设零秒保留。数值展示使用既有 `visualTransitionSeconds`：未配置的普通阶段与显式“立即”都显示有效 0 秒，保留字段内记忆的旧时长，不在打开面板时补写。隐藏对象的“沿用显示时设置”没有此处可确定的秒数，显示空值与沿用提示。

# UI 独立预览窗口（2026-10-03）

用户希望 UI 蓝图界面更简洁，并把预览放到独立窗口。开发版已移除事件图内的交互预演，设计与事件图顶部统一提供“预览窗口”。参数绑定仍可展开编辑。

## 使用行为

桌面预览为可移动、缩放的非模态窗口，主编辑器继续可操作。重复点击只显示并聚焦已有窗口，最小化后可恢复。画面按实际可用宽高缩放，测试数据与说明默认收起。

预览跟随编辑器当前页面、界面方案和未保存的草稿，包括撤销。选择控件或重复显示同一工程不重新发送预览上下文，因此不暂停计时或打断试听。切换页面或方案重新建立对应的测试会话；声音、计时、菜单、确认框和测试数据继续使用现有交互实现。主窗口按键与预览按键隔离。

关闭预览结束该窗口的计时和声音；重新打开从当前编辑页面开始，临时测试数据重新初始化。同一编辑器进程内保留窗口位置和尺寸，显示缩放可产生少量像素取整差异。离开界面编辑、重载或关闭主窗口会关闭预览；删除最后一个自定义页面也会关闭预览，撤销后可重新打开。预演不会保存 UI 草稿或修改玩家资料。

浏览器编辑模式使用独立弹窗，通过同源消息和素材 URL 同步上下文。弹窗重载后恢复同步；被浏览器拦截时显示允许弹窗的提示。

## 实现

桌面控制器位于 `src/desktop/ui-preview-window.ts`，主编辑器负责打开和更新，预览 renderer 负责读取上下文；工程使用可接受未完成 UI 草稿的 schema 验证。`#ui-preview` 加载专用 renderer，不挂载主 App。`useUiPreviewWindow` 挂在 UiEditor，避免设计/事件图或页面子编辑器重建时关闭窗口；文档更新合并 100ms，并按内容去重。

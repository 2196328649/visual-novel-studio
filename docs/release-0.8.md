# 叙事工坊 v0.8（0.8.0）

发布日期：2026-10-08。本次安装版与便携版包含此前的 v0.8 功能，以及试玩逐字显示修复、章节演出提速和独立演出参数合并。

## 试玩演出与独立演出参数

- 角色进场、换人、离场以及舞台等待后，新台词从头逐字显示；保留上一句对白框时不再带入上一段过渡的计时。
- 章节进入演出复用文字和图片，缓存粒子运动中的不变数据，并按发射区域批量绘制粒子，减少重复排版、对象创建和绘制。
- 文字版章节右侧年代的数字与汉字呈轻微斜体；编辑器预览、原生试玩和散字粒子同步更新，已有生成预设自动补齐该字形设置。
- 播放设置合并到声明，例如 `@独立演出：章节进入，允许点击跳过=否，结束转场=纯色，淡出=0.5，停留=0，淡入=0.5`。支持参数补全、可视化修改、保存重开和旧工程转换。

用法和原生运行实测见[试玩演出修复记录](runtime-playback-2026-10-08.md)。

## 流程图框样式与界面子对象

- 标题新增「样式」参数，可在章节、小章节和段落之间复用命名样式，支持名称补全与重命名同步。哀鸿模板提供主线框、回忆框和结局框；在「界面」的流程图控件中管理样式。
- 调浅流程图文字的阴影与描边，导出游戏采用单独柔化的阴影，保持文字本体清晰。
- 界面组件增加可展开的父子层级与子对象列表。背景、文字和子按钮可挂到父级，随父级移动、缩放、隐藏和禁用；背景图片可继承悬停与按住状态。
- 支持保留画面位置的拖放改父级、完整子树复制／删除、撤销重做与保存重开。子按钮的鼠标操作和快捷键均遵守父级可见性及启用状态。

用法见[流程图框样式与界面子对象](flow-styles-ui-hierarchy-2026-10-08.md)。

## 章节编辑修正

- 清空后重写章节名称、整行替换章节声明时，保留该章节的身份及下属小章节，左侧目录同步显示新名称。
- 已有小章节放到明确声明的新章节下时，以文本中的归属为准，不再恢复到原章节。
- 在 `#章节(...)`、`#小章节(...)`、`#段落(...)` 的括号内提示「流程图」「显示名称」「样式」；「流程图」可继续选择「是／否」。支持中文括号与拼音筛选。
- 补全和参数按钮只修改括号中的对应字段；带引号的逗号、括号、冒号不会截断标题。输入尚未完成的括号时保留当前章节范围，完成后仍可折叠和从目录删除。

```text
#章节(流程图=是，显示名称="归"): 第一章
```

「显示名称」用于游戏中的流程图，编辑器左侧目录使用冒号后的章节名称。

## 演出与舞台编辑

- 背景音乐指令统一为 `@背景音乐`；补全、插入面板、模板和示例同步更新，旧 `@bgm` 不再识别。
- 演出数字参数可左右拖动参数名调整，Shift 精调、Ctrl 加速、Esc 取消，仍可直接输入数字。
- `@显示图片` 默认「仅本句」。一个「变换」结构包含位置 X/Y、旋转 Z 和缩放 X/Y，去掉重复的尺寸与整体缩放；两轴分别改变宽和高。舞台图片支持移动、四角调整两轴及旋转，按住 Shift 拖动四角可等比缩放。
- 拖动演出数值时直接刷新局部预览，松开后统一写回剧本并生成一条撤销记录；数字输入在离开字段时提交，Esc 可以取消。
- 预览默认显示演出完成的画面；播放中途暂停后修改参数保留原时刻，停止后回到完成画面。模块与文本模式一致。
- 角色的默认过渡移到「角色过渡」页签，「构图与站位」集中调整位置和构图。
- `@显示角色` 省略默认参数，只有表情覆盖时保留表情；跟随发言人的角色默认仅本句显示，自动离场采用 0.5 秒渐变。旧「转场／时长」文本参数已移除，非默认阶段过渡使用对应的入场、离场设置。
- 剧情流程图移除右侧属性面板和展开按钮，节点与连线编辑、拖动、断线和撤销保留。
- 章节音效默认「无」，不会隐式开启「青梅竹马」背景音乐。作者工程的开头入口已清理，原生验收确认章节无 BGM，首句开始播放显式指定的「花街柳巷」。

```text
@背景音乐：当前背景音乐
@显示角色
@显示图片：题图，变换={"位置":[0.5,0.5],"缩放":[0.5,0.5],"旋转":0}
```

「替换过渡」用于仍在场上的同一对象 ID 换图，例如把日间照片渐变为夜间照片。不同 ID 可同时显示；单次显示只需设置入场与离场。详见[图片变换、数值拖动与预览](media-authoring-ux-2026-10-08.md)。

## 章节预览与素材选择追加优化

- 章节音效默认「无」，支持替换音效或显式填写「无」。修复公开音效参数未连到内部播放节点、清空参数又恢复默认音效的问题。BGM 由 `@背景音乐` 控制，预览下方手动试听。
- 独立演出的预览进度以画面和动作时长结束；72 秒音效不会把 2.4 秒演出拉长，结束时停止本次预览音效。
- 文字版保留章节背景、笔触叠图、笔触遮罩及装饰背景等可替换参数。四处标题文字各自可编辑；背景层可替换或清空，导出游戏也能处理空图片层。
- 合并动画相同的生成章节预设，统一图片版／文字版入口。原来各章不同的题图和背景转为各次调用参数；不同动画以及被自定义蓝图、界面、角色或小游戏逻辑引用的预设保留。
- 音效只显示音频、图片只显示图片，视频和字体同理。蓝图节点、公开参数、时间轴与文本补全使用一致的格式限制；「全部分类」只扩大分类范围，必填素材不能清空。
- 减少播放时素材目录遍历、背景波动尺寸计算、蓝图重绘和文字粒子字形准备。作者工程副本上的实测与限制见验收记录。

```text
@章节进入演出文字版：标题=醉梦，章节背景=夜色街道，笔触叠图=笔触图片，笔触遮罩=遮罩图片，章节音效=无
@独立演出：章节进入
```

预设修复和合并发生在打开工程后的内存数据中，用户保存时才写回工程。

## 图片、视频与独立文字

- 剧本中可插入「显示图片」「显示视频」「显示文字」「隐藏对象」。素材选择可直接导入项目外文件，支持位置、尺寸、图层、比例适配、持续或定时显示；视频可循环并设置音量。
- 图片过渡分为入场、离场、同 ID 替换，每项可以设置立即、渐变、先淡出再淡入或移动及秒数。替换未单独设置时沿用入场方式。相同持续图片重复显示时保留原对象与时钟，不闪烁、不重复等待。
- 「等待入场或替换过渡后继续」与「等待显示结束」独立。图片默认仅本句显示，跨句保留需选择「持续显示」；可以等待入场完成，但不会无限等待图片消失。
- 定时对象的离场包含在总时长内，例如显示 3 秒、离场 0.5 秒，将在第 2.5 秒开始离场。持续对象在「隐藏对象」时采用显示时的离场规则，也可以单独覆盖；换背景由背景转场统一处理。
- 文本与模块编辑、右侧演出属性、蓝图和原生游戏均保留过渡配置。支持过渡中替换或隐藏、存读档、跨台词延续，以及蓝图公开过渡参数。
- 参数面板在小窗口中滚动，插入和取消按钮保持可用。示例剧情组合与标题页专用控制不再堆在通用指令快捷列表中，原有蓝图仍可从资源库使用。

示例（将「题图」换成实际素材名）：

```text
@显示图片：题图，对象ID=overlay，显示范围=持续显示，入场过渡=渐变，入场秒数=0.5，离场过渡=渐变，离场秒数=0.4，等待过渡=是
旁白：图片已经入场，并会一直保留。
@隐藏对象：overlay，等待完成=是
```

## 统一显示角色

“显示角色”和“自动显示发言角色”合并为一个入口。角色留空时读取当前台词发言人，指定角色时显示所选角色；表情留空使用该角色的默认表情。旁白及没有立绘的发言人跳过，不额外隐藏其他角色，原有显示范围和离场规则继续生效。

文本参数、单行演出、批量添加和蓝图均支持这一规则。站位跟随对应角色的默认预设；拖动舞台角色后仍保留自动跟随。旧自动显示角色指令与专用蓝图节点已移除，内置模板统一改用“显示角色”。

```text
@显示角色
苏怜烟：这句自动显示苏怜烟。
@显示角色：表情=微笑
王生：这句使用王生名为“微笑”的表情。
@显示角色：苏怜烟
王生：这句发言人是王生，但显示指定的苏怜烟。
```

## 章节、台词与预览

文字版章节提供四个独立区域：第一行小字「- 记或忆 -」、第二行小字「- 第一回 -」、标题「醉梦」、右侧字「1645 弘光元年」。哀鸿模板使用原有宋体与书法字体，位置和字号参照原版题图，可在时间轴中继续调整。章节声音改为一次性音效，不会替换或停止 BGM。

```text
@背景音乐：当前背景音乐
@章节进入演出文字版：第一行小字="- 记或忆 -"，第二行小字="- 第一回 -"，标题=醉梦，右侧字="1645 弘光元年"，章节音效=开场音效
@独立演出：第一章进入
```

预览自动播放演出、音效和配音；BGM 由画面下方播放器独立手动控制。

`@播放台词演出` 在当前位置开始本句文字与配音，后面的动作继续执行。同句多次调用只启动一次；省略时，仍在前面的演出完成后播放台词。

```text
@等待：0.5
@播放台词演出
@等待：2
旁白：这句台词在后面的演出结束前就开始播放。
```

编辑区与预览之间的分隔条可拖动，双击复位。工具栏的「自动换行」保留原始逻辑行与文本内容。进度条或时间轴播放头定位后，空格可播放／暂停，预览下方控制区也已缩紧。

## 章节与流程图

```text
#章节(流程图=是，显示名称=酒醒): 第一章 · 酒醒城破
#小章节: 夜宴
#段落: 回家
#章节(流程图=否): 不展示的章节
#小章节(流程图=是): 额外入口
```

章节默认加入游戏流程图，小章节和段落默认隐藏。显示名称默认使用冒号后的标题；需要额外入口时显式写「流程图=是」。模块编辑不再把编译产生的内部节点显示成作者添加的段落。

三种实例入口合并为「复用节点」，用于复制已有剧情、互动或小游戏的配置。「角色功能」调用角色已定义的组合演出，无定义时隐藏。章节内部时间轴、空的保存演出节点和模板专用控制不再占用通用快捷入口；可用的通用蓝图逻辑仍保留。

设置、流程图、对话历史等菜单右键返回游戏；从标题打开则返回标题。画廊大图也支持右键直接返回。

## Windows 单 EXE

在「作品设置 → 游戏导出 → Windows 打包格式」选择：

| 格式 | 交给玩家的文件 | 运行方式 |
|---|---|---|
| ZIP | 一个 ZIP，需完整解压 | 运行解压目录中的游戏 EXE |
| 单 EXE | 一个 EXE | 双击，自动校验、解包并启动 |

单 EXE 内含引擎与素材，不要求玩家安装编辑器、Ren’Py、Node 或开发工具。适用于 Windows 10/11 64 位，启动器使用系统的 .NET Framework。游戏图标写入 EXE。生成过程按流处理大文件，导出文件先完整写入临时文件，再替换目标，防止失败时覆盖成半个包。

单 EXE 每次启动会释放到独立临时目录，需要额外磁盘空间，启动比解压好的 ZIP 慢；窗口显示准备进度，准备期间可取消。正常退出后清理临时引擎，存档和偏好保存在 Ren’Py 的用户目录，重启或换版本不会因为临时目录清理而丢失。系统强制终止或断电可能留下临时文件。

## 保存与导出

有未保存修改时关闭编辑器，会询问「保存／不保存／取消」。取消另存为、保存失败会保留窗口；不保存后，下次打开不会恢复已放弃的修改。导出成功后打开目标文件夹，取消和失败不打开；无法打开文件夹时仍明确提示游戏已导出。

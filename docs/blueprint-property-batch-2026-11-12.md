## 使用方式

“设置组件属性”节点直接显示目标组件和属性行。通过底部“添加属性”，在同一节点内增加文字、显隐、位置、颜色等设置；每项有独立值和连接点，左侧详细信息复用相同编辑器。属性选项按目标组件实际能力过滤，只读项不提供设置入口。节点收起后保留属性名称及连接点。

同一节点修改一个组件，最多 64 项。先读取所有输入、检查整组完成后的状态，再统一提交；无效输入、单向跟随属性或相互冲突的参数写入会拒绝整组，不留下部分修改。失败时停止本次执行链后续节点，旧单项节点保留原有兼容行为。数值范围、文字长度和 Spine 素材／皮肤按最终组合检查。

已连接端点可以直接拖动：有效端点改接、空白画布断开，支持撤销。共享端点优先操作唯一选中的连线；Ctrl／Meta 拖动另建分支，Alt 单击断开这个端点全部可编辑连线。Esc、失焦、右键、非法目标或松到节点正文／输入框／画布外保留原线。选中线仍只高亮，不增加端点圆圈或额外工具栏。固定读档线保持只读，页面按钮出口只允许改接目标。

图片、音频、视频、字体和 Spine 拖入普通蓝图或页面事件图时，创建对应的素材引用节点。两行卡片显示节点名称和当前素材，可直接更换同类素材；右侧素材输出点连接到实际使用它的动作或组件属性。素材节点没有执行点，不会自动切换背景或播放媒体。素材改名更新选择器与来源摘要，作者自定义节点名称保留；原有角色、场景、变量和蓝图拖入方式不变。

## 数据与兼容

- 节点类型仍是 `setUiProperty`。新增 `propertyBatchVersion: 1`，`propertyWrites` 保存 JSON 属性行，每行包含 `id`、`property`、`writeMode`。
- 行的稳定 `id` 同时用作输入连接点和 `properties[id]` 的值键。旧首行继续使用 `value`，已有连线不换身份。首次明确添加／删除行才升级旧节点；只读、加载、保存不会全量迁移。
- 相容属性变化保留接线，不相容变化在整张图连接点同步完成后清理，避免节点存储顺序影响结果。删行只删除该行的值、连接点及连线。
- 损坏版本、JSON 或重复行标识保留原始配置与连接点；语义错误的属性、赋值方式和重复属性支持逐项修复。
- 旧自动参数关联图继续使用原有单项签名。多项节点不会被认成自动托管图，关联列表可定位每一项的真实来源。
- 前台与后台任务编译共用表达式生成器；新格式调用 `vn_ui_set_many`，旧格式继续调用 `vn_ui_set`。界面预览使用同等批量准备与提交规则。
- 媒体的请求序号是各端内部失效标记，不作为跨端数值相等的契约。保留既有 Spine 行为：同源配置与挂起同时变化时预览计两次、原生计一次；两端均在提交前检查自己实际需要的递增，不在失败时替换原记录。
- 媒体预检只处理本次批量实际影响的组件，包含有效设置、显隐、布局和图片继承状态变化；显式设置媒体字段时即使值未变也会校验。无关损坏或待处理媒体不会阻止文字批次，也不会被顺带提交。
- 素材引用复用 `literal` 与 `asset` 输出，`assetKind` 仅标记新素材节点的种类；已有普通固定值和执行动作不迁移，工程保存和运行时继续使用原素材引用契约。

## 验收中修复的问题

Ren'Py 将 store 中的 `list` 替换为可回退容器，导致原生 Python 列表直接调用批量入口时被误拒绝。入口和属性行现在明确接受内置 list／tuple 及对应可回退容器，继续拒绝生成器和任意 iterable；新增组合用例同时检查输入不被修改。

真实鼠标操作发现右键释放先于 contextmenu 时可能误断线。已在捕获阶段取消改接，并正确结束原生拖动监听，正常右键菜单仍可打开。故事右键菜单在画布未聚焦时原来无法由 Escape 关闭，现在只在菜单打开期间监听文档按键，保留节点及连线选择，并跳过输入法合成事件。

旧存档动画验收的初次失败来自取样时机：恢复后动画正常推进约 63.8 毫秒才被拿来和存档时刻比较，超过原 60 毫秒阈值。验收改为在 `after_load` 末尾捕获恢复瞬间，用精确相等检查透明度和进度，并保留继续推进、完成值和事件次数检查。最终恢复误差为 0；本项未修改产品的存读档逻辑。

脚本另修正真实拖放的 DataTransfer 观察阶段、页面草稿撤销应在保存前检查，以及 Playwright 焦点模拟造成的失焦假象。失焦验收关闭焦点模拟后用本次专属临时窗口取得焦点，实际检查原窗口和 renderer 均失焦。失败日志、截图和 trace 均保留。

# 蓝图节点紧凑设计

用户要求：蓝图模块太大，参考 UE5 和现有剧情流程图重新优化节点。改动覆盖普通蓝图、复用模块和页面事件图，保留前轮的左侧属性栏与成员拖放。

## 使用方式

- 卡片按标题、执行接口、数据接口排列。输入在左，输出在右；只含输入时输入占满一行。名称、固定值或已连接来源同行，来源按钮仍可定位上游节点。
- 常用值可直接在卡片修改。数学运算、比较、取整和固定值保留简短的操作设置。事件、调用目标、角色阶段过渡等完整设置集中到左侧“节点参数”，选中节点或点击标题的设置图标即可编辑。
- “更多参数”收纳显示角色的编号、手动构图、坐标、缩放和层级，章节演出的背景、题图、音效和动效，以及镜头旋转。只有未改动、未接线、非必填且没有诊断问题的有效默认值才能隐藏。0、否、空文字只要与基准不同仍然显示；旧未知输入和用户模块接口完整保留。
- 标题右侧的箭头仍用于收起数值编辑器，工具栏支持批量收起。这与“更多参数”是两个独立偏好：前者收起输入框，后者显露附加接口。当前可见的连接点在收起输入框后仍然保留。
- 读取输入和状态保持单行形式；缺失对象和无效配置给出实际问题，长名称可悬停查看。摘要描述实际配置或上游来源，不把已接线输入的旧默认值当成当前值。
- 普通节点宽264，计算类232，简单开始／返回224，双侧复杂值280；读取节点按内容150～280。标题高32、常用输入高24。暗亮主题沿用编辑器节点表面与文字色，顶部细色条区分节点类别。
- 自动排列使用 React Flow 实测尺寸，尚未测量时采用同一布局模型的估计值。新增节点按完整卡片矩形避让，既有位置不会在打开图时被自动整理。

## 实现边界

- `BlueprintGraphNode.tsx` 从主编辑器中独立渲染卡片；`blueprint-nodes.css` 统一管理尺寸，移除旧330px最小宽度和重复大卡片规则。
- `blueprint-node-layout.ts` 只划分已有引脚并估算尺寸，不改模型、引脚身份、顺序或连接语义。
- `blueprint-card-summary.ts` 生成简明摘要。视图缓存记录直接上游的语义依赖，来源属性或资源名变化会更新摘要；只移动节点仍复用原视图。
- 保留原收起参数的本地键；新增 `vns:blueprint-advanced-pins:<projectId>` 记录已展开的更多参数，不写入工程。
- 补齐左侧背景／章节／角色的时长和等待项，以及已有原始演出的输入覆盖项。卡片和左侧仍共用素材、角色、参数值的语义适配器。
- 本轮不改变游戏运行时、蓝图执行语义或作者真实工程，不更新安装发行版。

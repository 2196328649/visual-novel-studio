# 组件连线视图保留源演出与输入参数

本批修复组件连线视图的演出属性编辑：此前面板使用已经应用字面输入的对象，任何修改都会把这个结果写回源对象；图片修改还清空全部 `object_*` 覆盖。改名或调整尺寸可能把6秒的生效动画写成新的源动画，丢失原3秒时钟。音频改名/淡入也会把时长、截取点和音量覆盖写回源音频。

## 修改

- 属性面板使用原始演出，并说明节点输入/连线可以覆盖对应内容。
- `updateSavedBlueprintAction` 对图片复用原始对象编辑，对音频只提交有变化的字段；其余字面输入、源文件时长和数据线保留。明确修改对应源字段时仅移除该字段的字面覆盖，连线继续优先。
- 图片原始动画时钟和输入缩放保持分离。错误类型或无效对象整次拒绝，不留半次修改。
- 桌面测试发现 `syncAudioClipPins` 替换端口对象时改变键顺序；工程历史用序列化比较，因此仅查看含音频事件图也会产生假草稿。改为更新已有端口并保持顺序，新端口顺序与 schema 一致。

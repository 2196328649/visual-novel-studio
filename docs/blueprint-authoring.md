# 中文节点编程

“流程图”在同一张画布连接启动、标题、新游戏、读档与真实剧情节点；“蓝图”统一制作台词演出、独立演出与通用逻辑，用时间轴或执行线和数据线组合演出、状态判断与可复用流程。两者共用同一个工程，支持保存、撤销、重做和导出。

制作章节入场、角色和镜头效果时，也可以进入顶部「蓝图」工作区，在左侧编辑成员与参数，在画布连接节点；时间轴预设、剧本预览和试玩用于检查演出。基础章节指令可从文本 Ctrl+点击或右键进入，再封装成可复用蓝图；见 [演出编辑与问题定位](performance-workspace.md)。

AI助手也能提供当前蓝图的自动排列、显示全图、节点参数收起/展开和属性页切换按钮。先打开要操作的节点蓝图，再点击助手按钮；普通蓝图与高级UI内的节点蓝图都支持。自动排列可撤销，计算期间图发生变化会取消旧结果。高级UI的排列仍按界面草稿保存或放弃。

## 第一次使用

1. 打开“蓝图”，点击“新建逻辑蓝图”。
2. 打开“入门帮助”，点击“创建已连线的入门示例”。编辑器会按已有素材创建并连接背景、角色、等待和返回节点；没有素材时先创建等待流程。
3. 在节点接口旁填写常用值，按中文名称选择素材、角色或表情。选中节点后，在左侧“节点参数”调整完整设置；角色快捷站位与阶段过渡也在这里。
4. 回到剧本，选中一句对白，在“添加演出动作”中选择“通用蓝图”，再选择刚创建的蓝图。也可以在场景属性的“场景蓝图”中绑定它。
5. 保存工程并点“试玩”，实际游戏就会执行蓝图。

蓝图被调用时，从“事件开始”出发。只有接在执行路线上的演出和状态修改才会执行；一个图只需要一个“事件开始”。同一张图还可以添加点击控件、按键和定时事件，分别连接交互流程。

## 认识画布

- 节点库默认收起，可按需展开并搜索。右键空白画布或按空格打开节点搜索，滚轮或 ↑↓ 选择、Enter 或空格添加；支持中文与拼音首字母，分类可以展开和折叠。
- **方形连接点**控制先后顺序，**彩色圆形连接点**传递数值、开关、文字和资源。
- 从右侧输出点拖到另一节点的左侧输入点即可连接，也可以依次点击两个连接点。
- 从未连接的端点拖到空白处松开，会显示兼容节点。选定后同时创建节点和连线，可以一次撤销；也支持从输入端反向拖出，例如从“时长”拖出并选择“固定值”，自动创建数值型数据节点。已连接端点按下方的改接规则处理；按住 Ctrl 拖动可另建分支。
- 未接线的参数直接在节点内填写或选择，接线后改由数据线提供值。数值框可清空重填，位置、缩放和层级不再受原有编辑范围限制；离开空白输入框时保留上次有效值。
- 节点标题下先列执行接口，再列数据接口；输入在左、输出在右。名称、初值和已连接的来源尽量放在同一行，来源可点击定位。数学运算、比较、取整和固定值保留直接影响操作含义的小控件；“设置组件属性”可直接在节点中添加多项属性和填写各自的值。调用目标、事件、角色过渡等完整配置在左侧“节点参数”；悬停标题时的设置按钮也可打开这里。
- “显示角色”“章节演出”和“移动镜头”的部分附加输入默认收进卡片底部的“更多参数”。已接线、已修改、必填或有诊断问题的输入会保持显示；展开可查看并连接其余输入。未知输入和用户模块接口不会自动隐藏。“更多参数”只改变本机显示偏好，可以随时展开，不会删除配置或连线。
- 点击节点标题右侧的箭头收起／展开参数；工具栏的“收起全部节点参数／展开全部节点参数”可批量切换。收起后保留端口名称和连接点，连线随节点尺寸更新。折叠状态按工程保存在本机，切换蓝图和重启后保留，不改动游戏参数或撤销历史。左侧属性栏仍可独立收起。
- “节点参数／输入与输出／变量”默认放在画布左侧；节点库默认收起，展开后在右侧。界面事件图采用左侧上方“我的界面”目录、下方唯一详情，右侧保留画布。拖动分隔条可调宽，拖动面板标题可交换位置，调整后会记住。旧默认方向会迁到左侧，已有宽度保留；恢复面板布局也使用新方向。
- 默认开启“添加时自动接线”。选中节点只有一个空闲执行出口时，新添加的执行节点会接在它后面。
- 一个数据输入只能连接一个值，再次连接会替换旧线。一个执行输出只能连接一条路线，多条流程依次执行时使用“依次执行”。
- 类型错误会显示中文原因。循环连线不会被接受，重复执行请使用“计数循环”。
- 剧情流程和节点编程都支持左键拖出框选、中键或右键拖动画布，滚轮缩放。框选碰到节点即选中，不必完整包住；连线按实际曲线与选框相交判断，可以独立框选一条或多条线，端点不必在框内。Ctrl 点击可增减选择。
- 工具栏放大镜显示全部节点，双击节点聚焦到可读大小；双击用户模块调用则进入被调用蓝图。自动排列按当前卡片实际大小留出间距，不会在打开图时自动移动既有节点。多选后拖动任一所选节点会移动整组，整组位置一起保存，支持一次撤销／重做。
- 连线拥有固定屏幕宽度的点击区域，缩小画布后仍可选中。选中只高亮线条，不显示端点圆圈、浮动断开按钮或额外的选择工具栏。连线原有的触发说明保持可见，浅色配色使用深色连线。
- 一个端点只接着一条可编辑连线时，直接拖动这个端点：松到有效端点就改接，松到空白画布就断开；Ctrl+Z 可以撤销。松回原端点不会产生修改，松到节点正文、输入框、其他控件或画布外会保留原线；类型不兼容、循环、Esc、右键或窗口失焦也会取消改接。
- 一个端点接着多条线时，先选中要改接的一条再拖端点；未明确选中时按新建分支处理。Alt+单击端点可一次断开这里全部可编辑连线，Ctrl／Meta+拖动始终新建分支。固定读档恢复等只读连线不能断开；页面按钮的连线只能拖动目标端改接。
- 选中节点或连线后按 Delete 删除全部所选内容，删除节点时一并清除关联连线；Ctrl+Z 一次撤销，Ctrl+Y 重做。节点与连线混选也作为一次操作处理，剧情的开始节点和固定读档恢复路径受保护。剧情流程图支持相同的连线选择与端点改接；页面按钮的连线只改接目标端，来源始终是原按钮。

## 一个节点同时设置多个组件属性

在普通蓝图或页面事件图中添加“设置组件属性”，先选择“界面组件”。节点上每一行都是“属性＋值”：例如同一个按钮的文字、显示状态、X／Y 位置和不透明度，可以在一个节点里一起设置。底部“添加属性”按类别列出目标支持的可写属性；每一行可直接输入，也可接入自己的一条数据线。选中节点后，左侧“节点参数”提供相同设置。

每个节点只修改一个目标组件，最多 64 项属性；修改其他组件时另加节点。当前数值、归一化值和选项索引表示同一个控件值，不能在同一节点重复设置。固定目标按实际控件过滤属性，目标由数据线决定时在执行时检查。

执行时先读取整组输入，再一起生效。任一项类型、范围、素材或绑定源无效，或者单向跟随参数而不允许蓝图赋值，整组都会拒绝，并停止这次执行链的后续节点。双向同步属性会把变化写回相应参数；同组中对同一个参数给出不同值也会拒绝。控件原有的“临时覆盖／修改绑定源”仍可逐项选择，程序写入不会伪造“用户值改变”事件。

需要同时改变控件范围和数值时，把最小值、最大值、步长和当前数值放在同一节点，校验以整组完成后的范围为准。原有“设置控件范围”节点仍可使用。输入文字和最大长度、Spine 素材和皮肤也按组合后的结果检查，不依赖行的先后顺序。

删除行会一并删除这一行的数据线，其他行保留；一次撤销可恢复整行和值、连线。更换属性时，会重置该行未接线的默认值；数据类型相容时保留接线，不相容时只断开该行。节点收起后仍显示各项属性和连接点。

旧工程单项节点仍可使用，首次添加属性时才升级为多项格式，原来的值与连线保留。无法识别的数据版本或损坏列表会保留原配置并给出诊断，不会静默重建。

## 资源管理器

点击底部“资源管理器”或按 Ctrl+空格展开资源抽屉，拖动上边缘调整高度。项目导航和蓝图属性也可以单独收起。

- 支持图片、音频、视频、字体、骨骼、脚本、蓝图、场景、角色和状态，提供名称搜索、类型筛选、缩略图／列表、收藏和媒体预览。
- 新建文件夹，Ctrl／Shift 多选资源，拖到左侧文件夹或从详情中的“移动到”整理。文件夹与收藏随工程保存，操作可以撤销。
- F2 或详情中的铅笔重命名；资源显示名变化保持原有引用。移除文件夹会把内容移到上级，不删除素材。
- 双击蓝图打开节点编程，双击场景打开剧情图，双击其他资源进入对应编辑面板。
- 从抽屉拖入图片、音频、视频、字体或 Spine，会创建对应的素材引用节点。卡片显示素材名称并可更换同类素材，右侧只有素材输出点；把它接到“切换背景”“播放音乐”或“设置组件属性”等节点的对应输入，执行到这些动作时才使用素材。拖入素材本身不会修改画面或开始播放，也不会自动接上执行线。
- 角色、状态、场景和其他蓝图仍分别创建显示角色、读取状态、切换场景和调用节点。图片和角色也可拖入已有的舞台编辑器；该处继续按舞台操作处理。

文件夹用于项目内整理，资源文件的实际路径保持稳定。实体素材的替换和移除仍在素材属性中操作。

点底部错误数量，再点具体问题，可以打开对应的蓝图和节点。

## 常用演出

| 节点 | 用途 |
| --- | --- |
| 切换背景 | 更换当前舞台的背景，继续当前剧情 |
| 显示角色 / 隐藏角色 | 选择角色和表情，设置位置、大小、层级与过渡 |
| 播放音乐 / 播放音效 / 停止音乐 | 选择音频，设置循环和淡入淡出；音效可使用环境音通道，停止节点可选择音乐、音效或环境音 |
| 等待 | 等待指定秒数后继续 |
| 移动镜头 / 画面震动 | 镜头位移、缩放、旋转和震动可叠加；分别设置时长与是否等待完成 |
| 打开界面 | 打开存档、设置、画廊等菜单；返回游戏后继续下一节点 |
| 演出效果 | 复用舞台编辑器中保存的动画、镜头等组合效果 |
| 切换场景 | 进入目标场景的剧情入口，支持渐变、淡出淡入、时长和颜色 |

**切换场景会结束当前蓝图，并离开当前剧情调用链。** 目标场景需要有剧情入口。只更换画面、继续当前对白时，使用“切换背景”。

资源选择使用稳定引用，改显示名称不会改变连线。显示角色支持继承的表情。常用演出中的资源和数值输入也支持数据线，同一用户节点可以在不同调用处接收不同素材、角色或位置。

角色位置中，横向 0 为左边、0.5 为中间、1 为右边；纵向 1 为底部。位置允许超出画面，例如纵向 1.4 可以把人物继续向下移，露出上半身。大小 1 为原始尺寸。

### 同时移动镜头与震动

执行线连接：**事件开始 → 移动镜头 → 画面震动**。在“移动镜头”上将“等待完成”设为“否”，在“画面震动”上设为“是”。两个节点不会在开始之间停顿，两种效果同时播放；若时长均为 1 秒，1 秒后继续对白。

如果两者时长不同，可以把两个节点都设为不等待，再连接“等待”，秒数填写两者较长的时长。“依次执行”本身不会让带等待的节点并行。

工具栏“添加示例… → 演出 · 镜头与震动同播”会创建一张已经接好的蓝图。文本形式为：

```text
@镜头：0.06，0，1.15，1，0，缓入缓出，否
@震动：横向，1，20，是
旁白：震动中，镜头向前推进。
```

## 创建自己的节点

1. 点击“新建用户节点”，在“输入与输出 → 模块设置”中填写中文蓝图名称。
2. 在上方“输入参数”点“＋ 新增”，填写名称，例如“等待时长”。名称旁边选择“数值”，默认值填 1，再点“创建输入”。类型菜单会显示用途和示例；开关使用“是 / 否”选择器。
3. 把“等待时长”这一行拖到画布，自动生成已经选好参数的“读取输入”。把它的彩色输出连接到“等待”的秒数输入；也可以直接点成员行右侧“读取”。
4. 把“事件开始”连接到“等待”。如需输出计算结果，在“输出结果”创建参数，拖到画布或点“写入结果”生成“写入输出”，接上值和白色执行线。写入结果不会立即结束蓝图，结果在本次调用完成后交给调用者。
5. 打开另一张蓝图，在“我的用户节点”中搜索并插入它，调用节点会自动带上接口和默认值。

参数默认值是可选的；新建表单的“默认值与调用要求”中可以取消默认值，或勾选“调用时必填”要求调用者提供值或连接数据线。0、否和空文字都按其真实类型保存。对象引用可以直接按名称选择默认对象，选择后自动启用默认值；清空选择保存为空值，只有取消“使用默认值”才移除默认配置。

“输入与输出”最上方是可拖动的输入参数和输出结果，名称、调用名、分组、模块说明及主调用入口运行要求收在“模块设置”。“调用与绑定”列表包含蓝图/时间轴、剧情演出、场景/角色、页面与按钮、小游戏和启动流程中的直接引用；不代表每个位置都会执行。可定位的位置提供按钮，其他位置说明其所属资源。

### “场景引用”等类型怎么使用

引用保存的是工程中某个对象的身份，例如“目标小章节”或“鸢”。声明参数本身不会执行动作，必须将读取出来的值连接到实际动作的彩色输入。

| 类型 | 保存什么 | 使用位置示例 |
| --- | --- | --- |
| 场景引用 | 剧情目录中的场景／小章节 | “切换场景”的“目标场景”输入 |
| 角色引用 | 角色列表中的一个角色 | “显示角色”的“角色”输入 |
| 页面引用 | 界面列表中的一个页面 | “打开页面”的“页面”输入 |
| 控件引用 | 页面中的一个控件 | “设置组件属性”的“界面组件”输入 |
| 素材引用 | 工程中的图片、音频等素材 | “切换背景”的“背景素材”输入；素材种类需匹配动作要求 |

例如制作一个可指定目的地的跳转模块：新增“目标场景”输入，类型选“场景引用”，默认对象选一个有入口的小章节；拖出这一行生成“读取输入”，把彩色输出连到“切换场景 → 目标场景”，再把“事件开始”的白线接到“切换场景”。使用这个模块时，在调用处选择目标小章节。同一模块就可以跳转到不同剧情。只想换背景图片时，使用“素材引用”配合“切换背景”。

输入只提供读取，输出只提供写入；它们属于当前蓝图，不能把内部成员拖到另一张图直接使用。在另一张图中应添加对这个模块的调用，再从调用节点的输入输出接线。页面的“打开时输入”同样只读，“完成时结果”可以读取和设置，定义和值仍遵循本次打开页面的生命周期。

修改接口名称、类型、默认值或必填状态时，所有调用节点在同一次编辑中同步。改名保留稳定引脚和原连线，每个调用处单独填写的参数（包括 0、否和空文字）不会被默认值覆盖。旧版位置参数会迁移到稳定接口引用。

删除参数或改变类型会先展示受影响的连线、填写值及模块内的读取/写入节点。取消不修改工程；确认后可一次撤销/重做接口和调用者。类型不兼容的连线与原实参保留，并显示诊断，不强制转换成另一种类型。删除参数只断开对应连线；引用已删参数的节点仍需修复。删除输入会同步清理已应用剧情中的旧实参，但独立的文本草稿不会被覆盖。

带有失效接口的工程仍可保存、重开，并进入模块或页面事件图修复。资源导航不会自动应用文本草稿，模块编辑保留作者的注释、空行和对白；只有需要同步的演出指令做局部替换。试玩前仍须修复相关错误。

调用节点执行完成后，输出点提供**这次调用**的结果。连续调用同一用户节点时，每个调用节点分别保留自己的结果。图再次执行时会重置这些结果，避免沿用上一次执行的值。

### 进入模块与返回

双击调用节点的标题，或使用“节点参数”中的“进入模块”按钮进入被调用的图。顶部“返回调用位置”或 Alt+← 可逐级返回原图、原选择、画布缩放/平移及属性页；返回不是撤销，不丢弃模块中已经做出的修改。输入框中的 Alt+← 不被导航抢走。

从页面事件图进入公共模块时，未保存的界面修改仍需要保存或放弃；取消会停留原处。目标随草稿放弃或删除时，会解释无法定位，不跳到其他图。仅浏览临时演出图不会把它写入工程；实际编辑时才创建可保存的图，并和原行演出一起撤销。导航历史只用于本次编辑，不作为工程数据保存。

## 状态与计算

蓝图左侧“变量”页和界面事件图“我的界面”中的变量分组共用同一套面板。先选择值要保留的范围，再创建或使用该范围内的变量；内置页面模板与新增页面共用变量系统。

| 作用域 | 值的生命周期 | 常见用途 |
| --- | --- | --- |
| 本次调用 | 每次调用或事件触发从初始值开始；嵌套与并发调用各自独立。等待、存读档和回滚跟随本次调用。 | 保存模块中间结果、单次事件计数 |
| 页面实例 | 同一打开实例的显示、点击、按键与定时事件共享。关闭后释放，重开重置；存读档、回滚恢复仍有效的实例。 | 页内选择、进度和连续点击计数 |
| 作品状态 | 剧情与页面共同访问，跟随存档和回滚；新游戏从初始值开始。 | 分支标志、好感度、游戏进度 |
| 玩家设置 | 跨存档与新游戏保留，不随剧情回滚。 | 玩家偏好；系统音量仍用“玩家选项”节点 |

点“＋ 新增”，在同一行填写名称、选择开关／数值／文字，填写初始值后点“创建变量”。0、否和空文字都是有效初始值，取消和 Esc 不创建占位项。类型说明下方的例子用于判断应该选择哪种类型；参数集中的已有素材变量仍可使用。

成员的名称、类型标记和行内留白均可拖到画布。普通变量松手后选择“读取”或“设置”；按住 Ctrl 拖动直接读取，按住 Alt 拖动直接设置。右侧明文按钮提供相同操作，支持键盘。读取节点用彩色线把当前值传给其他节点；设置节点还需要白色执行线，执行到它时才修改变量。

本次调用变量保存在所属蓝图中，页面变量定义保存在所属页面中；不同蓝图或页面可以使用同名定义，引用按稳定身份匹配。页面变量定义由界面方案共用，值仍按实际页面实例隔离。需要调用者指定角色、场景或页面等对象时，在“输入与输出”新增对应的引用参数。

普通模块也可以明确选择一个正在打开的页面，或通过“页面”输入传入目标。传入的页面必须声明同一稳定变量标识和类型；不按名称猜测绑定，也不自动绑定编辑器正在显示的页面。静态可知的缺失或异类型目标会提前诊断，动态目标会在实际读写时校验；关闭后失效的调用不能借用刚重开的新实例。

类型修改先显示受影响的节点，确认后重置定义初始值，但保留既有写入值与连线供诊断修复。删除定义不会删除读写节点；失效引用可保存、重开并在原节点重新选择。定义修改与调用者更新支持一次撤销／重做；页面编辑先进入界面草稿，保存或放弃遵循原界面历史。

“固定值”可提供数值、文字、开关或资源；“数学运算”“比较”“选择值”可直接填写输入，也可连接数据线。NOT/AND/OR/XOR 是不修改状态的纯计算；要翻转保存的开关，连接“读取状态 → NOT → 设置状态”，并给设置节点接执行线。“执行一次（Do Once）”和“门控（Gate）”会记住执行状态，与这些纯计算节点不同。

“条件分支”的“满足 / 不满足”决定执行路线，没有连接的分支在该处结束。“计数循环”包含起始数和结束数，例如 1～3 执行三次。循环体可包含分支、依次执行和另一层计数循环，结束后从“全部完成”继续。

内置节点按演出、界面与动画、流程控制、状态与计算、复用与参数分类，另可复用用户节点。每张蓝图最多 512 个节点、2048 条连线、32 个输入和 32 个输出。

“界面与动画”分类提供组件属性读写、重置、骨骼动画播放/暂停/调速。组件输入按页面和名称选择，也可以通过用户节点的“界面组件”接口传入。完整操作见 [实时骨骼动画创作](spine-authoring.md)。

同一分类还提供“读取玩家选项”“设置玩家选项”和“显示确认框”。设置值类型随所选项目变化，角色音量可指定配音角色；读档不会撤销玩家设置。“显示确认框”的确定／取消出口分别连接执行流程，其外观来自可编辑的消息框页面。界面按钮调用蓝图后，音乐、音效和环境音的播放／停止会继续生效。完整操作见 [玩家设置与确认框](player-settings.md)。

### 数值运算与多路选择

- **限制范围、绝对值、取整、范围判断、近似相等、数值映射、数值插值**都是数据节点，不修改输入来源。取整可选四舍五入（半值远离零）、向下、向上或向零；例如 2.5 → 3、−2.5 → −3。映射支持反向区间和是否限制范围，插值支持是否限制比例到 0～1。
- **多路分支（Switch）**用于枚举执行路线。例如把“打开页面”的关闭原因接入“匹配值”，在“节点参数”建立 `completed`、`cancelled` 等分支并分别接线，未命中走“其他情况”。匹配类型可选文字、数值或开关，数字 0、文字 `"0"` 和开关“否”不是同一个键。
- **多路选择（Select By Key）**用于按键选一个结果。例如匹配难度 `普通` / `困难`，返回不同的数值或图片素材；先选择结果类型，再填写对应候选值和默认值。只读取命中的候选项，未匹配才读取默认值；不会提前求值其余连线。
- 在“节点参数”的“多路分支配置”中编辑名称、匹配值、上下移动和添加分支，不必输入 JSON。重命名和重排保持引脚身份；删除会先说明受影响的连线，确认后可一次撤销。重复匹配值、错误类型和空分支名称都会明确报错。
- 修改匹配/结果类型不会把旧常量自动转换，也不偷偷改接已有连线。先修复提示中的值和连接点。未知分支数据版本保持原样；主动恢复默认定义时会保存旧配置并生成新的分支身份，避免错接旧线。

### 执行一次与门控

在节点库或“添加节点”中搜索中文名称、Do Once 或 Gate。节点卡片和“节点参数”使用同一组“记忆范围”“初始状态”和页面输入。

| 节点 | 尝试入口 | 改变状态的入口 | 出口 |
| --- | --- | --- | --- |
| 执行一次（Do Once） | “尝试执行”首次通过时立即记为已执行，在下游等待前就拦截第二次触发 | “重置”重新允许一次，不会自动执行首次通过；“初始已执行”只决定新调用/页面实例的起点 | 首次通过、已执行、重置完成 |
| 门控（Gate） | “尝试进入”仅在门打开时通过；通过不会自行关门 | 打开、关闭、切换、重置只改变门状态，沿“设置完成”继续；重置恢复作者指定的初始开关 | 通过、门已关闭、设置完成 |

- **本次调用**：同一调用内的循环共享状态，新的事件/调用重新初始化；嵌套或并发调用不互相占用。这里不适合跨点击防重。
- **页面实例**：显式指定页面，或从页面输入传入仍有效的实例；同一图的同一节点在该实例的事件和调用之间共享。内置模板和新增页面完全相同，复制节点会产生独立身份。普通蓝图也可操作已打开页面，不隐式绑定当前编辑器页面；缺失的动态实参不会回退到声明页面。
- 页面关闭时清除该实例的控制状态和未完成任务；重新打开从初始状态开始。存读档恢复调用/页面当时的状态；回滚恢复实际检查点。等待页面本身可以是回滚检查点，因此回滚可能恢复已打开且已经消费过的状态，而不是一律重新初始化。新游戏重新开始。
- 不提供作品/玩家专属的隐藏门控状态。需要跨页或跨存档保留的标志，使用已有类型化作者变量显式读写。

**防止工作期间重复点击**：点击事件 → 执行一次（页面实例）→ 工作/等待 → 同一节点的“重置”。“已执行”可不接线，或显示忙碌提示。“重置完成”只连接真正需要在工作结束后执行的后续。门控也可沿“通过”进入“依次执行”：第一步连接“关闭”，第二步工作结束后连接“打开”。这种按不同执行入口返回的有限连线允许创建；真正从完成出口不断重新进入的死循环仍会拒绝。

封装不能悄悄改变状态身份：包含这两种控制节点的选择会明确拒绝，请保留控制节点，另行整理其工作流程。非阻塞时间轴内联也不把状态节点当作可展平的演出动作。节流、防抖和通用可取消任务的作者节点仍未完成；本节不表示这些候选功能已经支持。

## 文本与实例调用

文本作者直接用 `@蓝图名称` 调用，省略参数时使用接口默认值。在“输入与输出”中可另外填写“调用名称”；留空时跟随蓝图名称。场景事件在进入场景时执行，角色事件在显示角色时执行，界面按钮也可以选择“调用蓝图”。“中文演出指令”节点用于复用已有文本指令，例如 `@等待：1`。

选中连续的演出指令，右键选择「封装选中演出为蓝图…」，填写名称、公开输入和默认值。分组使用资源管理器的文件夹，支持 `演出 / 章节 / 入场` 这样的嵌套路径。封装会同时替换选中文字、创建蓝图和分组，整次操作可以撤销。

在 `/` 菜单中按分组查找蓝图，也可以按中文或拼音首字母搜索。内置指令归入“基础”，可编辑的蓝图按资源管理器文件夹分组；各组可折叠，滚轮滚动菜单，↑↓ 移动选择，Enter 或空格采用。输入参数使用中文名称，也支持按公开输入的顺序填写，例如：

```text
@章节入场：时长=1.2，标题="第一章，酒醒城破"
```

包含逗号的文字用引号括起。Ctrl+点击调用文字进入该蓝图；模块模式点击演出模块展开参数，勾选「本次单独设置」覆盖默认值。删除输入接口会一并清理调用中的旧参数。

在文本调用行右键选择“修改蓝图名称…”或“修改调用名称…”，会同时替换工程中的已有调用，可以一起撤销；对白正文不会被替换。在蓝图设置中改名也会同步调用。名称需要唯一，不能与“背景”“跳转”等基础指令重名。

## 用普通蓝图制作游戏和 UI 交互

在“界面”工作区新建自定义页面，放置按钮和文字，再用普通蓝图连接交互逻辑：

| 节点 | 用法 |
| --- | --- |
| 打开页面 | 选择页面；等待关闭时只挂起本次调用，关闭后读取结果与原因。新增页面可不等待并叠加显示；系统模板仍按其菜单宿主和内容要求检查 |
| 点击控件时 | 选择按钮，将点击事件接到状态修改、判断、组件属性或其他蓝图 |
| 按键时 | 选择页面和按键，该页面显示期间响应；同一按键的多个回调都会执行 |
| 定时触发 | 选择页面、间隔秒数及是否循环，可实现倒计时；关闭页面后停止 |
| 随机数 / 格式化文字 | 产生随机位置或数值，将 `{value}` 替换成输入值后显示到 UI |
| 设置组件属性 | 修改文字、位置、尺寸、显示、启用状态等 |
| 关闭页面 | 关闭指定页面，取消该实例尚未完成的事件任务，并返回文字结果与关闭原因 |

工具栏“添加示例… → 交互 · 限时点亮”会加入普通蓝图、自定义页面和作品状态。示例包含鼠标点击或空格计分、按钮随机移动、倒计时、成功／失败判定及关闭返回；可在 UI 编辑器中修改布局，在蓝图中修改规则。文本输入 `@限时点亮：目标次数=5，限时秒数=8` 即可调用。整个示例的添加可以一次撤销。

这个示例的中途存档和读档会保留得分与进度，再次调用会按蓝图初始化状态。完整交互使用顶部“试玩”验证；剧本右侧预览主要呈现本句演出，不执行完整的页面交互事件循环。

## 预演执行轨迹

1. 在“界面”工作区选择页面，打开“预览窗口”。内置模板与新增页面共用这一入口。
2. 点击“执行轨迹”，直接操作画面中的控件或触发按键；涉及等待、舞台演出或动画时开启“按时间预演”。
3. 在列表中选择记录，检查输入/输出、写入状态、分支、等待、恢复、返回和停止原因。记录注明调用编号与页面实例；同一模块的并发调用不会混为同一份值。
4. 通过“轨迹类型”、调用筛选和搜索缩小范围。选择输入记录后可定位值来源；详情中的调用链可以打开模块或返回其调用节点。“返回调用点”只是编辑器定位，不会倒退或重新执行游戏。
5. “定位触发控件/来源页面”回到原页面和原方案。离开页面去公共模块时，未保存的界面修改仍需保存、不保存或取消；放弃草稿使目标消失后会报错，不跳到其他对象。

**值与边界：** 数字零显示 `0`，布尔假值显示 `false`，空文本显示 `""（空文本）`，与“未产生值（不可用）”分开。轨迹只观察已求出的值，不额外读取引脚。显示、隐藏或筛选不会改变测试状态。列表最多保留最近 1600 条，超出时显示丢弃数量，每页最多 60 条；长文本最多记录 4000 字。所选记录被丢弃或重演后变化时会提示重新选择，不沿用过期值。

在较窄窗口中，轨迹暂时覆盖画面；低矮窗口同时收起画面工具栏以留出日志空间。点击“返回画面”即可恢复控件和计时工具；这不会自动暂停或重新执行。恢复测试值会重新开始记录。测试参数和观察数据不会写入工程。页面、方案或工程切换后，不使用旧来源做定位。

未支持的节点、系统操作或无效目标会给出停止/不可用原因；“在实际游戏中验证”按正常试玩流程保存并启动游戏，不携带页面测试值。**当前的播放、暂停和推进秒数是预演时间控制，不是蓝图断点或逐节点单步。** 实时试玩的“蓝图调试”面板提供实际执行轨迹、断点、暂停及步入／步过／步出；需启用调试后重新运行。断点和记录仅用于本次隔离试玩，不进入发行游戏。

## 编辑器配色

“作品设置 → 编辑器外观”提供石墨、蓝灰、墨绿、暖白和自定义，默认石墨。自定义可从当前风格复制，再调整背景、面板、文字、重点色和节点颜色。选择后立即生效，并在本机记住；AI 独立窗口同步配色。游戏画面按作品自己的 UI 设计显示。

## 批量演出与自动发言角色

「批量演出」可向全部台词添加指定演出；文本右键菜单可限定为选中的台词。旁白默认排除，可手动包含；纯演出行始终跳过，已有的同一蓝图调用不会重复添加。

「显示角色」角色留空时读取本句发言人，表情留空时使用该角色默认表情。可以批量添加，也可以在单句中覆盖表情、位置和大小。旧自动显示角色指令和专用节点已删除。

「隐藏其他角色」默认关闭，开启后只保留当前发言角色。哀鸿示例默认开启该选项，并使用 0.5 倍立绘与 1.08 的纵向位置。旁白及没有立绘的角色不会改变舞台。

自动表情建议和可撤销的 AI 编辑见 [AI 创作助手](ai-assistant.md)。

## 当前边界

这是面向视觉小说的节点编程系统，支持类型化执行与数据流、嵌套流程、用户节点和输入输出。资源、角色、场景和界面组件有专用引用；通用对象、数组/结构体、事件分发器和第三方插件节点暂不提供。页面预演的时间控制与实时试玩的蓝图断点调试有不同作用范围。

## 节流、防抖与独立任务

- **节流**：输入一次立即通过，冷却期间走“被节流”。重复点击不延长冷却；“重置”只清除冷却。跨点击记忆选择“页面实例”，循环内的一次性计算可选择“本次调用”。
- **防抖任务**：选择普通可复用模块及安静秒数。触发只安排任务并立即返回，输入按最后一次触发取快照。新触发取消旧的待执行或未完成任务。把需要延后的业务写进模块，不要在同一点击链立刻“等待任务”，否则这条前台事件尚未返回，仍会拦截同一事件的重复触发。
- **启动任务**：可每次独立启动、取消旧任务保留最新，或已有任务时忽略。长任务的等待不会阻塞另一个短任务。任务在下一个调度点开始，执行出口不是任务完成通知。
- **取消/等待/读取任务状态**：连接启动产生的文字“任务标识”。取消不会撤销已完成副作用；重复取消没有额外效果。等待提供完成、取消、失败、标识失效四条路线，可选模块以取得类型化输出。只有“已完成”路线使用输出；其他路线不继承旧结果。需要长期保存的业务结果请写入作品状态，而不是长期保存任务标识。

生命周期只有已有的调用与页面实例：调用返回就取消其未完成任务；页面任务在所属实例关闭或被替换后取消，重新打开不恢复旧任务，内置模板也用同一机制。存读档和回滚保存剩余时间与任务步骤，不累计离线时间；临时界面回调本身不由 Ren’Py 保存，因此其调用内任务在读档丢失回调后取消。要跨点击和读档继续的工作应绑定页面实例。

后台模块可使用状态、逻辑、循环、等待、嵌套模块、控件属性与动画、声音和骨骼等非前台操作。导航、对话、场景跳转和时间轴仍放在前台调用/等待完成之后；编辑器会指出不支持的后台节点，不把它们默默降级为阻塞任务。正常完成的不等待动画继续沿用页面归属，取消中的动画停止。

节点库同时支持中文与英文名称搜索。所有页面与普通图共用字段和参数接口；改变模块或生命周期前会提示将断开的连接，不兼容类型保留诊断。未知版本不自动覆盖，明确恢复会保留原数据。页面预演需开启“按时间预演”，可暂停、逐步推进并查看后台任务状态；恢复测试值会重建隔离预演，不修改工程或真实玩家数据。

当前活动任务最多 256 个，结果按完成顺序保留最近 512 项；达到活动上限走未安排出口，超过保留期的标识返回失效。等待依赖环或超过执行步数上限会明确失败。

## 页面输入、结果与关闭事件

内置模板和新增页面使用同一套页面接口。在页面接口面板声明参数：名称可改，稳定标识保留；所有界面方案共享定义，输入和暂存结果属于本次打开的实例。

1. 在“接入游戏”或“打开页面”节点填写输入。勾选“提供”才传入该字段；不勾选使用默认值，没有默认值的必填参数会报错。0、否、空文字都是有效实参。
2. 页面事件和嵌套模块通过“读取页面输入”取得打开快照；调用者后来改变变量不会改写该快照。通过“设置页面结果”暂存返回值，也能读取自己的暂存结果。
3. “关闭页面”只覆盖明确填写的结果；不填写就保留暂存值。只有 completed 发布暂存结果，取消、父页退出、导航替换和未等待/重复打开返回接口默认值，不返回上次实例的旧结果。原文字结果/原因仍保留。
4. 动态目标需要声明“接口页面”，编译和原生按参数标识/类型检查实际目标。不会因恰好打开某页而偷偷借用其定义。

生命周期包括创建、页面显示、获得焦点、失去焦点、关闭请求、关闭完成。创建结束后才获得焦点；关闭请求可等待确认，再用“阻止页面关闭”否决本次请求。返回/Esc 也经过关闭请求。父页结束、导航等强制退出不等待可否决处理器。关闭完成是清理后的通知，不能阻塞已经结束的页面；通知失败会提示，但不会扣住调用者。

菜单模板保留真实宿主约束：直接打开必须等待并拦截底层输入；标题前没有可保存的进度，只能读档。系统内容型模板说明所需宿主，不提供虚假的独立打开入口。页面预演“测试数据”可选择标题或游戏内宿主，切换从头重演；此处只模拟菜单，不实际存读档。

页面最多 128 项输入、32 项类型化结果。包装模块另公开旧 result/reason 两项，所以超过 30 项类型化结果时提示直接使用“打开页面”节点，不丢弃结果。修改接口前列出受影响的节点、连线和统一流程步骤；不兼容旧值保留供修复。未知版本只在明确恢复后重建，并保留原定义。

### 任务循环与预演停止

任务计数循环接收有限整数（端点 ±100000），最多 100000 次；下一轮检查也占步骤，整个任务另有 100000 步限制。即使循环体为空也会逐轮让出执行权。全部完成时计数是结束值加一；空范围保留起始值；返回或取消不额外推进。

不按时间的静态预演最多演示 256 次循环。页面预演另受 60 秒/4096 次调度与请求的预算约束：达到上限只是本次预演停止，活动任务和等待仍未完成，不表示成功、失败或取消。任务自身真正超限则返回 failed/stepLimit。请用实际游戏检查超过预演预算的流程。

## 控件有效属性与绑定来源

在界面设计右侧展开“蓝图属性能力”，可查看本控件的属性范围、单位、读写权限与来源。蓝图中的属性选择来自同一目录；鼠标状态、画面坐标、来源范围、当前选项标签等只读项不会出现在写入或重置下拉框中。

- **读取组件属性**读取当前实例的有效值；**读取设计默认值**不包含运行覆盖，输入/选择/滑条的默认值来自所选参数或玩家设置的设计初值。
- “横向位置/宽度”等以父级比例表示；“画面横向坐标/画面宽度”等以画面像素表示。显示层级只在同父级、同前景/背景分组内排序，不能把子对象提到另一个页面或父级子树之上。
- 颜色可用 RGB 或 RGBA；透明度与颜色自身 alpha 相乘。状态色没有独立设计值时继承基础颜色覆盖；已设计的状态保持独立，进度填充不继承轨道背景。
- 输入、选择和滑条根据绑定类型提供“当前数值/当前文字值/当前开关值”。数值另有归一化值；选择提供从 0 开始的索引、当前标签与数量。索引读取 -1 表示未匹配，写入只能选择现有索引。
- 设置这些控件值时必须看清**赋值方式**：**临时覆盖本控件**只改当前实例显示，**修改绑定源**会写参数/玩家设置并解除本控件值覆盖。两种程序赋值都不触发“用户值改变”。真实用户改值才发出该事件，并写来源、清除自身覆盖。
- “重置组件属性”只清除所选覆盖。重置归一化值或选项索引会恢复同一控件值的来源；不会把已改的参数/玩家设置倒回设计初值。原先直接“设置状态/设置玩家选项”的节点仍只改来源，不取消其他控件的显示覆盖。
- 控件树和拖入控件的快捷菜单区分“读取/设置绑定源”和“读取有效控件值/临时覆盖控件值”，避免误读来源。例：共享滑条 A/B 绑定同一参数，对 A 临时覆盖为 0 后，A 有效值为 0，B 和绑定源仍保留原值。
- “禁止用户改值”不阻止蓝图赋值；输入长度按 Unicode 字符计数，减少上限不会主动截断已有保存内容。

### 控件范围与用户步长

数值控件的“下限/上限/步长”是当前有效控件范围，可读写；“来源下限/来源上限/来源步长”是绑定定义的只读信息。设计面板可编辑三个草稿并点击“应用整个控件范围”，一次提交，不产生先改下限导致的非法中间状态。它不修改参数定义。

- 蓝图的**设置控件范围**一次设置三个字段，**重置控件范围**一起解除三个范围覆盖。跨越原范围时优先使用它们；单字段设置/重置仍检查完整有效范围，若与其他覆盖冲突则拒绝，保留所有原值。
- 缩小范围只钳制有效显示/读取值，不写绑定源、不清除原值覆盖、不发用户改值事件；扩大或重置范围后，原来源/覆盖值重新显现。控件数值赋值必须落在当前有效范围，程序赋值不会强制按步长取整。
- 用户拖动和键盘调整按下限锚定最近步长，半步向较大一侧取整，两端点始终可达。最小值等于最大值时显示固定值，归一化值为 0，不能再由用户拖动。
- 范围必须是有限数、下限不大于上限、步长大于 0，跨度和相对步长必须可表示。参数来源范围只是默认控件范围；玩家设置仍受引擎边界限制，不能借此把音量设成 2。
- 文字速度下限为 0、上限大于 0 时保留末端“立即显示”（实际值 0）；正范围不包含该档，来源为 0 时有效显示上限。固定 0 范围的归一化值仍为 0。反向只影响视觉方向，不反转归一化含义。

### 请求输入焦点

**请求输入焦点**仅适用于自由文字输入。“聚焦=是”请求开始编辑，“聚焦=否”请求释放该输入框；释放其他输入框不会打断当前输入。输出“已接受”仅表示请求入队，**不等于已聚焦**；只读“正在编辑”属性查询实际状态。同一执行链的下一节点仍看到旧状态，宿主刷新后才应用请求；后一个被接受的请求替换前一个。

程序聚焦、释放和生命周期清理均不合成文字提交。请求与页面实例绑定，不持有可保存的显示对象；隐藏（含祖先）、禁用、只读、模态遮挡、关闭重开、读档、回滚和新游戏会清理无效请求与编辑状态，不向新实例重放。页面预演按新命令应用一次，不持续抢回用户自己移动的焦点；一次推进跨越多次刷新时应用最终焦点净结果。

玩家设置控件范围只能在引擎边界内调整。运行时选项列表见下节；垂直滑条暂不提供。

## 控件选项列表

- 选中绑定了选项的控件，使用“读取控件选项”或“编辑控件选项”，也可把控件拖到蓝图画布后选同名快捷入口。自由文字输入和滑条不提供列表编辑。
- 读取节点选择与控件绑定一致的值类型，输入从 0 开始的索引，输出“选项存在”“选项标签”和类型化“选项值”。不存在的整数索引不是错误：存在为否，标签为空，值为文字空串/数值 0/开关否。索引的小数、非有限数和不安全整数会报错。
- 编辑节点选择插入、修改、移除、移动、清空或恢复设计选项。插入时当前数量代表末尾；移动的目标是移动之后的位置。最多 256 项，标签 1～2000 个 Unicode 字符；标签与值可以不同。改操作如将移除已连线的输入，会先显示断线数量并确认；改值类型不自动转换旧值或旧线。
- 编辑列表不自动选择、不写绑定源、不撤销值覆盖、不触发用户值改变。移除当前值会保留它，但当前索引变成 -1。清空列表不会把控件变成输入框；恢复列表与重置整控件是两个不同操作。数值选项超出当前控件范围时不可选，但不会被自动删除。
- 要选中新项，之后用“设置组件属性”的“当前选项索引”或相应类型的有效值属性；明确选择临时覆盖或修改绑定源。读取“选项数量/当前索引/当前标签”取得当前实例状态，读取设计默认值不含列表覆盖。
- 内置模板和新增页面共用此接口。列表跟随页面实例，离页/重开不继承；游戏存读档和回滚按页面覆盖规则保存。玩家真正选择时，来源仍按作品参数或玩家设置的既有生命周期更新；不能把列表恢复当作撤销来源修改。

## 普通图片：效果与加载事件

图片控件继续通过“获取/设置组件属性”选择能力，不填写磁盘路径。图片素材使用资源引脚；裁切 X/Y/宽/高使用源图 0～1 比例，取与源图相交的部分，零面积透明。先裁切后缩放，九宫格边距以裁切后的源图像素计。水平/垂直翻转与 RGB/RGBA 乘色只影响本图片，不改变子项坐标或整个控件的命中区域。

在页面事件图选中图片，可定位或添加“图片加载成功时”“图片加载失败时”。输出的素材、错误、宽和高是本次请求的快照；即使处理流程里换图，也不会把旧事件输出改成新素材。实际图片解码完成才有成功事件，素材已导入或仅查询属性不代表已加载；清空没有加载事件。普通素材绑定或实际状态图片变化建立新请求，单纯裁切/翻转/乘色/重绘不重复派发。迟到的旧来源和旧页面实例报告被忽略；事件所属页面关闭后不继续剩余事件链。

“图片加载状态/错误”“实际显示图片”和“源图片宽度/高度”只读；实际图片包含父按钮的状态皮肤，因此可能不同于可写的普通图片。页面设计数据不会被预演写回。要重试同一来源，可先清空再恢复；单字段重置只恢复该属性，不重置其他效果。原生未知版本的加载记录需明确重置，原记录保留用于恢复。

## 通用布局、容器与滚动

在设计页选择普通控件，展开“通用布局、容器与滚动”；蓝图使用相同目录中的“获取组件属性”“修改组件属性”“获取设计默认值”及单字段/整控件重置。所有页面共用这套机制。此处只布局作者创建的子对象，不开放复杂控件内部条目或详情模板。

- **父内容区与轴心**：X/Y 是相对父内容区锚点的偏移，宽/高仍是父内容区的比例。锚点 0～1 选父内容区位置，轴心 0～1 选自身旋转/缩放中心；先缩放再顺时针旋转。缩放可以为负（镜像），为 0 时不显示也不能命中。整体变换影响子树和命中，不等于图片翻转、裁切或 Spine 内部变换。
- **排列与内边距**：容器选择自由、横向或纵向排列；间距和四侧内边距使用像素。排列顺序默认 0，同值按声明顺序；不随绘制层级或对象列表重排而改变。隐藏前景子项不占槽位。背景子项使用父外框，不参与排列、内边距和滚动；变换后的溢出会计入有效滚动范围。
- **裁剪与滚动**：可选横向、纵向或双轴滚动。开启滚动会将前景裁剪在父内容区。滚动位置及上下限使用像素；读到的是根据当前子项、条件和几何夹紧的有效位置，设置的请求不会反过来修改作品设计值。向负方向伸出的子项可以产生负下限。内容宽高与滚动上下限只读，右侧“容器设计滚动范围”显示设计时的结果。
- **坐标观察**：画面横纵位置、画面宽高是变换后的轴对齐外框（AABB），不是自身未变换宽高。拖动自动换算父坐标，缩放保持对侧手柄；改变父对象保留可表达的完整世界变换。若需要尚未公开的斜切、零内容区或滚动重夹紧导致无法保形，会明确拒绝，先恢复滚动原点或调整父级变换后再操作。
- **实例与输入**：预演/运行赋值不改设计；滚轮优先给控件内部已有滚动，再传给外部创作容器，每档 40 像素，Shift 横向。被模态遮挡、已经关闭/重开的旧实例和裁剪外控件不能接收这次输入。几何变化使输入框不可用时清理焦点，不制造用户文字提交事件；选项旧回调与按钮抓取也需重新通过当前实例和几何检查。
- **动画与恢复**：新增布局字段当前不提供动画；已有 X/Y/宽/高动画继续生效并经过同一几何解析。缺少布局字段的旧控件沿用旧行为；不支持的版本先保留并诊断，可明确“保留原数据并恢复默认布局”。

## 视频控件

- 选择视频控件，在事件图用“播放视频”“暂停或继续视频”“停止视频”；“重新开始”为是时从头重播。默认播放继续暂停位置；停止或结束后播放也从头开始。
- 通过统一组件属性修改视频素材、封面或循环。相同素材赋值不重播；清空不派发结束。所有界面共用这一套属性和页面实例机制。
- “视频播放结束时”“视频播放失败时”给出本次素材资源、位置、时长、是否已知时长与错误快照。资源引脚接文字参数时请显式经过“格式化文字”，不要把资源类型强行改成文字。循环、隐藏、停止不触发结束；重复点击添加入口会定位已有事件。
- 播放状态、位置、时长、时长已知、进度和错误是只读观察值，不支持绑定写入、动画或单字段重置。未知时长不会仅凭导入元数据猜测；位置单位为秒。当前不支持作者定位播放位置，能力查询返回否。
- 作者暂停独立于隐藏/宿主挂起；重新显示继续原来的作者模式。预演播放状态来自真实浏览器播放器，视频保持静音；“暂停计时”只暂停蓝图/舞台预演时钟，不替代视频暂停。实际游戏通过原生播放器验证声音和保存位置恢复。
- 程序修改不改作品设计；页面关闭/重开清理当前实例。存读档和回滚恢复可序列化状态，不把播放器、纹理或后台线程写入存档；未知记录需明确重置并保留恢复数据。

### 骨骼控件的运行时状态与事件

骨骼控件沿用“播放骨骼动画 / 暂停骨骼动画 / 设置动画速度”。属性目录可切换骨骼素材、皮肤、循环及内部变换；素材引脚保持资源类型，动画和皮肤按名称选择。更换素材后使用该素材首个动画及默认皮肤，保留作者暂停、循环与速度；相同素材赋值、皮肤切换、速度和变换变化不重播。明确重新开始或完成后再次播放会重建轨道。内部变换不改变控件的布局和命中范围。

“骨骼动画完成时 / 骨骼播放失败时”是页面事件，提供本次素材、动画、皮肤、位置、时长和错误快照。真实运行库反馈非循环动画完成才派发完成；循环、清空和隐藏不发完成。只读观察包含当前动画、状态、播放/暂停、位置/时长/时长是否已知、进度及错误，不能写入、动画或单字段重置。零时长动画与未知时长不同。

作者暂停、零速度和宿主隐藏各自保留语义：重新显示不解除作者暂停，模态子页下仍可见的父页继续播放。整控件重置恢复设计动画、皮肤和自动播放。内部存档位置恢复不表示开放定位播放位置的节点。预演使用实际 WebGL 库；原生使用 Spine 4.2 适配器 ABI 2。

### 历史工程与未知节点的恢复保护

遇到当前不支持的工程版本或蓝图节点，加载器明确说明不兼容并保留原文件，不把它当作损坏写入而自动换成较旧备份。较新的同工程自动保存同样受保护；请使用支持其格式的编辑器处理，不要为了继续打开而删掉未知节点。真正损坏的 JSON 仍可从有效自动保存／previous 恢复。

需要迁移时，恢复副本保存在实际来源旁的 `.before-migration` 文件；来源是自动保存或 previous 时相应后缀也保留。已有恢复副本不会覆盖，后续不同内容另加哈希后缀。恢复副本不是运行缓存或临时构建目录，不应当作为临时产物删除。

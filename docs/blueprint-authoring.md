# 中文节点编程

“流程图”独立连接对白段落、选项和结局；“蓝图”统一制作台词演出、独立演出与通用逻辑，用时间轴或执行线和数据线组合演出、状态判断与可复用流程。两者共用同一个工程，支持保存、撤销、重做和导出。

制作章节入场、角色和镜头效果时，也可以进入顶部「蓝图」工作区，在同一窗口编辑模块或蓝图并播放预览。基础章节指令可从文本 Ctrl+点击或右键进入，再封装成可复用蓝图；见 [演出编辑与问题定位](performance-workspace.md)。

AI助手也能提供当前蓝图的自动排列、显示全图、节点参数收起/展开和属性页切换按钮。先打开要操作的节点蓝图，再点击助手按钮；普通蓝图与高级UI内的节点蓝图都支持。自动排列可撤销，计算期间图发生变化会取消旧结果。高级UI的排列仍按界面草稿保存或放弃。

## 第一次使用

1. 打开“蓝图”，点击“新建逻辑蓝图”。
2. 打开“入门帮助”，点击“创建已连线的入门示例”。编辑器会按已有素材创建并连接背景、角色、等待和返回节点；没有素材时先创建等待流程。
3. 直接在节点上填写参数，按中文名称选择素材、角色或表情。选中节点也可使用右侧属性；角色站位可以直接点“左侧 / 中间 / 右侧”。
4. 回到剧本，选中一句对白，在“添加演出动作”中选择“通用蓝图”，再选择刚创建的蓝图。也可以在场景属性的“场景蓝图”中绑定它。
5. 保存工程并点“试玩”，实际游戏就会执行蓝图。

蓝图被调用时，从“事件开始”出发。只有接在执行路线上的演出和状态修改才会执行；一个图只需要一个“事件开始”。同一张图还可以添加点击控件、按键和定时事件，分别连接交互流程。

## 认识画布

- 节点库默认收起，可按需展开并搜索。右键空白画布或按空格打开节点搜索，滚轮或 ↑↓ 选择、Enter 或空格添加；支持中文与拼音首字母，分类可以展开和折叠。
- **方形连接点**控制先后顺序，**彩色圆形连接点**传递数值、开关、文字和资源。
- 从右侧输出点拖到另一节点的左侧输入点即可连接，也可以依次点击两个连接点。
- 将连接线拖到空白处松开，会显示兼容节点。选定后同时创建节点和连线，可以一次撤销；也支持从输入端反向拖出，例如从“时长”拖出并选择“固定值”，自动创建数值型数据节点。
- 未接线的参数直接在节点内填写或选择，接线后改由数据线提供值。数值框可清空重填，位置、缩放和层级不再受原有编辑范围限制；离开空白输入框时保留上次有效值。
- 点击节点标题右侧的箭头收起／展开参数；工具栏的“收起全部节点参数／展开全部节点参数”可批量切换。收起后保留端口名称和连接点，连线随节点尺寸更新。折叠状态按工程保存在本机，切换蓝图和重启后保留，不改动游戏参数或撤销历史。右侧属性栏仍可独立收起。
- 默认开启“添加时自动接线”。选中节点只有一个空闲执行出口时，新添加的执行节点会接在它后面。
- 一个数据输入只能连接一个值，再次连接会替换旧线。一个执行输出只能连接一条路线，多条流程依次执行时使用“依次执行”。
- 类型错误会显示中文原因。循环连线不会被接受，重复执行请使用“计数循环”。
- 剧情流程和节点编程都支持左键拖出框选、中键或右键拖动画布，滚轮缩放。框选碰到节点即选中，不必完整包住；连线按实际曲线与选框相交判断，可以独立框选一条或多条线，端点不必在框内。Ctrl 点击可增减选择。
- 工具栏放大镜显示全部节点，双击节点聚焦到可读大小，也可自动排列。多选后拖动任一所选节点会移动整组，整组位置一起保存，支持一次撤销／重做。
- 连线拥有固定屏幕宽度的点击区域，缩小画布后仍可选中。选中时高亮并显示浮动断开按钮；右侧“连线”标签列出来源节点、输出、目标与输入，点击列表可定位两端。浅色配色使用深色连线，保持对比度。
- 拖动选中连线的端点可以改接。类型错误或产生循环时保留原来的连线并显示原因。
- 选中节点或连线后按 Delete 删除全部所选内容，删除节点时一并清除关联连线；Ctrl+Z 一次撤销，Ctrl+Y 重做。节点与连线混选也作为一次操作处理，剧情的开始节点受保护。右侧也提供复制节点和断开连线按钮。剧情流程图支持相同的连线选择、列表与端点改接。

## 资源管理器

点击底部“资源管理器”或按 Ctrl+空格展开资源抽屉，拖动上边缘调整高度。项目导航和蓝图属性也可以单独收起。

- 支持图片、音频、视频、字体、骨骼、脚本、蓝图、场景、角色和状态，提供名称搜索、类型筛选、缩略图／列表、收藏和媒体预览。
- 新建文件夹，Ctrl／Shift 多选资源，拖到左侧文件夹或从详情中的“移动到”整理。文件夹与收藏随工程保存，操作可以撤销。
- F2 或详情中的铅笔重命名；资源显示名变化保持原有引用。移除文件夹会把内容移到上级，不删除素材。
- 双击蓝图打开节点编程，双击场景打开剧情图，双击其他资源进入对应编辑面板。
- 从抽屉拖入图片、音频、角色、状态、场景或其他蓝图，可直接建立对应的背景、音乐、角色、读取状态、切换场景或调用节点。图片和角色也可拖入已有的舞台编辑器。

文件夹用于项目内整理，资源文件的实际路径保持稳定。实体素材的替换和移除仍在素材属性中操作。

点底部错误数量，再点具体问题，可以打开对应的蓝图和节点。

## 常用演出

| 节点 | 用途 |
| --- | --- |
| 切换背景 | 更换当前舞台的背景，继续当前剧情 |
| 显示角色 / 隐藏角色 | 选择角色和表情，设置位置、大小、层级与过渡 |
| 播放音乐 / 播放音效 / 停止音乐 | 选择音频，设置循环和淡入淡出；音效可使用环境音通道，停止节点可选择音乐、音效或环境音 |
| 等待 | 等待指定秒数后继续 |
| 移动镜头 / 画面震动 | 镜头位移、缩放、旋转和震动可叠加；分别设置时长与是否等待完成 |
| 打开界面 | 打开存档、设置、画廊等菜单；返回游戏后继续下一节点 |
| 演出效果 | 复用舞台编辑器中保存的动画、镜头等组合效果 |
| 切换场景 | 进入目标场景的剧情入口，支持渐变、淡出淡入、时长和颜色 |

**切换场景会结束当前蓝图，并离开当前剧情调用链。** 目标场景需要有剧情入口。只更换画面、继续当前对白时，使用“切换背景”。

资源选择使用稳定引用，改显示名称不会改变连线。显示角色支持继承的表情。常用演出中的资源和数值输入也支持数据线，同一用户节点可以在不同调用处接收不同素材、角色或位置。

角色位置中，横向 0 为左边、0.5 为中间、1 为右边；纵向 1 为底部。位置允许超出画面，例如纵向 1.4 可以把人物继续向下移，露出上半身。大小 1 为原始尺寸。

### 同时移动镜头与震动

执行线连接：**事件开始 → 移动镜头 → 画面震动**。在“移动镜头”上将“等待完成”设为“否”，在“画面震动”上设为“是”。两个节点不会在开始之间停顿，两种效果同时播放；若时长均为 1 秒，1 秒后继续对白。

如果两者时长不同，可以把两个节点都设为不等待，再连接“等待”，秒数填写两者较长的时长。“依次执行”本身不会让带等待的节点并行。

工具栏“添加示例… → 演出 · 镜头与震动同播”会创建一张已经接好的蓝图。文本形式为：

```text
@镜头：0.06，0，1.15，1，0，缓入缓出，否
@震动：横向，1，20，是
旁白：震动中，镜头向前推进。
```

## 创建自己的节点

1. 点击“新建用户节点”，在“输入与输出”中填写中文蓝图名称。
2. 添加输入参数，例如“等待时长”，类型选“数值”，默认值填 1。开关使用“是 / 否”选择器。
3. 添加“读取输入”，选择“等待时长”，把输出连接到“等待”的秒数输入。
4. 把“事件开始”连接到“等待”。如需输出计算结果，添加输出接口，用“写入输出”提供结果。
5. 打开另一张蓝图，在“我的用户节点”中搜索并插入它，调用节点会自动带上接口和默认值。

参数默认值是可选的；勾选“调用时必填”可以要求调用者提供值或连接数据线。0、否和空文字都按其真实类型保存。资源参数必须选择存在的工程资源。

修改接口名称、类型、默认值或必填状态时，所有调用节点都会同步。改名保留原连线，每个调用处单独填写的参数覆盖也会保留。删除接口会清理对应连线，撤销可以恢复。旧版位置参数会迁移到稳定接口引用。

调用节点执行完成后，输出点提供**这次调用**的结果。连续调用同一用户节点时，每个调用节点分别保留自己的结果。图再次执行时会重置这些结果，避免沿用上一次执行的值。

## 状态与计算

“读取状态”和“设置状态”按名称选择作品状态。“固定值”可提供数值、文字、开关或资源；“数学运算”“比较”“选择值”可直接填写输入，也可连接数据线。

“条件分支”的“满足 / 不满足”决定执行路线，没有连接的分支在该处结束。“计数循环”包含起始数和结束数，例如 1～3 执行三次。循环体可包含分支、依次执行和另一层计数循环，结束后从“全部完成”继续。

内置节点按演出、界面与动画、流程控制、状态与计算、复用与参数分类，另可复用用户节点。每张蓝图最多 512 个节点、2048 条连线、32 个输入和 32 个输出。

“界面与动画”分类提供组件属性读写、重置、骨骼动画播放/暂停/调速。组件输入按页面和名称选择，也可以通过用户节点的“界面组件”接口传入。完整操作见 [实时骨骼动画创作](spine-authoring.md)。

同一分类还提供“读取玩家选项”“设置玩家选项”和“显示确认框”。设置值类型随所选项目变化，角色音量可指定配音角色；读档不会撤销玩家设置。“显示确认框”的确定／取消出口分别连接执行流程，其外观来自可编辑的消息框页面。界面按钮调用蓝图后，音乐、音效和环境音的播放／停止会继续生效。完整操作见 [玩家设置与确认框](player-settings.md)。

## 文本与实例调用

文本作者直接用 `@蓝图名称` 调用，省略参数时使用接口默认值。在“输入与输出”中可另外填写“调用名称”；留空时跟随蓝图名称。场景事件在进入场景时执行，角色事件在显示角色时执行，界面按钮也可以选择“调用蓝图”。“中文演出指令”节点用于复用已有文本指令，例如 `@等待：1`。

选中连续的演出指令，右键选择「封装选中演出为蓝图…」，填写名称、公开输入和默认值。分组使用资源管理器的文件夹，支持 `演出 / 章节 / 入场` 这样的嵌套路径。封装会同时替换选中文字、创建蓝图和分组，整次操作可以撤销。

在 `/` 菜单中按分组查找蓝图，也可以按中文或拼音首字母搜索。内置指令归入“基础”，可编辑的蓝图按资源管理器文件夹分组；各组可折叠，滚轮滚动菜单，↑↓ 移动选择，Enter 或空格采用。输入参数使用中文名称，也支持按公开输入的顺序填写，例如：

```text
@章节入场：时长=1.2，标题="第一章，酒醒城破"
```

包含逗号的文字用引号括起。Ctrl+点击调用文字进入该蓝图；模块模式点击演出模块展开参数，勾选「本次单独设置」覆盖默认值。删除输入接口会一并清理调用中的旧参数。

在文本调用行右键选择“修改蓝图名称…”或“修改调用名称…”，会同时替换工程中的已有调用，可以一起撤销；对白正文不会被替换。在蓝图设置中改名也会同步调用。名称需要唯一，不能与“背景”“跳转”等基础指令重名。

## 用普通蓝图制作游戏和 UI 交互

在“界面”工作区新建自定义页面，放置按钮和文字，再用普通蓝图连接交互逻辑：

| 节点 | 用法 |
| --- | --- |
| 打开自定义界面 | 选择页面；“等待关闭”为“是”时暂停当前剧情，关闭后从“关闭结果”读取返回值；设为“否”时页面叠加显示，剧情继续 |
| 点击控件时 | 选择按钮，将点击事件接到状态修改、判断、组件属性或其他蓝图 |
| 按键时 | 选择页面和按键，该页面显示期间响应；同一按键的多个回调都会执行 |
| 定时触发 | 选择页面、间隔秒数及是否循环，可实现倒计时；关闭页面后停止 |
| 随机数 / 格式化文字 | 产生随机位置或数值，将 `{value}` 替换成输入值后显示到 UI |
| 设置组件属性 | 修改文字、位置、尺寸、显示、启用状态等 |
| 关闭自定义界面 | 关闭指定页面，并返回文字结果 |

工具栏“添加示例… → 交互 · 限时点亮”会加入普通蓝图、自定义页面和作品状态。示例包含鼠标点击或空格计分、按钮随机移动、倒计时、成功／失败判定及关闭返回；可在 UI 编辑器中修改布局，在蓝图中修改规则。文本输入 `@限时点亮：目标次数=5，限时秒数=8` 即可调用。整个示例的添加可以一次撤销。

这个示例的中途存档和读档会保留得分与进度，再次调用会按蓝图初始化状态。完整交互使用顶部“试玩”验证；剧本右侧预览主要呈现本句演出，不执行完整的小游戏事件循环。

## 编辑器配色

“作品设置 → 编辑器外观”提供石墨、蓝灰、墨绿、暖白和自定义，默认石墨。自定义可从当前风格复制，再调整背景、面板、文字、重点色和节点颜色。选择后立即生效，并在本机记住；AI 独立窗口同步配色。游戏画面按作品自己的 UI 设计显示。

## 批量演出与自动发言角色

「批量演出」可向全部台词添加指定演出；文本右键菜单可限定为选中的台词。旁白默认排除，可手动包含；纯演出行始终跳过，已有的同一蓝图调用不会重复添加。

「显示角色」角色留空时读取本句发言人，表情留空时使用该角色默认表情。可以批量添加，也可以在单句中覆盖表情、位置和大小。旧自动显示角色指令和专用节点已删除。

「隐藏其他角色」默认关闭，开启后只保留当前发言角色。哀鸿示例默认开启该选项，并使用 0.5 倍立绘与 1.08 的纵向位置。旁白及没有立绘的角色不会改变舞台。

自动表情建议和可撤销的 AI 编辑见 [AI 创作助手](ai-assistant.md)。

## 当前边界

这是面向视觉小说的节点编程系统，支持类型化执行与数据流、嵌套流程、用户节点和输入输出。资源、角色、场景和界面组件有专用引用；通用对象、数组/结构体、事件分发器、第三方插件节点和蓝图断点调试尚未实现，不宣称等同 UE5 的完整 Blueprint 系统。

验证包含真实界面操作、工程保存重开、Ren'Py 编译与 lint，以及带素材和存读档的原生游戏运行。它不能替代零开发经验创作者的实际试用反馈。

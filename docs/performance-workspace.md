# 演出编辑与问题定位

## 在文本中隐藏演出

进入「剧本 → 文本编辑」，开启工具栏的「隐藏演出」。正文中的角色、背景、音乐、镜头等演出指令和配音会收起，右侧实时预览下方默认只显示选中台词的演出。勾选「显示未选中台词演出」可查看同段落的其他台词。

- 移动文本光标会选择对应台词；取消预览标题栏的「跟随光标」可固定当前预览。
- 点击右侧台词行展开或收起演出，点击演出模块编辑参数；加号用于添加效果，也可调整顺序或删除。
- 只选中一条台词时自动展开演出参数。参数修改立即反映到预览，点击「播放预览」查看播放过程，也可暂停或拖动进度。
- 数值可以先清空再填写，支持负数和小数；未填写完的草稿不会把作品参数改成零。
- 开关只改变编辑视图并记住本机偏好，原指令、顺序和资源引用仍保存在工程中。修改正文、右侧调参和撤销共用编辑历史。

独立演出的 `@独立演出` 声明保留可选择的模块入口。无法解析的指令保持可见；正在输入的新指令也不会立即消失。

删除整句对白时，其关联演出和配音一起删除；插入新台词不会把下一句的演出移给新台词。撤销会一起恢复。

## 独立制作与实时预览

顶部「蓝图」统一编辑演出与逻辑，「流程图」独立用于剧情连接。也可以在文本里 Ctrl+点击演出指令，或右键选择「在蓝图中编辑演出…」。

工作区直接制作可复用的演出蓝图。上方选择已有蓝图或点击「新建演出」，用「时间轴」安排片段，用「节点蓝图」编辑条件、参数和连线。时间轴横跨创作区域，预览单独显示；这里预览的是选中的蓝图定义。

Ctrl＋左键点击演出调用进入对应蓝图。章节进入演出使用外层蓝图，输入参数连接到内部时间轴组件；双击组件打开时间轴，点击“返回蓝图”继续编辑连线。

是否创建独立模块只由 `@独立演出：模块名称` 决定。调用写在声明上方，例如先写 `@章节进入演出文字版：标题=第一章`，再写 `@独立演出：章节进入`。多个调用可由一次声明组成同一个模块；不写声明则附着下一句台词。工作区“试播方式”只切换预览环境，不修改剧情结构。

旧章节专用指令不再提供。载入旧工程时保留章节内容、素材、时长、剧情身份与连接，转换为普通蓝图和明确的独立演出声明；未应用的其他文本保持原样。

章节时间轴由普通文字、图片、色块与组合对象组成，可以更换素材、调整动画和组合前后的演出。时间标尺和播放头均可连续拖动定位；中键或空格加拖动平移，滚轮横向滚动，Ctrl 加滚轮缩放。片段支持跨轨移动、边缘调时长、吸附和边缘自动滚动；按住 Shift 暂时取消吸附。刻度网格跟随缩放，可用「适合窗口」显示整段；操作见[轨道与参数](authoring-tracks-and-parameters.md)。复杂交互仍通过顶部「试玩」验证。

双击灰色组合片段进入组合剪辑工作区，每个子对象显示为一条轨道。双击子组合或点击轨道上的“进入”继续往里编辑，顶部路径和“返回上层”用于返回。绿色显示区间的双击和 Enter 也会打开相应组合并选中对象。

- 拖动片段调整出现时间，拖动左右两端调整开始和结束；上方图层显示在前面，拖动左侧手柄调整顺序。
- 选中片段后直接修改文字、字号、图片、位置和透明度。暂停预览时，也可在画面中拖动当前层的对象。
- 从左侧素材库拖入图片或角色，工具栏添加文字、色块和组合。“元素”分类还可添加粒子效果。
- 点击属性旁的菱形添加关键帧，开启“关键帧”后可直接拖动时间轴中的菱形。Ctrl＋滚轮缩放，Shift＋滚轮横向滚动；方向键移动片段，Alt＋方向键调整时长，Shift 增大步长。
- Ctrl＋D 复制，Delete 删除。每次拖动和复制都能单独撤销，Esc 取消正在进行的片段拖动。

超出组合可见范围的片段仍保留在轨道中，可通过开始时间或“移到开头”移回。已有公开文字和图片参数可直接修改默认值，共享此参数的其他对象会同步更新。由蓝图计算的属性需在组件连线中修改。

原来的完整效果表单保留在“高级效果”或“详细编辑”入口。真正的时间轴组件仍通过双击打开内部时间轴。

## 从提示定位到具体控件

重复的文本问题列表和操作提示已从预览侧栏移到左下角状态区。点击问题数量展开底部列表，问题会显示具体路径，并提供定位和处理说明。

例如未绑定按钮会显示类似：

```text
界面 / 夜间界面 / 对话 / 打开背包
按钮“打开背包”尚未绑定点击行为。
```

点击问题会进入「界面」，选择正确的页面和界面实例，在层级中选中该控件，并聚焦「点击行为」。可以选择内置行为、调用蓝图，或为该按钮配置「点击控件时」事件。已有点击事件的按钮不会再被误报为未绑定。

只查看问题不会改变游戏使用的界面实例。在定位出的实例内修复控件时，修改只作用于该实例；主题默认、自定义页面和其他实例不会被连带改写。修改可以撤销。

指令补全和参数填写提示仍在输入位置显示；预览状态及音频试听也继续保留。

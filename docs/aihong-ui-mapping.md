## 已确认的资源

用户素材根目录为 `E:/Project/Model/SLY/T/Assets`。本轮只读取该目录，没有修改原素材。

- `Texture2D` 包含 `UI_CN.png`、`UI_Common.png`、`UI_Common_1.png`、`UI_Common_2.png`、`UI_Common3.png` 等界面图集，以及 `title_bg.png`、标题按钮和部分对话菜单按钮图片。

- `Resources/title/titlebg` 包含多个结局对应的标题背景，`Resources/title/chapterbg` 包含章节背景。

## 层级文件的实际内容

当前导出包中的 `PrefabHierarchyObject` 是 GLB 文件，不是可直接读取 Unity UI 组件的 `.prefab` 文件。本轮解析了下列 GLB 的 JSON 块：

| 文件 | 节点数 | 已保留信息 |
| --- | ---: | --- |
| Main Menu.glb | 19 | 名称及父子关系 |
| Pause Menu.glb | 7 | 名称及父子关系 |
| SaveLoadItem.glb | 15 | 名称及父子关系 |
| CgGalleryItem.glb | 6 | 名称及父子关系 |
| SoundRoomItem.glb | 2 | 名称及父子关系 |
| UI_MessageBox.glb | 7 | 名称及父子关系 |

这些文件没有网格，也未提供完整的 RectTransform 布局、字体参数、按钮行为和动画配置。`Main Menu.glb` 的子项还包含 Accessibility Settings 和 Difficulty Dropdown，不能仅凭文件名把它认定为原作的标题页。

因此，素材名和层级名可以帮助建立资源清单，但不足以证明位置、字体、状态和交互与原作一致。

存档分页采用 `SaveLoad/GridPage/PageCarousels/Carousels/CarouselButton` 的图片、选中标记和纵向位置。原作轮播区域会在运行时展开，模板为 Ren’Py 的上一页、自动、快速及页码预留居中的 880 像素区域，不再铺满屏幕遮挡返回。普通按钮使用浅色文字，选中后使用深色文字；位置与两种文字颜色均可在“存档格内部布局”中修改。

历史页面按 `UI/BackLog` 恢复背景、标题、返回按钮和条目布局。按钮皮肤通过原始简体中文图片关联读取，避免选择同名日文版本。章节按钮使用无字底图叠加可编辑章节名；标题和正文按背景调整颜色，避免重复文字和低对比度。章节与流程页提供互相切换的入口，额外故事按钮维持锁定。

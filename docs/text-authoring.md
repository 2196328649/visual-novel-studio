# 中文文本编剧

本版可拖动文本与预览之间的分隔条，双击复位。「自动换行」只改变长行的显示，不添加真实换行。未点击播放时，预览显示本句演出完成后的画面；点击播放后才播放演出、音效和配音。背景音乐在下方手动播放。暂停后修改参数保留当前时刻，停止后恢复完成画面；拖动进度条或时间轴播放头后，空格可播放／暂停。

游戏流程图按标题控制：`#章节(流程图=是，显示名称=酒醒): 第一章 · 酒醒城破`。章节默认显示，小章节和段落默认隐藏，显示名称默认是冒号后的标题；小章节、段落也可设置「流程图=是」。自动生成的内部执行节点不会伪装成段落标题。

`@播放台词演出` 可放在本句演出指令中间，从该处开始文字与配音，后面的动作继续。章节进入演出的声音使用「章节音效」，背景音乐用 `@背景音乐` 控制。文字版四区参数与完整示例见 [v0.8 说明](release-0.8.md)。

进入顶部的“剧本”工作区，在“模块编辑”和“文本编辑”之间切换。两种模式始终共用右侧实时预览、剧情目录、选中的对白与撤销历史，切换时同步有效内容。模块模式把演出放在台词上方，说话人与台词并排；点击演出模块展开参数，用每行的加号添加背景、角色、音乐、配音、等待、镜头和效果。段落及逻辑节点的设置也在对应模块里展开。

文本模式提供行号、语法颜色、查找替换、指令与素材补全。常用指令也可通过 `/` 或中文全角 `／` 菜单插入。“应用到项目”可手动同步，“实时试玩”和顶部“试玩”使用 Ren'Py 运行时。

默认只显示当前章节，通过左侧剧情目录选择章节、段落或台词；每章数千句也只渲染可见的高亮行和结构行。切换章节会记住光标和滚动位置，关闭重开会恢复所选章节与文本模式。修改当前章会拼回完整剧本，保留其他章节的正文和已有编号。

查找、替换、批量演出与右侧“结构”跟随当前章；文件导出使用完整工程的有效文本。入口和全局指令仍是剧本内容，可通过剧情目录定位。“保存工程”保存当前文本草稿，“应用到项目”将有效文本同步到节点；章节之间的跳转仍按整个作品解析。

左侧章节名右侧的垃圾桶删除整章及其小章节；小章节行的垃圾桶只删除该小章节。删除后可以撤销、重做。包含故事入口的目录不能直接删除，请先更换故事入口；至少保留一个章节和小章节。目录新增、删除读取当前文本草稿，保留其余正文、注释和演出指令。指向被删除目录的显式跳转或调用会提示目标缺失，请重新选择目标。

AI 助手可以通过工程修改新建章节、小章节和段落，先预览修改再应用。导入 TXT、MD、DOCX 时，目前按文件中的 `# 章节：名称`、`# 小章节：名称` 等声明建立目录；导入流程尚不支持根据无标题正文的剧情含义自动分章。完整导入会替换当前剧情，应用后可撤销。

剧情脚本标题栏的「隐藏演出」可收起正文中的演出与配音指令，右侧实时预览下方默认只显示选中的台词。单选时自动展开演出参数，选中多句时显示对应台词；勾选「显示未选中台词演出」可展开本段的其他内容。隐藏不删除指令，开关与编辑均保留光标位置。顶部「演出」工作区提供模块、蓝图与轨道，详见 [轨道演出与参数集](authoring-tracks-and-parameters.md)。

旁边的「彩色标注」默认关闭。开启后，`#` 标题显示紫色，`@` 指令显示青色，各发言人的整行台词按姓名分配稳定颜色，旁白也有自己的颜色；颜色适配明暗主题。开关保留原文、光标和选区，并记住本机偏好，可与“隐藏演出”同时使用。着色只处理可见区域附近的行，不增加全文剧本解析；关闭时跳过着色分类。

实时预览标题栏的“跟随光标”决定是否随当前台词更新；取消勾选可固定预览。点击“播放预览”按顺序播放本句的转场、角色、镜头、等待、BGM、音效与配音，并按玩家初始文字速度逐字显示台词。停止、切换台词、打开设置或进入完整试玩时会清理当前播放。涉及交互或自定义脚本的蓝图仍使用完整试玩验证。

集中写作时，可点击实时预览栏的“暂停实时预览”。暂停后停止画面、演出和音频预览，仍可输入、切换台词、隐藏演出、撤销和保存。“恢复实时预览”会显示当前选中的最新台词。暂停偏好会在重开编辑器后保留；它与播放过程中的“暂停预览”分别控制实时预览开关和单次播放进度。

## 补全与参数提示

在指令名或参数处输入中文、拼音首字母、完整拼音或常用英文别名，会在光标附近展开补全。例如 `@xsjs` 补全为 `@显示角色：`，角色参数中输入 `sly` 可选择“苏怜烟”。表情候选随角色变化，素材按背景、BGM、配音、音效分别筛选，图片候选附带缩略图。

滚轮上下滚动候选，↑↓ 改变选择，Enter、空格或 Tab 接受，Esc 收起；Ctrl+空格主动展开补全。中文输入法组词期间不接管 Enter。参数提示会突出当前项：`@显示角色：穗，通常，0.5，0.4，1.2` 依次是角色、表情、横向位置、缩放、纵向位置，`0.4` 表示立绘原始大小的 40%。也可只写指定参数，如 `@显示角色：穗，缩放=0.4，纵向位置=1.2`，未写的参数沿用默认值。点击签名中的「表情」会添加或定位 `表情=`，随后选择表情。显示立绘统一使用 `@显示角色`。

角色纵向位置以立绘底部为锚点：0 为画面顶部，1 为画面底部；大于 1 会把立绘底部移到画面外，可配合缩放形成半身构图。横向、纵向位置和镜头偏移都可为负数或大于 1。在右侧“编辑舞台”拖动角色，或在演出模块调整位置时，会回写指令中的数值。图层默认 10。角色过渡分别设置入场、离场与表情切换，例如 `@显示角色：穗，表情=通常，入场过渡=移动，入场秒数=0.8，离场过渡=渐变，离场秒数=0.5`；支持立即、渐变、先淡出再淡入、移动。整组省略则继承角色设置，默认离场为 0.5 秒渐变。旧的“转场／时长”参数已移除，不再识别。

## 基本语法

插入指令会保留编辑位置。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；工具栏插入和斜杠插入各自作为一次操作，不会把前面的输入一起撤销。顶部撤销按钮也使用相同历史。

Ctrl+F 查找，Enter / Shift+Enter 或 F3 / Shift+F3 查找下一处或上一处；Ctrl+H 打开替换，可单处替换或全部替换，一次批量替换可一步撤销。Tab 插入两个空格，选中多行时统一缩进，Shift+Tab 取消缩进。点击左侧行号定位整行，底部显示光标所在行列；错误提示与预览均使用可见正文的行号。

文本模式只显示正文、中文名称和演出指令。对白标记以及章节、小章节、段落、素材等引用中的内部编号均由编辑器隐藏维护，日常编辑和复制文本不需要携带编号。新增对白直接输入“角色名：正文”，演出通过 `/` 插入并编辑。工程文件仍保留编号，以维持已有身份和连接；它不触发游戏存档。正文、选项和标题中自己写的 `【括号文字】` 会原样保留。

“配音”“背景音乐”“音效”和“背景”指令会分别打开对应分类，沿用资源管理器的文件夹分组；缩略图按钮可打开图片预览或音频试听。需要选择其他用途的素材时，可在浏览弹窗里切换分类。

每一行可以是标题、对白、指令或空行。建议用空行分隔段落，用 `---` 结束当前段落。

```text
# 章节：第一章
# 小章节：校门
# 段落：雨后相遇
@背景：校门
@背景音乐：雨声 循环
旁白：雨后的空气很清澈。
小雨：你来了。
@效果：入场
@跳转：图书室

# 小章节：图书室
# 段落：窗边
旁白：我们翻开书页。
# 段落：是否留下
@选择：要留下来吗？
@选项：留下来 -> 温暖结局
@选项：先回家 -> 独自结局

# 段落：温暖结局
@结局演出：文字=我们在窗边读完了这个故事。
@独立演出：温暖结局
@返回标题界面

# 段落：独自结局
@结局演出：文字=我独自走上了归途。
@独立演出：独自结局
@返回标题界面
```

### 标题和对白

`#` 只负责整理目录，不是注释，也不会播放章节过场、更换背景或执行跳转。只接受下面三种声明。`#`、`##`、`###` 的数量不改变层级，层级由“章节 / 小章节 / 段落”决定。在行首输入 `#` 可以补全这三种声明。

| 声明 | 作用 |
| --- | --- |
| `# 章节：名称` | 章节目录，后续小章节归入其中 |
| `# 小章节：名称` | 章节内的目录分组，后续段落归入其中 |
| `# 段落：名称` | 为这段内容命名，便于目录定位和跳转 |

段落里的台词和 `@` 指令决定播放内容。例如 `# 段落：前往码头` 只命名这段内容，下一行 `@跳转：码头入口` 才执行跳转。章节过场调用 `@章节进入演出文字版` 或 `@章节进入演出图片版`，随后用 `@独立演出` 声明独立模块，选择写成 `@选择`，片尾使用普通时间轴 `@结局演出`，随后用 `@返回标题界面` 结束。

- `@跳转：名称` 跳到指定章节、小章节或段落。跳到章节或小章节时进入其剧情入口；仅更换背景图使用 `@背景`。
- `角色名：对白` 建立角色对白；没有角色名的普通句子或 `旁白：内容` 是旁白，不会创建角色。
- `@选择：文字` 显示问题；后续 `@选项：文字 -> 名称` 添加回答和去向。
- `@设置：好感度 += 1` 或 `@变量：已来过 = 是` 修改状态变量。变量不存在时会按值类型创建。
- `@设置：如果 章节进度 < 2，章节进度 = 2` 只在条件满足时修改状态，保留已有的更高进度。
- `@结局演出` 调用可编辑的普通结局时间轴，支持字幕和时长参数；`@返回标题界面` 返回标题。旧工程中的 `@结局：文字` 会在载入时迁移为普通演出；新剧本调用 `@结局演出` 后，用 `@独立演出：片尾` 声明模块。
- `@调用：名称` 进入可复用剧情；被调用的剧情用 `@返回` 结束，再继续调用处后面的内容。调用后的 `@跳转` 可指定返回后继续的位置。
- `@实例：名称` 保留蓝图中已有节点的配置和连接，适用于复杂条件、互动、小游戏等内容。

普通内容省略 `@跳转` 时按文本顺序继续。跳转后新写的台词属于后续内容，不会挤进跳转前的对白。`@跳转：无` 表示不连接后续内容。

这个顺序也跨越章节标题：第一章末尾没有返回标题或其他流程指令时，会继续到文本中的第二章。已有 `@返回标题界面`、`@跳转：无` 或指向其他位置的连接不会因新增目录而改变；需要续接时移除终止指令，或将跳转目标改为下一章。整部剧本最后一句仍按正常对白等待玩家推进（开启自动播放时由自动播放推进）；没有后续内容后返回标题界面，不会自动生成片尾演出。

`@入口：开始` 设置整部作品的故事入口。冒号后的“开始”是一个目录项的名称，和 `@入口：雨后相遇` 中的“雨后相遇”一样，可以由用户命名。入口可以直接指向对白、章节过场等内容，不要求目标是“开始”类型的节点。

`@开始` 则把所在段落定义为一个**流程起点**，沿下一段连接继续，用于蓝图或小章节入口。它没有台词或入场特效，也不会覆盖显式指定的故事入口。普通顺序剧情通常不需要手写这两条指令，编辑器会维护默认入口。

剧本窗口上方显示当前“故事入口”，点击可进入作品设置更换。`@入口` 支持目录项名称和拼音补全；补全菜单与插入指令面板会说明它和 `@开始` 的区别。

```text
# 段落：问路
@调用：打听消息
@跳转：码头入口

# 段落：打听消息
旁白：前面的路已经封住了。
@返回

# 段落：码头入口
旁白：我们沿河走向码头。
```

普通跳转写为 `@跳转：归途`。需要过渡时可以写 `@跳转：归途，淡入淡出，1.2，#112233`，也可以写 `@跳转：归途，切换方式=淡入淡出，时长=1.2，颜色=#112233`。转场可用于任意目录目标。

名称用于选择剧情目标与素材。选择器在工程内部记录稳定引用，文本模式只显示中文名称；重命名段落后，原编号和连接保持不变，同步时其他位置的名称一同更新。手动修改某条指令引用的素材或目标名称时，会重新按新名称选择目标。手写名称需要能够确定唯一对象；同名素材可以通过插入指令的选择器明确选择，缺失或歧义会提示所在行。

### 检查提示和定位

“从故事入口无法到达某段落”表示从新游戏入口沿当前剧情连接走不到那里。常见原因是前一段的 `@跳转` 跳过了这段、选项没有指向它，或者蓝图连接断开。备用内容可以暂时保留，这类提醒不阻止试玩。更改故事入口也会改变哪些内容可以从新游戏到达。

点击左下角的问题数量展开底部列表，可查看完整目录路径、文本位置及“定位文本 / 定位模块 / 定位蓝图 / 定位控件”等入口。点击问题会定位并展开处理说明；问号按钮可以只查看原因。文本模式会选中指令或段落行，需要时暂时显示隐藏的出错指令。模块模式会切换到对应小章节并选中模块。界面问题会明确页面、实例与控件；未绑定按钮可直接定位到“点击行为”。列表支持滚动和收起。

### 场景、音频和演出

舞台动作写在对白前面，会附加到紧随其后的对白行：

| 文本指令 | 作用 |
| --- | --- |
| `@背景：图片名称` 或 `@切换背景：图片名称` | 切换背景并使用淡入过渡 |
| `@背景音乐：音乐名称 循环` / `@背景音乐：音乐名称 不循环` | 播放背景音乐 |
| `@显示图片：图片名称` | 默认仅本句显示，推进台词后离场 |
| `@音效：音频名称` | 播放一次音效 |
| `@停止音乐：0.5` | 用指定秒数淡出音乐 |
| `@显示角色：角色，表情，0.5，0.4，1.2` | 在舞台显示角色、表情，并设置横向位置、缩放和纵向位置；纵向位置可省略，默认 1 |
| `@隐藏角色：角色` | 隐藏角色 |
| `@等待：1` | 等待指定秒数 |
| `@震动：横向，1，20，是` | 方向、时长（秒）、幅度（像素）、是否等待完成；后面三项可省略 |
| `@镜头：0，0，1.15，0.8，0，缓入缓出，否` | 横移、纵移、缩放、时长、旋转、缓动、是否等待完成；后面三项可省略 |

图片的位置、旋转和独立 X/Y 缩放统一放在一个「变换」参数中。可以省略整组或其中任意项，默认位置为画面中央、两轴缩放为 1、旋转为 0；缩放以适配画布后的图片为基准：

```text
@显示图片：题图，变换={"位置":[0.5,0.4],"缩放":[0.5,0.5],"旋转":0}
@显示图片：徽章，对象ID=badge，显示范围=持续显示
@显示图片：闪光，显示范围=定时显示，时长=2
```

「仅本句」在玩家推进台词后按离场设置隐藏；「持续显示」保留到隐藏对象或切换背景；「定时显示」按秒数结束。仅填写正时长也会使用定时显示。独立演出中的「仅本句」图片随该演出结束清理。

右侧「图片变换」按位置 X/Y、旋转 Z、缩放 X/Y 分组，X 单独控制宽、Y 单独控制高；面板使用百分比，文本使用比例。数字输入框支持左右拖动参数名，Shift 精调、Ctrl 加速，Esc 取消本次拖动。拖动只更新预览，松开后统一提交，一次撤销即可恢复。开启「编辑舞台」后，拖动图片移动位置，拖动四角分别调整两轴，按 Shift 拖动四角保持比例，旋转把手调整角度。

同一个对象 ID 换成另一张图片时，「替换过渡」控制旧图如何切换到新图，例如日间照片渐变成夜间照片。不同 ID 会同时显示两张图。只显示一次的图片使用入场和离场设置即可。

章节演出是普通蓝图，内部调用时间轴组件，公开参数通过数据线传给组件。示例：`@章节进入演出文字版：第一行小字="- 记或忆 -"，第二行小字="- 第一回 -"，标题=醉梦，右侧字="1645 弘光元年"，时长=7`。下一行写 `@独立演出：章节进入` 才单独占用模块；省略时，调用附着到下一句台词。蓝图的名称、类型和包含几个时间轴都不会自动拆分剧情。

`@独立演出` 只收束它上方的演出。写在它之后、下一句台词之前的 `@背景`、角色和音频等指令属于那句台词；开启“隐藏演出”后会随台词收起，不需要额外插入空行或段落标题。

时间轴工具栏的“播放设置”打开“允许点击跳过”和结束转场。由剧情进入演出时，“设置范围”可选择当前调用或演出默认值；恢复演出默认设置会清除该调用的覆盖。章节演出默认禁止点击跳过。设置也可直接写在 `@独立演出` 声明同一行：

```text
@等待：2
@独立演出：片尾停留，允许点击跳过=否，结束转场=纯色，淡出=0.5，停留=0，淡入=0.5，颜色=#000000
@返回标题界面
```

`模块名称`、`允许点击跳过`、`结束后`、`结束转场`、`淡出`、`停留`、`淡入`、`颜色` 都支持按参数名填写。`结束后` 可选“继续剧情”或“返回标题”；转场可选“无”“溶解”“纯色”。名称含逗号时用引号包住；名称和设置均可省略，省略的设置继承演出默认值。旧工程中的独立设置行在载入时合并，原有台词、注释和模块连接保留。

图鉴条件在“界面 → 画廊”中选中画廊网格设置。分组、分镜及未分组的单张图片都可选择“参数条件”。例如选择参数集中的“章节进度”、比较方式“大于或等于”、值 `2`，再在剧情中写上面的条件赋值，即可在进度达到 2 时解锁。`> 2` 需要进度大于 2 才解锁；需要跨周目保留时，在参数集中开启“跨存档保留”。显式条件以参数为准，剧情中显示过图片不会绕过它。

资源名称来自“素材”页面的显示名称。也可以使用英文半角 `/` 或全角 `／` 开头；例如 `/背景音乐：雨声 循环` 与 `@背景音乐：雨声 循环` 等价。

让镜头和震动同时播放：先写不等待的 `@镜头`，紧接 `@震动`。例如 `@镜头：0.06，0，1.15，1，0，缓入缓出，否` 后接 `@震动：横向，1，20，是`，两者同时开始，一秒后进入对白。位置与缩放可超出原有编辑范围，参数输入框允许清空后重新输入。

## 可复用效果

在剧本中选择一行，到属性面板添加背景、角色关键帧、镜头、震动或音频等演出动作。点击“保存为效果”，输入中文名称；随后可以在任意文本位置写 `效果 名称` 或 `@效果：名称`，也可从斜杠菜单选择该实例。简单效果还可以直接定义：

```text
@效果定义：入场
@动作：震动：横向
@动作：等待：0.2
@动作：镜头：0，0，1.1，0.6
@效果结束

# 段落：相遇
@效果：入场
旁白：镜头从雨幕中推进。
```

效果定义支持背景、BGM、音效、角色、等待、镜头和其他效果调用等动作。缺失资源、缺失效果和递归调用会被诊断，修复错误后才能试玩和导出。复杂关键帧和特殊参数通过自动生成的 `@演出实例` 保留；其后的对白仍可直接改写。配音使用 `@配音` 指令，内部对白编号不占用正文行。

属性栏顶部的星光图标打开“管理效果”。可以新建、重命名、修改或排序共享效果动作；保存后，引用此效果的对白和其他效果一同更新，也支持撤销与重做。仍被调用的效果不能删除，需先移除或替换调用。列表会排除造成循环调用的目标。

## “/”快速指令

在文本编辑框中输入 `/` 或 `／`，会打开中文指令面板。可筛选跳转、背景、BGM、音效、停止音乐、角色、效果、等待、震动、镜头、状态和剧情指令。需要参数的指令会打开参数面板：

- “跳转”按章节、小章节、段落分组选择目标，可设置过渡；“调用”使用相同的目录目标；
- “背景”“BGM”“音效”从素材库选择资源，“停止音乐”设置淡出秒数；
- “显示角色”选择角色、表情、横向位置、缩放和纵向位置；“隐藏角色”选择要隐藏的角色；
- “效果”选择已定义的效果实例；
- “设置”选择变量、运算和数值；
- “选择”填写问题，“选项”填写回答和目标，“返回”结束调用，“返回标题界面”结束故事；片尾可调用普通“结局演出”；
- “复用节点”统一复制已有剧情、互动和小游戏的设置。“角色功能”用于调用角色已定义的组合演出，没有定义时不显示这个入口。

插入结果仍是普通中文文本，可以继续手动修改。`Esc` 关闭面板；工具栏的“插入指令”也能在没有输入 `/` 时打开同一面板。

内置指令列在“基础”分组，可编辑蓝图按资源管理器文件夹分组；组标题可展开和折叠。滚轮滚动，↑↓ 选择，Enter 或空格采用。蓝图可以写为 `@蓝图名称：值1，值2` 或 `@蓝图名称：参数名=值`，两种填写方式可以混用。调用名称可在蓝图设置中单独指定。右键调用行可以修改蓝图名或调用名，并一起替换已有调用；支持整体撤销。选中连续演出后，还可封装为带默认参数的蓝图；Ctrl+点击调用文字进入图编辑。右键也可为所选台词批量添加演出，详见 [蓝图与批量演出](blueprint-authoring.md)。

章节调用与独立演出使用同一预览区域。Ctrl＋左键点击调用先打开外层蓝图，双击时间轴组件进入动画编辑，再通过“返回蓝图”回到参数连线。旧章节指令已移除；旧文件在载入时转换，不作为可继续创作的语法。

## 导入 DOCX、TXT 和 Markdown

点击“导入文本”选择 `.docx`、`.txt` 或 `.md`。DOCX 按正文顺序读取段落、表格文字、制表符和换行，忽略删除修订与字段指令；字体、颜色、图片、批注和 Word 样式不转换为演出。TXT/Markdown 支持 UTF-8、带 BOM 的 UTF-16 LE/BE，并对非 UTF-8 文本回退使用 GB18030。单个文件上限为 32 MB，DOCX 解压后的正文上限为 16 MB；损坏、加密或包含外部实体声明的文档会显示中文错误。

导入后先选择“完整导入”或“仅更新台词”，核对预览，再点击“应用导入”。解析错误会显示在对话框中并阻止应用。原文件名称记录在工程的文本来源中；导入不复制 DOCX 本身，也不自动导入其中的图片和音频，素材仍需在素材库中导入并按名称引用。整次操作可撤销。

## 导出文本与保留演出的改稿

模块编辑和文本编辑的工具栏都提供“导出文本”，保存为 UTF-8 TXT。也可让AI提供“导出完整脚本”“导出纯对白”“导出对白修订稿”按钮，直接选择保存位置；导出包含当前有效草稿，不会保存工程。AI的“导入文本…”按钮打开相同文件选择与审阅流程，应用前可取消，应用后可整批撤销。

三种格式如下：

| 格式 | 用途 |
| --- | --- |
| 完整剧本 | 台词、演出、配音、流程指令及稳定引用；可在当前工程重新导入。资源、蓝图和复杂实例仍依赖工程。 |
| 对白修订稿 | 角色名、台词和 `@对白标记`；可重排记录或只保留需要修改的句子。 |
| 纯台词 | 只有角色名与台词，同时生成同路径的 `.vns-lines.json` 对应表；多行对白用制表符标明续行。 |

仅改文字时，导入对话框选择“仅更新台词：保留演出、配音与流程”。通过稳定行标识匹配，不依赖会随指令增删而改变的屏幕行号。更新会保留每句的角色、演出、配音和节点连接，也保留源文本中的命令与注释。带指令的完整剧本也可这样导入，其中的演出指令不会覆盖当前演出。

纯台词请保留对应表，并维持对白数量和顺序；增删或重排请使用带行标识的修订稿。数量不符、角色不符、检测到原台词乱序，或工程在导出后已独立修改时，会要求核对，避免错配。没有行标识和对应表时，可以明确勾选“按当前对白顺序替换”；数量必须相同，并须核对逐句预览。删除修订稿中的记录不会删除工程内未提及的台词。

对应表及原 TXT 与工程放在一起，方便下次回填。需要新增、删除或调整完整剧情结构时，选择“完整导入”。

## 文本与蓝图的同步边界

文本和蓝图使用同一份 `Project` 数据，但两者不是两个独立的版本库：

1. 画面预览跟随光标，也可选定对白；显示背景、角色、对白，并支持音频试听和演出重播。它按编辑文本顺序呈现画面，不模拟所有条件、调用栈和小游戏结果；这些流程用真正的试玩验收。
2. 顶部试玩、导出和“实时试玩”使用当前有效草稿。遇到文本错误会阻止并定位，不会静默使用旧稿。“应用到项目”或转到图形编辑页时，将有效草稿同步到共享工程；错误草稿须先修正，素材库仍可用于解决资源引用。
3. 保存、自动保存和撤销包含文本草稿，尚未应用或有错误的内容也可以保留。应用文本重建正文中声明的剧情结构，保留素材、角色、变量和界面。稳定引用维持节点、场景和对白身份；图形修改也会同步为文本。
4. 组合条件、点击互动和小游戏通过“实例”保留；复杂演出仍保留可编辑对白。详细参数在蓝图、预览内的“编辑舞台”或演出模块中配置。实例依赖所在工程，单独复制文本不能代替完整工程备份。
5. 导入正文会替换文本中未声明的剧情结构。操作可撤销；重要改稿前也可另存工程副本。运行错误仍可从问题面板定位节点或对白。

建议流程是：先导入或编辑文本，确认实时结构预览无提示，应用并在蓝图中检查连线，再在右侧预览打开“编辑舞台”补充复杂演出，最后保存、试玩和导出。

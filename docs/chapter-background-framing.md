# 章节背景取景

在“界面 → 章节标题 → 游戏设置 → 章节进场 → 章节背景与消散效果”中，可调整背景横向、纵向偏移。单位为画面宽度、高度的百分比，正值向右、向下；只移动背景，不移动题字、蒙板和底纹。设置对全作品章节演出生效，也可用于台词或独立演出中的章节动作。

哀鸿模板使用横向偏移 `265 / 1920`（界面显示约 13.802%），来自原作前两章的 `ChapterAnimation` 命令。旧工程未设置时保持居中。波动开启和关闭均保留偏移。

原作直接截图见 `artifacts/original-visual-2026-09-30/title-start-*.png`。菜单点击到截图的时间包含加载，不能直接等同于内部动画时间。题字入场、停留、消散、背景淡出的阶段已观察；粒子随机分布不承诺逐像素相同。

# 组合内部显示区间与参数（2026-10-03）

本轮继续用户要求的剪辑编辑一致性，修正可选“显示区间”辅助轨道的内部对象拖动。整体 goal 未完成，其他 UI 工作流、原作对照与 AI 操作矩阵待办继续保留。

## 问题与修正

旧实现读取已套用字面参数的组合再整体写回，并删除全部 `object_*`。最小复现中原组合 4 秒、覆盖 8 秒，移动子对象后原组合被改成 8 秒，外层时长及子文字覆盖被清空。首次复现命令因 stdin 中误用 TypeScript 非空断言而报语法错误；改成 JavaScript 后确认上述结果。

新增 `editTimelineVisualLifetime`，按稳定实例身份找到原始子对象，将时间轴上的移动量换算到父组合的原始时间；裁剪则只更新该子对象已有的时长输入。子对象自己的动画比例与祖先组合比例分开处理，避免重复缩放。原始关键帧、其他时长/图片/文字覆盖及兄弟对象保持。可见区间被父组合裁切时，右边缘按屏幕上的可见末端修改。

保留原有对已连接组合参数的拖动限制，不替用户解除连线或修改计算节点。非法值和失效对象在写入前拒绝。本轮没有把内部对象改成必须使用的蓝图节点。

截图检查另发现播放时刻的采样数值显示如 `50.0000108506945`。属性框现在最多显示三位小数；原始数据和预览采样不取整，只有实际编辑才产生属性帧。

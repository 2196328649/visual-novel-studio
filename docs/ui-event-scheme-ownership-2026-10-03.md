# 控件事件按当前界面方案保存（2026-10-03）

在子方案中查看父方案事件图时，原来的按下/悬停、值改变和文字提交入口可能直接向父方案图添加节点。现在从左侧控件新增事件时，只复用当前页面、当前方案拥有的图；没有合适的图则创建一张。查看父方案、共用图或其他页面的绑定图，都不会使新增事件落入这些图。

已有事件仍可直接定位。当前方案和父方案都有对应事件时，优先定位当前方案的事件。只有继承或共用事件时，侧栏提供“为当前方案添加悬停事件”“为当前方案添加文字提交事件”等入口，并说明原有事件仍会执行；新增不是覆盖继承行为。点击事件采用相同归属规则，保留原来的独立点击入口和执行顺序列表。

查看继承或共用图时，顶部显示图的来源及编辑影响。直接修改所选父方案图依旧是修改父方案；这次隔离的是左侧控件的新增事件入口，不改变手动编辑已有图的语义。自定义页面没有方案作用域，按页面归属复用事件图。窄侧栏中的新增按钮可换行。

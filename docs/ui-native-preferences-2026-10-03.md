# 标准设置与角色音量交互预演（2026-10-03）

本轮补齐控件事件图预演中标准设置页和角色音量页的内置操作。此前只显示作者放置的组件，标准设置入口打开后缺少实际滑块和选项，不能完整验证控件事件与设置读取的联动。整体 goal 仍未完成。

## 实现

`ui-native-preview.ts` 根据当前方案和页面布局生成临时设置控件，不写入工程。标准设置支持滚动，保留作者覆盖的控件；角色音量按角色身份独立替换。自定义布局继续使用作者的组件。内置控件使用与作者控件相同的测试状态，事件图可以立即读取变化后的值。

支持显示模式、文字速度、自动推进、跳过范围、转场、各类音量、对话透明度、静音、语音延续、分辨率、可见且未放置的设置参数及恢复默认。显示模式与分辨率只改变测试状态，不改变编辑器宿主窗口。标题入口的存档和历史导航禁用，设置页支持 Escape/右键返回，角色音量返回设置。

恢复默认复用标准或自定义确认层，实际确认后恢复作者设置默认值、角色音量及包含隐藏项的设置参数，并取消静音；剧情参数和转场偏好保持，与原生 `vn_reset_preferences` 一致。过期确认不执行。内置转场按钮的选中状态遵循原生 ToggleField 的值，沿用现有“跳过转场”文案。

真实舞台音频和收藏语音的增益纳入静音状态。测试变量在设置预演中折叠，设置画面使用完整面板宽度，内置内容滚动、作者组件覆盖在其上方。1024 宽窗口没有横向溢出。切换“按时间预演”仍会按既有行为重置页面与事件历史。

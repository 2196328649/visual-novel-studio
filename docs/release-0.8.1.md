# 叙事工坊 v0.8.1

发布日期：2026-11-15。Windows 10/11 64 位。

本版整理从编剧到导出的常用编辑流程，集中改进剧情结构、玩家剧情图、属性编辑、蓝图、时间轴与 AI 助手。安装版和便携版自带离线运行时，内置空白作品、哀鸿两章分支模板及模板库。

## 本版变化

- **剧本与角色**：模块编辑和中文文本共用舞台预览，台词旁小箭头展开文字演出，局部文字可单独设置样式、计时和动画。“显示角色”使用固定“第几个”编号；同号更新同一角色副本，隐藏后其他编号保持，相邻台词续用角色时保留画面。
- **剧情结构与过渡**：流程图逐层进入章节和剧情组，同级节点可框选打组、嵌套、解组和撤销；实际连线可设置切换过渡及时间。游戏页面出口、覆盖层及剧情入口与真实执行关系对应。
- **玩家剧情图**：内容可跟随剧本或由当前图自定义，展示可用分支图或目录列表。自定义图管理已有剧情入口、顺序、显示分组和独立位置。节点支持多段文字、各段字体、字号、颜色、字间距和段后间距。子剧情调用显示进入与返回后的后续，可逐层浏览共享正文；解锁和重玩返回按实际调用位置处理。
- **界面属性**：上方通用属性编辑位置、大小、层级、显示与子对象，下方控件功能编辑内容、外观和交互。存档、历史等列表的内部文字和按钮可独立编辑。属性名称或输入区支持右键查看来源、恢复单项、单向跟随参数或双向同步。
- **蓝图与参数**：中文节点、成员和属性集中在左侧，普通蓝图保留主要画布空间；界面事件图采用上方目录、下方唯一详情。参数集只负责分组，每项独立选择保存方式和是否参与恢复初始设置；玩家控件按需要显式添加。
- **时间轴**：默认上方素材、预览及片段属性，下方通栏轨道；属性跟随选择，时间轴设置保留统一入口。支持多选移动、复制、删除、音视频裁剪、关键帧及操作取消，空格播放／暂停。公开素材和其他参数后可重复调用。
- **AI 助手**：默认连接设置收敛为地址、密钥、模型，更多连接选项按需展开。会话列表可收起，附件和方案操作集中，未完成事项与警告直接显示。停止等待请求完整退出，坏配置可重新读取或完整备份后重新配置，双窗口保留未保存输入。工程修改方案支持游戏流程与文字预设，应用前检查引用和范围，内置文字预设保持只读。
- **保存与导出**：工程和界面草稿分别恢复，删除与引用检查、PNG 导入和取消操作得到修正。含空格的蓝图调用名称在修改其他台词、应用和保存后保持完整。Windows 可导出完整 ZIP 或单 EXE；Android 提供 SDK 许可确认、私有工具配置和原生 Spine 支持库检查。

## 下载与更新

在 [v0.8.1 下载页](https://github.com/2196328649/visual-novel-studio/releases/tag/v0.8.1) 选择：

| 下载类型 | 用途 |
| --- | --- |
| `Visual Novel Studio Setup 0.8.1.exe` | 安装到电脑，从开始菜单启动 |
| `Visual-Novel-Studio-0.8.1-portable-win-x64.zip` | 全部解压后运行 `Visual Novel Studio.exe` |
| GitHub 自动生成的 Source code（zip／tar.gz） | 开发维护源码，需自行安装依赖和准备 SDK |

`SHA256SUMS-0.8.1.txt` 提供安装程序和便携 ZIP 的 SHA-256。可在 PowerShell 使用 `Get-FileHash -Algorithm SHA256 -LiteralPath '<下载文件完整路径>'`，与清单中对应文件核对。

更新前保存作品、关闭旧程序，并备份完整作品目录。安装版按安装程序更新，保留原有用户数据；便携版解压到新目录，再复制旧版 `data`，不要只替换 EXE。作品的工程文件、素材和 `.studio` 应一起保留。换 Windows 账户或电脑后，受系统保护的 AI 密钥可能需要重新填写。已有作品打开后应检查剧情、试玩和导出；更新自己发布的游戏仍需使用旧存档实测兼容性。

## 验证范围

本版最终源码通过 **2699／2699 项离线单元测试**及类型检查，含蓝图名称引用的新增回归。另有 **48 组离线桌面检查**覆盖 AI 助手功能回归和界面／配置恢复，检查停止等待、会话归属、方案审阅与撤销、附件、配置备份、双窗口同步和窄窗布局；使用模拟模型，不代表真实模型质量或全部服务商兼容性。剧情图、界面和时间轴的桌面与 Ren'Py 专项结果分别保留在源码的历史记录中。

发行包验收使用重新构建的安装版和便携版：解包后逐文件核对内容与 SHA-256，检查随附运行时、模板、导出工具及使用文档；随后从独立目录启动两个实际程序，创建哀鸿模板、修改台词、保存并完整重开，再检查真实 Ren’Py 试玩首帧与停止退出。安装包只解包执行程序，不覆盖已有安装；便携版使用新目录中的默认 `data`。最终发布结果与下载文件校验清单见 GitHub 下载页。

支持 DOCX 正文和表格文字导入，复杂分支及最终演出以真实试玩为准。Windows 安装程序未做代码签名，真实中文输入法及零基础真人使用体验没有被上述自动化检查完整覆盖。

入门见 [使用说明](user-guide.md)，解压和用户数据见 [便携版](portable.md)，独立游戏分发见 [游戏导出](game-export.md)。素材和依赖许可随程序提供；源码尚未单独指定对外开源许可证。

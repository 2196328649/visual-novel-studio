# 幼年／成年立绘适配方案（待实施）

建议在同一个角色下增加「立绘组」，例如幼年、成年。每组管理自己的表情、基础构图和大小校准；姓名、对白身份、声音及剧情引用仍属于同一个角色。本文只提出方案，没有新增字段或改动现有角色数据。

## 先区分两种大小差异

图片分辨率、画布大小、透明留白造成的是素材差异，需要校准。同一个成年人不同表情应保持相同的视觉身高和落脚位置。

幼年和成年本身的身高差属于演出设计，应予保留。例如成年人全身高度设为画面高度的 85%，幼年为 64%，两者脚底在同一基准线上。64% 只是示例，实际以画风和构图决定，不自动把所有人物拉成一样高。

## 建议的设置与操作

1. 在角色中创建「幼年」「成年」两组，将相应表情放入各组，选择每组默认表情。
2. 每组用一张代表图校准：全身模式对齐脚底，半身／胸像模式对齐头顶或眼线，设置画面占比。先按可见图像边界排除透明留白，再调整校准点。
3. 同组表情默认共享校准；坐姿、弯腰等姿态允许单张图片修正。全身、半身、坐姿差别较大时可进一步分组，避免按外接框强行拉伸。
4. 显示角色增加「立绘组」选择，表情列表跟随该组。切换组后找不到同名表情时使用新组默认表情，并在编辑器显示选择结果；导出前缺图应报错。
5. 左／中／右仍作为站位预设，负责舞台位置；立绘组负责人物大小和锚点。两者组合使用，避免为每个年龄重复维护所有站位。

计算顺序：角色基础构图 → 立绘组校准 → 单张素材微调 → 站位预设 → 本次演出调整。组切换默认按表情切换过渡处理；需要从画面退出再换年龄时，使用明确的隐藏／显示演出。

## 现有功能可以怎样临时使用

现在可建立「幼年居中」「成年居中」等角色站位预设，分别设置缩放和纵向位置，在显示角色时同时选择正确的表情与预设。透明留白差异可先用角色默认构图纠正。

局限是切换表情还不会自动切换年龄校准，而且同一个角色只有一套默认构图。正式立绘组方案可以解决这个重复操作问题；实施前需要确认分组、构图和站位的关系，不能自动推断年龄或改写已有剧情中的缩放。

## 作者操作

在剧情流程中点击一条连线，右侧打开“连线过渡”。先看来源模块、具体出口和目标，再选择方式：

- **沿用原设置**：不添加覆盖，保留原演出或场景的衔接。
- **直接切换**：本次画面衔接不使用可被该连线覆盖的自动过渡。
- **叠化**：上一画面逐渐变成下一画面。
- **淡黑、淡白、经过颜色**：淡出到指定颜色，停留，再淡入下一画面。

常用项只显示方式和总秒数；“分段时间与颜色”中可分别设置淡出、停留、淡入。调整总时长按现有比例缩放三段。时长支持非负有限数值，零秒立即完成。

配置后的线上出现方式和时长小标记，点击标记也能编辑。没有配置的线不增加按钮。选中仍只高亮，不显示端点圆圈、选中数量条或浮动断开按钮。

相邻连线的透明点击区重叠时，左键和右键优先选择距离光标最近的实际曲线。保留原有较宽点击范围，重连端点、标记按钮和框选仍按各自规则操作；交叉点上几乎重合的曲线沿用原命中顺序。

“效果示意”是样例 A 到样例 B，可播放、暂停、拖动进度和重播。实际剧情会使用当前舞台和目标内容，需通过试玩查看；两个模块没有改变舞台时，叠化可能看不出明显变化。

## 本批范围

支持有真实剧情目标的出口：开始、段落、条件、选择、赋值、跳转、调用、互动热点／超时／取消及小游戏结果。旧章节演出的实际继续出口也支持。

调用的“进入调用”与“返回后继续”各自配置。动态返回节点本身没有固定目标；在调用者的返回后继续线上设置效果。

分组、章节和内容层级只是投影。进组、解组或改变画布布局都不增减播放次数，配置始终属于真实源出口。

菜单按钮、顶层游戏启动步骤、独立页面、视频步骤、系统读档和返回标题导航暂时只说明实际含义并提供来源定位。这些路径需要各自的页面关闭、媒体结束和图层生命周期适配，不能直接把剧情舞台过渡当作页面退出动画。玩家剧情图控件的装饰线和蓝图数据线不属于本功能。

普通剧情连线进入结束节点时，显式过渡先到黑色空舞台，再进入原有结束／标题流程；不改变该流程的业务含义。

## 编辑和运行规则

- 配置保存在源节点的真实出口 ID，选择和热点使用各自稳定 ID。
- 改接目标保留源出口配置；改换源端使用新源自己的配置。断开后原设置仍可恢复。
- 节点属性顶部列出“未启用的过渡”，包括断开、失效出口、缺失目标和未启用超时。可以显式移除并撤销。
- 删除选择或热点一并清其配置；复制节点重建分支 ID 并重映射配置。设置、改接和移除继续使用原有撤销历史。
- 条件和赋值等没有呈现画面的逻辑按原顺序执行；到下一处画面或等待交互前，以实际经过的最后一个显式设置为准。未配置不会取消前面的请求，显式直接切换会覆盖前面的效果。
- 一次可见衔接只处理一次请求，不同时运行两个剧情模块。仅视觉过渡不重置场景身份，不重复入场动作和参数初始化；实际场景跳转仍执行其原有初始化。
- 过渡只作用于舞台层。已有界面和音乐继续使用原规则；目标的新短文字、视频、音频片段和演出时间轴在整段衔接结束后开始计时。
- 旧演出结束效果若要等待后续分支决议，会暂存。实际路径没有显式覆盖时，仍执行原结束效果和场景衔接。多段旧效果共同持有新目标，避免短内容在中间耗尽。
- 被替换或清场的源视频保留最后画面到过渡结束，再释放旧播放通道；组合对象递归处理。原生跳过、点击结束、转场偏好、存读档、回滚与返回标题复用同一释放边界。

文本源码可往返保存，例如：

```text
@连线过渡：模块=岔路【choice】，出口=左边【option_left】，方式=叠化，时长=0.8
@连线过渡：模块=对白【first】，出口=next，方式=纯色，淡出=0.3，停留=0.2，淡入=0.5，颜色=#000000
```

普通文本编辑投影会隐藏身份标记。保存源码包含必要的稳定身份；删除过渡声明会清除对应配置。复杂 `@实例` 延续现有的工程内模块依赖，不把整个节点结构另存成一份 JSON 指令。

## 实现位置

- `src/core/flow-transition-schema.ts`、`flow-transitions.ts`：描述、校验、真实出口、原子编辑、复制重映射。
- `src/core/text-script.ts`、指令补全及标记辅助：源码往返和稳定分支身份。
- `src/renderer/FlowTransitionInspector.tsx`、`flow-transition.css`、`Blueprint.tsx`、`SelectableEdge.tsx`：属性、样例预览、线上标记、非活动设置。
- `src/renderer/story-wire-hit.ts`：只在实际选线时处理重叠点击区，使用屏幕坐标下曲线距离，不为每帧扫描全图。
- `src/runtime/flow-transition-runtime.ts`、`compiler.ts`：按真实执行出口排队、首呈现边界、旧效果协调及结束导航。
- 演出、视觉、音频、角色、章节和任务运行时：源画面保留、新目标持有、专用舞台时钟、读档与释放。

舞台时钟只为演出和编译时间轴排除过渡耗时，未全局替换任务、界面和旧音乐时钟。运行中的转场记录归属实际上下文；原生菜单可渲染已暂停的舞台，但不会消费另一上下文的待处理剧情出口。

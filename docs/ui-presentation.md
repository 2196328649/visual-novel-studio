# 界面与演出编辑

在正式版“界面”工作区设计页面和组件，通过“试玩”检查交互与演出。

## 按工作区分配空间

「剧本 / 流程图 / 蓝图 / 界面 / 资源 / 角色 / 参数集」在同一排工作区标签中切换。剧本内包含模块与文本两种模式；右侧预览的“编辑舞台”提供角色拖拽、镜头和关键帧编辑。「蓝图」集中编辑演出与逻辑，成员和属性位于左侧；普通蓝图不占用独立右侧预览，演出可通过时间轴、剧本预览和试玩检查。剧情目录只放在剧本和文本页内，可整体收起，也可单独折叠章节；文本页点击目录会定位对应正文。「资源」使用完整资源管理器，底部抽屉或 Ctrl+空格可以在其他编辑页取用相同资源。

界面设计采用左侧控件层级、中间画布、右侧属性。顶部单行保留页面、模式、预览和保存；添加控件在层级标题栏，布局工具贴合画布底部。右侧按「组件设置 / 页面设置」区分作用范围，详见[页面设置](https://github.com/2196328649/visual-novel-studio/blob/v0.8.1/docs/ui-page-settings.md)。

左下角的问题列表会显示界面问题所属的页面、实例和控件。点击「定位控件」会打开正确页面并选中层级；未绑定按钮会聚焦右侧「点击行为」。查看问题不会更改游戏当前使用的界面实例，修复只写入正在检查的实例。详见 [演出编辑与问题定位](performance-workspace.md)。

## 层级与资源选择

- 在层级中搜索名称、类型或 ID，可直接选中被遮挡的控件。悬停会在画布标出位置。
- 双击或 F2 重命名控件；名称仅用于作者识别，不替换游戏里的文字。
- 上下移动或拖动行可调整前后顺序；一般只为移动的控件创建本地覆盖，其他组件继续继承基础界面。
- 眼睛和锁只影响设计画布。隐藏的控件仍会出现在文本预览和游戏中；锁定后仍可在属性里输入位置。
- 点击图片字段旁的缩略图，打开资源浏览器。可搜索名称/路径、查看透明背景缩略图和图片尺寸，单击查看大图、双击应用；Escape 取消。音频字段可试听。

## 页面接入与预览起点

在「界面」中新建自定义页面后，可以先直接设计，再从顶部「… → 页面使用位置」接入游戏。可接入当前剧情、已有按钮、启动到标题之间、新游戏到故事之间，或先保留为备用资源。页面内部事件图与外部调用图分开；保存界面后，使用位置可以定位到同一张流程蓝图的对应节点。

「流程图」中，启动、标题、新游戏、读档与剧情节点共用画布和连线，不需要在作品信息里寻找另一套特殊入口。选中启动节点，在右侧选择执行时机：

- **每次应用启动**：冷启动播放一次；同次运行返回标题不重播。
- **每次进入标题**：冷启动和之后每次返回标题都播放。
- **本机玩家资料首次**：当前作品的玩家资料只播放一次，关闭游戏再开也保留标记。
- **指定版本首次**：按填写的版本标识分别记忆；改用新标识会再次播放，回到已看过的标识不会重播。

开始新游戏会先重置非持久的本局变量，再执行新游戏前流程，最后进入剧情入口。标题按钮曾修改的本局变量也会重置；玩家持久设置不会跟着清空。读档直接恢复保存位置和值，不重跑初始化或角色创建。

三种预览各有明确范围：

| 起点 | 作用 |
| --- | --- |
| 从启动预览 | 运行真实游戏的启动路径，按启动节点的策略播放标题前内容。 |
| 从标题预览 | 本次先直接显示标题，只跳过第一次标题前内容；之后返回标题仍按策略判断，尚未执行的首次内容也可能在那时运行。 |
| 从当前页面预览 | 只验证当前页面及其调用逻辑，不执行整条启动、新游戏或剧情流程；窗口显示正在预览的页面名称，并跟随未保存的页面编辑。 |

真实试玩右侧同时显示预览起点、新游戏后的剧情入口和实际变量值。尚在启动或标题阶段时显示“尚未进入剧情”，不会伪造当前台词。重新运行保留上次起点，但使用新的隔离存档目录；首次标记也与正式玩家资料分开。试玩设置中的测试变量在本局重置之后、新游戏前流程之前应用，不代表改变设计默认值。

## 启动路径诊断

问题面板中的“标题前流程 / …”或“新游戏前流程 / …”会列出页面、事件和嵌套模块的调用路径。点击问题可定位到真正出错的节点；按钮主操作的问题定位到控件；没有具体错误节点的完成出口警告定位到流程画布中的页面步骤。

- **缺少运行能力**：启动阶段没有当前台词或小游戏会话。检查路径中具体的读取/动作节点；显示角色时应传入明确的角色，不依赖当前说话人。新检查按可达执行连线和数据短路分析，不把备用节点当成已经执行。
- **页面已打开（alreadyOpen）**：保留已有自定义页面实例并立即返回，不会再派发显示事件，也不会建立第二个等待。若需要重新初始化，应先关闭原实例再顺序打开；不要把这条警告理解成无限递归。
- **没有找到可达完成出口**：把关闭动作接到实际可触发的事件上，或选择自动/确认完成。默认页面在可交互时可按 Esc 取消，但 cancelled、parentClosed 与 completed 是不同结果；取消出口不等于成功完成出口。
- **动态目标或分析上限**：运行时页面参数不会被偷偷替换成模块默认页面；递归模块或过多路径组合会明确标为尚未验证。请结合“从启动预览”的真实游戏验证，不把静态检查无错误当成所有时序都已证明。

页面显示事件与普通定时事件并不完全同一时刻执行：同步打开后立即关闭可能还未派发显示事件；底页的显示事件可能等模态子页退出后才触发。独立 UI 图的能力检查可能对确定不执行的备用节点额外提示问题，应结合具体调用路径和试玩结果判断。

## 配乐和章节入场

哀鸿模板的标题菜单播放原作 `Main.ogg`；两章分别接入夜宴和雨声配乐，后续剧情蓝图继续切换音乐。真实试玩会播放音频，文本预览提供试听控件。

在「界面 → 章节标题」选择第一章或第二章，点击「播放进场」。在剧情的章节节点里调整时长、背景、完整题字图片、配乐及效果；「作品设置 → 全局界面 → 章节进场」可以替换以下资源：

| 字段 | 作用 |
| --- | --- |
| 章节笔触底图 | 原作 `chapter_bg_J.png`，包含深色底纹和横向笔刷。 |
| 章节蒙板 | `chapter_img_mask2.png` 的透明通道裁切底图，露出右侧庭院。 |
| 渐变纹理 | `FadeCircle.png` 的透明通道控制中心向外的柔边渐显、消散和题字柔光。 |
| 章节标题图片 | 原作简体「记·第一回 醉梦」「记·第二回 遇雁」完整题字，包含章号和年代；选图后不重复绘制文字副题。 |

两张蒙板的 RGB 都是黑色，形状在 Alpha 通道中；不能把它们当普通黑图或按亮度处理。构图依据用户提供的原作截图和原始资源恢复。浏览器 SVG 与原生 Ren’Py shader 共用渐变纹理、软边参数及时间分段；未宣称逐帧复现原 Unity 动画的全部实现。

现有工程可用 `scripts/update-aihong-presentation.ts <project.vns.json>` 补齐示例资源和默认演出。它按正常加载规则优先使用更新的自动恢复数据，备份原工程及恢复文件，保留已替换的资源和作者覆盖。不要在另一个正在修改同一工程的编辑器中同时运行它。

## 文本预览

历史列表在画布中使用实际台词，支持姓名、重播按钮、收藏按钮和对白分列；「语音按钮图片」可以分别设置普通、悬停、按下、收藏和禁用状态。章节与流程列表使用作品中的真实章节和段落，支持锁定未到达内容、显示已读和当前位置，以及游戏中跳转前确认。

语音收藏提供全部／仅收藏切换、重播、取消收藏和停止试听。历史与收藏使用独立试听通道，遵循语音总音量和角色音量；离开页面停止试听。没有配音的台词不显示语音按钮。收藏与已读记录按该游戏的玩家数据保存。

在语音收藏组件的「收藏条目与分页」中，可隐藏筛选和停止按钮、选择仅对白或姓名与摘要、启用单行省略，并编辑文字、收藏按钮和分页区域。设置每页行数后使用固定分页；不设置行数则使用滚动列表。哀鸿模板采用两列六行，整条播放、右侧删除，仅显示收藏。删除正在播放的条目会停止该语音，删除末页最后一项会回到有效页面。画布用作品配音条目演示布局，玩家的实际收藏仍需在试玩中查看。

从章节或流程菜单开始剧情会重置本次游戏状态；在游戏中切换可先确认，取消后保留当前进度。模板标题中的「剧情流程图」可进入章节选择。原作“额外故事”按钮仍以锁定状态展示。

文本预览与 UI 画布、原生生成器共用对话框布局，读取当前界面实例的底图、控件位置、字体、透明度及等待图标。蓝图的确定性演出可展开预览，包括背景、配乐、嵌套调用和条件执行。

文本预览按编辑中的段落顺序重建舞台；有玩家输入或外接脚本时提示无法静态推演，完整分支请用真实试玩验证。

## 高级 UI 参数预演

在“高级 UI 蓝图”展开“参数预演”，可以改变测试参数、操作按钮和设置控件。设置、角色音量、存读档等菜单按钮会切换预演页面，测试值在页面之间保留；当前页面名称和可测试按键随页面更新。角色音量页返回设置，从对话或选项打开菜单后返回原页；直接从菜单页开始预演时，返回目的地为标题。

勾选“按时间预演”后可播放、暂停或逐步推进，计时器按当前页面的间隔触发，离开页面后停止，重新进入时重新计时。未勾选时，在测试值或按钮操作后直接采样联动逻辑。“恢复测试值”会回到编辑起始页并重置临时参数与音量，不改工程初始值或玩家实际设置。

预演显示当前方案的作者组件和页面背景。图鉴网格和语音收藏支持下述交互；自定义页面的打开、等待关闭和叠加、蓝图标准菜单调用及确认框也可预演。标准菜单布局的内置控件、其他复杂列表及演出协同仍需使用试玩检查。

蓝图使用“打开自定义界面”并选择等待关闭时，预演保留当前执行位置，关闭页面后将结果交回打开节点，再继续后续路线；支持嵌套页面及函数/循环内等待。选择不等待时，页面作为叠加层显示并立即继续。页面的模态设置控制是否拦截底层输入，各页计时器在显示期间独立运行，关闭后停止。

可使用页面内按钮关闭，也可按Escape或右键取消；已绑定的页面按键优先。关闭后焦点回到原按钮。“恢复测试值”会取消全部临时等待并回到起点。直接预演的自定义页关闭后，恢复测试值可重新打开。此过程不修改工程或玩家资料。

确认框会显示动态提示，并等待确认或取消后继续对应蓝图分支；支持当前方案的自定义消息框和默认标准框，长提示可滚动。按钮回调中的再次确认会先完成，之后执行原按钮响应。Escape或右键取消，关闭恢复调用按钮焦点。

蓝图打开标准菜单时会保留执行位置，菜单内切换页面不结束调用；返回后恢复真正的调用页并继续蓝图。菜单显示期间底层页隐藏且计时暂停，返回后继续；确认框显示期间底层计时继续。角色音量的返回、Escape及右键先回设置。

语音收藏列表可翻页、筛选收藏、播放语音及移除收藏。展开“语音测试数据”可设置临时收藏和解锁；初始全部解锁、没有收藏，不使用玩家实际资料。删除末页最后一条后自动回退；自定义收藏列表删除正在试听的条目会停止，删除其他条目继续。音量使用测试主音量、语音音量与角色音量。

确认框覆盖语音页时试听继续；离页、折叠或恢复测试值会停止，重新展开不会自动重播。文件缺失会显示错误，恢复文件后可再次点击。普通设计画布继续显示静态样例。

### 图鉴分组

画廊网格支持“图鉴分组与分镜”：每组一张缩略图和有序图片列表，可搜索、改名、增删、上下移动；分镜可增删排序，缩略图独立选择。任一分镜解锁即可打开组，只查看已解锁分镜。详情可以选择完整显示/裁切/拉伸、末张返回或循环、控制按钮显隐。分组未启用时沿用原平面素材列表。所有修改进入UI草稿，需显式保存，支持撤销重做。

页码大小与文字可设置按钮宽高、间隔、字号、字体和粗体；“画廊图片与分页位置”内可设置缩略图各状态亮度。AI可按组ID读取和修改这些通用字段。

在高级UI的参数预演中，可以点击图鉴页码和卡片，查看详情及切换分镜。点击图片或按右方向键查看下一张，左方向键查看上一张，Escape或右键关闭；启用详情控制按钮时也可直接点击。关闭后保留页码并返回原卡片焦点，离开图鉴菜单后重新进入则回到第一页。详情打开期间底层控件不响应，页面计时器继续。

展开“图鉴测试数据”，取消“全部图片已解锁”后，可用素材浏览器添加本次预演的已解锁图片，或取消单张解锁。任一分镜可用的组才可打开，详情只显示已解锁分镜并保留作者顺序；独立缩略图不算解锁分镜。“恢复测试值”同时恢复全部解锁和起始页面。测试数据只在本次预演中使用。

## 将所选节点封装为用户节点

在普通蓝图或“界面 → 事件图”中框选一段执行节点和相关数据节点，点击“封装所选节点”。窗口会预览输入参数、输出结果和连线数量；命名后选择“创建并替换”。相同数据来源合并为一个参数，原输出的多处连线保留。创建后可双击调用节点进入模块，并在“输入与输出”调整名称与默认值。

事件入口必须留在原图。多个不同执行出口、跨边界循环、实时数据被提前求值、输出可能在调用前读取等情况会给出拒绝原因，不修改原图；按说明扩大选择或调整执行路径后重试。时间轴/组合请继续使用原有的预设/组合封装入口。

原图替换与新模块属于同一次历史操作，一次撤销即可一起恢复。页面事件图仍使用界面草稿，确认后保存界面和工程；取消封装不会清空已有选择。事件入口和跨边界执行关系需保留在原图。

## 普通控件运行属性补充

输入、选择、滑条和普通文字/按钮/面板继续共用页面实例与蓝图，不增加小游戏专用机制。设计面板新增“蓝图属性能力”目录；输入控件的占位文字、最大长度及禁止用户改值，滑条的轨道/填充/滑块颜色和已有图片/尺寸字段，均有相应运行属性。

请区分设计值、绑定源和当前实例的临时覆盖。设计右侧仍编辑作品；页面蓝图的临时覆盖只影响当前实例，改绑定源则遵循原参数的剧情存档/玩家设置持久化规则。独立预演使用隔离测试值，两种赋值都不回写工程或真实玩家设置。“恢复测试值”清除整次预演，不是只重置当前控件。

数值控件的设计范围采用三个本地草稿和“应用整个控件范围”按钮；蓝图可原子设置/重置范围，缩小范围不改绑定源。来源范围仍只读，玩家设置不能突破引擎边界。输入控件可“请求输入焦点”，已接受只表示排队，实际编辑状态等宿主刷新后再读；程序焦点操作不会触发用户提交。

具体属性、有效/来源范围、坐标单位、赋值方式、焦点与重置规则见[控件有效属性与绑定来源](blueprint-authoring.md#控件有效属性与绑定来源)。此接口不提供完整的复合控件内部模板体系。

### 运行时选择项

选择控件的设计列表仍在参数或玩家设置绑定中配置；事件图新增“编辑控件选项”与“读取控件选项”。它们修改/读取当前页面实例的有效列表，不改设计，不新增复杂列表模板接口。标签与值可分开设置，支持文字、数值、开关；空列表仍为选择控件。

编辑列表不自动改当前值。需要选择新项时再设置当前索引或有效值，并明确临时覆盖/写绑定源；单独恢复设计选项保留当前值覆盖。设计侧“控件蓝图操作”按实际绑定列出这两个入口，自由文字输入不会提供它们。详见 [蓝图使用说明](blueprint-authoring.md)。

## 图片表面扩展

普通图片新增 imageEffects：源图比例裁切、水平/垂直翻转与乘色。设计页“图片裁切、翻转与乘色”和蓝图共用属性目录；图片缩放统一支持完整显示、裁切铺满、拉伸和九宫格。裁切越过源图边缘时取交集，零面积不绘制；裁切不改变外部布局或子项。透明乘色按 RGBA 与原图相乘，状态亮度与禁用透明度继续叠加。

浏览器和原生使用相同的整数源图裁切/九宫格分片规则，实际解码决定加载状态与源图尺寸。加载成功/失败事件为页面实例事件，不是用户输入事件；已结束实例、已被替换来源及重复反馈不写入当前状态。内置模板与普通页面共用机制，页面关闭清理资源观察与覆盖。

## 通用布局与作者容器

设计页新增“通用布局、容器与滚动”，包含父内容区锚点、自身轴心、整体旋转/缩放、独立排列顺序、像素间距/内边距、裁剪及双轴滚动。默认排列值相同的子项按声明顺序，不随绘制层级或对象列表的顺序变化；背景子项相对外框且不滚动，隐藏的前景子项不占槽位。原有控件无布局字段时沿用原相对布局。

主画布、对白/章节预览、动画画布和独立交互预演都接入同一像素几何；设计拖动/缩放、父级辅助线和重设父级使用实际变换。布局属性的读写范围与作者示例见[通用布局、容器与滚动](blueprint-authoring.md#通用布局容器与滚动)。整体布局、图片效果和 Spine 内部姿态分别设置。

### 视频控件与实际反馈

视频素材、封面、循环与新增的播放/暂停/停止节点已续接同一套界面属性和事件。设计“蓝图属性能力”列出支持范围；事件图提供结束、失败入口和独立继承事件。位置、时长、是否已知时长、进度、错误均为只读，当前没有作者 seek 操作。

预演使用真实静音视频元素，不用预演时钟推算完成；原生使用电影通道及统一页面实例清理。隐藏/宿主挂起会暂停，模态子页下仍显示的父视频继续，重新显示不会撤销作者暂停。停止、结束或失败时显示同位置封面。

### 骨骼播放的实例反馈

骨骼皮肤、素材、循环、速度和内部变换可由通用属性读写；完成/失败通过同一页面事件图处理，内置模板与新增页面没有单独的骨骼接口。每控件拥有独立播放器，预演不以时间推进冒充动画完成。隐藏或系统宿主挂起保留位置，作者暂停不会被重新显示解除。

预演与原生的时长/完成必须由真实运行库反馈；保存的是版本化实例记录，不保存 WebGL/C 原生对象。未知记录需要明确重置，并保留原数据用于恢复。

# 界面与演出编辑

本轮修改通过根目录的 `启动开发版.cmd` 使用，暂不生成安装包。

## 按工作区分配空间

「剧本 / 演出 / 蓝图 / 界面 / 素材 / 角色 / 状态」在同一排工作区标签中切换。剧本内包含模块与文本两种模式；右侧预览的“编辑舞台”提供角色拖拽、镜头和关键帧编辑。「演出」用于集中编辑章节或台词演出，并在同一窗口播放预览。剧情目录只放在剧本和文本页内，可整体收起，也可单独折叠章节；文本页点击目录会定位对应正文。「素材」使用完整资源管理器，底部抽屉或 Ctrl+空格可以在其他编辑页取用相同资源。

界面设计采用左侧控件层级、中间画布、右侧属性。页面切换与添加控件分成两行，避免工具被挤散；上方的位置提示改为「界面设计」。

左下角的问题列表会显示界面问题所属的页面、实例和控件。点击「定位控件」会打开正确页面并选中层级；未绑定按钮会聚焦右侧「点击行为」。查看问题不会更改游戏当前使用的界面实例，修复只写入正在检查的实例。详见 [演出编辑与问题定位](performance-workspace.md)。

## 层级与资源选择

- 在层级中搜索名称、类型或 ID，可直接选中被遮挡的控件。悬停会在画布标出位置。
- 双击或 F2 重命名控件；名称仅用于作者识别，不替换游戏里的文字。
- 上下移动或拖动行可调整前后顺序；一般只为移动的控件创建本地覆盖，其他组件继续继承基础界面。
- 眼睛和锁只影响设计画布。隐藏的控件仍会出现在文本预览和游戏中；锁定后仍可在属性里输入位置。
- 点击图片字段旁的缩略图，打开资源浏览器。可搜索名称/路径、查看透明背景缩略图和图片尺寸，单击查看大图、双击应用；Escape 取消。音频字段可试听。

## 配乐和章节入场

哀鸿模板的标题菜单播放原作 `Main.ogg`；两章分别接入夜宴和雨声配乐，后续剧情蓝图继续切换音乐。真实试玩会播放音频，文本预览提供试听控件。

在「界面 → 章节标题」选择第一章或第二章，点击「播放进场」。在剧情的章节节点里调整时长、背景、完整题字图片、配乐及效果；「作品设置 → 章节进场」可以替换以下资源：

| 字段 | 作用 |
| --- | --- |
| 章节笔触底图 | 原作 `chapter_bg_J.png`，包含深色底纹和横向笔刷。 |
| 章节蒙板 | `chapter_img_mask2.png` 的透明通道裁切底图，露出右侧庭院。 |
| 渐变纹理 | `FadeCircle.png` 的透明通道控制中心向外的柔边渐显、消散和题字柔光。 |
| 章节标题图片 | 原作简体「记·第一回 醉梦」「记·第二回 遇雁」完整题字，包含章号和年代；选图后不重复绘制文字副题。 |

两张蒙板的 RGB 都是黑色，形状在 Alpha 通道中；不能把它们当普通黑图或按亮度处理。构图依据用户提供的原作截图和原始资源恢复。浏览器 SVG 与原生 Ren’Py shader 共用渐变纹理、软边参数及时间分段；未宣称逐帧复现原 Unity 动画的全部实现。

现有工程可用 `scripts/update-aihong-presentation.ts <project.vns.json>` 补齐示例资源和默认演出。它按正常加载规则优先使用更新的自动恢复数据，备份原工程及恢复文件，保留已替换的资源和作者覆盖。不要在另一个正在修改同一工程的编辑器中同时运行它。

## 文本预览

历史列表在画布中使用实际台词，支持姓名、重播按钮、收藏按钮和对白分列；「语音按钮图片」可以分别设置普通、悬停、按下、收藏和禁用状态。章节与流程列表使用作品中的真实章节和段落，支持锁定未到达内容、显示已读和当前位置，以及游戏中跳转前确认。

语音收藏提供全部／仅收藏切换、重播、取消收藏和停止试听。历史与收藏使用独立试听通道，遵循语音总音量和角色音量；离开页面停止试听。没有配音的台词不显示语音按钮。收藏与已读记录按该游戏的玩家数据保存。

在语音收藏组件的「收藏条目与分页」中，可隐藏筛选和停止按钮、选择仅对白或姓名与摘要、启用单行省略，并编辑文字、收藏按钮和分页区域。设置每页行数后使用固定分页；不设置行数则使用滚动列表。哀鸿模板采用两列六行，整条播放、右侧删除，仅显示收藏。删除正在播放的条目会停止该语音，删除末页最后一项会回到有效页面。画布用作品配音条目演示布局，玩家的实际收藏仍需在试玩中查看。

从章节或流程菜单开始剧情会重置本次游戏状态；在游戏中切换可先确认，取消后保留当前进度。模板标题中的「剧情流程图」可进入章节选择。原作“额外故事”按钮仍以锁定状态展示。

文本预览与 UI 画布、原生生成器共用对话框布局，读取当前界面实例的底图、控件位置、字体、透明度及等待图标。蓝图的确定性演出可展开预览，包括背景、配乐、嵌套调用和条件执行。

文本预览按编辑中的段落顺序重建舞台；有玩家输入或外接脚本时提示无法静态推演，完整分支请用真实试玩验证。

## 高级 UI 参数预演

在“高级 UI 蓝图”展开“参数预演”，可以改变测试参数、操作按钮和设置控件。设置、角色音量、存读档等菜单按钮会切换预演页面，测试值在页面之间保留；当前页面名称和可测试按键随页面更新。角色音量页返回设置，从对话或选项打开菜单后返回原页；直接从菜单页开始预演时，返回目的地为标题。

勾选“按时间预演”后可播放、暂停或逐步推进，计时器按当前页面的间隔触发，离开页面后停止，重新进入时重新计时。未勾选时，在测试值或按钮操作后直接采样联动逻辑。“恢复测试值”会回到编辑起始页并重置临时参数与音量，不改工程初始值或玩家实际设置。

预演显示当前方案的作者组件和页面背景。图鉴网格和语音收藏支持下述交互；自定义页面的打开、等待关闭和叠加、蓝图标准菜单调用及确认框也可预演。标准菜单布局的内置控件、其他复杂列表及演出协同仍需使用试玩检查。

蓝图使用“打开自定义界面”并选择等待关闭时，预演保留当前执行位置，关闭页面后将结果交回打开节点，再继续后续路线；支持嵌套页面及函数/循环内等待。选择不等待时，页面作为叠加层显示并立即继续。页面的模态设置控制是否拦截底层输入，各页计时器在显示期间独立运行，关闭后停止。

可使用页面内按钮关闭，也可按Escape或右键取消；已绑定的页面按键优先。关闭后焦点回到原按钮。“恢复测试值”会取消全部临时等待并回到起点。直接预演的自定义页关闭后，恢复测试值可重新打开。此过程不修改工程或玩家资料；实现与验收范围见 [自定义页面预演记录](ui-page-preview-2026-10-02.md)。

确认框会显示动态提示，并等待确认或取消后继续对应蓝图分支；支持当前方案的自定义消息框和默认标准框，长提示可滚动。按钮回调中的再次确认会先完成，之后执行原按钮响应。Escape或右键取消，关闭恢复调用按钮焦点。

蓝图打开标准菜单时会保留执行位置，菜单内切换页面不结束调用；返回后恢复真正的调用页并继续蓝图。菜单显示期间底层页隐藏且计时暂停，返回后继续；确认框显示期间底层计时继续。角色音量的返回、Escape及右键先回设置。验收与原生标题菜单返回修复见 [确认框与菜单预演记录](ui-confirm-preview-2026-10-02.md)。

语音收藏列表可翻页、筛选收藏、播放语音及移除收藏。展开“语音测试数据”可设置临时收藏和解锁；初始全部解锁、没有收藏，不使用玩家实际资料。删除末页最后一条后自动回退；自定义收藏列表删除正在试听的条目会停止，删除其他条目继续。音量使用测试主音量、语音音量与角色音量。

确认框覆盖语音页时试听继续；离页、折叠或恢复测试值会停止，重新展开不会自动重播。文件缺失会显示错误，恢复文件后可再次点击。普通设计画布继续显示静态样例。完整范围和验收见 [语音收藏预演记录](ui-voice-preview-2026-10-02.md)。

### 图鉴分组

画廊网格支持“图鉴分组与分镜”：每组一张缩略图和有序图片列表，可搜索、改名、增删、上下移动；分镜可增删排序，缩略图独立选择。任一分镜解锁即可打开组，只查看已解锁分镜。详情可以选择完整显示/裁切/拉伸、末张返回或循环、控制按钮显隐。分组未启用时沿用原平面素材列表。所有修改进入UI草稿，需显式保存，支持撤销重做。

页码大小与文字可设置按钮宽高、间隔、字号、字体和粗体；“画廊图片与分页位置”内可设置缩略图各状态亮度。AI可按组ID读取和修改这些通用字段。验收及原作还原范围见 [CG 图鉴核对](gallery-fidelity-2026-10-02.md)。

在高级UI的参数预演中，可以点击图鉴页码和卡片，查看详情及切换分镜。点击图片或按右方向键查看下一张，左方向键查看上一张，Escape或右键关闭；启用详情控制按钮时也可直接点击。关闭后保留页码并返回原卡片焦点，离开图鉴菜单后重新进入则回到第一页。详情打开期间底层控件不响应，页面计时器继续。

展开“图鉴测试数据”，取消“全部图片已解锁”后，可用素材浏览器添加本次预演的已解锁图片，或取消单张解锁。任一分镜可用的组才可打开，详情只显示已解锁分镜并保留作者顺序；独立缩略图不算解锁分镜。“恢复测试值”同时恢复全部解锁和起始页面。测试数据只在本次预演中使用。

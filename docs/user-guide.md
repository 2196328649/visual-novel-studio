# 叙事工坊使用说明

## 安装与作品

v0.8.1（2026-11-15）支持 Windows 10/11 64 位。运行安装程序并选择安装位置，或将便携 ZIP 全部解压后双击 `Visual Novel Studio.exe`。编辑器随附运行时、《哀鸿》素材演示与两章剧情模板（示例媒体来自用户提供的原作素材副本），创作者无需安装 Node.js、Python 或 Ren'Py SDK。首启会准备可写运行时，之后可以离线创作。便携版设置和缓存保存在程序旁的 `data`，更新与移动时保留它；作品目录另行备份。下载及更新方法见 [v0.8.1 发行说明](release-0.8.1.md)。

“新建工程”可选择空白作品或“哀鸿模板 · 两章与三个结局”。模板包含两章分支剧情、原作背景和音乐、可编辑的界面皮肤、字体、实时骨骼动画和控制蓝图。“保存工程”选择作品目录，工程文件和导入的 `assets` 素材目录一起构成作品。移动或备份作品时保留整个目录，包括 `.studio` 发行基线和恢复文件。本版移除了旧的自动显示角色指令；旧文本需改用「显示角色」。工程、素材与备份须一起保留。

## 资源与工作区

顶部提供“剧本、流程图、蓝图、界面”，并有“资源、角色、参数集”入口。“剧本”内可切换“模块编辑”和“文本编辑”，两种模式共用右侧实时预览及可收起的剧情目录，切换时保持当前对白并同步内容。模块模式在台词上方显示演出，点击展开参数，旁边的加号用于添加效果；台词旁的小箭头展开本句文字演出。“资源”打开完整资源管理器；底部“资源管理器”和 Ctrl+空格可打开抽屉，文本编辑区内此快捷键用于补全。

右上角“作品设置”打开独立设置窗口。“作品信息”设置名称、版本、画面尺寸与故事入口；“试玩设置”指定试玩方式、起点及测试状态，工具栏“试玩”和 F5 使用这些设置。测试状态不会改写剧情初始值，设置窗口支持 Esc 关闭。

资源按“场景、立绘、UI素材、BGM、配音、音效、视频、字体、骨骼动画、脚本”分类。保存工程会自动建立 `assets` 下的分类目录；“作品设置 → 资源管理”采用复制模式时，后续导入放入对应的实际目录，例如 `assets/立绘/`、`assets/BGM/`。可直接把系统文件或文件夹拖入资源管理器，也可以点击导入文件夹按钮；保留子文件夹结构，同内容文件会跳过。选择目标分类后导入，或拖到分类目录，即可指定用途；未指定时按文件类型和名称推断，不能识别的放入“未分类”。导入后自动定位所在分类。选中资源后可修改分类，Ctrl/Shift 多选可批量移动，图片和音频选择器沿用同样的分组，例如“配音 / 苏怜烟 / 第一章”。移动资源与改显示名称不改变已有物理路径及既有引用。

拖动资源抽屉上边缘调整高度，剧情目录和属性面板也可收起。节点库默认收起，蓝图空白处右键或空格可搜索添加节点；连线可直接点选，也可从连线列表选择。选中后拖动端点改接、点击断开或按 Delete 删除，Ctrl+Z 撤销。详细操作见 [中文节点编程](blueprint-authoring.md)。

## 从空白到第一段游戏

1. 新建作品并保存到自己的目录。在“资源”栏导入背景、立绘和音乐，修改方便查找的中文名称。
2. 在“角色”栏添加角色并设置表情图片。在“参数集”创建好感度、开关或文字参数；每项独立选择“随存档保存”或“保存在本机”，后者可用于跨周目解锁记录。
3. 在“剧本 → 模块编辑”中连续输入对白、选择说话人，用台词上方的加号添加演出；也可切到“文本编辑”导入 Word 剧本或使用中文指令。文本模式显示行号和语法颜色，支持拼音首字母补全、参数提示、Ctrl+F 查找、Ctrl+H 替换，内部编号自动隐藏。右侧“播放预览”播放当前台词的演出、音效与配音；BGM 只通过预览下方的播放器手动控制。拖动进度条或时间轴播放头后，按空格可播放／暂停。详细语法见 `text-authoring.md`。
4. 选择对白，打开右侧实时预览标题栏的“编辑舞台”，直接拖动立绘或图片；图片四角可缩放，旋转把手可调整角度。画面下方也可调整位置、表情、缩放、图层、镜头和关键帧，数字参数名支持左右拖动，Shift 精调、Ctrl 加速。两种剧本模式共用这套工具；编辑区与预览之间可拖动分隔条调整宽度，双击复位。文本工具栏的「自动换行」只改变显示，不修改原文。修改写入当前台词，支持撤销，文本的光标和滚动位置保持不变。未播放时显示演出完成后的画面；播放中暂停后修改参数保留当前时间，停止后恢复完成画面。角色、关键帧和镜头的位置不限于画面边界，可输入负数或超过 100% 的位置。角色纵向位置表示脚底位置，调到 100% 以上可把下半身移出画面；画面外的角色仍可从角色选择框选中调整。
5. 在“流程图”连接剧情段落、选项、条件和结局；同级节点可框选后右键“打组为剧情组”，双击进入，使用面包屑返回。选择实际连线可调整切换过渡和时长。需要演出、条件或复用逻辑时进入“蓝图”，成员和属性在左侧编辑，画布用于接线，普通蓝图没有独立右侧实时预览；演出通过剧本预览、时间轴或真实试玩检查。
6. 点击“试玩”或按 F5，使用“作品设置 → 试玩设置”中的起点和初始状态运行。运行状态面板可定位当前节点和对白。

## 演出蓝图与 AI

点击台词旁的小箭头展开文字演出，可设置这句的字体、颜色、文字演出时长、画面位置和逐字入场／持续效果，也可在角色的“文字演出”页签设置默认值。在台词框里选中几个字，可以只给这些字改颜色、大小、计时和动画，或在它们前面停顿。详见[文字演出](text-presentation.md)。

文本中选中一组演出后右键，选择“封装选中演出为蓝图”，可命名、按资源文件夹嵌套分组，并设置公开参数和默认值。用 `/` 菜单调用，Ctrl+点击蓝图指令进入编辑。工具栏“批量演出”处理全部台词，右键“为选中台词添加演出”只处理选择范围；旁白默认排除。“显示角色”的角色留空时跟随当前台词，表情留空使用默认表情；“第几个”默认第 1 个，相同角色的同号副本更新原画面，不同编号可同时显示。隐藏一个副本不会让其他副本变号，相邻台词连续显示本句角色时可续接表情和站位。详见 [演出蓝图](blueprint-authoring.md)。

在资源管理器创建时间轴预设，或从蓝图双击时间轴调用进入片段编辑。默认上方为素材、预览和片段属性，下方为通栏轨道。图片和角色显示缩略图，音乐与音效显示波形，视频显示画面。拖动片段改变开始时间或轨道，拖动左右边缘裁剪，黄色把手调整淡入淡出；多选可一起移动、复制或删除，Escape 取消正在进行的拖动或裁剪。空格播放／暂停，方向键精调时间。属性跟随所选片段，标题处“时间轴设置”编辑整个预设；试播使用调用参数的默认值。时间轴按最晚片段结束时间自动完成。

音频波形横向对应时间，起伏显示源音频的强弱，安静段接近细线。裁剪后显示相应的源区间，不会把安静段放大。音视频的鼠标裁剪和数值时长都不能超过已读取的素材末尾，直接更换视频会重新读取新素材长度。

需要调用时换图片、音乐、音效或视频，选中片段，在“可替换参数”中公开相应素材；从“时间轴设置”编辑调用参数的名称和默认值。返回父蓝图后，可在调用节点选择本次素材或连接素材输入。未传入时使用默认值，调用节点的“默认”按钮可恢复默认素材。结局使用普通 `@结局演出`，随后填写 `@返回标题界面`。

“作品设置 → AI 服务”默认显示地址、密钥和模型，模型可在同一输入框手填、筛选或选择，其他连接选项放在“更多连接设置”。顶部“AI 助手”打开独立窗口，会话列表可收起，附件集中在“添加参考”。助手可参考当前工程和台词，提出剧情、蓝图、界面、游戏流程或文字预设修改方案；审阅后应用，与主编辑器共用撤销。停止后须等待当前请求完整结束再继续。坏配置可重新读取或完整备份后重新配置，不能解密的密钥需重新填写。详见 [AI 创作助手](ai-assistant.md)。

## 界面与互动

“界面”页可编辑标题、对话、选项、存档与设置等页面。组件属性上方“通用属性”调整位置、大小、层级、显示和子对象，下方“控件功能”设置当前类型的内容、外观和交互。存档、历史等列表可双击内部文字、按钮或分页进入部件编辑，再返回整个控件。右键属性名称或输入区可查看来源、恢复该项、设置单向跟随参数或双向同步。原生对话、选项列表、存档格及设置项通过绑定工作，不需要编写脚本。Spine 4.2 素材可添加为“骨骼动画”组件，使用蓝图播放、暂停和调速，详见 [骨骼动画操作](spine-authoring.md)。最后在试玩中检查按钮和组件。

选中“剧情流程图”控件，在“展示方式”选择“跟随剧本”或“自定义”；旧工程默认跟随剧本，两种模式分别保留内容和位置。“分支图／目录列表”是独立的展示选择，自动布局和手动位置按当前图调整。自定义模式可管理已有剧情入口、顺序、显示分组和位置，显示分组不改变真实剧情执行。节点文字可分成多段，分别设置字体、字号、颜色、字间距和段后间距，也可引用共享外观预设。可以调整连线样式、点击行为与未到达内容的显示方式。

调用子剧情时，玩家图显示“调用者 → 子剧情 → 返回后的后续”。双击或 Enter 进入共享正文，使用返回按钮逐层退出；同一子剧情的各次调用分别判断入口解锁，内部正文共用已读记录。“从这里重玩”按正在浏览的调用路径返回自己的后续；“仅查看”只浏览而不跳转。按钮点击音效和文字阴影可在相应外观中设置，详见[流程图布局与样式](flow-layout-click-sounds.md)。

在“界面 → 画廊”选中画廊网格，分组、分镜及未分组图片都可设置“参数条件”。例如条件选择“章节进度 大于或等于 2”，剧情对应位置写 `@设置：如果 章节进度 < 2，章节进度 = 2`，即可解锁且保留更高进度。跨周目解锁需在参数集中开启“跨存档保留”。大于 2 与大于或等于 2 是不同条件，值恰好为 2 时只有后者满足。

“参数集”按名称整理剧情、蓝图和界面共用的变量。每个参数独立选择保存方式，并在“恢复初始设置”中决定是否参与玩家恢复操作；分组的新建默认只影响以后新增的参数。自定义参数不自动创建设置菜单，需要玩家输入时展开“界面控件（可选）”，选择页面并添加或定位控件。内置玩家设置和作者已放置的设置控件继续工作，详见[玩家设置](player-settings.md)。参数除数值、开关、文字外，还可从“素材”添加图片、音频、视频参数，例如头像或主题曲。界面图片、视频的来源选择参数后随值更新，空值使用控件自身素材；剧情可用 `@设置：头像 = 素材名` 切换，蓝图也可读取同一参数。存档或本机记录指向已删除的素材时，会恢复为初始值。

“点击互动”节点可配置场景热点、角色绑定、条件和出口；选中节点后，右侧预览的“编辑舞台”可拖拽和调整热点范围。“小游戏”节点提供密码锁和限时点击模板，配置成功、失败、取消分支。动态效果和互动说明见 `interaction-authoring.md`。

## 检查与恢复

问题面板提示缺失素材、断开的分支、无效变量、递归效果和不能等待的逻辑循环。点击问题定位相关素材、节点或对白；文本错误带所在行。修复错误后再试玩或导出。

撤销与重做作用于共享工程。编辑停止后会自动保存恢复副本；关闭窗口前保存最新恢复数据。异常退出后，下次打开会优先恢复较新的有效副本，损坏的副本不会覆盖正常工程。正式保存后恢复内容成为当前工程。

删除节点、变量或素材前检查引用。修改名称通常不会更换对象身份。导入旧工程会升级已支持的数据格式；比当前版本新的格式会明确拒绝，避免错误覆盖。

## 导出与玩家功能

在“作品设置 → 游戏导出”选择平台、打包格式和输出位置；顶部“导出”也可打开此页。环境缺失时点击“一键配置”，就绪后点击页面底部“导出”。Windows 可选择 ZIP 或单 EXE：ZIP 全部解压后运行游戏 EXE，单 EXE 直接运行；玩家无需安装编辑器或开发环境。Android 首次配置和构建需要联网并同意 SDK 许可。详见[游戏导出](game-export.md)。发布 ZIP 时保留完整目录及许可声明。

游戏包含存档、读档、回滚、自动播放、跳过、历史、文字与声音设置，以及按配置条件解锁的画廊和音乐回放。历史中的语音重播和收藏按钮在有有效配音的对白上显示。小游戏的剩余次数、点击进度和倒计时可以保存恢复，进入存档或设置菜单时暂停计时。

在“界面 → 设置”可编辑内置玩家选项、滑条、下拉菜单和选项按钮，也可分别设置角色及旁白音量。自定义选项由同一个通用参数的初始值、保存方式和恢复配置决定；需要界面入口时显式添加参数控件。保存在本机的玩家偏好不随剧情读档回退。

“界面 → 消息框 → 创建确认框布局”生成普通组件，可继续换图和排版；退出、返回标题、存档确认、恢复初始设置和蓝图询问共用这张页面。对话底图可勾选跟随玩家透明度，保持对白文字清晰。详见 [玩家设置与确认框](player-settings.md)。

选择“保存在本机”的参数不随旧存档或回退恢复到过去的值；反复读档也不会重复执行已经完成的修改。玩家主动回到分支并再次选择该路线时，状态修改节点会再次执行。需要每个结局只计一次时，可用保存在本机的开关和条件节点控制。

作品发布后应保留 `.studio` 中的编译基线。已经验证保留节点、对白、变量和调用身份时的对白修改与插入兼容；删除这些对象、修改变量类型或更换运行时不属于已验证的旧存档兼容范围。每次更新作品仍应拿旧存档实测。

## 发布前自查

从开头走完每个分支和结局，验证变量与跨周目状态。检查中文对白、背景、角色和声音，操作每个互动与小游戏出口。在不同位置存档读档，回滚到分支前重新选择。关闭重开工程后再改一次并导出，最后从解压包启动 EXE 完成同样的流程。

版本功能和验证范围见 [v0.8.1 发行说明](release-0.8.1.md)。自动化操作不等同于真实零基础创作者的易用性测试；后者应安排实际创作者试用并记录卡点。

## 零基础验收流程

1. 从“新建工程”创建哀鸿模板副本。改写一行对白，在文本页输入 `/` 选择背景和音乐，确认画面与试听更新；打开资源管理器，找到并双击“夜宴”蓝图。
2. 从开头试玩，分别选择以下路线。每次从主菜单重新开始，确认“谨慎”和“小路记忆”不会沿用上一局：

| 选择路线 | 结局 |
| --- | --- |
| 任意酒宴与归路选择 → 入左屋 → 关好院门，先让她暖过来 | 灯火暂安 |
| 借酒压下心事 → 任意归路选择 → 入右屋 | 惊梦未醒 |
| 记下劝告，放下酒坛 → 辨认废井旁的小路 → 入左屋 → 收好盘缠，寻找避兵的小路 | 远舟 |

3. 在方院存档，继续后读档，确认回到保存对白；回滚到选项，重新选择另一间屋。再操作自动、跳过、历史和音量设置。模板改编范围和额外分支见 [哀鸿剧情示例](aihong-story-sample.md)。
4. 新建空白作品，按前面的创作流程建立双角色、三场景和三个结局。加入好感度修改与条件节点，再配置一次镜头演出、点击热点和小游戏三个出口。
5. 保存并关闭编辑器，重开后修改一句话并导出。解压 ZIP，直接打开其中的 EXE，再次走完三条路线和互动出口。记录实际耗时、不明白的按钮、错误提示及无法独立完成的步骤。

这是一份待实际创作者执行的流程，不代表已经完成真人试用。

## 已知限制

- 编辑器面向 Windows 10/11 的 64 位桌面环境；自动化验证不代表所有电脑、干净虚拟机或真实零基础使用体验均已覆盖。
- Ren’Py 部分 Windows 打包操作受系统路径长度影响。编辑器会在构建路径过长时自动改用系统临时目录下的短路径；素材自己的相对路径、导出与解压位置仍需满足 Windows 限制。
- DOCX 只导入正文和表格文字，不自动转换 Word 图片、字体样式或排版；详细支持范围见 `text-authoring.md`。
- 文本页画面预览按文本顺序展示，复杂分支、互动和最终演出时序以真实试玩为准。存档兼容范围限于前面明确验证的修改类型。
- 安装包没有代码签名；Windows 可能显示未知发布者。真实中文输入法候选窗操作和真人零基础体验尚未验收。

# 叙事工坊使用说明

## 安装与作品

运行 Windows 安装程序并选择安装位置。编辑器随附运行时、《哀鸿》素材演示与两章剧情模板（示例媒体来自用户提供的原作素材副本），创作者无需安装 Node.js、Python 或 Ren'Py SDK。首启会在用户目录准备可写运行时，之后可以离线创作。

“新建工程”可选择空白作品或“哀鸿模板 · 两章与三个结局”。模板包含两章分支剧情、原作背景和音乐、可编辑的界面皮肤、字体、实时骨骼动画和控制蓝图。“保存工程”选择作品目录，工程文件和导入的 `assets` 素材目录一起构成作品。移动或备份作品时保留整个目录，包括 `.studio` 发行基线和恢复文件。本版移除了旧的自动显示角色指令；旧文本需改用「显示角色」。工程、素材与备份须一起保留。

## 资源与工作区

“剧本、蓝图、界面、素材、角色、状态”位于窗口最上方，直接占用原 Logo 的位置。“剧本”内可切换“模块编辑”和“文本编辑”，两种模式共用右侧实时预览及可收起的剧情目录，切换时保持当前对白并同步内容。模块模式在台词上方显示演出，点击展开参数，旁边的加号用于添加效果；说话人与台词并排。“素材”打开完整资源管理器；点击底部“资源管理器”可打开抽屉，Ctrl+空格也可打开，但文本编辑区内此快捷键用于补全。

右上角“作品设置”打开独立设置窗口。“作品信息”设置名称、版本、画面尺寸与故事入口；“试玩设置”指定试玩方式、起点及测试状态，工具栏“试玩”和 F5 使用这些设置。测试状态不会改写剧情初始值，设置窗口支持 Esc 关闭。

资源按“场景、立绘、UI素材、BGM、配音、音效、视频、字体、骨骼动画、脚本”分类。保存工程会自动建立 `assets` 下的分类目录；“作品设置 → 资源管理”采用复制模式时，后续导入放入对应的实际目录，例如 `assets/立绘/`、`assets/BGM/`。可直接把系统文件或文件夹拖入资源管理器，也可以点击导入文件夹按钮；保留子文件夹结构，同内容文件会跳过。选择目标分类后导入，或拖到分类目录，即可指定用途；未指定时按文件类型和名称推断，不能识别的放入“未分类”。导入后自动定位所在分类。选中资源后可修改分类，Ctrl/Shift 多选可批量移动，图片和音频选择器沿用同样的分组，例如“配音 / 苏怜烟 / 第一章”。移动资源与改显示名称不改变已有物理路径及既有引用。

拖动资源抽屉上边缘调整高度，剧情目录和属性面板也可收起。节点库默认收起，蓝图空白处右键或空格可搜索添加节点；连线可直接点选，也可从连线列表选择。选中后拖动端点改接、点击断开或按 Delete 删除，Ctrl+Z 撤销。详细操作见 [中文节点编程](blueprint-authoring.md)。

## 从空白到第一段游戏

1. 新建作品并保存到自己的目录。在“素材”栏导入背景、立绘和音乐，修改方便查找的中文名称。
2. 在“角色”栏添加角色并设置表情图片。在“状态”栏创建好感度、开关或文本状态；需要多周目保留的状态可勾选“跨周目保留”。
3. 在“剧本 → 模块编辑”中连续输入对白、选择说话人，用台词上方的加号添加演出；也可切到“文本编辑”导入 Word 剧本或使用中文指令。文本模式显示行号和语法颜色，支持拼音首字母补全、参数提示、Ctrl+F 查找、Ctrl+H 替换，内部编号自动隐藏。右侧“播放预览”播放当前台词的演出、音效与配音；BGM 只通过预览下方的播放器手动控制。拖动进度条或时间轴播放头后，按空格可播放／暂停。详细语法见 `text-authoring.md`。
4. 选择对白，打开右侧实时预览标题栏的“编辑舞台”，直接拖动立绘或图片；图片四角可缩放，旋转把手可调整角度。画面下方也可调整位置、表情、缩放、图层、镜头和关键帧，数字参数名支持左右拖动，Shift 精调、Ctrl 加速。两种剧本模式共用这套工具；编辑区与预览之间可拖动分隔条调整宽度，双击复位。文本工具栏的「自动换行」只改变显示，不修改原文。修改写入当前台词，支持撤销，文本的光标和滚动位置保持不变。未播放时显示演出完成后的画面；播放中暂停后修改参数保留当前时间，停止后恢复完成画面。角色、关键帧和镜头的位置不限于画面边界，可输入负数或超过 100% 的位置。角色纵向位置表示脚底位置，调到 100% 以上可把下半身移出画面；画面外的角色仍可从角色选择框选中调整。
5. 到“蓝图”添加选项、条件、状态修改和结局，连接对应出口。蓝图以段落和逻辑节点组织剧情，双击或选中节点即可编辑。可搜索、自动布局、折叠节点和创建可复用段落。
6. 点击“试玩”或按 F5，使用“作品设置 → 试玩设置”中的起点和初始状态运行。运行状态面板可定位当前节点和对白。

## 演出蓝图与 AI

文本中选中一组演出后右键，选择“封装选中演出为蓝图”，可命名、按资源文件夹嵌套分组，并设置公开参数和默认值。用 `/` 菜单调用，Ctrl+点击蓝图指令进入编辑。工具栏“批量演出”处理全部台词，右键“为选中台词添加演出”只处理选择范围；旁白默认排除。“显示角色”的角色留空时跟随当前台词，表情留空使用默认表情；单句模块可覆盖表情与位置。详见 [演出蓝图](blueprint-authoring.md)。

在蓝图中添加时间轴组件，双击进入片段编辑。图片和角色图片显示缩略图，音乐与音效显示真实波形，视频显示实际画面。音乐和视频可拖动片段左右边缘裁剪入点、出点；黄色把手调整淡入淡出。拖动片段改变开始时间或轨道，上方轨道遮住下方轨道。右侧“时间轴组件”和“片段”是二选一属性页；试播直接使用组件参数的默认值。组件按所有轨道中最晚片段的结束时间自动完成，工具栏的“完成”时间随裁剪更新。

音频波形横向对应时间，起伏显示源音频的强弱，安静段接近细线。裁剪后显示相应的源区间，不会把安静段放大。音视频的鼠标裁剪和数值时长都不能超过已读取的素材末尾，直接更换视频会重新读取新素材长度。

需要调用时换图片、音乐、音效或视频，选中片段，在右侧“调用参数”中点击对应的“设为素材参数”。在“时间轴组件”页修改参数名称和默认素材；返回父蓝图后，可在调用节点直接选择本次素材或连接素材输入。未传入时使用组件默认值，调用节点的“默认”按钮可恢复默认素材。结局使用普通 `@结局演出`，随后填写 `@返回标题界面`。

“作品设置 → AI 服务”可填写地址和密钥、获取模型列表或手填模型。顶部“AI 助手”打开独立窗口，可一边编辑一边连续提问，跟随当前工程和台词；用法、表情与工程修改共用一个输入框。建议审阅后应用，与主编辑器共用撤销，详见 [AI 创作助手](ai-assistant.md)。

## 界面与互动

“界面”页可编辑标题、对话、选项、存档与设置等页面。添加组件后调整大小、位置和显示层级，在属性中设置图片状态、九宫格、字体及标准行为。原生对话、选项列表、存档格及设置项通过绑定工作，不需要编写脚本。Spine 4.2 素材可添加为“骨骼动画”组件，使用蓝图播放、暂停和调速，详见 [骨骼动画操作](spine-authoring.md)。最后在试玩中检查按钮和组件。

在“界面 → 画廊”选中画廊网格，分组、分镜及未分组图片都可设置“参数条件”。例如条件选择“章节进度 大于或等于 2”，剧情对应位置写 `@设置：如果 章节进度 < 2，章节进度 = 2`，即可解锁且保留更高进度。跨周目解锁需在参数集中开启“跨存档保留”。大于 2 与大于或等于 2 是不同条件，值恰好为 2 时只有后者满足。

“点击互动”节点可配置场景热点、角色绑定、条件和出口；选中节点后，右侧预览的“编辑舞台”可拖拽和调整热点范围。“小游戏”节点提供密码锁和限时点击模板，配置成功、失败、取消分支。动态效果和互动说明见 `interaction-authoring.md`。

## 检查与恢复

问题面板提示缺失素材、断开的分支、无效变量、递归效果和不能等待的逻辑循环。点击问题定位相关素材、节点或对白；文本错误带所在行。修复错误后再试玩或导出。

撤销与重做作用于共享工程。编辑停止后会自动保存恢复副本；关闭窗口前保存最新恢复数据。异常退出后，下次打开会优先恢复较新的有效副本，损坏的副本不会覆盖正常工程。正式保存后恢复内容成为当前工程。

删除节点、变量或素材前检查引用。修改名称通常不会更换对象身份。导入旧工程会升级已支持的数据格式；比当前版本新的格式会明确拒绝，避免错误覆盖。

## 导出与玩家功能

点击“导出”，在设置页点击“一键配置”，就绪后选择目标目录生成 Windows ZIP。解压后的 EXE 可独立运行，玩家无需安装编辑器或开发环境。编辑器也有[解压即用版](portable.md)。发布时保留完整解压目录及许可声明。

游戏包含存档、读档、回滚、自动播放、跳过、历史、文字与声音设置，以及按配置条件解锁的画廊和音乐回放。历史中的语音重播和收藏按钮在有有效配音的对白上显示。小游戏的剩余次数、点击进度和倒计时可以保存恢复，进入存档或设置菜单时暂停计时。

在“界面 → 设置”可编辑 13 类玩家选项，配置换肤滑条、分辨率下拉菜单和选项按钮；“角色音量”页可以分别调节每名角色及旁白。右侧“玩家初始设置”指定首次启动和恢复默认时使用的值。玩家调整后的设置不随剧情读档回退。

“界面 → 消息框 → 创建确认框布局”生成普通组件，可继续换图和排版；退出、返回标题、存档确认、恢复初始设置和蓝图询问共用这张页面。对话底图可勾选跟随玩家透明度，保持对白文字清晰。详见 [玩家设置与确认框](player-settings.md)。

勾选“跨周目保留”的状态不随旧存档或回退恢复到过去的值；反复读档也不会重复执行已经完成的修改。玩家主动回到分支并再次选择该路线时，状态修改节点会再次执行。需要每个结局只计一次时，可用跨周目开关和条件节点控制。

作品发布后应保留 `.studio` 中的编译基线。已经验证保留节点、对白、变量和调用身份时的对白修改与插入兼容；删除这些对象、修改变量类型或更换运行时不属于已验证的旧存档兼容范围。每次更新作品仍应拿旧存档实测。

## 发布前自查

从开头走完每个分支和结局，验证变量与跨周目状态。检查中文对白、背景、角色和声音，操作每个互动与小游戏出口。在不同位置存档读档，回滚到分支前重新选择。关闭重开工程后再改一次并导出，最后从解压包启动 EXE 完成同样的流程。

本机自动化验收记录在 `PROGRESS.md`。自动化操作不等同于真实零基础创作者的易用性测试；后者应安排实际创作者试用并记录卡点。

## 零基础验收流程

1. 从“新建工程”创建哀鸿模板副本。改写一行对白，在文本页输入 `/` 选择背景和音乐，确认画面与试听更新；打开资源管理器，找到并双击“夜宴”蓝图。
2. 从开头试玩，分别选择以下路线。每次从主菜单重新开始，确认“谨慎”和“小路记忆”不会沿用上一局：

| 选择路线 | 结局 |
| --- | --- |
| 任意酒宴与归路选择 → 入左屋 → 关好院门，先让她暖过来 | 灯火暂安 |
| 借酒压下心事 → 任意归路选择 → 入右屋 | 惊梦未醒 |
| 记下劝告，放下酒坛 → 辨认废井旁的小路 → 入左屋 → 收好盘缠，寻找避兵的小路 | 远舟 |

3. 在方院存档，继续后读档，确认回到保存对白；回滚到选项，重新选择另一间屋。再操作自动、跳过、历史和音量设置。模板改编范围和额外分支见 [哀鸿剧情示例](aihong-story-sample.md)。
4. 新建空白作品，按前面的创作流程建立双角色、三场景和三个结局。加入好感度修改与条件节点，再配置一次镜头演出、点击热点和小游戏三个出口。
5. 保存并关闭编辑器，重开后修改一句话并导出。解压 ZIP，直接打开其中的 EXE，再次走完三条路线和互动出口。记录实际耗时、不明白的按钮、错误提示及无法独立完成的步骤。

这是一份待实际创作者执行的流程，不代表已经完成真人试用。

## 已知限制

- 编辑器面向 Windows 10/11 的 64 位桌面环境；本机实际验收系统及范围见 `acceptance-report.md` 和 `workbench-1.1.md`，干净虚拟机和其他设备仍待验证。
- Ren’Py 部分 Windows 打包操作受系统路径长度影响。编辑器会在构建路径过长时自动改用系统临时目录下的短路径；素材自己的相对路径、导出与解压位置仍需满足 Windows 限制。
- DOCX 只导入正文和表格文字，不自动转换 Word 图片、字体样式或排版；详细支持范围见 `text-authoring.md`。
- 文本页画面预览按文本顺序展示，复杂分支、互动和最终演出时序以真实试玩为准。存档兼容范围限于前面明确验证的修改类型。
- 安装包没有代码签名；Windows 可能显示未知发布者。真实中文输入法候选窗操作和真人零基础体验尚未验收。

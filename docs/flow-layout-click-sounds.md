# 流程图布局、字体、滑条、点击音效与文字阴影

## 流程图布局

选中流程图控件后，可以直接在设计画布上拖动节点。

- 拖动时吸附 10 像素网格和附近节点的边，按住 Alt 不吸附。
- 点击节点编辑文字与使用样式。恢复位置使用“当前节点恢复自动排列”按钮，“全部恢复自动排列”清除全部手动位置；双击保留位置。
- 没有拖过的节点继续自动排列；工程不存放这些节点的位置。
- 选中流程图时，空白处仍可移动整张图。

“布局与连线”提供排列方向、尺寸间距和连线形状；“玩家操作”提供未到达的节点、文字和连线显示：

| 设置 | 选项 |
| --- | --- |
| 排列方向 | 从左到右、从上到下 |
| 连线样式 | 折线、直线、曲线 |
| 未到达的节点 | 显示、隐藏 |
| 未到达时显示的文字 | 默认“未到达”，可改成“？？？”或留空 |
| 未到达的连线 | 正常显示、变暗、隐藏 |

连线的任意一端未到达时，这条线按未到达处理。未到达相关设置在“可进入的剧情”选择“曾经到达的剧情”后出现。

直线连接两个节点相对的边缘，拖动节点后端点随之变化。折线和曲线按排列方向连接；节点在同一列或同一行靠近时，改接相对的上下或左右边缘。回返连线绕过两端节点，自身跳转也有可见回环。连线超出节点范围时，滚动范围会随之扩大。

连线图片按线宽等比例缩放，并沿路径重复铺贴，短线和长线保持相同的圆点、虚线间距；曲线不会在每一小段重新压缩整张图片。只设置水平或垂直连线图片时，另一方向自动旋转使用它。未设置图片时使用连线颜色。零长度线段不绘制，曲线变暗在整条线合成后统一处理，避免接缝处透明度叠加。

## 节点文字：多种字体和大小

选中“玩家剧情图”控件后，在“内容”中选择节点，在“节点样式”中设置外观：

- **基础字体、基础字号、普通文字色**：作用于整张图，节点外观预设单独设置的属性优先。字体可以搜索、浏览和导入项目字体。
- **分段文字样式**：点“添加分段样式”，给每段单独设置字体、字号、颜色和后面的间距，最多 8 段。空项沿用基础设置，可以恢复继承。
- **当前节点文字**：点击画布节点或查找后选择，逐段输入文字并添加文字段，例如分别输入“记 第一回”和“醉梦”。存储仍兼容 `记 第一回｜醉梦`。点击“使用剧情标题”恢复目录标题。
- **当前节点外观预设**：给当前节点选择一套可复用的字体、颜色和底图；“编辑这个外观预设”会跳到预设列表并显示影响数量。样例使用真实文字，编辑状态和预览状态同步切换。“节点外观预设”是原“共享样式”的新名称，旧工程和剧本的 `样式=` 参数保持兼容。

文字段和节点文字的分段从最后一段开始对应：设了两段时，没有分段的节点使用第 2 段。这样主名称的样式不会因为某个节点没写小字而改变。

节点外观预设也能设置自己的整套分段，使用此预设的节点优先用它。修改预设会更新所有使用它的节点；未单独设置的属性沿用当前图的基础样式。左、中、右对齐作用于整组分段文字，分支图、目录列表和实际游戏一致。

节点文字也可以写在剧本里，和编辑器里改的是同一个值：

```text
# 小章节(流程图=是，显示名称="记 第一回｜醉梦"): 第一回
```

确认跳转的提示里，各段用空格连起来显示。未到达的节点只显示“未到达时显示的文字”。

哀鸿模板已设好两段：第 1 段思源宋体粗体 30 号，第 2 段沿用流程图字体。模板自带的章节没有写分段，需要时直接在节点文字里加 `｜`。

## 流程图滑条

修复了编辑器画布里滑条显示不对的三个问题：

- 轨道受居中文字影响，向右偏移了半个滑条长度。现在从滑条左端开始。
- 选中流程图后，滑条被移动控件的透明层盖住，无法拖动。现在可以直接在画布上拖动。
- 滑块素材宽 48 像素，左右九宫格各 24 像素，中间没有可拉伸的部分，编辑器里中段是空的，游戏里整张图被压成细长条。现在左右边距相加达到素材宽度时，保留 1 像素作为中段拉伸，编辑器和游戏都这样处理，与原作的切片效果一致。

排列方向选“从上到下”时，自定义滑条和鼠标滚轮改为控制纵向滚动。

## 点击音效

点击音效现在和悬停音效一样分三层继承：

1. 主题：`界面 → 属性 → 游戏设置 → 按钮点击音效`。
2. 页面：页面设置里的“按钮点击音效”，可沿用上级或关闭。
3. 控件：组件设置里的“点击音效”，可使用页面默认、指定音效或不播放。

主题默认对标题、菜单按钮和列表条目都生效。流程图、章节列表、音乐列表、语音收藏和历史列表也有自己的“悬停音效”和“点击音效”，对列表里的每个条目生效。

哀鸿模板已按原作 `Utage.UguiButtonSe` 的引用补入三段音频：

| 音频 | 用途 |
| --- | --- |
| `Click_New` | 标题按钮、流程图节点和流程图返回 |
| `点击1` | 模板默认，用于对话工具栏、画廊分页、存档位和选项等 |
| `点击2` | 各页面的返回、关闭类按钮 |

设置页的二选一按钮、确认框和历史条目在原作里没有点击音效，模板中设为不播放。语音收藏条目使用原作的 `Highlight_New`。流程图节点和返回按钮的悬停音效也改回原作的 `Highlight_New`。

## 文字阴影扩展

文字新增“阴影扩展”：先把阴影向外加粗，再做柔化，用来做贴着文字的深色外圈。原来的“阴影柔化”只模糊文字本身的形状，笔画细时阴影会被冲淡。

哀鸿模板的流程图文字改为柔化 14、扩展 4、不透明度 90%，比之前的柔化 7、不透明度 40% 更接近原作的深色外圈。这是按截图调的视觉近似，并非原作着色器的复刻。

## 现有工程

旧版本兼容：匹配原模板7px/40%阴影的基础及内置共享样式，在打开时于内存中修复；自动恢复草稿保留用户实际修改，未改的旧阴影不会盖回。主文件不会在打开时重写。自定义样式可在“文字描边与阴影”点击“使用柔边黑底”。

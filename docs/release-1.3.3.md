# 叙事工坊 1.3.3

2026-09-30，Windows x64。

“新建作品”新增“分支入门 · 两个结局”。示例《雨中的车站》使用六句旁白、一个选择、三处小章节和两个结局，无需导入素材即可试玩。全部内容保存在普通剧情节点中，可以改稿、调整分支或添加背景、角色与音乐。

剧情目录可搜索章节、段落、对白、发言角色、选项和结局。用空格组合关键词，例如“苏怜烟 旧忆”。点击对白结果定位到具体一句；文本模式搜索当前草稿并定位源码行。搜索结果最多展示 100 条，显示总数并提示缩小范围；Enter 定位第一条，Esc 或 × 清除搜索。没有输入搜索词时不建立对白索引。

从哀鸿模板创建作品时，默认建议保存到“文档 / Visual Novel Studio / 作品名称”目录。取消系统保存对话框后，新建表单保留名称和模板选择，便于改选目录。

“另存为”和模板复制会先检查全部素材与骨骼配套文件。同名同内容文件复用；同名不同内容、文件缺失或 Android 签名冲突时提示具体问题，不覆盖目标已有文件。源项目与用户素材保持原样。磁盘写入失败时仍可能留下本次已复制的新文件，可修复问题后重新保存。

修复多行结局、含换行或箭头的选择文字在切换文本模式时被拆成额外对白的问题。这类复杂节点使用现有的“@实例”引用保留，具体内容可在模块模式编辑；普通单行选择和结局继续直接显示文字指令。

默认游戏快捷栏在全屏章节标题和结局期间隐藏，回到对白或选择时恢复。入门模板的标题使用内置字体支持的标点，避免显示缺字方框。

本版继承 1.3.2 的中文确认提示。原游戏直接视觉对照仍待截图组件恢复；本版验收不将编辑器截图和导出游戏测试等同于原作对照。Android 本轮未重新构建，旧版本设备记录保留其原验证范围。

源码单测 307 项通过。入门模板由正式导出服务生成 Windows ZIP，直接运行包内 EXE，验证两个结局、选择处存读档、重新开局和快捷栏恢复。结局文字检查实际渲染的 Text 控件，另保存画面检查换行、标点和遮挡。哀鸿模板覆盖 14 条模型路线与 5 个原生用例。

重验入口为 `pnpm exec tsx scripts/verify-editor-template.ts`、`pnpm exec tsx scripts/verify-branching-template.ts` 和 `pnpm test:aihong-story`。设置 `VNS_INSTALLED_EXE` 后，编辑器验收使用实际安装程序；安装内容和便携版分别由 `verify-installer-content.ts`、`verify-portable.ts` 验证。完整报告与发行文件校验值见发行目录中的 `verification-1.3.3.json`。

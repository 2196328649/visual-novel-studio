# 事件图单左栏方案

日期：2026-11-12。本文保留最初只读分析与交互草案。用户已批准“目录＋详情”方案，现已实现并完成统一验收；最新行为、83组桌面验证和清理例外见 [实现与验收](event-graph-left-sidebar-2026-11-12.md)。下文“当前”指提案形成时，代码行号和旧布局不作为现状。

## 推荐结构

事件图只保留一个常驻左栏，上方“我的界面”是短目录，下方“详情”是当前对象唯一的完整编辑区；右侧全部用于画布。两区的分隔条可调，目录可折叠为一行，让长表单使用整个左栏。选中对象只更新详情，不自动折叠目录。

借鉴 UE5 的职责划分：My Blueprint 用来列出、查找、新建成员，Details 用来编辑选中对象。左侧上下放置是本项目的建议布局，并非宣称 UE5 默认也将这两区上下放在左侧。

与“内容／详情”页签相比，上下分区可在选择控件、变量和节点时保持目录上下文。页签是备选：能给当前内容完整高度，但每次选对象都切到详情，会隐藏刚使用的目录；新建多个事件或连续拖多个变量时需要反复返回。交互草案提供两种布局比较。

## 当前问题及真实来源

- `BlueprintGraphEditor.tsx:848` 用 `UiDock` 拼装四槽：详细信息、事件图、我的界面、参数绑定。`src/core/editor-layout.ts:27` 的默认左右宽度分别为24和18份，中间58份；当前两个侧栏持续占用大量宽度。
- `UiLogicEditor.tsx:146` 的“我的界面”同时包含目录、选中控件的事件与操作、变量和页面参数的定义表单、页面设置及模块库。控件一经选中，详细说明和操作就挤进目录。
- `UiGraphVariables.tsx` 是 `BlueprintVariables` 的别名。右侧我的界面和左侧变量页签都挂载同一编辑组件，造成重复的列表、搜索、新建和定义编辑状态。
- `BlueprintGraphEditor.tsx:944` 的详情区兼任节点检查器、蓝图调用接口、变量编辑和“本图节点”完整目录；未选择时又复制了一套节点定位入口。
- `UiParameterBindings` 当前是底部独立区。它与属性右键共享“来源”能力，还承担旧联动修复和定位；应统一入口和上下文，保留其修复能力。

## 唯一入口分配

| 内容 | 目录中保留 | 唯一详情中显示 |
| --- | --- | --- |
| 控件 | 名称、类型、选择、拖入 | 对应控件的可用事件、执行顺序、属性来源、在设计中定位 |
| 事件 | 事件名称、所属控件、定位、新建 | 触发对象、触发条件和事件参数 |
| 变量 | 名称、类型和所属范围，分组新建、拖入 | 名称、类型、初始值、可用范围及引用；共享参数沿用参数集的受保护编辑流程 |
| 控件动画 | 名称、新建、拖入 | 名称、目标、摘要；双击进入原有关键帧编辑器 |
| 页面输入与结果 | 短成员行、新建、拖入 | 类型、默认值、是否必填及含义 |
| 可调用蓝图／用户节点 | 名称、分类、拖入 | 用途、调用接口、引用位置；双击进入该图 |
| 本图设置 | 一个入口 | 图名称、说明、调用输入输出和引用位置 |
| 属性关联 | 一个入口；控件详情可预选属性进入 | 控件、属性、来源模式、关联参数、旧联动修复和控制它的蓝图 |

取消详情区的独立“变量”与“输入输出”常驻页签，把它们变成目录可选择的对象。取消底部参数绑定面板，入口移到左栏；设计属性右键保留为打开同一关联编辑器的快捷方式。删除空选中状态下的重复全节点目录，节点搜索和事件目录承担定位。

节点卡片中的直接填值和接线继续保留，这是画布内快捷操作；左侧只有一份选中节点的详情，不再在另一面板复制变量或成员定义。节点卡片编辑实例值、变量详情编辑变量定义，名称及说明应明确区分。

画布添加节点、排列、定位、缩放留在画布工具栏。节点库用搜索弹层或左栏中的可调用模块目录承载，不再另开常驻右栏。资源管理器沿用现有底部抽屉，属于全应用资源入口。

## 不可混淆的数据含义

1. **页面输入／页面结果**：打开页面时接收数据，页面正常完成时交回结果；输入只读，结果可读写，各界面方案共用定义，数值属于本次打开实例。
2. **蓝图调用输入／输出**：其他蓝图调用这张图时传入和返回，保留现有签名同步和变更影响确认。不能因当前图在页面里编辑就删除这套接口。
3. **变量**：可修改的状态，明确标注“本次调用”“本次打开页面”“作品”“本机”；作品与本机变量仍是参数集里的同一对象。
4. **属性关联**：某个控件的某项属性由谁控制，不是新增变量类别，也不是另一个参数集。

## 操作及文案

- 单击目录对象显示详情；单击事件定位到相应节点；拖入变量、控件、素材的现有语义保持。目录选择和画布选择分别记录，以明确的详情对象类型避免混淆。
- 新增按钮放在对应分组标题右边。点击后在详情显示新建表单，名称和类型同行、初始值在下一行；确认后才创建，取消不留下空变量或孤立接口。
- 控件的事件按能力列出。已创建显示“定位 →”，未创建显示“＋”；“新增独立事件”只在明确需要多个处理流程时提供，保留旧事件的真实执行顺序与继承来源。
- 控件动画和可调用蓝图双击进入；返回恢复原页面、图、节点、视口和详情。目录中用“进入编辑”短提示说明，不长篇解释实现。
- 无选中对象时详情显示当前图名称和一行操作提示；多选只显示真实支持的共同操作，不假装已有通用批量改属性。选中连线不新增端点圆圈、选中数量横条或额外断开按钮。
- 参数说明采用一句话。例如页面变量：“本页事件共享；再次打开时重置。”页面输入：“打开界面时传入，只能读取。”页面结果：“页面正常完成时返回。”双向同步：“属性与参数互相同步，蓝图仍可修改。”
- 只有遇到失效引用、共享修改范围或不允许写入时才显示对应提示。常见操作的长说明收进帮助，不让每个分组常驻多段说明；错误、删除影响和共享来源警示仍直接可见。

## 布局和状态约束

左栏建议初始宽320～360px，允许拖宽并设置上下限；目录约占左栏四分之一到三分之一，具体值应在实际桌面验收后确定。两区分别滚动，外层不再嵌套滚动。标题保持可见，矮窗口可手动收起目录；不因选中对象自动改高度或抢输入焦点。整栏可收起以放大画布。

新视图状态使用明确的详情对象：节点、控件、变量定义、页面输入、页面结果、图调用接口、动画、属性关联、本图设置。保存稳定ID与所属页面／方案／图，不使用名称作身份，不把不同对象的 selection ID 混用。

沿用 `UiAuthoringSession` 的页面与方案范围，按图保存视口、选择与返回位置；详情表单草稿、搜索、折叠和滚动须有各自正确的归属。改面板或切换对象只改视图状态，不隐式保存、丢弃或重置界面草稿及撤销历史。失效对象采用明确回退，不显示别的对象的旧表单。

迁移只针对 `uiLogic` 布局。新的单栏布局需要独立的版本和类型，保存一次迁移后的宽度及折叠状态，不能继续把两栏宽度相加，也不能让旧“交换左右”命令重新造出右栏。现有设计模式、时间轴布局和未改动的其他偏好保持其各自定义；AI布局动作、恢复默认命令也需认识新布局。

共享或继承图在上下文处保留短警示，明确“修改共用图影响哪些页面”和“新增控件事件保存到当前页／方案”的区别；当前页面与图的所属页面不能因左栏合并而被当成同一个值。

## 实施顺序建议

先拆“列表导航”和“定义表单”，建立唯一详情对象路由，再替换事件图 Dock、迁移布局偏好，最后统一文案和快捷入口。不要先把原两个长面板原样堆到左侧；那样只能释放宽度，不能解决重复与滚动混乱。

正式实现后再统一编译与验收。重点覆盖：目录和节点切换、同名不同范围成员、新建取消、变量拖入、接口变更影响、属性关联及旧联动修复、未保存草稿、撤销重做、共享图归属、动画进入返回、搜索键盘焦点、窄窗和长详情，以及旧布局偏好迁移。此次只分析，无产品验收结果可宣称。

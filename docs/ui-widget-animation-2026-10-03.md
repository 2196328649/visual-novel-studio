# UI 事件图中的控件属性动画 · 2026-10-03

沿用户要求的 UE5 Widget Blueprint 工作方式，控件事件图现在可直接控制控件的连续变化：点击按钮 → 变量提供移动终点 → 同时移动与淡出 → 动画结束后隐藏。已有的设计/事件图切换、控件拖入、事件入口、变量读写和执行连线保留。

## 操作与行为

- 左侧选中控件，可添加“属性动画”或“停止动画”；拖控件到画布也可选择这两种节点。新增节点默认指向当前控件。
- “控件属性动画”支持横纵位置、宽高、不透明度和适用控件的进度值。目标和时长可直接填写或连接数值引脚；支持匀速、缓入、缓出、缓入缓出。时长为 0–3600 秒，不透明度及进度为 0–1。
- 勾选“等待结束”时，动画结束才执行后续连线；关闭时立即继续，可串接多个不同属性动画，让它们同时运行。同一属性的新动画从当前值接续并替换旧动画。
- “停止控件动画”可停止单个属性或全部属性，保留当前值或直接到目标值。设置控件属性会停止同属性动画，重置控件会停止全部动画并恢复设计默认。
- 停止或替换同样结束原动画的等待。另一个按钮回调替换动画时，先完成该回调，再恢复原回调后续连线，与原生嵌套调用顺序一致。
- 不透明度变为 0 只改变透明度。需要隐藏控件时，在后面连接“设置组件属性：可见 = 否”。
- 交互预演勾选“按时间预演”后，可播放或逐步推进，查看中间值和后续事件；关闭按时间时直接完成动画。预演不修改设计默认、UI 草稿和玩家资料。

## 实现与原生对照

属性、缓动和输入校验由 `src/core/ui-animation.ts` 定义，并接入节点目录、工程结构、蓝图检查、编辑字段及 AI 操作说明。预演运行器保留等待位置，同时推进计时器和动画；一次推进可跨越连续动画。静态舞台预览遇到控件动画请求会停止并标记不完整，避免提前执行后续 UI 副作用。

`src/runtime/ui-animation-runtime.ts` 生成 Ren’Py 动画运行时：持久状态保存已播放时间，墙钟采样放在函数属性中，不进入存档/回滚状态。读取存档或回滚恢复不同记录对象后，从保存的进度重新采样，避免把离线时间计入动画。菜单与剧情页面均可更新控件属性；多个计时器不会重复累计时间。

原生对照还覆盖了两个按钮调用同一共享动画图：编译器将各动画节点的等待标识放入生成 label 的局部参数中，防止嵌套重入覆盖外层等待标识。预演相应延后恢复被替换动画的等待，直到替换回调返回。

## 当前范围

本轮是节点级属性渐变，尚未提供命名控件动画、多关键帧轨道或完整 UMG 动画编辑工作流。隐藏页面不会自动取消已启动动画，需要按需求连接停止或重置；预演仍保留既有 60 秒时间上限。舞台演出时间轴与控件动画仍是不同能力。

没有新增外部 AI 模型调用，不能由字段接入推出 AI 全覆盖。旧蓝图脚本入口迁移、剧情流程全选删除等既有未解决项未在本轮修复。原作目录保持只读，未恢复用户停止的原作电脑操作，也未替换安装版。整体持续目标未完成。

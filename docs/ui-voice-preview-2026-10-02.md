# 高级 UI 语音收藏预演（2026-10-02）

语音收藏列表已从静态样例扩展为可操作的参数预演，普通设计画布与高级 UI 共用布局和皮肤渲染。整体目标未完成；本轮没有扩展为完整历史、音乐室、剧情播放或原作等价验收。

## 行为与实现

`voice-preview.ts` 根据实际对白绑定和列表指定素材生成条目，保持工程素材顺序。每页独立记录页码和收藏筛选；收藏在本次预演中跨页面保留。支持多列分页、自定义页码区域和未设置行数的滚动列表，删除末页唯一收藏后回退至有效页码。进入页面重新从第一页开始。动态解锁、收藏变化也会校正所有列表的页码，不会恢复已经失效的末页。

测试数据默认全部解锁、没有收藏。在“语音测试数据”中可选择已解锁语音、添加单条收藏、收藏全部或清空收藏；改变测试数据会停止试听。锁定条目不能播放或普通收藏切换；自定义收藏列表中的已收藏锁定条目仍可移除，与原生 `VnRemoveFavoriteVoice` 相同。普通列表的收藏切换与自定义收藏列表的移除行为分别处理：仅后者删除当前试听条目时停止声音，删除其他条目继续播放。

`UiVoiceCollectionPreview` 复用原生几何规则显示条目、文字框、收藏按钮、控制区和页码。长文本按字面显示并省略，不解释文本标记。界面方案、图片皮肤和组件参数仍由现有编辑系统管理。

`UiVoicePreviewAudio` 使用真实音频元素：点击会开始或重新播放，切换条目替换上一条；音量为主音量、语音音量和本次播放的角色音量之积。播放结束会清除选中状态，过期结束事件不能停止较新的播放。确认框覆盖收藏页时继续播放；离页、折叠、切换预演范围或恢复测试值会停止，重新展开不会自动重播。每次请求使用独立媒体实例并刷新素材请求，使文件缺失时显示错误、文件恢复后可以再次点击重试。

收藏、解锁、页码和试听状态均为临时预演数据，不写工程或玩家资料。这里的语音试听不启动完整剧情演出。

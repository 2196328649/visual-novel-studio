# 实例化创作

本引擎把可复用内容分成场景、角色、效果和界面实例。实例保存自己的覆盖项，基础对象修改后，未覆盖的内容会自动更新。

## 场景实例

在“剧情”中选中场景内任意节点，属性面板的“场景实例”区域可以选择基础场景，并填写实例参数。参数使用 `键=值`，多个参数用中文逗号分隔，例如：

```text
天气=雨，时间=夜晚，室内=是
```

文本编辑器也支持：

```text
# 小章节：雨夜
@场景基础：街道模板
@场景参数：天气=雨，时间=夜晚
```

场景跳转可以在跳转节点的“场景切换”区域配置源场景、目标场景、无/溶解/淡入淡出、时长和颜色。无模式直接跳转；淡入淡出会生成双场景引用，编译为 Ren'Py 的 `Fade` 转场。

文本写法：

```text
@跳转：归途，淡入淡出，1.2，#112233
```

## 角色基础与功能

在“角色”资源属性中选择“基础角色”。子角色会继承基础角色的表情和角色功能；在子角色中新增同 ID 内容即可覆盖同名内容。

角色功能由一组舞台动作组成，可以包含背景、音乐、角色动画、镜头、震动或其他效果。对白的动作列表中使用“角色功能”调用它，也可以在文本中写：

```text
@角色功能：主角，发光
```

## 界面实例

打开“界面”视图后，在页面上方选择“主题默认”或某个界面实例。使用加号创建实例，随后设置实例名称和基础界面实例。新增组件会写入当前实例；编辑继承来的组件时，编辑器会自动创建同 ID 覆盖项。

文本可以切换当前界面实例：

```text
@界面实例：古风标题页
```

界面实例覆盖标题、对话、选项、存读档和设置五类页面，组件可绑定作品名称、说话人、对白和玩家设置。编译器只使用当前实例解析后的有效组件。

## 设计边界

实例只保存数据和覆盖关系，不复制基础对象。删除基础对象或形成循环继承会在问题面板中提示。复杂动画仍建议保存为“效果实例”，文本中使用 `@效果：名称` 调用，以保持对白文本可读和可编辑。

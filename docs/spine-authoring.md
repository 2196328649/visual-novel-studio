# 用图片与骨骼数据制作实时动画

“骨骼动画”素材把 JSON 数据、图集索引及对应图片保存在一起。界面编辑器和导出的 Windows 游戏都实时计算骨骼与网格。创作者通过中文控件和蓝图配置，不需要编写代码。

## 打开可编辑示例

点击“新建工程”，工程模板选择“哀鸿模板 · 两章与三个结局”，填写名称并选择保存位置。示例包含标题、对话、存读档、画廊、音乐室和语音收藏的界面组件，以及标题实时动画和两章分支剧情。图片状态、字体、布局和骨骼参数可以直接查看和修改。

蓝图列表中的“标题动画 · 播放 / 暂停 / 继续 / 半速”是普通可编辑蓝图。可以把界面按钮的“点击行为”改成“执行蓝图”，再在“调用蓝图”中选它。示例原有游戏按钮仍按其名称执行开始游戏、读档等操作。

示例剧情是用于验证的短篇内容；原作的全部页面、解锁规则和剧情尚未复刻，也尚未完成与原作运行画面的逐页对比。

## 自己导入这张图

1. 打开“素材”，点击“导入骨骼动画”。
2. 选择 `E:/Project/Model/SLY/T/Assets/TextAsset/1.bytes`。这是 Spine 4.2 JSON 数据，包含 `idle` 动画。
3. 同目录的 `1.atlas.bytes` 会自动匹配。其他素材如果没有同名索引，界面会让你选择 `.atlas` 或 `.atlas.bytes`。
4. 当提示“为图集 1.png 选择对应图片”时，选择 `E:/Project/Model/SLY/T/Assets/Texture2D/1_0.png`。导出素材包中的文件可能被重命名，因此图片需要按对应关系选择。
5. 导入完成后，在素材属性中预览动画，切换动画、皮肤和速度，或点击“暂停预览”。

也可在AI助手中要求“导入骨骼动画”，点击返回的按钮后使用同一套文件选择流程。任一步都可以取消；导入完成可撤销、重做。重复导入相同骨骼及配图会跳过已有项，保留作者修改的名称。

这些文件会复制到工程目录。保存副本和导出游戏会带上全部配套文件。素材库里的一项骨骼素材可以用于多个组件，各组件独立播放。

## 放到标题页

1. 在“界面”的“标题”页点击“添加骨骼动画”，选择骨骼素材。
2. 默认“适应组件区域”会把骨骼放入组件边界。可通过位置、宽度和高度调整画面。
3. 对于这份《哀鸿》标题，在 1920 × 1080 工程中设置组件位置为 0%、0%，宽高均为 100%，骨骼布局选择“自定义原点与缩放”。
4. “骨骼缩放”填 `0.32`，“横向原点 %”填 `50`，“纵向原点 %”填 `50.277778`。动画选择 `idle`，启用自动播放和动画循环。
5. 用“显示层级”把动画放在背景图片上方、Logo 和按钮下方。数值越大越靠前，允许小数；例如背景 0、动画 0.5、Logo 1。新建的示例工程已保留相应顺序。

水平翻转、垂直翻转、旋转、自动适配及自定义缩放均在组件属性中设置。“自动播放”关闭时显示当前初始姿态，之后可由蓝图启动。

## 用按钮控制动画

以暂停按钮为例：

1. 进入“蓝图”，点击“新建逻辑蓝图”。
2. 在节点库搜索“暂停骨骼动画”并添加。
3. “骨骼组件”按页面和组件名称选择标题动画，“暂停”选择“是”。
4. 把“事件开始”的开始连接点接到“暂停骨骼动画”的执行连接点。
5. 回到“界面”，添加按钮，填写“暂停动画”。点击行为选择“执行蓝图”，调用刚创建的蓝图。
6. 点击“试玩”，在真实标题页点击这个按钮。

将“暂停”设为“否”可以继续；添加“播放骨骼动画”并启用“重新开始”可以从头播放。

| 节点 | 参数和效果 |
| --- | --- |
| 播放骨骼动画 | 骨骼组件、动画名称、循环播放、重新开始 |
| 暂停骨骼动画 | 暂停选择“是”保留姿态，选择“否”继续 |
| 设置动画速度 | 1 为原速，0.5 为半速，2 为倍速，范围 0～8 |
| 设置组件属性 | 显示、启用、选中、文字、位置和不透明度 |
| 读取组件属性 | 把当前值传给比较、分支或其他节点 |
| 重置组件 | 清除蓝图对组件的覆盖，恢复初始动画设置 |

“设置组件属性”选择属性后会同步数据连接点的类型。显示、启用和选中使用开关；文字使用文字；位置和不透明度使用 0～1 的数值。读取“显示”后连接“条件分支”，两条分支分别设置显示为“否”和“是”，即可制作同一个显示/隐藏按钮。

制作互斥分支时，可先关闭节点库里的“添加时自动接线”，再分别连接两条分支；已自动串接的多余连线可选中后按 Delete 删除。文字属性用于固定文字和按钮，启用和选中用于按钮；不适用的属性会在选择器中禁用。

按钮的“选中”与鼠标“按住”是两种状态。蓝图设置选中后，按钮使用其选中图片；鼠标按下时仍使用按住图片。重置组件后，条件和原有按钮动作继续决定它的状态。

用户节点的输入类型可选“界面组件”，这样同一个动画控制流程可以接收不同组件。“界面”类型用于存档、设置等菜单，“界面组件”用于页面里的具体对象。

## 格式与维护

当前支持 Spine **4.2 JSON** 和 Windows x64 导出。`.bytes` 文件须包含 JSON；其他主次版本及二进制 `.skel` 暂不支持。缺少骨骼数据的单张图可以作为普通图片使用。

导入器保留图集中声明的原始尺寸，用其计算纹理坐标，兼容 Unity 对纹理的缩小。预乘透明度 PNG 在导入时转换为普通透明度；原素材保持不变。骨骼、动画、网格变形和裁切由官方 Spine 运行库计算。

Spine 运行库的许可和版权原文随安装包及导出游戏提供，见 `resources/spine/LICENSE-Spine.txt`；其集成和使用遵循该协议。源码包含对应 C 源码、来源提交和构建脚本。维护者可执行 `pnpm spine:build` 重建 DLL；使用安装版创作无需安装 C++ 编译工具。

# 事件图返回设计后控件消失（2026-10-03）

开发版已修复设计 → 事件图 → 设计后控件不可见的问题。旧实现把尺寸监听绑定在首次挂载的画布上，监听只随工程宽度变化重建；切入事件图会移除该画布，旧监听把宽度更新为零，返回时的新画布未被监听，图片、文字、按钮和进度条的尺寸与字号因此变成零。

## 复现与修复

未修复版本的实际桌面复现报告：`artifacts/ui-design-return/2026-10-03T07-46-25.381Z/report.json`。画布往返前后均为 798 × 449，四个控件在返回后宽高和字号全部为零；磁盘工程保持原样。`before.png` 和 `after-return.png` 保存前后画面。

`UiEditor.tsx` 改用画布节点的 callback ref：每次挂载新画布时重新监听，移除旧画布时解除监听，忽略旧节点或零宽度通知。画布引用仍供选中、拖动和内置控件编辑使用。监听随工程宽度变化重新绑定。

旧事件图验收只检查 `.ui-canvas` 可见，画布有尺寸时即使全部控件已缩成零也会通过。现在检查真实控件的宽高、字号、图片实际绘制及图片加载，并验证返回后仍可编辑。

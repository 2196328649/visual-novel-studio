# 叙事工坊 1.3.5

剧情流程图现在拥有独立工作区。原来的蓝图编程与演出编辑合并到「蓝图」，不再显示「返回剧本」按钮。

- 新建时可选择台词演出或独立演出，两者均支持时间轴、节点编辑、公开参数及预览。通用逻辑在同一工作区编辑。
- 现有章节标题、背景、题图、配乐可转为独立演出，保留剧情节点编号、连接、内容与时长；转换可撤销。原章节指令继续兼容。
- `@独立演出：蓝图名称` 单独调用演出。无参数的 `@独立演出` 将此前的普通演出指令作为独立一组执行，保存回写保留它与后续台词的边界。
- 独立演出在编辑器预览与导出的游戏中隐藏对白框。预览画面按窗口可用空间等比显示。
- 时间轴自动适配打开的演出与窗口大小；“适合窗口”不再受最小缩放限制，长演出刻度随缩放调整。展开片段参数后可独立滚动，预览和播放控件保持可见。
- 演出分类随工程保存；修改分类不会自动删除或重写既有台词。

操作说明见 [蓝图与演出工作区](performance-workspace.md)。验证脚本为 `scripts/verify-unified-blueprint.ts`，核心回归包括 `tests/standalone-performance.test.ts`。原游戏画面与动画的直接对照仍受此前截屏工具故障阻碍，本版不宣称完成该对照。

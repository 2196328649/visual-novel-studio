# 叙事工坊 1.2.0

2026-09-20 的 Windows x64 正式编辑器，安装器为 `release/Visual Novel Studio Setup 1.2.0.exe`。安装时可选择目录；随附 Ren’Py 8.5.3、Spine 4.2 运行时、示例与中文文档，无需 Node、Python 或开发环境。

## 本版内容

- 资源管理器支持框选、Ctrl/Shift 多选、混合移动、剪切粘贴、重命名和批量撤销。
- 演出工作区直接制作可复用蓝图；时间轴支持拖动、调整时长、跨轨、吸附、平移和缩放。
- 文本支持完整指令、带标识修订稿和纯台词导出；导入预览后可仅更新台词并保留演出、配音和流程。
- AI 可用一句话导入剧本、添加发言角色演出、结合上下文选表情、匹配目录配音；长任务分批处理，超时自动拆批，应用和撤销均为整次操作。
- 新建哀鸿模板包含 182 个可编辑 UI 组件、272 项资源、九位角色的 100 张表情和 11 张蓝图；画廊相框裁切、横向流程图与存档分页已更新。
- 真正的 Ren’Py 实时试玩与 Windows 游戏导出，覆盖标题、剧情、存读档、选项、结局和返回标题。
- 自动排版引擎在首次点击时加载，并由两种蓝图工作区共用；启动主脚本从 3.15 MB 降至 1.69 MB。排版等待期间有状态提示，失败可重试。

## 安装与数据

安装器更新程序文件；工程、素材和自动保存保存在原来的位置。打开旧工程仍使用其已有界面和资源，选择“新建工程 → 哀鸿模板”才会复制新版模板。AI 地址和模型属于本机配置，密钥不会打入安装器、工程或游戏；未勾选“在本机安全保存密钥”时，重启后需要重新填写密钥。

本版没有代码签名。当前发行对象为 Windows x64；Android 功能需要另行准备构建环境，本轮没有实际发行 Android 包。

程序文件属性显示 1.2.0 版本，发行内容只包含已打包的代码、资源和文档。构建会检查桌面程序是否遗漏外部依赖，避免重复携带开发依赖目录。

## 验证记录

功能回归、完整游戏与真实 AI 工作流证据见 [当前验收记录](current-authoring-work.md)。本版安装与后续检查的报告保存在 `release/verification-1.2.0.json`，安装器的校验值保存在 `release/SHA256SUMS-1.2.0.txt`；以报告中的实际检查项为准。

维护者可设置 `VNS_INSTALLED_EXE` 为已安装的 EXE 路径，运行 `scripts/verify-release-authoring.ts`、`scripts/verify-resource-timeline-authoring.ts`、`scripts/verify-text-exchange.ts` 和 `scripts/verify-ui-responsiveness.ts`。这些检查通过独立的 `--user-data-dir` 加载真实安装版，不使用开发服务器或原用户配置。`scripts/verify-installed.ts` 另外验证旧版工程、DOCX、试玩和独立游戏。

原作 UI 根据已恢复素材与布局制作，不宣称逐像素复刻。AI 配音匹配使用文件名、台词标记、文本旁注或 JSON 索引，不包含语音识别；缺少立绘的角色会明确提示。

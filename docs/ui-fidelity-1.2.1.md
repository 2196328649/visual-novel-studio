## 使用与验证范围

模板现有 183 个可编辑 UI 组件、277 项资源、九位角色的 100 张表情。新建「哀鸿模板」会复制新版内容；旧工程保持已有模板数据，可主动调整其组件。角色预设用法见[角色站位预设](character-presets.md)，AI 用法见[AI 助手](ai-assistant.md)，发行说明见[1.2.1](release-1.2.1.md)。

窗口实测在当前 Windows 10 x64、125% 显示缩放完成；96／144／192 DPI 是几何模拟，不代表多显示器实测。Android 本轮验证图标生成与预览，没有新 APK 发行。AI 配音测试使用两份低音量合成测试音及明确文本索引，验证匹配、复制、绑定和原生 voice 通道播放，不代表语音合成或音频识别。原作样式依据给定截图与素材制作，不宣称逐像素、逐帧复刻完整原作。

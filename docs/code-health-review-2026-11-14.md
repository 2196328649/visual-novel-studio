# 代码审查、边界修复与验收

日期：2026-11-14。对应用户“看看还有没有什么 bug 和屎山代码”。本轮接续时间轴体验整理，优先处理可确认的数据丢失、操作竞态和运行时状态串扰，并整理这些路径中重复的处理逻辑。

## 修复内容

### 局部文字无损保存

旧的 `〖文字｜效果〗` 格式无法完整表达包含字面 `〖〗` 的局部样式。整段文字设色、单独给括号加粗后，经过模块写回、文本模式或试玩前解析，会丢失括号上的样式。

现在仅在旧格式无法无损表达时，为该句写入 `@局部文字语法：带引号`，正文及特殊字体名称使用明确的 JSON 字符串。声明只影响下一句及其连续续行；普通旧稿保持原含义，不把旧引号、反斜杠当成新转义。首尾空白、换行、空续行、CR 和特殊字体名也能保留。

全文导出、舞台修改、修订稿回填共用 `dialogueMarkupRows`。修改整句样式、配音或舞台动作时，指令写在声明前，不拆开声明与正文。修订稿按当前工程解析字体名称。错误的新格式保留可保存草稿，阻止替换有效剧情；文本右键不能在已有标记、JSON 正文或参数里再次嵌套标记。

主要文件：`src/core/text-spans.ts`、`text-script.ts`、`stage-edit.ts`、`text-exchange.ts`、`command-parameters.ts`，以及 `src/renderer/TextEditor.tsx`。格式说明见 [文字演出](text-presentation.md)。

### 时间轴操作与异步回调

- 组合复制后，选区和键盘焦点指向副本，方向键不会误改原片段；删除后焦点回到画布，多选时不会把方向键应用到旧单选对象。
- 关键帧单击或不足 3px 的轻移只定位播放头，保留例如 `0.123` 秒的原始时间；真实拖动后才应用 0.05 秒吸附。
- 根片段、组合片段、关键帧、生命周期区间共用 `useTimelineGestureCancellation`。取消先清理手势引用，再释放指针捕获，防止迟到的松鼠标事件提交已取消的修改。
- 多选后右键“进入组合／保存为组合资源”使用右键命中的对象；复制、删除继续使用选区。
- 视频时长异步读取绑定工程版本和原组合。切换组合、撤销或修改工程后，旧回调失效，不把视频插进旧组，也不抢当前播放头。

### 复制与打组的数据保护

复制先为整个选区分配新标识，再重映射选区内部的数据连线：`A→B` 的副本为 `A'→B'`，外部输入继续引用外部来源，嵌套画面属性引脚一起映射。

混合片段打组时，如果输出仍供组合外对象使用，现阶段在修改前说明原因并拒绝，不静默删除连线。本轮没有实现向外输出自动提升。对会改变前后遮挡的非连续选区同样提前拒绝；根时间轴允许跨过空轨、纯音频或时间不重叠的画面片段。现有原子编辑事务保留，拒绝后工程不发生半完成修改。

主要文件：`src/core/composition-authoring.ts`。

### 内联时间轴保留角色过渡

普通蓝图调用原本有角色过渡覆盖作用域，但子时间轴内联后会丢掉调用上的覆盖设置。现在展开阶段保留内部覆盖信息，预览和生成的游戏都在角色显示及角色回调期间应用，结束或取消后恢复。

优先级保持：角色默认值 → 显示角色节点 → 外层调用 → 内层调用。没有把内层设置直接烘焙进节点，避免被仍然保留的外层真实调用再次覆盖。作者图、节点来源和断点定位保持原身份。

主要文件：`src/core/timeline-interleave.ts`、`preview-actions.ts`、`src/runtime/compiler.ts`。

### 原生菜单与父演出的等待隔离

原生菜单使用子上下文，但继承了父演出的等待记录。旧守卫可能在菜单内继续消耗父等待，甚至调用结束交互而提前关闭菜单；菜单中的保存也可能污染父等待的恢复依据。

现在等待绑定所属上下文。菜单继续维护自己的资源，但不推进或结束父等待；返回后重新锚定采样，保留剩余时间。活动等待、存档中的时钟与视觉对象核对同一所属上下文及等待记录，读档仅恢复一次补偿。有限画面对象及替换渐变不会因为菜单时间或子场景状态被提前结束、清除。菜单子蓝图仍可运行自己的独立等待。

持久对象的同配置复用也核对实际显示状态和所属上下文，避免父记录被保留后，子上下文显式重新显示时错误早退。

主要文件：`src/runtime/blueprint-task-runtime.ts`、`flow-transition-runtime.ts`、`visual-transitions.ts`。

### 导入与另存为互斥

素材浏览器的项目外导入原来只锁局部弹层。原生文件选择关闭、后台仍在读取图片时，快捷键可能另存工程，造成会话路径已改变而新资源还留在旧目录。

`App.tsx` 现在让导入、普通保存和界面保存共用同步操作锁，同一事件周期内重复快捷键也不会启动两个保存。取消或失败在 `finally` 释放。导入只合并素材，不以旧工程快照覆盖当前编辑；“放弃界面草稿后继续打开”先完成放弃、释放锁，再执行后续打开。

### 验收追加发现：时间轴菜单超出窗口

在靠近窗口底部的片段上右键，菜单按固定高度定位，实际条目比估计更多，底部“保存为组合资源”等选项跑出窗口，正常鼠标无法点击。根时间轴、组合与添加片段菜单现共用实际尺寸测量，四边保留 8px，随内容、窗口尺寸和滚动更新，过长菜单内部滚动。原来的“添加片段”还存在估宽 240px、实际宽 520px 的差异，一起修正。

主要文件：`src/renderer/TimelineCreateMenu.tsx`、`PerformanceTimeline.tsx`、`CompositionWorkspace.tsx`、`performance-workspace.css`。独立静态交叉审查确认没有尺寸反馈循环，键盘与外部点击关闭路径保留。最终正常鼠标点击、菜单边界和末项命中检查均通过。

# 流程图框样式与界面子对象

## 按名称复用流程图样式

在「界面」中选择「剧情流程图」页面，再选中流程图控件，右侧「框样式」可以新建、复制和编辑样式。哀鸿模板提供「主线框」「回忆框」「结局框」，分别使用原有的三套图片。

剧本标题可通过「样式」引用它们，输入等号后会提示可用名称：

```text
#章节(样式=主线框):归
#小章节(流程图=是，样式=回忆框):前尘旧梦
#段落(流程图=是，样式=结局框):殊途
```

可以分别设置普通、悬停、按住、选中和禁用时的图片与颜色，以及字体、字号、图片缩放、边框和阴影。同名样式的修改会更新所有引用；重命名会同步剧本中的引用。正在使用的样式需要先替换引用才能删除。

省略「样式」时沿用流程图控件的默认设置。同一入口由更具体的标题控制：小章节或段落显式展示为流程节点时，使用该标题自身的设置。

哀鸿模板的流程图文字阴影浓度调整为 40%，柔化为 7，描边透明度为 20%。编辑器与导出游戏都应用这些值；游戏的柔化阴影单独绘制，文字本体保持清晰。

## 组件父子层级

界面左侧的组件列表可以展开和折叠子对象。拖到条目的上、下边缘时显示插入线，用于调整列表位置；拖到条目中间时高亮目标，用于设置父级。拖到页面名称则解除父级；也可以在属性的「父级与子对象」中选择「父对象」。跨父级插入会加入目标的同级列表，完整子树保留当前画面位置和大小。

列表顺序与显示层级分别保存。上下移动按钮只整理左侧条目；「显示层级」数值越大，同级对象越靠前。背景子图和前方子对象继续由「放置位置」决定。

选择按钮，在「父级与子对象」中点击「添加背景子图」，即可添加铺满按钮矩形的独立背景对象。选中子图后为它选择素材和状态图片；父按钮原有图片与各状态继续保留。子图位于父级内容后方，默认跟随父级按钮状态。图片和文字装饰不会挡住父级按钮的点击。

也可以添加子文字、子按钮，或通过「子对象列表」直接选择已有子对象。

- 子对象的位置、宽度和高度相对于父级矩形；父级移动或改变大小时，子对象一同变化。
- 画布选中控件后可拖动四边或四角调整尺寸，Shift 等比缩放，Esc 取消；松开鼠标后的调整支持一次撤销。也可直接在属性面板输入位置与大小。
- 「父级内容后方」用于背景；「父级内容前方」用于文字、角标等装饰。
- 父级隐藏或禁用时，子对象跟随隐藏或禁用。设计画布的隐藏和锁定会影响整个子树。
- 「复制组件及子对象」复制完整层级。删除本地父对象会删除其子树，支持撤销和重做；删除派生界面的覆盖仍会恢复基础对象。

顶部「流程图」工作区继续保留节点和连线编辑，原来移除的右侧属性面板不会恢复。

本次工程更新只调整流程图外观和加入样式库，剧情文本、章节名称、模块连接和演出内容保持原值。

# 连续公开时间轴参数的节点位置（2026-10-03）

## 问题与修改

时间轴片段中每次点击“设为参数”都会单独调用 `exposePerformanceInputs`，旧实现每次从 `(40,70)` 开始放置读取节点。连续公开图片和音频等输入后，读取节点完全重叠；批量公开的固定160像素间距也没有考虑其他节点。

读取节点现在从对应片段节点左侧开始，按展开节点的保守宽高检查已有节点矩形，遇到占用向下寻找空位。检查包括此前公开、同批新建以及用户手动移动的节点。只设置新读取节点坐标，不重新排列已有节点。参数名称、默认值、接线和播放语义保留。

修改入口：`src/core/blueprint-authoring.ts`。普通时间轴、UI事件图内时间轴与批量封装共用这一入口。

## 功能与修复

- 图片、视频和独立文字支持入场、离场与同 ID 替换过渡，独立设置方式、秒数和等待；覆盖定时、持续、蓝图参数、文本往返、跨台词和存读档。
- 合并角色显示入口：角色留空跟随当前台词，表情留空读取角色默认表情；支持指定角色、站位、显示范围和实例。旁白及无立绘角色跳过。旧自动显示指令和专用节点已删除，模板统一替换为显示角色。
- 舞台拖动自动角色后保留跟随关系；持续角色的范围在预览与原生游戏中保持一致。
- 修复视频在结束时遇到交互重启、采样时钟短暂回退而重新启动的问题；离场结束后也会清理已退出对象。
- Windows 可选择 ZIP 或单 EXE，保留作者图标；单 EXE 验证数据、自动解包运行，正常退出清理临时引擎，存档位于用户目录。
- 关闭未保存工程的保存／放弃／取消、保存失败保留窗口、恢复文件清理，以及导出成功后打开目录均已验收。

- 章节文字版包含两行小字、书法标题和右侧字，使用原版字体与题图布局；章节音效播放一次且 BGM 持续。修复题图通过参数传入却误报缺图的问题。
- 预览 BGM 手动控制，音效和配音自动播放；进度条／播放头定位后空格播放暂停。文本可自动换行，分栏支持拖动、键盘调整和双击复位。
- `@播放台词演出` 支持中途开始打字和配音，后续动作继续；原生验证字形递增、配音只启动一次、历史只记录一次、点击补全后存读档保持状态。
- 章节控制游戏流程图的显示与名称，内部节点不再显示成多余段落。修复保存重开误选新插入前言的问题；三种实例入口合并，空功能与内部节点隐藏。
- 游戏和标题打开的菜单右键分别返回游戏和标题，包含画廊大图。

## 验收边界

本轮实际运行和发布验证针对 Windows。没有重新执行 Android SDK 下载、签名和真机安装；三个 Android Spine 库已核对打包完整性。安装器完成构建和内容核对，并运行其解出的编辑器，但没有在用户系统上执行安装／卸载流程。

单 EXE 是自动解包启动格式，每次运行需要临时磁盘空间；强制结束或断电可能留下临时目录。旧工程需重新导出游戏，才会包含本次运行时修复。以上测试覆盖明确列出的路径，不等同于保证所有自定义工程没有问题。

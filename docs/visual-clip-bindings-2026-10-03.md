# 图片、文字片段的参数显示与编辑（2026-10-03）

修正外层蓝图传入图片或文字后，片段属性和时间轴缩略图仍可能显示原素材的问题。时间轴现在复用计算时长时已解析的动作，素材字段、文字字段、缩略图与预览保持一致。

普通名称、素材、尺寸、适配与初始变换只修改对应字段，保留原始动画数据、其他字面参数和数据连线。修改片段显示时长通过已有时长输入保存，运行时仍只缩放一次；不会先把原始3秒动画改成6秒，再在传参时重复缩放。存在运动曲线时，初始位置等属性同时修改曲线起点，后续关键帧保持。

“动画与效果”内编辑原始动画数据；当片段时长经过参数缩放时，界面说明原始时长，定位关键帧会换算到时间轴中的实际位置。组合中的对象按实例身份编辑，保留未修改子对象与其参数。

## 导出

- Windows 的目录与名称合为“导出文件位置”一个输入框，例如 `E:\游戏导出\作品名`。选择位置和打开位置是输入框同一行的图标；选目录后接上名称，更换目录保留原名称，打开位置只打开父目录。Android 同一行选择导出目录。
- Windows 路径末尾名称可留空，默认采用作品名称并转换文件名不支持的字符。底部按钮为“导出”；原有工程的目录、名称配置自动合并显示。未填目录时导出前选择目录；手动填写的目录必须为绝对路径。
- 正式导出排除无引用资源、工程 `.rpy` 源码、调试映射和构建清单，Windows 只附带 64 位运行时。保留编译脚本、必要引擎文件、骨骼动画库与许可文件。
- 含外部脚本或动态资源名的工程保守保留资源库；使用全部图片的画廊保留其所需图片。本次模板资源由 297 项减为 295 项，避免为了体积裁掉功能所需文件。

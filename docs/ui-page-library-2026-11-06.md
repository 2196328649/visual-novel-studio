## 实现

- 页面选择器共用于设计与事件图。常用页留在下拉框，未接入可选页和已停用页在「更多内置页面」；浏览不写工程，启用保留数据并支持界面草稿撤销。
- 章节入口定位项目实际资源和第一处剧情调用，按 ID 识别而非名称；包装蓝图直接进入其子时间轴。直接被剧情调用的子时间轴仍单独列出。旧版章节布局及默认配置保留明确的兼容入口。
- 「消息框」统一显示为「确认对话框」。页面设置顶部增加可定位的用途摘要。
- 页面名称、系统宿主、菜单地址、按钮动作与默认菜单定义集中到 `ui-page-catalog.ts`；页面用途分析从 `game-flow.ts` 拆到 `ui-page-usages.ts`；页面选择逻辑和组件分别为 `ui-page-authoring.ts`、`UiPagePicker.tsx`。运行时动作表达式由 `ui-actions.ts` 复用。
- 用途分析纠正 screen 名与 `ui:*` 地址混比、忽略数据连线、同一事件图按钮串算、未连接节点误算入口的问题。沿实际入口执行连线传播页面目的地，普通函数、宏、任务及防抖均参与；动态目标单独标记。包含系统入口、各方案按钮、剧情、场景、流程、显示/生命周期事件及页面状态引用。此清单并非完整的运行时可达性证明。
- 停用页面的默认按钮和暂停菜单控件入口同步移除，保留自制绑定但禁用点击。Esc 使用可用菜单回退；没有菜单时设置为 None。`VnUiMenu` 防护保留无参数默认菜单、历史 `_screen` 标签/屏幕兼容。
- 停用自制对白、选项、确认、输入、旧章节布局时保留引擎必需宿主及默认内容。校验不再要求停用的自制页面补齐控件，重新启用后仍严格检查必需控件。角色音量页的设置父页停用时可正常返回。
- 旧章节的矩形、四段文字颜色、粒子字形字体改读有效界面方案；原来部分读取基础组件会忽略派生覆盖。旧章节预览只在查看该页时展开解析。
- 从下拉框打开页面库时先将焦点交给入口按钮，Esc 关闭后可返回入口；选择备用页后回到页面下拉框。

未改文字时长优先规则、局部粗斜体三态、用户作品或工程格式。未提交、打包、发布。

- 新单测的公共 fixture 将对白、选项、确认都设为自定义且没有必需控件，导致编译器拒绝生成文件；Esc 测试改用完整的默认工程，并先断言编译诊断。检查过程中另发现停用页仍触发必需控件校验的真实 bug，已补修并增加重新启用后恢复严格校验的用例。
- 从下拉框打开页面库后的 Esc 回焦失败属于实际界面问题，已修复并复验。最后一次全量单测有旧用例按“自定义消息框”筛选诊断；随产品名称改为“自定义确认对话框”，保留原有 3 个必需控件断言。
- 300 项素材模板的首次保存包含素材路径整理，实测最终运行约 13.5 秒；桌面用例原来 5 秒超时，现等待真实的“已保存”状态，最长 60 秒，并记录耗时。本轮未声称优化了保存速度。
- 旧模板“结局演出”有一个尚未同步的 `object_textItalic` 参数。已确认现有正常参数同步会补齐；在隔离 fixture 取基线前完成同步，保留控件、页面、剧情、蓝图和时间轴的全量一致性断言。真实模板文件和用户工程未因此修改。
- 章节按钮的文本包含用途说明，原精确文本定位器无法匹配；改为按名称筛选且断言唯一。旧工具栏脚本原来点击已经展开的用途分组将其收起，改为仅在收起时展开。
- Ren'Py `run` 会先等待动作可用，无法用它测试已禁用动作；改为直接调用动作，继续断言页面保持。`assert not screen` 要求屏幕已有定义，已移除屏幕改用 `has_screen`，并额外检查没有进入菜单上下文。均为验收语义修正，未放宽目标行为。

# 模板管理

启动 `启动开发版.cmd`，在项目窗口左侧点击“模板库”。“分支入门”已从新建入口移除；以前用它创建的工程仍可正常打开。

## 新建、复制与编辑

- **新建模板**：填写模板名称，从空白内容进入编辑器。
- **复制模板**：在模板卡片点击“复制模板”，输入新名称，复制已保存的内容和素材，再进入编辑器。原模板与副本互不影响。
- **打开编辑**：可以编辑剧情、蓝图、界面、参数和素材。标题旁会显示“模板编辑”；点击“保存模板”或按 Ctrl+S 保存。
- **保存并返回模板库**：保存当前修改（包括界面草稿），回到模板列表。模板名称可以在“作品设置 → 作品信息”中修改。

哀鸿模板首次编辑时会建立本机副本，程序自带文件保持原样。后续从哀鸿模板新建项目会使用本机保存的版本。自制模板也会出现在项目窗口和编辑器内的“新建工程”列表中。

## 模板与项目的关系

每次新建项目都会生成独立工程标识，并复制模板里的素材，包括外部引用的素材文件。模板的后续修改只影响以后创建的项目，已有项目不会跟随变化。游戏的存档和持久化数据按项目标识区分。

新建项目和复制模板使用正式保存的版本；编辑模板时可以恢复较新的自动保存副本。模板保存在编辑器用户数据目录的 `templates` 文件夹，重启后保留，不混入“最近项目”。普通项目通过顶部“项目窗口”按钮返回选择页，当前修改会先保存。
